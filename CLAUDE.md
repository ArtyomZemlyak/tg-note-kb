# CLAUDE.md

Инструкции для Claude при работе с этим репозиторием (база знаний из заметок Telegram).

## Задача: регулярный дайджест новостей по AI/LLM

Эта база уже содержит большой объём заметок по темам: LLM, агенты, DS/research-агенты,
LLM в рекомендательных системах (recsys), search & retrieval, physical AI (см. `index.md`
и `topics/ai/**`).

При выполнении регулярной задачи "найди и суммируй новые статьи/новости по этим темам за
последние 24 часа" **обязательно**:

1. **Сначала проверь, что уже есть в базе.** Прочитай `index.md` (общий индекс со всеми
   заметками и датами) и просмотри релевантные поддиректории `topics/ai/` (agents, llm,
   recsys, nlp, machine_learning, security и т.д.), прежде чем формировать дайджест.
2. **Не повторяй уже добавленное.** Если находка (модель, статья, бенчмарк, событие) уже
   описана в существующей заметке — не включай её в дайджест как "новое" (максимум —
   короткая пометка "уже есть в базе: <ссылка на файл>", если это прямо релевантно новому
   событию, например апдейт уже описанной модели).
3. **Не повторяй уже озвученные пользователю дайджесты.** Если это не первый запуск задачи,
   учитывай, что часть найденного в предыдущих запусках могла не быть строго "за 24 часа"
   (индексация поиска не всегда даёт точные даты) — не пересказывай те же новости снова из
   раза в раз, ищи действительно новые события/публикации.
4. В финальном дайджесте отмечай только то, что: (а) отсутствует в базе знаний, и (б)
   реально свежее (за последние ~24 часа, максимум несколько дней при отсутствии более
   свежих находок).
5. По желанию: если найдено значимое событие, которого нет в базе — можно предложить
   добавить по нему заметку в `topics/ai/...` в соответствующую поддиректорию, следуя
   существующему стилю/структуре заметок (см. `index.md` для формата записи и структуру
   папок `topics/ai/agents`, `topics/ai/llm`, `topics/ai/recsys` и т.д. как образец).
