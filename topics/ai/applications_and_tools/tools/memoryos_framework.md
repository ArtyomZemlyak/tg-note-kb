# MemoryOS: Комплексное управление памятью для AI-агентов

## Краткое описание

MemoryOS - это инновационная "операционная система памяти" для AI-агентов, разработанная для достижения комплексного и эффективного управления памятью. Вдохновленная принципами управления памятью в операционных системах, MemoryOS создает иерархическую архитектуру хранения и состоит из четырех ключевых модулей: Memory Storage, Updating, Retrieval и Generation.

## Архитектура

### Четыре ключевых модуля

1. **Memory Storage**:
   - Организует информацию в трехуровневую структуру памяти:
     - **Краткосрочная память (STM)**: для своевременных разговоров
     - **Среднесрочная память (MTM)**: для резюме по повторяющимся темам
     - **Долгосрочная персональная память (LPM)**: для предпочтений пользователя или агента

2. **Memory Updating**:
   - Управляет динамическим обновлением памяти
   - Обновления STM в MTM следуют принципу FIFO на основе цепочки диалогов
   - Обновления MTM в LPM используют стратегию сегментированной организации страниц

3. **Memory Retrieval**:
   - Использует семантическую сегментацию для запросов к этим уровням
   - Двухуровневый подход в MTM: сначала идентификация сегментов по семантической близости, затем извлечение соответствующих страниц диалога

4. **Response Generation**:
   - Интегрирует извлеченную информацию из памяти для генерации согласованных и персонализированных ответов

## Иерархическая память

### Краткосрочная память (STM)
- Хранит данные текущего разговора в единицах, называемых страницами диалога
- Каждая страница диалога содержит: запрос пользователя Q, ответ модели R и временную метку T
- Для обеспечения контекстной согласованности создается цепочка диалогов для каждой страницы

### Среднесрочная память (MTM)
- Использует архитектуру сегментированной памяти с разбиением на страницы
- Диалоговые страницы с одинаковой темой группируются в сегменты
- Каждый сегмент содержит несколько страниц для уникальной темы
- Сходство определяется как семантически, так и по ключевым словам

### Долгосрочная персональная память (LPM)
- Состоит из двух компонентов: пользовательского профиля и профиля агента
- **Пользовательский профиль** включает:
  - Статическую часть с фиксированными атрибутами (пол, имя, год рождения)
  - Базу знаний пользователя (User KB), которая динамически хранит фактическую информацию
  - Пользовательские черты, содержащие эволюционирующие интересы, привычки и предпочтения
- **Профиль агента** включает:
  - Фиксированные настройки, такие как роль агента или черты характера
  - Динамические атрибуты, развивающиеся через взаимодействия

## Механизмы обновления

### STM в MTM обновления
- Использует стратегию First-In-First-Out (FIFO) для миграции информации
- Новые страницы диалога добавляются в конец очереди
- При достижении максимальной емкости, самая старая страница передается из STM в MTM

### MTM в LPM обновления
- Основаны на оценке "температуры" (heat score) сегментов:
  - Nvisit: количество обращений к сегменту
  - Linteraction: общее количество страниц диалога в сегменте
  - Rrecency: коэффициент затухания времени
- Сегменты с высокой "температурой" передаются в LPM и обновляют пользовательские черты и базу знаний

## Экспериментальные результаты

### Производительность
- Среднее улучшение **49.11%** на F1 и **46.18%** на BLEU-1 над базовыми моделями на GPT-4o-mini по бенчмарку LoCoMo
- Превосходит такие методы как TiM, MemoryBank, MemGPT, и A-Mem

### Результаты на разных типах задач
- В задачах Single-hop, Multi-hop, Temporal и Open-domain MemoryOS показывает лучшие результаты по сравнению с конкурентами
- Успешно справляется с задачами, требующими долгосрочной согласованности и персонализации

## Сравнение с конкурентами

### Отличия от других подходов:
- В отличие от TiM, MemoryOS использует иерархическую структуру вместо простого хранения цепочек мышления
- По сравнению с MemoryBank, предлагает более систематический подход к управлению памятью
- В отличие от MemGPT, имеет более тонкую сегментацию и управление разными уровнями памяти
- A-Mem организует память в граф, в то время как MemoryOS использует иерархическую структуру
