# LoopCoder Architecture: Циклическая трансформер-декодер архитектура

## Обзор

LoopCoder - это уникальная архитектура трансформер-декодера, примененная в IQuest-Coder-V1. Главной особенностью является "петлевая" структура, при которой одни и те же блоки трансформера используются дважды (2 итерации) с общими параметрами. Эта архитектура позволяет обрабатывать данные в два прохода, создавая более глубокое понимание контекста при меньшем числе параметров.

## Структура архитектуры

### Две итерации
- **Первая итерация**: Входные эмбеддинги проходят через трансформерные блоки, формируя скрытые состояния с позиционным сдвигом, которые сохраняются для использования во второй итерации
- **Вторая итерация**: Использует сохраненные состояния из первой итерации с двумя типами внимания

### Типы внимания

#### Global Attention (Глобальное внимание)
- Queries из второй итерации обращаются ко всем key-value парам из первой итерации
- Позволяет "уточнить" понимание глобального контекста
- Обеспечивает доступ к информации из первого прохода

#### Local Attention (Локальное внимание)
- Queries обращаются только к предшествующим токенам внутри второй итерации
- Сохраняется причинность - модель не видит будущие токены
- Подходит для позиционно-зависимых операций

### Gating Mechanism (Механизм шлюзования)
- Комбинирует оба типа внимания через обученный gate
- Формула: output = gate * global_attention + (1 - gate) * local_attention
- Gate (значение от 0 до 1) вычисляется на основе query-представлений
- Модель сама учится, когда использовать глобальный контекст, а когда - локальный

## Преимущества архитектуры

### Эффективность параметров
- Повторное использование параметров через циклическую структуру
- Более глубокое понимание при меньшем количестве параметров
- Оптимизация вычислительной эффективности

### Улучшенное понимание контекста
- Двухпроходная обработка для более глубокого анализа
- Комбинирование локального и глобального контекста
- Лучшее понимание долгосрочных зависимостей

### Практическое применение
- Используется в IQuest-Coder-V1 для задач программирования
- Улучшает производительность на бенчмарках программирования
- Особенно эффективна для задач, требующих понимания контекста кода

## Сравнение с традиционными архитектурами

| Аспект | Традиционные трансформеры | LoopCoder |
|--------|---------------------------|-----------|
| Проходы | Один | Два (итеративно) |
| Параметры | Один проход на параметры | Повторное использование параметров |
| Контекст | Локальный/глобальный (один тип) | Комбинированный (глобальный + локальный) |
| Контроль внимания | Статический механизм | Динамическое шлюзование |

## Технические детали

### Реализация
- Использование auto_map функции Hugging Face
- Совместимость с библиотекой transformers ≥4.52.4
- Поддержка Grouped Query Attention (GQA) для эффективности вывода

### Возможности
- Поддержка до 128K контекста
- Повышенная эффективность при ограниченных вычислительных ресурсах
- Улучшенная способность к планированию и исправлению кода

## Будущее развитие

LoopCoder представляет собой инновационный подход к архитектуре трансформеров, который может стать основой для следующего поколения языковых моделей, особенно в специализированных задачах, где важно глубокое понимание контекста.
