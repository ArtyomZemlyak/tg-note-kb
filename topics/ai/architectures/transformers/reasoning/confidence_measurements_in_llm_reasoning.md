# Измерения уверенности в логическом мышлении LLM

## Обзор

Измерения уверенности - это метрики, используемые для оценки качества цепочек рассуждений в Large Language Models (LLMs). Эти метрики позволяют отличать высококачественные пути рассуждений от ошибочных без внешнего надзора.

## Основные метрики уверенности

### Энтропия токенов (Token Entropy)

#### Определение
Для предсказанного распределения токенов P_i в позиции i, энтропия токена определяется как:

H(P_i) = -Σ P_i(j) * log(P_i(j))

где P_i(j) представляет вероятность j-го токена в словаре.

#### Интерпретация
- Низкая энтропия: острое распределение с высокой уверенностью модели
- Высокая энтропия: неопределенность в предсказании

### Уверенность токена (Token Confidence)

#### Определение
Уверенность токена C_i определяется как отрицательное среднее логарифмическое вероятности топ-k токенов в позиции i:

C_i = -log(1/k * Σ P_i(top-k_tokens))

где k обозначает количество рассматриваемых топ-токенов.

#### Интерпретация
- Высокая уверенность: острое распределение и большая уверенность модели
- Низкая уверенность: неопределенность в предсказании токена

### Средняя уверенность трассы (Average Trace Confidence)

#### Определение
Требует агрегации метрик на уровне токенов для оценки полных цепочек рассуждений:

C_avg = (1/N) * Σ C_i

где N - общее количество сгенерированных токенов.

#### Проблемы
1. Глобальная агрегация маскирует промежуточные сбои рассуждений
2. Несколько высоконфиденциальных токенов могут маскировать многочисленные сегменты с низкой уверенностью
3. Требует завершенных трасс для оценки качества, предотвращая раннюю остановку низкокачественных генераций

## Альтернативные измерения уверенности

### Групповая уверенность (Group Confidence)

#### Описание
Количественная оценка уверенности промежуточных этапов рассуждения с помощью групповой уверенности. Предоставляет более локализованный и плавный сигнал за счет усреднения уверенности токенов по перекрывающимся участкам цепочки рассуждений.

#### Определение
Для каждой группы G_i с n предыдущими токенами:

C_group = (1/|G_i|) * Σ C_j, где j ∈ G_i

где |G_i| - количество токенов в группе G_i.

### Bottom 10% Group Confidence

#### Описание
Захватывает влияние групп с экстремально низкой уверенностью. Уверенность трассы определяется средним значением нижних 10% групп уверенности в трассе:

C_bottom_10 = (1/|G_b|) * Σ C_group, где G_b - набор групп с нижними 10% оценок уверенности.

#### Практическое применение
Эмпирически 10% эффективно захватывает наиболее проблемные сегменты рассуждений в разных моделях и наборах данных.

### Lowest Group Confidence

#### Описание
Представляет уверенность самой ненадежной группы в цепочке рассуждений. Частный случай bottom 10% group confidence.

#### Определение
C_lowest = min(C_group), где G - набор всех групп токенов в цепочке рассуждений.

### Tail Confidence

#### Описание
Оценивает надежность цепочки рассуждений, фокусируясь на конечной части. Мотивировано наблюдениями, что качество рассуждений часто ухудшается к концу длинных цепочек мышления, и конечные шаги критичны для правильных заключений.

#### Определение
C_tail = (1/|T_tail|) * Σ C_i, где T_tail представляет фиксированное количество токенов (например, 2048).

## Применение в DeepConf

### Офлайн-мышление с уверенностью
- **Взвешенное голосование по большинству**: вместо равного веса каждого голоса трассы, вес каждого финального ответа определяется уверенностью связанной трассы
- **Фильтрация уверенностей**: выбирает верхний η процент трасс на основе оценок уверенности трассы, гарантируя, что только самые надежные пути вносят вклад в финальный ответ

### Онлайн-мышление с уверенностью
- Позволяет реальную оценку качества трассы во время генерации
- Динамически останавливает неперспективные трассы
- Использует lowest group confidence для адаптивной остановки генерации, когда уверенность падает ниже критического порога

## Оценка эффективности

### Ключевые наблюдения
1. Метрики "tail" и "bottom" не уступают глобальной средней уверенности трассы и, в среднем, доставляют равную или лучшую точность
2. Head-ориентированные метрики (на основе первых токенов трассы) имеют слабую корреляцию с финальной корректностью
3. Локальные сигналы уверенности особенно надежны как дефолтные значения

### Сравнительные результаты
- Bottom 10% и tail confidence метрики лучше разделяют распределения некорректных и корректных трасс, чем методы средней уверенности
- Lowest Group Confidence (LGC) остается конкурентоспособной: в среднем 84.4% для LGC (2k window) с 10% фильтром по сравнению с 84.0% для Bottom-10%@10% и 83.9% для Mean@10%
