# FastVideo Framework

## Общее описание

FastVideo - это фреймворк с открытым исходным кодом, разработанный для ускорения больших видео диффузионных моделей. Это легковесный фреймворк, который предоставляет полный конвейер для ускорения диффузионных моделей. FastVideo тесно сотрудничает с командой SGLang Diffusion в создании полной экосистемы для диффузионных моделей - от пост-обучения до промышленного обслуживания.

В отличие от SGLang Diffusion, который сфокусирован на непрерывной инновации в производительности инференса и поддержке моделей, FastVideo обеспечивает всестороннюю поддержку задач обучения, таких как дистилляция модели.

## Архитектура и особенности

FastVideo предоставляет end-to-end унифицированный пайплайн для ускорения диффузионных моделей. Основные особенности включают:

1. **Ускорение инференса** - Фреймворк достигает 8x ускорения инференса для видео диффузионных моделей
2. **Поддержка обучения** - В отличие от SGLang Diffusion, фокусируется на задачах обучения (дистилляция модели)
3. **Легковесность** - Разработан как легковесный фреймворк для ускорения больших видео диффузионных моделей
4. **Открытые рецепты дистилляции** - Предоставляет первые открытые рецепты дистилляции для видео DiT, основанные на PCM (Probabilistic Consistency Models)

## Применение и использование

FastVideo особенно важен для задач обучения диффузионных моделей, таких как:
- Дистилляция модели
- Пост-обучение моделей
- Оптимизация моделей для инференса

## Связь с SGLang Diffusion

FastVideo и SGLang Diffusion тесно сотрудничают для создания полной экосистемы диффузии:
- **SGLang Diffusion** - фокусируется на доставке передовой скорости инференса
- **FastVideo** - обеспечивает всестороннюю поддержку задач обучения, таких как дистилляция модели

Это разделение труда позволяет командам фокусироваться на своих сильных сторонах: SGLang Diffusion на инференсе и FastVideo на обучении.

## Поддерживаемые модели и технологии

FastVideo работает с различными типами видео диффузионных моделей:
- FastHunyuan
- FastMochi
- Другие видео DiT (Diffusion Transformer) модели

## Примеры использования

FastVideo предоставляет инструменты для:
- Ускорения инференса видео диффузионных моделей
- Обучения новых оптимизированных моделей
- Дистилляции крупных моделей в более быстрые версии
