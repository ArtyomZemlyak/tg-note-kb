# SGLang Diffusion

## Общее описание

SGLang Diffusion - это система, которая приносит передовую производительность SGLang для ускорения генерации изображений и видео для моделей диффузии. Это расширение фреймворка SGLang, изначально разработанного для LLM, на диффузионные модели, обеспечивая высокую скорость инференса и простоту использования.

SGLang Diffusion поддерживает ключевые открытые модели генерации видео и изображений (Wan, Hunyuan, Qwen-Image, Qwen-Image-Edit, Flux), обеспечивая ускорение от 1.2x до 5.9x в различных рабочих нагрузках. Система предоставляет несколько точек доступа API (совместимое с OpenAI API, командная строка, интерфейс Python).

## Архитектура

SGLang Diffusion разработан для производительности и гибкости, построен на проверенной боем архитектуре обслуживания SGLang. Он наследует мощный планировщик SGLang и повторно использует высокооптимизированный sgl-kernel для максимальной эффективности.

### Основные компоненты архитектуры:

1. **ComposedPipelineBase** - гибкая абстракция, которая управляет рядом модульных PipelineStages
2. **PipelineStages** - модульные этапы, каждый из которых охватывает общую функцию диффузии:
   - DenoisingStage - цикл денойзинга
   - DecodingStage - VAE-декодирование
3. **Высокооптимизированный sgl-kernel** - ядро для максимальной эффективности
4. **Планировщик SGLang** - мощный планировщик, унаследованный из основного SGLang

### Методы параллелизма

Для достижения передовой скорости SGLang Diffusion интегрирует передовые методы параллелизма:

- **Unified Sequence Parallelism (USP)** - сочетание Ulysses-SP и Ring-Attention для основных блоков трансформера
- **CFG-параллелизм** (Classifier-Free Guidance) для других компонентов модели
- **Тензорный параллелизм** (TP) для эффективного распределения вычислений

SGLang Diffusion поддерживает различные популярные открытые модели генерации видео и изображений:

### Видео-модели:
- Серия Wan

- Hunyuan

### Изображение-модели:
- Qwen-Image
- Qwen-Image-Edit
- Flux

Полный список поддерживаемых моделей доступен в официальной документации.

## Производительность

SGLang Diffusion обеспечивает значительное улучшение производительности по сравнению с популярным открытым базовым решением Hugging Face Diffusers:

- Ускорение от 1.2x до 5.9x в различных рабочих нагрузках
- При различных настройках параллелизма: CFG-Parallel и USP обеспечивают значительное ускорение по сравнению с одноГПУ установкой
- Оптимизирован для GPU H100 и H200

## Использование

SGLang Diffusion предоставляет набор привычных интерфейсов для безупречного пользовательского опыта:

### Установка
```bash
# с pip или uv
uv pip install 'sglang[diffusion]' --prerelease=allow

# из исходного кода
git clone https://github.com/sgl-project/sglang.git
cd sglang
uv pip install -e "python[diffusion]" --prerelease=allow
```

### CLI (Command Line Interface)
Запуск сервера с последующей отправкой запросов:
```bash
sglang serve --model-path black-forest-labs/FLUX.1-dev --port 3000

curl http://127.0.0.1:3000/v1/images/generations \
  -o >(jq -r '.data[0].b64_json' | base64 --decode > example.png) \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "black-forest-labs/FLUX.1-dev",
    "prompt": "A cute baby sea otter",
    "n": 1,
    "size": "1024x1024",
    "response_format": "b64_json"
  }'
```

Или генерация изображения без запуска сервера:
```bash
sglang generate --model-path black-forest-labs/FLUX.1-dev \
  --prompt "A Logo With Bold Large Text: SGL Diffusion" \
  --save-output
```

### API, совместимое с OpenAI
Система предоставляет API, совместимое с OpenAI, позволяя пользователям интегрировать генерацию диффузии в свои рабочие процессы с минимальными усилиями.

## Экосистема и дорожная карта

SGLang Diffusion развивается в сотрудничестве с командой FastVideo, обеспечивая полную экосистему для моделей диффузии - от пост-обучения до промышленного обслуживания. Команда SGLang Diffusion сосредоточена на непрерывной инновации в производительности и поддержке моделей:

### Планы по поддержке и оптимизации моделей:
- Оптимизация Wan, FastWan, Hunyuan, Qwen-Image series, FLUX
- Поддержка LongCat-Video

### Планы по поддержке ядра и объединений:
- Ядра квантизации
- Ядра вращательного встраивания
- Интеграция Flash Attention 4 в sgl-kernel для blackwell

### Планы по дополнительным функциям сервера:
- Настраиваемая загрузка в облачное хранилище сгенерированных файлов
- Поддержка пакетной обработки
- Больше методов параллелизма
- Квантизация

### Планы по общей архитектуре:
- Упрощение усилий по поддержке новых моделей
- Улучшение поддержки кеша и бэкэнда внимания
