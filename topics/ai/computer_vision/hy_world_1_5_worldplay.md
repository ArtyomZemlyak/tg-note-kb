# HY World 1.5 (WorldPlay) - Интерактивное моделирование 3D миров в реальном времени

## Общее описание

**HY World 1.5 (WorldPlay)** - это открытый фреймворк для интерактивного моделирования миров в реальном времени, разработанный командой Tencent Hunyuan. Это один из самых продвинутых инструментов для создания и исследования интерактивных 3D-миров с долгосрочной геометрической согласованностью. Модель представляет собой стриминговую video diffusion-модель, позволяющую создавать и исследовать интерактивные 3D-миры, которые можно создавать по тексту или изображениям, свободно перемещаться по ним, осматриваться и взаимодействовать с окружением, как в видеоигре.

HY World 1.5 является значительным улучшением по сравнению с HY-World 1.0, который имел ограничения.offline генерации, позволяя теперь осуществлять реальное интерактивное моделирование мира с поддержанием долгосрочной геометрической согласованности и потоковой генерацией видео в реальном времени.

## Архитектура

HY-World 1.5 использует четыре ключевых архитектурных компонента:

### 1. Двойное представление действий (Dual Action Representation)
- Обеспечивает надежный контроль действий в ответ на ввод с клавиатуры и мыши
- Позволяет корректно реагировать на пользовательский ввод клавиатуры и мыши
- Обеспечивает точное и устойчивое управление

### 2. Восстановленная память контекста (Reconstituted Context Memory)
- Динамически перестраивает контекст из прошлых кадров
- Использует временное переформулирование (temporal reframing) для поддержания геометрически важной информации
- Предотвращает ослабление памяти (memory attenuation)
- Использует механизм динамического пересбора контекста из предыдущих кадров, предотвращающий деградацию памяти

### 3. WorldCompass
- Это фреймворк пост-обучения с подкреплением (Reinforcement Learning), который улучшает следование действиям и визуальное качество долгосрочных автoregressive видео моделей

### 4. Принудительный контекст (Context Forcing)
- Метод дистилляции для моделей с памятью
- Выравнивает контекст памяти между учителем и учеником
- Сохраняет способность ученика использовать информацию на длинном горизонте, при этом поддерживая скорости в реальном времени

## Ключевые возможности

### Реальное время
- Генерация длинных видеопотоков со скоростью 24 FPS с высокой стабильностью сцен
- Потоковая генерация видео в реальном времени
- Поддерживает непрерывное взаимодействие без необходимости регенерации с нуля

### Геометрическая согласованность
- Использует механизм Reconstituted Context Memory для поддержания геометрической согласованности
- Применяет временное переформулирование для сохранения доступности геометрически важных кадров
- Эффективно решает проблему деградации геометрической согласованности со временем

### Точное и устойчивое управление
- Dual Action Representation обеспечивает корректную реакцию на ввод с клавиатуры и мыши
- Поддержка пользовательского ввода для динамического изменения мира
- Поддержка пользовательских траекторий камеры

### Широкие сценарии применения
- Поддержка вида от первого и третьего лица
- События, управляемые промптом
- Бесконечное расширение мира
- 3D реконструкция
- Применение в виртуальной реальности, геймдеве и симуляциях

## Технические спецификации

- **Базовая модель**: Построен на основе HunyuanVideo-1.5 (конкретно вариант 480P-I2V)
- **Производительность**: Потоковая генерация видео в реальном времени с 24 FPS
- **Требования к памяти**: Минимум 14 ГБ GPU (с выгрузкой модели)
- **Разрешения**: Поддерживает различные видео разрешения (в настоящее время доступна модель 480p)
- **Общая генерализация**: Сильная генерализация в различных сценах
- **Поддержка окружения**: Работает как в реальных, так и в стилизованных средах

## Особенности генерации

- Использует подход предсказания следующего чанка (16 видео кадров за раз)
- Позволяет создавать интерактивные 3D-миры на основе одного изображения или текстового промпта
- Обеспечивает стриминговую генерацию видео с поддержанием последовательности и согласованности
- Поддерживает настраиваемые траектории камеры (с использованием файлов позы JSON)
- Предоставляет интерфейсы для переписывания промптов с использованием внешних AI моделей (Gemini/vLLM)

## Инновации

HY World 1.5 решает фундаментальную проблему сохранения геометрической согласованности при достижении реального времени, преодолевая компромисс между скоростью и ограничениями памяти в существующих методах. Он включает полный конвейер обработки данных, обучения и развертывания инференса, а также функциональную инженерию для снижения задержки передачи сети и инференса модели.

## Применения

- Создание интерактивных 3D миров для игр и виртуальной реальности
- Визуализация пространств на основе текстовых описаний
- Симуляции и визуализации для планирования и анализа
- Создание контента для метавселенной и архитектурных визуализаций
