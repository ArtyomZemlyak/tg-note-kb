# Физически обоснованные материалы (Physically Based Materials)

## Описание

Физически обоснованные материалы (Physically Based Materials, PBM) - это подход к моделированию материалов в компьютерной графике, основанный на физических принципах и законах взаимодействия света с поверхностями. Такие материалы обеспечивают реалистичную визуализацию, независимо от условий освещения.

## Компоненты PBM

### Основные параметры
- **Альбедо (Albedo)** - базовый цвет поверхности без влияния освещения
- **Металличность (Metallic)** - степень металличности поверхности (0 - диэлектрик, 1 - металл)
- **Шероховатость (Roughness)** - микроскопическая шероховатость поверхности
- **Нормаль (Normal)** - векторы нормалей для детализации поверхности
- **Высота (Height)** - карта высот для дополнительной геометрической детализации

### Дополнительные параметры
- **Анимация (Anisotropy)** - анизотропное отражение для материалов с направленной структурой
- **Прозрачность (Transmission)** - свойства пропускания света через материал
- **Толщина (Thickness)** - для моделирования тонких прозрачных объектов

## Применения

### В компьютерной графике
- **3D-визуализация** - создание реалистичных сцен
- **Игровая индустрия** - материалы для персонажей, предметов и окружения
- **Кино и визуальные эффекты** - фотореалистичные материалы для съемок

### В машинном обучении
- **Генерация материалов** - создание материалов с помощью нейронных сетей
- **Редактирование материалов** - изменение физических свойств поверхностей
- **Синтез текстур** - создание текстур с физически правильными свойствами

### В видеообработке
- **V-RGBX** - использует физически обоснованные представления материалов для редактирования видео
- **Извлечение материалов из видео** - восстановление физических свойств поверхностей из видео
- **Перенос материалов** - применение материалов с одной сцены на другую
