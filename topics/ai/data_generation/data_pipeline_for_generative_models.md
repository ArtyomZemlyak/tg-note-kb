# Пайплайн обработки данных для генеративных моделей

## Общее описание

Пайплайн обработки данных для генеративных моделей — это комплексная система подготовки, фильтрации и балансировки датасетов для обучения моделей генерации изображений. Качественная подготовка данных критически важна для достижения высоких результатов генерации.

## Четырёхкомпонентный пайплайн (на примере Z-Image)

### 1. Data Profiling Engine

**Назначение:** Базовая фильтрация по качеству изображений и обогащение метаданных.

#### Компоненты фильтрации:

**Фильтрация изображений:**
- Отсев картинок с **высоким уровнем шума**
- Удаление изображений с **чрезмерным объёмом фона**
- Фильтрация изображений с **артефактами компрессии**
- Другие критерии качества

**Aesthetic Score:**
- Отдельная модель оценивает **эстетичность изображения**
- Создаётся дополнительный атрибут для ранжирования
- Позволяет приоритизировать визуально приятные изображения

**CLIP-фильтрация пар изображение-текст:**
- Специально **дообученный CLIP** оценивает соответствие пар
- Возвращает **коэффициент соответствия** (шкала от 0 до 1)
- Пары с низкой похожестью фильтруются
- Датасет очищается от не подходящих друг другу пар

**Обогащение caption через VLM:**
- Генерируются **три версии описания**:
  - **Очень подробная** — развёрнутое описание всех деталей
  - **Детальная** — сбалансированное описание
  - **Короткая** — краткое основное описание
- Все версии создаются с помощью **VLM (Vision Language Model)**
- Используется для **прогрессивного обучения**:
  - Постепенное повышение разрешения изображений
  - Постепенное увеличение длины caption
  - Модель постепенно знакомится с миром изображений

### 2. Cross-modal Vector Engine

**Назначение:** Проверка покрытия датасетом множества реальных пар «картинка + текст» и дедупликация.

#### Принцип работы:

1. **Векторизация пар:**
   - Пары «картинка + текст» пропускаются через энкодеры
   - Получаются их **векторные представления** (embeddings)

2. **Построение индекса:**
   - На всём множестве векторов строится **индекс для поиска**
   - Индекс позволяет эффективно работать с большими объёмами данных

3. **Применение индекса:**
   - **Дедупликация пар** — удаление дубликатов и почти идентичных примеров
   - **Аналитика покрытия** — оценка того, какие области пространства пар покрыты хорошо, а какие слабо

#### Преимущества:
- **Нестандартный механизм** проверки качества датасета
- Позволяет оценить **покрытие пространства данных**
- Эффективная дедупликация на уровне векторных представлений

### 3. World Knowledge Topological Graph

**Назначение:** Оценка и балансировка представленности концептов реального мира в датасете.

#### Принцип работы:

1. **Построение графа:**
   - **Вершины** — концепты реального мира
   - **Рёбра** — ссылки концептов друг на друга (семантические связи)

2. **Фильтрация графа:**
   - Алгоритм **PageRank** удаляет маловажные концепты
   - Остаются только значимые узлы знаний

3. **Классификация концептов:**
   - Оставшимся точкам присваиваются **теги**
   - Теги группируются в **иерархические деревья**

4. **Балансировка датасета:**
   - Граф позволяет выявлять **слаборепрезентованные концепты**
   - Повышается вероятность семплов для редких концептов
   - Обеспечивается **сбалансированное покрытие** знаний

#### Преимущества:
- **Необычный механизм** оценки датасета через граф знаний
- Автоматическое выявление пробелов в покрытии концептов
- Динамическая балансировка во время обучения

### 4. Active Curation Engine

**Назначение:** Итеративная проверка и улучшение качества датасета.

#### Принцип работы:

1. **Чередование проверок:**
   - **Люди** проверяют выборки датасета
   - **VLM** автоматически оценивает качество
   - Процесс итеративный

2. **Критерии качества:**
   - Соответствие изображений и текстов
   - Отсутствие артефактов и ошибок
   - Репрезентативность доменов

3. **Итеративное улучшение:**
   - Проверки продолжаются до достижения **достаточного качества**
   - Датасет постепенно очищается и улучшается

## Применение пайплайна

### Для каких моделей подходит:
- **Text-to-Image модели** — генерация изображений по тексту
- **Image Editing модели** — редактирование изображений
- **Мультимодальные модели** — работа с несколькими модальностями
- **Diffusion Transformer (DiT)** — диффузионные модели на трансформерах

### Примеры использования:
- **Z-Image** — 6B параметрическая модель с эффективным обучением
- **Stable Diffusion** — популярные открытые модели генерации
- **DALL-E** — коммерческие системы генерации изображений

## Ключевые преимущества комплексного пайплайна

1. **Многоуровневая фильтрация** — несколько стадий контроля качества
2. **Автоматизация** — минимизация ручного труда через VLM и модели оценки
3. **Балансировка** — равномерное покрытие концептов и доменов
4. **Масштабируемость** — возможность работы с большими датасетами
5. **Адаптивность** — настройка под конкретные задачи и домены
