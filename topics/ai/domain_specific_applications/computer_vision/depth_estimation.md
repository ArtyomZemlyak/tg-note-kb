# Оценка глубины (Depth Estimation)

## Краткое описание

Оценка глубины — это задача в компьютерном зрении, заключающаяся в предсказании расстояния от камеры до объектов сцены на основе одного или нескольких изображений. Результатом является карта глубины, где каждый пиксель содержит значение расстояния до соответствующей точки в реальном мире.

## Основные характеристики

### Задача
- **Монокулярная оценка глубины**: Получение карты глубины из одного изображения
- **Стереоскопическая оценка глубины**: Использование нескольких камер для вычисления глубины
- **Оценка глубины в реальном времени**: Высокая скорость обработки для интерактивных приложений

### Типы задач
- **Предсказание абсолютной глубины**: Оценка метрической глубины (в физических единицах)
- **Предсказание относительной глубины**: Оценка порядка глубины (кто ближе/дальше)
- **Оценка глубины с восстановлением масштаба**: Абсолютная глубина с восстановлением масштаба

## Технические подходы

### Традиционные методы
- **Стереоскопическое сопоставление**: Поиск соответствий между изображениями нескольких камер
- **Оптический поток**: Анализ движения объектов между кадрами для оценки глубины
- **Сопоставление шаблонов**: Сопоставление текстур и изображений для восстановления геометрии

### Современные нейронные методы
- **Глубокие CNN**: Использование сверточных нейронных сетей для непосредственного предсказания глубины
- **Многомасштабные архитектуры**: Сети, предсказывающие глубину на нескольких масштабах
- **Рекуррентные архитектуры**: Использование временной информации для улучшения оценки

## Архитектуры и модели

### Универсальные архитектуры
- **MiDAS**: Модель для монокулярной оценки глубины, обученная на множестве датасетов
- **DPT (Dense Prediction Transformer)**: Использование трансформеров для плотного предсказания, включая глубину
- **LEO**: Архитектура для монокулярной оценки глубины с высокой точностью

### Специализированные архитектуры
- **Neural RGB-D**: Комбинация RGB и глубинных данных для улучшения представления
- **Depth Anything**: Модель, способная оценивать глубину на разнообразных сценах

## Применение

### Робототехника
- **Навигация**: Построение 3D-карт и избежание препятствий
- **Грэппинг**: Оценка глубины для захвата объектов
- **Симуляция**: Создание виртуальных сред для обучения роботов

### Дополненная реальность
- **Размещение объектов**: Правильное размещение виртуальных объектов в реальном мире
- **Сегментация**: Разделение объектов на основе глубины
- **Смешивание освещения**: Адаптация освещения виртуальных объектов к реальной сцене

### Автономные транспортные средства
- **Обнаружение препятствий**: Оценка расстояний до других транспортных средств и пешеходов
- **Планирование траектории**: Построение безопасных маршрутов
- **3D-маппинг**: Создание пространственных карт окружения

### Фотография и мультимедиа
- **Преобразование 2D в 3D**: Создание 3D-эффектов из 2D-изображений
- **Редактирование изображений**: Сегментация по глубине для точного редактирования
- **Портретный режим**: Размытие фона на основе оценки глубины

## Оценка качества

### Метрики для метрической глубины
- **AbsRel (Absolute Relative)**: Среднее отношение ошибки к истинной глубине
- **SqRel (Squared Relative)**: Квадратичное отношение ошибки к истинной глубине  
- **RMSE (Root Mean Square Error)**: Корень из среднеквадратичной ошибки
- **RMSE_log**: RMSE в логарифмическом пространстве

### Метрики для порядковой глубины
- **Thresh**: Процент пикселей, где отношение глубин предсказано верно в пределах порога
- **ORD (Ordinal Regression Disagreement)**: Мера разногласий в порядковых отношениях

### Бенчмарки
- **NYU Depth V2**: Внутренние сцены с RGB и глубинными данными
- **KITTI**: Уличные сцены с высокоточной глубиной
- **ETH3D**: Разнообразные сцены с точными 3D измерениями

## Технические вызовы

### Проблемы оценки глубины
- **Неоднозначность**: Одинаковые 2D-изображения могут соответствовать разным глубинам
- **Новые объекты**: Трудности с оценкой глубины для незнакомых объектов
- **Стеклянные/прозрачные поверхности**: Проблемы с прозрачными и отражающими поверхностями

### Ограничения
- **Масштаб**: Монокулярные методы часто не восстанавливают абсолютный масштаб
- **Общность**: Модели могут не обобщаться на новые сцены
- **Вычислительные требования**: Высокие требования к вычислительной мощности

## Современные достижения

### Apple SHARP
- Использует оценку глубины как часть процесса восстановления 3D-гауссианов
- Совмещает оценку глубины с 3D-гауссиановым представлением для реального времени синтеза новых ракурсов
- Обеспечивает метрическое представление с абсолютным масштабом

### Методы на основе трансформеров
- **DPT**: Использование Vision Transformers для плотного предсказания глубины
- **TransDepth**: Трансформер для стереоскопической оценки глубины

### Self-supervised методы
- Обучение на стереоскопических парах без истинных меток глубины
- Использование фотометрической ошибки для обучения
- Возможность обучения на неограниченных наборах данных

## Сравнение методов

| Метод | Тип | Точность | Скорость | Обучение | Комментарии |
|-------|-----|----------|----------|----------|-------------|
| SfM (Structure from Motion) | Традиционный | Средняя | Низкая | Без | Требует несколько изображений |
| Stereo matching | Традиционный | Высокая | Средняя | Без | Требует калиброванные камеры |
| MiDAS | CNN | Высокая | Высокая | Supervised | Хорошая общность |
| DPT | Transformer | Очень высокая | Средняя | Supervised | Лучшее качество на момент создания |
| SHARP | Комбинированный | Очень высокая | Высокая | Supervised | Метрическая глубина + 3D представление |
