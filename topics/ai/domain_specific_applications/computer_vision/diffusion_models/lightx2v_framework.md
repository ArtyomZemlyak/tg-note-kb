# LightX2V Framework

## Общее описание

LightX2V - это передовой легковесный фреймворк для инференса генерации видео, созданный для обеспечения эффективных решений синтеза видео высокой производительности. Это унифицированная платформа, интегрирующая различные современные технологии генерации видео, поддерживая как текст-в-видео (Text-to-Video, T2V), так и изображение-в-видео (Image-to-Video, I2V). X в названии обозначает различные входные модальности (X, такие как текст или изображения), преобразуемые в видео (V).

## Архитектура и ключевые компоненты

Фреймворк LightX2V следует модульной архитектуре со следующими основными компонентами:

- **lightx2v**: Основной код фреймворка
- **lightx2v_kernel**: Пользовательские реализации ядра для оптимизации производительности
- **lightx2v_platform**: Платформо-специфичные оптимизации
- **app**: Прикладной уровень
- **configs**: Файлы конфигурации для различных моделей и задач
- **examples**: Примеры использования для различных моделей
- **docs**: Документация
- **dockerfiles**: Конфигурации Docker-контейнеров

## Основные особенности

### 1. Оптимизация производительности

- **Рекордная скорость инференса**: Достижение ~20x ускорения за счет дистилляции шагов и системной оптимизации (на одном GPU)
- **Революционная 4-шаговая дистилляция**: Сжатие исходных 40-50 шагов инференса до всего 4 шагов без необходимости в CFG (Classifier-Free Guidance)
- **Поддержка передовых операторов**: Интеграция с передовыми операторами, включая Sage Attention, Flash Attention, Radial Attention, q8-kernel, sgl-kernel, vllm

### 2. Энергоэффективное развертывание

- **Преодоление барьеров оборудования**: Работа 14B моделей для генерации 480P/720P видео только с 8 ГБ VRAM + 16 ГБ RAM
- **Интеллектуальная выгрузка параметров**: Передовая архитектура выгрузки трех уровней диск-CPU-GPU с детальным управлением на уровне фаз/блоков
- **Комплексное квантование**: Поддержка w8a8-int8, w8a8-fp8, w4a4-nvfp4 и других стратегий квантования

### 3. Богатая экосистема функций

- **Умное кэширование функций**: Интеллектуальные механизмы кэширования для устранения избыточных вычислений
- **Параллельный инференс**: Многопроцессорная параллельная обработка для повышения производительности
- **Гибкие варианты развертывания**: Поддержка Gradio, сервисного развертывания, ComfyUI и других методов
- **Динамическая инференция с разрешением**: Адаптивная настройка разрешения для оптимального качества генерации
- **Интерполяция кадров видео**: Интерполяция кадров RIFE для плавного увеличения частоты кадров

## Установка и использование

### Варианты установки
1. **Из Git**: `pip install -v git+https://github.com/ModelTC/LightX2V.git`
2. **Сборка из исходного кода**: Клонирование репозитория и использование `uv pip install -v .`

### Пример использования
Фреймворк предоставляет унифицированный интерфейс пайплайна:
```python
from lightx2v import LightX2VPipeline

# Инициализация пайплайна для задачи Wan2.2 I2V
pipe = LightX2VPipeline(
    model_path="/path/to/Wan2.2-I2V-A14B",
    model_cls="wan2.2_moe",
    task="i2v",
)

# Включение выгрузки для уменьшения использования VRAM
pipe.enable_offload(
    cpu_offload=True,
    offload_granularity="block",
    text_encoder_offload=True,
)

# Создание генератора с указанными параметрами
pipe.create_generator(
    attn_mode="sage_attn2",
    infer_steps=40,
    height=480,
    width=832,
    num_frames=81,
    guidance_scale=[3.5, 3.5],
)

# Генерация видео
pipe.generate(
    seed=seed,
    image_path=image_path,
    prompt=prompt,
    negative_prompt=negative_prompt,
    save_result_path=save_result_path,
)
```

## Методы развертывания

- **Интерфейс Gradio**: Чистый и удобный веб-интерфейс для быстрого ознакомления и прототипирования
- **Интерфейс ComfyUI**: Мощный узловой интерфейс с поддержкой сложных задач генерации видео
- **Развертывание одним щелчком для Windows**: Удобное решение для пользователей Windows с автоматической настройкой среды

## Продвинутые функции

- **CFG параллелизм**: Параллелизм без классификации по руководству для улучшения производительности
- **Параллелизм Ulysses**: Продвинутые методы параллельной обработки
- **Эффективная выгрузка**: Интеллектуальное управление памятью между CPU и GPU
- **TeaCache/MagCache**: Передовые технологии кэширования для устранения избыточных вычислений
- **Поддержка формата GGUF**: Инференс модели и развертывание на специализированном оборудовании (Cambricon MLU590/MetaX C500)
- **Поддержка Hygon DCU**: Развертывание на оборудовании Hygon DCU

## Сравнение с другими фреймворками

LightX2V конкурирует и дополняет другие фреймворки ускорения диффузионных моделей:
- **SGLang Diffusion**: LightX2V обеспечивает лучшую производительность и поддержку большего количества моделей
- **FastVideo**: LightX2V акцентирует внимание на инференсе, тогда как FastVideo фокусируется на задачах обучения
- **TurboDiffusion**: LightX2V предлагает более продвинутую систему оптимизации с 4-шаговой дистилляцией
