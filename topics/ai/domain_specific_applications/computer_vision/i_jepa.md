# I-JEPA: Image-based Joint Embedding Predictive Architecture

## Общее описание

**I-JEPA (Image-based Joint Embedding Predictive Architecture)** - это архитектура для self-supervised обучения изображений, представленная в работе "Self-Supervised Learning From Images With a Joint-Embedding Predictive Architecture". I-JEPA является первоисточником для других JEPA-архитектур, включая V-JEPA, VL-JEPA и LeJEPA.

## Архитектурные особенности

I-JEPA представляет собой радикальный отход от традиционного подхода к self-supervised learning. Вместо предсказания пикселей или фич в пространстве данных, I-JEPA обучается предсказывать абстрактные представления (эмбеддинги) одной части изображения на основе другой части в латентном пространстве.

### Основные компоненты

- **Context encoder**: Обрабатывает видимую часть изображения
- **Target encoder**: Обрабатывает скрытую часть изображения для получения целевого представления
- **Predictor**: Предсказывает эмбеддинги целевой области на основе контекстных эмбеддингов

### Ключевые различия от других подходов

- В отличие от masked autoencoders (MAE), I-JEPA не пытается восстановить пиксельное пространство
- Вместо этого модель предсказывает представления в абстрактном пространстве
- Минимизирует контраст между предсказанными и целевыми представлениями через функцию InfoNCE

## Обучение и стабильность

I-JEPA использует эвристики для стабилизации обучения:
- Stop-gradient для предотвращения коллапса представлений
- Teacher-student архитектуру с экспоненциальным скользящим средним (EMA)
- Whitening-слои для нормализации представлений

## Связь с другими архитектурами

- **V-JEPA**: Расширение I-JEPA для видеоанализа
- **VL-JEPA**: Расширение I-JEPA для визуально-языковых задач
- **LeJEPA**: Теоретически обоснованное развитие I-JEPA с доказуемой оптимальностью

## Применение

I-JEPA используется в self-supervised обучении визуальных представлений, позволяя обучение без разметки на больших датасетах изображений, таких как ImageNet.
