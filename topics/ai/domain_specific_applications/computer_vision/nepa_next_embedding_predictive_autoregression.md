# NEPA: Next-Embedding Predictive Autoregression

## Краткое описание

**Next-Embedding Predictive Autoregression (NEPA)** — это фреймворк для self-supervised обучения визуальных трансформеров (ViT), основанный на идее предсказания эмбеддинга следующего патча изображения при условии знания предыдущих. Это подход, который объединяет методы обучения визуальных и языковых моделей, используя парадигму next-token prediction в непрерывном латентном пространстве вместо дискретных токенов или попиксельной реконструкции.

## Основные концепции

### Принцип NEPA: предсказание будущего в латенте

Базовая единица операции в NEPA — это эмбеддинг патча. Входное изображение разбивается на последовательность из непересекающихся патчей, которые отображаются через общий энкодер в последовательность эмбеддингов. В отличие от маскированного моделирования, где энкодер видит испорченную версию картинки, здесь патчи обрабатываются строго каузально — модель предсказывает эмбеддинг следующего патча на основе всех предыдущих.

### Отличие от других методов

- **Не использует дискретные токенизаторы** (как в BEiT с VQ-VAE)
- **Не требует попиксельной реконструкции** (как в MAE)
- **Работает полностью в непрерывном латентном пространстве**
- **Не требует momentum encoders** или контрастных пар
- **Унифицирует объекты обучения** с языковыми моделями (next-token prediction)

## Архитектура и реализация

### Основные компоненты

NEPA использует современные Vision Transformers (ViT) с каузальным вниманием над последовательностями патчей:

- **RoPE** (rotary positional embeddings)
- **LayerScale** для стабилизации
- **SwiGLU** для активации
- **QK-Norm** для нормализации
- Прямые Transformer-блоки с Conv2d patch embedder

### Алгоритм обучения

```
# f: embedding layer
# h: autoregressive model
for pixel_values in loader:   # x, [B, H, W, C]
    input_embed = f(pixel_values)   # z, [B, T, D]
    pred_embed  = h(input_embed)    # z_hat, [B, T, D]
    loss = Dist(input_embed, pred_embed)
```

### Ключевые технические особенности

- **Каузальное маскирование**: Каждый патч может видеть только предыдущие патчи при предсказании следующего эмбеддинга
- **Stop-gradient**: Применяется к таргетам для предотвращения коллапса модели
- **Нет случайного маскирования**: Сложность задачи встроена, в отличие от masked image modeling

## Результаты и перформанс

### Результаты на ImageNet-1K

- **NEPA-B**: 83.8% top-1 точность
- **NEPA-L**: 85.3% top-1 точность
- Конкурентоспособные результаты по сравнению со сложными методами MAE, BEiT и MoCo v3
- Достигнуты с более простым пайплайном обучения

### Сравнение с другими методами

| Модель | Точность (Top-1) | Особенности |
|--------|------------------|-------------|
| NEPA-B | 83.8% | Только next-embedding objective |
| MAE-B | 83.6% | Декодер, маскирование |
| BEiT-B | 83.4% | Дискретный токенизатор |
| NEPA-L | 85.3% | Простая архитектура |
| MAE-L | 85.6% | Сложный декодер |
| BEiT-L | 85.2% | Внешний токенизатор |

## Преимущества и ограничения

### Преимущества

1. **Минималистичный дизайн**: Зависит только от next-embedding loss, без декодеров, расписаний маскирования или дополнительных трюков
2. **Работа с нативными эмбеддингами**: Оперирует напрямую эмбеддингами из энкодера без необходимости в оффлайн энкодерах
3. **Стабильные техники**: Идентифицированы компоненты (LayerScale и QK-Norm), которые делают более глубокие каузальные трансформеры стабильными
4. **Унифицированный фреймворк**: Предполагает возможность модальности-агностичного подхода, где разные модальности могут обучаться под одним next-embedding objective

### Ограничения

1. **Низкая точность при linear probing**: По сравнению с полным файнтюнингом, что указывает на то, что репрезентации оптимизированы под динамическую задачу предсказания
2. **Проблемы со сложным освещением**: Модель может сбиваться при сложном освещении, принимая тени за отдельные объекты
3. **Вычислительная сложность**: Каузальное предсказание в непрерывном пространстве может быть вычислительно затратным

## Связь с JEPА и другими методами

NEPA следует той же философии, что и JEPА, в том, что обучение происходит через предсказание латентных таргетов, но в отличие от JEPА, не требует momentum encoders. Это упрощает архитектуру и делает её более похожей на обучение языковых моделей.
