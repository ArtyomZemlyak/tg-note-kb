# Nexels: Neurally-Textured Surfels для синтеза новых ракурсов в реальном времени с разреженной геометрией

## Краткое описание

Nexels — это новое представление для синтеза новых ракурсов, в котором используется декомпозиция геометрии и внешнего вида для достижения компактного представления. В отличие от традиционного 3D Gaussian Splatting, которое использует точки, nexels используют surfels (поверхностные элементы) для геометрии и комбинацию глобального нейронного поля и цветов на примитиве для внешнего вида. Это позволяет достичь качества, сопоставимого с 3D Gaussian Splatting, при использовании в 9.7 раз меньше примитивов на наружных сценах и в 31 раз меньше примитивов на внутренних сценах, а также уменьшении использования памяти.

## Основные характеристики

### Технический подход
- Использование surfels для геометрии вместо точек
- Декомпозиция геометрии и внешнего вида для более эффективного представления
- Комбинация глобального нейронного поля и цветов на примитиве для внешнего вида
- Нейронное поле текстурирует фиксированное число примитивов для каждого пикселя

### Преимущества
- **Компактное представление**: Использование в 9.7-31 раз меньше примитивов по сравнению с 3D Gaussian Splatting
- **Экономия памяти**: В 3.7-5.5 раза меньше использования памяти
- **Высокая скорость рендеринга**: Работает в 2 раза быстрее существующих текстурированных примитивов
- **Высокое качество**: Соответствует перцептивному качеству 3D Gaussian Splatting
- **Реальное время**: Возможность рендеринга в реальном времени

## Архитектура и реализация

### Геометрия
- Используются surfels (поверхностные элементы) вместо точек для представления геометрии
- Вводится дифференцируемый индикатор квадрата для лучшей реконструкции поверхностей и резких границ
- Применяется обобщённое гауссово ядро для моделирования близких к непрозрачным примитивов
- Параметр γ контролирует, насколько прямоугольным является примитив

### Внешний вид
- Используется общее нейронное поле в мировом пространстве, которое предоставляет текстуру, зависящую от вида, только для наиболее релевантных примитивов
- Поле нейронной текстуры обеспечивает эффективное захват деталей с низкими вычислительными затратами
- Вводится схема top-K для ограничения числа текстурированных примитивов на пиксель

### Ядро
- При γ = 1, nexels соответствуют гауссовому распределению
- При γ → ∞, они сходятся к индикатору квадрата
- Ядро подходит для моделирования непрозрачных и плоских поверхностей
- Поведение как у гаусса, где требуется гладкость, и возможность получения резких краёв в областях с резкими переходами

## Применение

### В компьютерном зрении
- **Синтез новых ракурсов**: Генерация изображений с новых точек зрения с высоким качеством
- **Реал-тайм рендеринг**: Возможность интерактивного просмотра 3D-сцен
- **3D реконструкция с разреженной геометрией**: Моделирование сцен с высокотекстурированными областями при простой геометрии

### В области рендеринга
- **Эффективное использование ресурсов**: Значительное снижение числа необходимых примитивов
- **Качественные текстуры**: Лучшее качество по сравнению с конкурентными методами текстурирования
- **Высокая скорость**: Более двукратное увеличение скорости по сравнению с конкурентами

## Сравнение с другими методами

### Nexels vs. 3D Gaussian Splatting
- **Число примитивов**: Использование в 9.7-31 раз меньше примитивов при сопоставимом качестве
- **Память**: Использование в 3.7-5.5 раз меньше памяти
- **Скорость**: В 2 раза быстрее существующих текстурированных примитивов
- **Качество**: Соответствие перцептивному качеству 3D Gaussian Splatting

### Nexels vs. NeST-Splatting
- **Скорость рендеринга**: Nexels быстрее (50 FPS) по сравнению с NeST-Splatting (23 FPS)
- **Время обучения**: Nexels обучается быстрее (1.1ч) по сравнению с NeST-Splatting (4.9ч)
- **Качество**: Лучшая LPIPS метрика при сопоставимых условиях

### Nexels vs. BBSplat
- **Скорость рендеринга**: Nexels быстрее (50 FPS) по сравнению с BBSplat (20 FPS)
- **Качество**: Лучшие метрики при сопоставимых условиях

## Технические детали

### Процесс рендеринга
- Двухпроходный процесс: первый проход вычисляет начальный рендер, используя только непротекстурированное внешнее восприятие, и собирает информацию о том, какие примитивы должны быть текстурированы
- Второй проход применяет нейронную текстуру в собранные точки пересечения луч-примитив и обновляет начальный рендер

### Оптимизация плотности
- Адаптивный контроль плотности для добавления и удаления примитивов
- Использование алгоритма farthest point sampling для инициализации
- Регуляризация для поддержания стабильности

### Ограничения
- Скорость Instant-NGP модели зависит от операций тензорного ядра, доступных только на высокопроизводительных GPU
- Nexels не работают в реальном времени на мобильных GPU или GPU низкого класса
- Производят шум в незнакомых регионах, что может быть менее привлекательным для конечных пользователей, чем размытые артефакты гауссианов

## Результаты

### Качество
- Достигает перцептивного паритета с 3DGS при использовании в 9.7 раз меньше примитивов на наружных сценах
- Достигает перцептивного паритета с 3DGS при использовании в 31 раз меньше примитивов на внутренних сценах
- Лучшие метрики LPIPS при меньшем числе примитивов

### Скорость
- Рендеринг со скоростью 50 FPS в среднем на сценах Mip-NeRF360
- Более быстрое обучение по сравнению с NeST-Splatting и BBSplat

### Память
- Использование 160MB памяти при 400K nexels
- Значительно меньше использования памяти по сравнению с конкурентами
