# DroPE: Метод отбрасывания позиционных эмбеддингов для расширения контекста предобученных LLM

## Определение

DroPE (Dropping the Positional Embeddings of LMs after training) - это метод расширения контекста предобученных языковых моделей (LLM) без необходимости дорогостоящей дообучки на длинных контекстах. Метод основан на простой идее: после завершения основного этапа предобучения позиционные эмбеддинги (Positional Embeddings, PE) модели отбрасываются, а затем проводится короткая фаза перекалибровки модели на исходной длине контекста.

## Основная концепция

DroPE основывается на трех ключевых теоретических и эмпирических наблюдениях:

1. **Позиционные эмбеддинги играют важную роль в процессе предобучения** - они обеспечивают важный индуктивный сдвиг, который значительно способствует сходимости во время тренировки.

2. **Избыточная зависимость от явной позиционной информации препятствует обобщению** - те же позиционные эмбеддинги, которые помогают во время обучения, фактически мешают модели обобщаться на последовательности неизвестной длины во время тестирования.

3. **Позиционные эмбеддинги не являются обязательными для эффективного языкового моделирования** - они могут быть безопасно удалены после предобучения после короткой фазы перекалибровки, что позволяет модели адаптироваться к более длинным контекстам.

## Механизм работы

### Процесс применения DroPE

1. **Предобучение с RoPE** - модель сначала обучается с использованием традиционных Rotary Position Embeddings (RoPE), как это обычно делается

2. **Отбрасывание позиционных эмбеддингов** - после завершения основного предобучения все позиционные эмбеддинги удаляются из модели

3. **Фаза перекалибровки** - проводится короткая фаза дообучения (рекалибровки) на исходной длине контекста для восстановления способности модели эффективно работать в пределах исходного контекста

4. **Нулевая экстраполяция контекста** - после перекалибровки модель способна обрабатывать значительно более длинные последовательности без дополнительной специальной дообучки

### Преимущества нулевой экстраполяции контекста

- **Нулевая дополнительная дообучка** - не требуется дорогостоящее обучение на длинных контекстах
- **Быстрое адаптирование** - модели быстро приспосабливаются без компромиссов в исходных способностях
- **Сохранение исходных способностей** - модель сохраняет свои способности в исходном тренировочном контексте
- **Применимость к различным архитектурам** - работает с различными моделями и размерами наборов данных

## Преимущества по сравнению с методами RoPE-масштабирования

### Масштабирование RoPE

Традиционные методы масштабирования RoPE (такие как PI, RoPE-NTK и YaRN) требуют:

- **Дополнительной дообучки на длинных последовательностях** - для достижения значимого использования токенов за пределами исходной длины последовательности
- **Невозможность обобщения "из коробки"** - методы не обобщаются на задачи с длинным контекстом без дообучки

### Преимущества DroPE

- **Нулевая дообучка для расширения контекста** - метод достигает расширения контекста без какой-либо дополнительной дообучки
- **Сохранение способностей исходного контекста** - не компрометирует первоначальные способности модели
- **Превосходная производительность** - значительно превосходит предыдущие специализированные архитектуры и установленные методы масштабирования ротационных позиционных эмбеддингов
- **Универсальная применимость** - работает с различными моделями и размерами до 7 миллиардов параметров, предобученных на триллионах токенов

## Эмпирическая оценка

### Интеграция DroPE без дополнительных затрат

В экспериментах DroPE интегрировался в процесс предобучения без дополнительных затрат:

- Была обучена модель RoPE с половиной миллиарда параметров на 16 миллиардах токенов
- После 14 миллиардов токенов позиционные эмбеддинги были удалены
- Модель продолжила обучение на оставшихся 2 миллиардах токенов
- Результаты показали, что DroPE соответствует итоговой перплексии RoPE, обученной на всех 16 миллиардах токенов, и превосходит базовую модель NoPE

### Долгосрочное обобщение нулевого уровня

На задачах Needle-in-a-Haystack (NIAH) при длине контекста в 2 раза больше, чем длина обучающего контекста:

- **DroPE** значительно превосходит все базовые методы:
  - Multi-Query: 28.0%
  - Multi-Key: 41.6%
  - Multi-Value: 23.3%

В то время как традиционные RoPE-методы с масштабированием показали:
- RoPE-NTK: 21.1% (Multi-Query), 19.4% (Multi-Key), 16.5% (Multi-Value)
- YaRN: 17.8% (Multi-Query), 0.5% (Multi-Key), 14.6% (Multi-Value)

## Связь с NoPE архитектурами

DroPE тесно связан с архитектурами NoPE (No Positional Embeddings), но имеет важное отличие:

- **Традиционные NoPE** - модели, обученные без каких-либо позиционных эмбеддингов с самого начала
- **DroPE** - модели, которые используют позиционные эмбеддинги вначале для эффективного обучения, а затем отбрасывают их после завершения основной фазы обучения

Это позволяет использовать преимущества позиционных эмбеддингов для обучения, избегая при этом ограничений, налагаемых на обобщение контекста.

## Результаты на крупных моделях

DroPE успешно масштабируется до более крупных моделей, включая:

- **SmolLM-1.7B** (предобучена на 1 триллионе токенов)
- **Llama2-7B** (предобучена на 4 триллионах токенов)

Для обеих моделей перекалибровка проводилась всего на 20 миллиардах токенов (2% бюджета предобучения SmolLM-1.7B и 0.5% для Llama2-7B), но все равно превосходила современные методы масштабирования RoPE.

## Значение для области

### Архитектурные инсайты

DroPE подчеркивает важное понимание роли позиционных эмбеддингов в трансформерах:

- Позиционные эмбеддинги являются полезным индуктивным сдвигом, который важен для эффективного обучения (Observation 1)
- Однако они по своей сути ограничивают экстраполяцию контекста нулевого уровня (Observation 2)
- Позиционные эмбеддинги можно и нужно удалять после выполнения своей обучающей функции (Observation 3)

### Практическое значение

- **Снижение стоимости обучения** - позволяет адаптировать предобученные модели без дорогостоящей дообучки
- **Создание устойчивых и масштабируемых трансформеров для длинного контекста** - открывает новые возможности для создания моделей, эффективно работающих с длинными последовательностями
- **Универсальная применимость** - может быть использован для быстрого адаптирования любых предобученных LLM "в дикой природе"

## Сравнение с альтернативными архитектурами

### ALiBi (Attention with Linear Biases)
- Использует линейные смещения вместо позиционных эмбеддингов
- Показывает умеренные результаты на задачах NIAH

### RNoPE-SWA (Rotary No Positional Embeddings with Sliding Window Attention)
- Альтернативная архитектура, ориентированная на длинный контекст
- Показывает худшие результаты на логически интенсивных задачах

### NoPE трансформеры
- Обучены без позиционных эмбеддингов с самого начала
- Показывают ухудшенную производительность по сравнению с RoPE-архитектурами

## Применение в моделях

DroPE может быть применен к различным архитектурам трансформеров:

- **RoPE-трансформеры** - как метод улучшения возможности экстраполяции
- **7-миллиардные модели** - успешно масштабируется до крупных архитектур
- **Существующие предобученные модели** - может быть применен к уже существующим моделям для улучшения их возможностей работы с длинным контекстом

## Заключение

DroPE представляет собой парадигмальный сдвиг в подходе к расширению контекста в предобученных языковых моделях. В отличие от традиционного подхода, требующего дорогостоящей дообучки на длинных контекстах, DroPE предлагает простой, но эффективный метод достижения нулевой экстраполяции контекста за счет отбрасывания позиционных эмбеддингов и короткой фазы перекалибровки. 

Результаты показывают, что метод универсально применим, масштабируем и значительно превосходит существующие подходы. Это открывает новые возможности для разработки эффективных и устойчивых методов расширения контекста, которые могут быть легко интегрированы в существующие тренировочные конвейеры.
