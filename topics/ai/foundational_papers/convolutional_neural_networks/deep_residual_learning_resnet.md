# Deep Residual Learning for Image Recognition (ResNet, 2015)

## Обзор

Статья "Deep Residual Learning for Image Recognition" Кайминга Хе и коллег, представленная в 2015 году на конференции CVPR, описывает архитектуру ResNet (Residual Networks), которая решила одну из ключевых проблем глубокого обучения: трудности при обучении очень глубоких нейронных сетей. Эта работа стала победителем ImageNet Challenge 2015 и получила награду Best Paper на конференции.

## Основные идеи

### Проблема "деградации"

Авторы выявили фундаментальную проблему при обучении глубоких нейронных сетей:
- При увеличении глубины сети точность насыщается и затем начинает деградировать
- Это не связано с переобучением, так как ухудшение происходит и на обучающей выборке
- Проблема становится более выраженной при увеличении глубины сети

### Архитектура ResNet

Решение основано на "остаточном обучении" (residual learning):
- Вместо обучения H(x) напрямую, обучается F(x) := H(x) - x
- Это позволяет модели легко изучать идентичное отображение
- Входные данные добавляются к выходу слоя как "skip connection" (пропускное соединение)

### Остаточные блоки

Ключевой компонент - остаточный блок, который:
- Содержит несколько слоев (обычно 2-3 сверточных слоя)
- Имеет прямое соединение (shortcut connection) через всю структуру
- Складывает вход с выходом слоев перед активацией

## Технические детали

### Архитектура ResNet

ResNet может быть построен с различной глубиной:
- ResNet-18, ResNet-34: использует блоки с 2 сверточными слоями
- ResNet-50, ResNet-101, ResNet-152: использует "bottleneck" блоки с 3 сверточными слоями

### Bottleneck Architecture

Для очень глубоких сетей используются bottleneck блоки:
- 1x1 свертка для сжатия размерности
- 3x3 свертка для основной обработки
- 1x1 свертка для восстановления размерности

### Реализация skip connections

Skip connections могут быть:
- Идентичностью (без параметров)
- С линейным проецированием при несовпадении размерностей

## Влияние на развитие ИИ

### Решение проблемы глубоких сетей

ResNet решила ключевую проблему:
- Позволила обучать сети с сотнями и тысячами слоев
- Показала, что деградация может быть решена эффективно
- Стала стандартом для глубоких архитектур

### Архитектурные инновации

ResNet принесла:
- Концепцию skip connections, которая используется во многих архитектурах
- Базовую архитектуру для последующих разработок
- Пример успешного решения проблемы глубоких сетей

### Практическое применение

ResNet повлияла:
- На большинство современных архитектур компьютерного зрения
- На подходы к обучению глубоких сетей
- На инженерные практики в области ИИ

## Связь с другими работами

### Предшественники

ResNet была вдохновлена:
- Работами по очень глубоким сетям (GoogLeNet, VGG)
- Проблемами с обучением глубоких архитектур
- Проблемами исчезающего градиента

### Последующие разработки

ResNet повлияла на:
- DenseNet (более плотные соединения)
- Highway Networks (управляемые пропускные соединения)
- Modern architectures (EfficientNet, RegNet, и др.)
- Transformer architectures (skip connections в внимании)

## Значение для списка Суцкевера

ResNet включена в список как:
- Решение фундаментальной проблемы глубокого обучения
- Архитектурная инновация, позволившая создавать гораздо более глубокие сети
- Пример эффективного использования skip connections
- Важное достижение в компьютерном зрении
- База для многих современных архитектур
