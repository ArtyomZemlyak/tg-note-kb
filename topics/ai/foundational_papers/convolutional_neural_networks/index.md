## Значение для глубокого обучения

Работы в этой области заложили основу для современного компьютерного зрения. AlexNet в 2012 году фактически начал эпоху глубокого обучения, значительно победив в конкурсе ImageNet. ResNet затем решил проблему обучения очень глубоких сетей с помощью skip-соединений. Эти архитектуры стали основой для всех современных систем компьютерного зрения.
