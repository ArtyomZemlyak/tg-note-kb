# An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale (Dosovitskiy et al., 2020)

## Обзор

Статья "An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale", представленная Алексеем Досовицким и коллегами в 2020 году, описывает Vision Transformer (ViT), который адаптирует архитектуру Transformer для задач классификации изображений. Это работа революционизировала компьютерное зрение, показав, что Transformer могут превзойти сверточные нейронные сети в задачах распознавания изображений.

## Основные идеи

### Патчинг изображений

Основная идея ViT заключается в:
- Разделении изображения на фиксированные патчи (например, 16x16 пикселей)
- Линейным проецированием каждого патча в вектор (встраивание)
- Добавлении positional embeddings для сохранения пространственной информации
- Обработке последовательности патчей с помощью стандартной архитектуры Transformer

### Преимущества подхода

ViT предлагает:
- Меньшую индуктивную предвзятость по сравнению с CNN
- Более эффективное использование вычислительных ресурсов для длинных последовательностей
- Параллельную обработку всех патчей
- Возможность масштабирования до больших моделей и датасетов

### Потребность в данных

Однако работа также показывает, что:
- ViT требует больше данных для обучения, чем CNN
- На малых датасетах ViT показывает худшие результаты
- На больших датасетах ViT превосходит SOTA CNN

## Технические детали

### Архитектура Vision Transformer

ViT состоит из:
- **Patch Embedding Layer**: преобразование изображения в последовательность патчей
- **Linear Projection**: проецирование патчей в векторное пространство
- **Class Token**: специальный токен для классификации
- **Positional Embeddings**: для сохранения пространственной информации
- **Transformer Blocks**: стандартные блоки Transformer
- **MLP Head**: для финальной классификации

### Patch Embedding

Изображение размера `H × W × C` преобразуется в последовательность патчей:
- Изображение разбивается на `N = (H × W)/(P²)` патчей размера `P × P × C`
- Каждый патч линейно проецируется в вектор размерности `D`
- Получается последовательность `N + 1` векторов размерности `D` (плюс class token)

### Обучение

ViT можно обучать:
- С нуля на больших датасетах (ImageNet-21k, JFT-300M)
- С предобучением на других задачах
- С трансфером знаний от CNN

## Влияние на развитие ИИ

### Революция в компьютерном зрении

ViT произвел революцию:
- Применил архитектуру Transformer к изображениям
- Показал, что CNN не являются обязательными для компьютерного зрения
- Открыл новую эпоху архитектур на основе внимания

### Масштабирование и эффективность

ViT позволил:
- Лучшее масштабирование с вычислительными ресурсами
- Более эффективные архитектуры для больших моделей
- Новые подходы к обучению визуальных представлений

### Новые архитектуры

ViT привел к:
- Разработке новых архитектур (DeiT, Swin Transformer, и др.)
- Гибридным моделям (CNN + Transformer)
- Мультимодальным моделям (CLIP, DALL-E, и др.)

## Связь с другими работами

### Предшественники

ViT был вдохновлен:
- Работой "Attention Is All You Need" по архитектуре Transformer
- Ранними попытками применения внимания к изображениям
- Работами по self-attention в CNN

### Связь с трансформерами

ViT показал:
- Универсальность архитектуры Transformer
- Возможность применения к разным типам данных
- Эффективность внимания в визуальных задачах

### Последующие разработки

ViT стал основой для:
- Vision Transformers с улучшенной архитектурой (Swin, ConvNeXt, и др.)
- Мультимодальных трансформеров
- Foundation models для визуальных задач

- Успешным применением архитектуры Transformer за пределами NLP
