# Auto-Encoding Variational Bayes (Kingma & Welling, 2013)

## Обзор

Статья "Auto-Encoding Variational Bayes" Дидерика Кингмы и Макса Веллинга, представленная в 2013 году и опубликованная в 2014 году, описывает Variational Autoencoder (VAE) - глубокую генеративную модель, сочетающую вариационный вывод с параметризованными функциями, обучаемыми с помощью стохастического градиентного спуска. Эта работа стала ключевым достижением в области генеративных моделей.

## Основные идеи

### Вариационный автокодировщик

VAE объединяет:
- Автокодировщики (autoencoders) для изучения латентных представлений
- Байесовский вывод для генерации новых данных
- Трюк с репараметризацией для обучения стохастических моделей

### Цель моделирования

VAE стремится:
- Изучить плотность данных p(x), где x - наблюдаемые данные
- Уметь генерировать новые данные из обученной модели
- Обеспечить эффективный вариационный вывод с помощью нейронных сетей

### Латентные переменные

Модель включает:
- Наблюдаемые переменные x (например, изображения)
- Латентные переменные z (внутреннее представление)
- Объединение генеративной модели (декодер) и вариационного приближения (энкодер)

## Технические детали

### Вариационный нижний предел (ELBO)

Цель обучения VAE формулируется как максимизация вариационного нижнего предела:
`L(θ, φ; x) = E[log p(x|z)] - KL(qφ(z|x)||p(z))`

Где:
- `E[log p(x|z)]` - восстановительный термин (reconstruction term)
- `KL(qφ(z|x)||p(z))` - регуляризационный термин (regularization term)

### Трюк с репараметризацией

Из-за стохастичности латентных переменных z сложно брать градиенты. Авторы предлагают:
- z = μ + σ ⊙ ε, где ε ~ N(0, I)
- Это позволяет дифференцировать через сэмплирование
- Градиенты могут проходить через стохастический узел

### Архитектура

VAE состоит из:
- **Энкодер (Inference/Distribution Network)**: qφ(z|x) приближает апостериорное распределение p(z|x)
- **Декодер (Generator/Generation Network)**: pθ(x|z) моделирует процесс генерации из латентного представления
- **Латентное пространство**: обычно предполагается нормальное распределение p(z) = N(0, I)

### Обучение

Алгоритм обучения VAE включает:
1. Выбор батча данных x(i)
2. Для каждого образца x(i):
   - Кодирование: вычисление μ(i) и σ(i) из x(i)
   - Сэмплирование: z(i) = μ(i) + σ(i) ⊙ ε, где ε ~ N(0, I)
   - Декодирование: вычисление p(x(i)|z(i))
3. Вычисление ELBO и обновление параметров с помощью SGD

## Влияние на развитие ИИ

### Новый класс генеративных моделей

VAE принес:
- Новый подход к обучению генеративных моделей с вариационным выводом
- Возможность эффективного обучения стохастических моделей
- Баланс между качеством генерации и качеством представления

### Сравнение с GAN

VAE дополнили GAN:
- В отличие от GAN, VAE обучается стабильно
- VAE позволяют явно моделировать распределение
- VAE обеспечивают структурированное латентное пространство

### Применения

VAE нашли применение:
- В генерации изображений и аудио
- В изучении латентных представлений
- В моделировании сложных вероятностных распределений
- В задачах с_missing data_

### Академическое влияние

VAE привели к:
- Расширению исследований в области вариационного вывода
- Новым архитектурам (β-VAE, CVAE, и др.)
- Пониманию компромисса между восстановлением и регуляризацией

## Связь с другими работами

### Предшественники

VAE были вдохновлены:
- Работами по вариационному выводу
- Автокодировщиками и их глубокими вариантами
- Байесовскими графическими моделями

### Современные разработки

VAE повлияли на:
- Нормализующие потоки (Normalizing Flows)
- Современные генеративные модели
- Автоэнкодеры со спарсификацией (Sparse Autoencoders)
- Модели с неявной регуляризацией

## Значение для списка Суцкевера

VAE включены в список как:
- Один из ключевых подходов к генеративным моделям
- Комбинация вариационного вывода и глубокого обучения
- Пример интеграции байесовских методов и нейронных сетей
- Основа для многих современных подходов к обучению представлениям
- Стабильная альтернатива GAN
