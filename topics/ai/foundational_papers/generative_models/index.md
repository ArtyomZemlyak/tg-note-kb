# Генеративные модели

## Обзор

Эта секция содержит ключевые работы по генеративным моделям, включая вариационные автоэнкодеры (VAE), генеративные соперничающие сети (GAN) и другие архитектуры, способные генерировать данные.

## Ключевые темы

### Вариационные автоэнкодеры
- [[auto_encoding_variational_bayes.md]] - "Auto-Encoding Variational Bayes" (Kingma, Welling, 2013) - Оригинальная работа о VAE
- [[introduction_variational_autoencoders.md]] - "An Introduction to Variational Autoencoders" (2019) - Обширное введение в VAE
- [[variational_lossy_autoencoder.md]] - "Variational Lossy Autoencoder" (Chen et al., 2017) - Улучшенная архитектура VAE

### Генеративные соперничающие сети
- [[generative_adversarial_networks.md]] - "Generative Adversarial Networks" (Goodfellow et al., 2014) - Оригинальная работа о GAN

## Значение для глубокого обучения

Генеративные модели открыли новый класс задач для нейронных сетей - генерацию новых данных. GAN и VAE стали основой для множества современных приложений, включая генерацию изображений (DALL-E, Midjourney), аудио и текста. Эти подходы позволяют моделям учиться на неотмеченных данных и генерировать реалистичные образцы.
