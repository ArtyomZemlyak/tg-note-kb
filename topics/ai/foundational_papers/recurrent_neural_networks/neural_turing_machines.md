# Neural Turing Machines (Graves et al., 2014)

## Обзор

Статья "Neural Turing Machines" (NTM), представленная Алексом Грейвсом и коллегами в 2014 году, описывает архитектуру нейронной сети, которая сочетает контроллерную сеть с адресуемой внешней памятью. NTM был одним из первых подходов к обучаемым нейронным архитектурам с внешней памятью и стал предшественником других архитектур с механизмом внимания.

## Основные идеи

### Компоненты архитектуры

Neural Turing Machine состоит из двух основных компонентов:
- **Контроллер**: нейронная сеть (обычно LSTM или простая полносвязная сеть), которая принимает входные данные и взаимодействует с памятью
- **Память**: внешний массив ячеек памяти, к которым сеть может читать и писать с помощью механизмов внимания

### Механизмы внимания к памяти

NTM использует два основных механизма для взаимодействия с памятью:
- **Чтение**: считываются взвешенные комбинации содержимого памяти
- **Запись**: записываются новые данные в взвешенные комбинации ячеек памяти

### Дифференцируемость

Важным аспектом NTM является то, что все операции:
- Дифференцируемы, что позволяет использовать обратное распространение
- Управляемы с помощью мягкого внимания (softmax), а не жестких указателей
- Позволяют обучать всю систему с градиентным спуском

## Технические детали

### Архитектура памяти

Массив памяти представляет собой матрицу `M_t` размером `N × M`, где:
- `N` - количество мест в памяти
- `M` - размер слова памяти

### Операции чтения

Считывающий вектор `r_t` вычисляется как взвешенная сумма всех векторов памяти:
`r_t = Σ(i=1 to N) w_t(i) * M_t(i)`

Где `w_t(i)` - вес внимания к месту `i` в момент времени `t`.

### Операции записи

Процесс записи включает в себя:
1. **Стирание**: `M̃_t(i) = M_{t-1}(i) * [1 - w_t(i) * e_t(i)]`
2. **Добавление**: `M_t(i) = M̃_t(i) + w_t(i) * a_t(i)`

Где `e_t` - вектор стирания, а `a_t` - вектор добавления.

### Механизмы адресации

NTM использует смешанную систему адресации:
- **Содержательная адресация**: выбор места на основе содержимого
- **Временная адресация**: выбор места на основе предыдущего режима адресации

## Влияние на развитие ИИ

### Новая парадигма

NTM внесли новую парадигму:
- Комбинация нейронных сетей с внешней памятью
- Дифференцируемые внешние памяти как компонент архитектуры
- Возможность обучения сетей выполнять алгоритмы

### Предшественник внимания

NTM стали важным предшественником:
- Современных механизмов внимания
- External memory архитектур
- Differentiable computing

### Алгоритмическое обучение

NTM показали возможность:
- Обучения сетей алгоритмическим задачам (копирование, сортировка, ассоциативный поиск)
- Обобщения на более длинные последовательности, чем обученные
- Решения задач, требующих манипуляций с данными

## Связь с другими работами

### Предшественники

NTM были вдохновлены:
- Classical Turing machines и идеями вычислений
- Hopfield networks и ассоциативными памятями
- Early work on external memory in neural networks

### Последующие разработки

NTM привели к:
- Memory Networks от Facebook
- Neural Programmer-Interpreters
- Differentiable Neural Computers (DNC)
- Modern attention mechanisms

### Связь с RNN

NTM были естественным продолжением работ по рекуррентным сетям:
- Улучшили возможности долгосрочной памяти
- Предложили альтернативу внутренним скрытым состояниям
- Позволили решать задачи, которые были трудны для стандартных RNN

## Значение для списка Суцкевера

NTM включены в список как:
- Один из первых примеров нейронных архитектур с внешней памятью
- Важный шаг в понимании того, как сети могут использовать память для вычислений
- Пример того, как нейронные и символические подходы могут быть объединены
- Архитектура, которая повлияла на развитие внимания и внешних памятей
