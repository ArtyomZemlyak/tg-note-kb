# Механизм объединенного внимания (Merged Attention)

## Описание

Механизм объединенного внимания (Merged Attention) - это архитектурная новизна, представленная в T5Gemma 2, которая отходит от канонического дизайна блока трансформера. В стандартном энкодер-декодере блок декодера содержит два отдельных подслоя внимания: self-attention (смотрит в прошлое декодера) и cross-attention (смотрит на выход энкодера). Merged Attention унифицирует эти две операции в один модуль, снижая количество параметров примерно на 6.5%.

## Архитектурное решение

### Традиционный подход
В стандартной архитектуре энкодер-декодера декодерный блок содержит:
- Self-attention: позволяет декодеру учитывать предыдущие токены из генерируемой последовательности
- Cross-attention: позволяет декодеру обращаться к информации из энкодера

### Merged Attention
В Merged Attention эти две операции объединяются:
- **Входы**: выход энкодера H (длина n) и вход декодера X (длина m)
- **Ключи и значения**: получаются из конкатенации входа декодера и выхода энкодера
- **Операции**: 
  - Q = X @ W_q (запросы только из текущего декодера)
  - K = concat(X, H) @ W_k (ключи из объединенной последовательности)
  - V = concat(X, H) @ W_v (значения из объединенной последовательности)
- **Выход**: A = Softmax( (Q @ K.T / sqrt(d_h)) * M ) @ V

### Ключевая особенность - маска M
Маска M управляет логикой видимости:
- Гарантирует, что токены декодера видят полную последовательность энкодера H (эквивалент cross-attention)
- Гарантирует, что токены декодера видят соответствующую каузальную историю X (эквивалент self-attention)

## Преимущества

### Эффективность
- Унификация архитектуры: декодер становится строго похожим на стандартный блок decoder-only, но с расширенным окном контекста
- Снижение числа параметров примерно на 6.5%
- Уменьшение сложности модели без потери качества

### Функциональность
- Объединение функционально похожих операций (обе собирают информацию из "прошлого")
- Каждый модуль теперь может обращаться как к генерируемой последовательности, так и к закодированному контексту
- Повышение эффективности при длинных контекстах

## Сравнение с другими архитектурами

### В отличие от стандартного энкодер-декодера:
- Не требует отдельных параметров для self-attention и cross-attention
- Более унифицированная структура
- Меньше общее количество параметров

### В отличие от decoder-only моделей:
- Все еще сохраняется архитектурное разделение обработки входа и генерации
- Позволяет использовать преимущества двунаправленной обработки энкодера
- Дает возможность "глубокого чтения" контекста перед генерацией

## Применение

- Использован в T5Gemma 2 для повышения эффективности энкодер-декодер архитектуры
- Может быть применим в других моделях, где важна эффективность при длинных контекстах
- Унификация подходов между разными типами архитектур трансформеров

## Влияние на будущие архитектуры

Механизм Merged Attention указывает на потенциал в размытии границ между энкодер-декодерами и decoder-only моделями, потенциально ведя к гибридным системам, динамически переключающимся между режимами. Это может привести к архитектурам, которые объединяют преимущества разных подходов без увеличения сложности.
