# OLMo Hybrid

## Описание

OLMo Hybrid — серия языковых моделей от Allen Institute for AI (AI2), представляющая гибридную архитектуру, которая комбинирует полные слои внимания (Full Attention) со слоями Gated DeltaNet в соотношении 3:1. Модель демонстрирует двукратную эффективность данных (2x data efficiency) по сравнению с OLMo 3 при сохранении сопоставимых показателей на бенчмарке MMLU.

## Ключевые архитектурные особенности

### Гибридная архитектура 3:1

Основная инновация OLMo Hybrid заключается в чередовании двух типов слоёв:

- **Gated DeltaNet слои (75%)**: 3 из 4 слоёв используют архитектуру Gated DeltaNet — рекуррентный механизм с линейной сложностью, основанный на дельта-правиле с гейтированием
- **Full Attention слои (25%)**: 1 из 4 слоёв использует традиционное полное внимание для точного моделирования сложных зависимостей

Такое соотношение обеспечивает баланс между вычислительной эффективностью и мощностью моделирования.

### Gated DeltaNet (GDN)

Gated DeltaNet — это рекуррентная архитектура с линейной сложностью, которая использует гейтирование для управления потоком информации и обновления параметров. Основные характеристики:

- **Линейная сложность**: O(n) вместо O(n²) у традиционного внимания
- **Гейтирование**: Контроль обновления параметров через обучаемые гейты
- **Эффективность памяти**: Сниженные требования к KV-кэшу
- **Адаптивность**: Возможность адаптации во время инференса

### Полные слои внимания

Традиционные слои полного внимания в архитектуре служат для:

- Точного моделирования глобальных зависимостей
- Стабилизации обучения
- Сохранения высокой ёмкости модели

## Производительность

### Эффективность данных

- **2x data efficiency**: OLMo Hybrid достигает тех же показателей MMLU, что и OLMo 3, используя вдвое меньше данных для обучения
- Это означает значительное сокращение вычислительных затрат и времени обучения

### MMLU и другие бенчмарки

- **MMLU**: OLMo Hybrid достигает той же точности, что и OLMo 3 7B, используя **на 49% меньше токенов**
- **Common Crawl**: паритет достигается **на 35% меньше токенов**
- **Коэффициент эффективности использования данных**: 83,7 у гибрида против 94,9 у трансформера
- **Экономия данных растет с масштабом**:
  - ~1,3 раза на 1B параметров
  - ~1,9 раза на 70B параметров

### RULER (длинный контекст)

После дообучения и адаптации к длинному контексту OLMo Hybrid обходит OLMo 3 во всех категориях оценки:

| Метод | OLMo Hybrid | OLMo 3 | Разница |
|-------|-------------|--------|---------|
| **RULER @ 64k (DRoPE)** | 85,0 | 70,9 (YaRN) | +14,1 |
| **RULER @ 64k (YaRN)** | 76,9 | 70,9 (YaRN) | +6,0 |

На других бенчмарках после long-context extension:
- **BBH**: выше чем у OLMo 3
- **MMLU Pro**: выше чем у OLMo 3
- **LBPP**: небольшой регресс
- **DM Math**: небольшой регресс

## Сравнение с другими моделями

### Отличия от OLMo 2

| Аспект | OLMo 2 | OLMo Hybrid |
|--------|--------|-------------|
| Архитектура | Пост-нормализация, традиционное многоголовое внимание | Гибрид Gated DeltaNet + Full Attention |
| Эффективность | Стандартная | 2x data efficiency |
| Сложность | O(n²) | Преимущественно O(n) |

### Отличия от других гибридных архитектур

- **Kimi-Linear**: Использует соотношение 3:1 (KDA:MLA), аналогично OLMo Hybrid
- **Jamba**: Чередует Mamba и трансформерные слои
- **Qwen3-Next**: Использует гибридный подход с линейным вниманием и полным вниманием

## Контекст в области LLM

OLMo Hybrid продолжает тенденцию к созданию гибридных архитектур, которые сочетают эффективность линейных моделей с точностью полного внимания. Это соответствует общим направлениям развития эффективных архитектур LLM, описанным в обзоре ["Speed Always Wins"](../../../algorithms/neural_networks/transformers/speed_always_wins_survey.md) <!-- TODO: Broken link -->.

Модель демонстрирует, что стратегическое комбинирование различных типов слоёв позволяет достичь значительного повышения эффективности без потери качества.

## Технические детали

### Размер модели

- **OLMo Hybrid 7B**: Основная версия модели с 7 миллиардами параметров

### Архитектурные решения

- Чередование слоёв по фиксированной схеме 3:1
- Интеграция Gated DeltaNet для эффективной обработки последовательностей
- Сохранение полных слоёв внимания для критических операций

## Преимущества

- **Эффективность данных**: 2x сокращение необходимых данных для обучения (49% меньше токенов на MMLU, 35% на Common Crawl)
- **Вычислительная эффективность**: Линейная сложность большинства слоёв (75% Gated DeltaNet)
- **Качество**: Сохранение показателей MMLU на уровне полномерных моделей
- **Длинный контекст**: Превосходство на RULER при 64k токенах (85,0 против 70,9)
- **Масштабируемость**: Экономия данных растет с размером модели (1,3x на 1B → 1,9x на 70B)
- **Прозрачность**: Продолжение традиции OLMo по открытости кода и данных
- **Лицензирование**: Apache 2.0 License

## Ограничения

- **Сложность архитектуры**: Требует более тщательной настройки по сравнению с однородными архитектурами
- **Обучение**: Сложнее обучать из-за комбинации разных типов слоёв
