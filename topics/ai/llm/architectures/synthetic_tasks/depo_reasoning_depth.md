# Задача DEPO: Глубина рассуждений

## Краткое описание

Задача DEPO (Mental reasoning depth) - это синтетическая задача предварительного обучения, разработанная для оценки глубины рассуждений языковых моделей. Она представляет собой k-шаговую трансверсию над направленными перестановками, где модели вычисляют k-го преемника для каждого запроса q полностью внутренне, без промежуточных шагов, таких как Chain-of-Thought (CoT).

## Основные характеристики

### Формат задачи
- Каждый экземпляр задачи форматируется как: 2n токенов кодируют n направленных рёбер x_i → y_i, формируя случайную перестановку n узлов
- Задача требует k-шагового вычисления: модели нужно найти k-го преемника в последовательности для заданного запроса

### Параметры задачи
- N: максимальный размер перестановки (количество узлов)
- K: максимальная глубина рассуждений (k-шаговость)
- Во время обучения n выбирается из [3, N], а k ∈ [1, K]
- Длина контекста фиксирована на 2048 токенах

### Варианты DEPO
- **DEPO1**: Каждый узел занимает 1-2 токена из словаря размером 50, с N = 225, 300, 375 и K = 8
- **DEPO2**: Каждый узел занимает 5-7 токенов из словаря размером 4, с N = 75, 100, 125 и K = 16
- **DEPO с K=4**: Упрощённые версии DEPO1 и DEPO2 для более слабых моделей

## Цель задачи

Задача DEPO изолирует и оценивает способность языковой модели выполнять многошаговые вычисления без внешней подсказки или пошагового рассуждения. Использование CoT сокращает k-шаговую задачу до более простой 1-шаговой задачи ассоциативного воспоминания, поэтому задача направлена на оценку внутреннего (ментального) рассуждения.

## Применение в исследовании Canon слоёв

Задача DEPO использовалась для демонстрации эффективности Canon слоёв - легких архитектурных компонентов, которые способствуют горизонтальному потоку информации между соседними токенами. Canon слои значительно улучшают производительность в задачах типа DEPO (на 200-400%), что свидетельствует об улучшенной глубине рассуждений.

## Значение для архитектур языковых моделей

- Задача помогает выявлять различия в способности к глубокому рассуждению между разными архитектурами (трансформеры, линейное внимание, state-space модели)
- Позволяет проводить контролируемые сравнения архитектур в изолированных условиях
- Используется для оценки Canon слоёв, которые улучшают горизонтальный поток информации
