# Задача LANO: Иерархическая языковая структура

## Краткое описание

Задача LANO (Hierarchical language structure) - это синтетическая задача предварительного обучения, разработанная для оценки структурных рассуждений над иерархическими отношениями и зависимостями на большом расстоянии. В отличие от DEPO, BREVO и MANO, которые полагаются на явные пары ключ-значение (в контексте или знаниях), LANO ставит перед моделями задачу выводить неявные рекурсивные структуры в последовательностях и разрешать глобальные неоднозначности внутри них.

## Основные характеристики

### Формат задачи
- Использует синтетические наборы данных, построенные из контекстно-свободных грамматик (CFG)
- Обучающие последовательности состоят из допустимых по CFG предложений, разделённых токенами `<bos>`
- CFG разработаны с неоднозначностью на уровне токенов, где локальные токены (например, 1, 2, 3) недостаточны для прямого вывода их отображения в правила CFG
- Для решения этого требуется динамическое программирование для глобального отображения всей последовательности в допустимое рекурсивное применение правил CFG

### Сложность задачи
- Рассуждения растут в сложности худшего случая (O(n^3)) по мере увеличения длины последовательностей
- Требует сложного динамического программирования для разрешения глобальных неоднозначностей

## Цель задачи

Задача LANO оценивает способность языковой модели обрабатывать иерархические отношения и решать задачи структурного анализа - ключевые способности для понимания сложных языковых структур. В отличие от других задач, LANO требует от моделей выявлять неявные структуры, а не просто обрабатывать явные отношения в данных.

## Особенности задачи

- Проверяет способность модели к глобальному пониманию структуры, а не локальной обработке
- Использует рекурсивные структуры для имитации сложных языковых отношений
- Основана на динамическом программировании, что увеличивает сложность задачи
- Проверяет способность модели к иерархическому пониманию языка

## Применение в исследовании Canon слоёв

LANO входит в набор из пяти синтетических задач, используемых для оценки Canon слоёв. Эти задачи показывают, как Canon слои влияют на различные аспекты способностей языковых моделей, включая структурное понимание.

## Значение для архитектур языковых моделей

- Задача помогает выявлять различия в способности к обработке иерархических языковых структур между разными архитектурами
- Позволяет проводить контролируемые сравнения архитектур в изолированных условиях
- Используется для оценки Canon слоёв, которые могут улучшить обработку иерархических структур за счёт улучшенного потока информации
