# DeMix Corpora: Компрехенсивный 22T-токенный набор данных

## Краткое описание

DeMix Corpora - это комплексный 22-триллионный токенный набор данных высококачественных данных преподготовки с проверенными составами, предназначенный для открытых исследований в области предобучения LLM. Он представляет собой всеобъемлющий, высококачественный, крупномасштабный и тщательно смешанный ресурс, который можно напрямую использовать для преподготовки языковых моделей.

## Основная информация

### Цель и назначение

DeMix Corpora был создан для решения проблемы недостатка проверенных корпорусов с проверенными соотношениями данных, которые можно было бы напрямую использовать для крупномасштабной предварительной подготовки. В отличие от других публичных наборов данных, DeMix Corpora предлагает:

- Мультилингвальные возможности
- Математические и кодовые данные
- Проверенные составы смешивания данных

### Структура и состав

DeMix Corpora включает три этапа преподготовки:

1. **Этап 1 (≈14T токенов)**: Основной этап с акцентом на разнообразие данных
2. **Этап 2 (≈6T токенов)**: Повышенная доля высококачественных данных
3. **Этап 3 (≈2T токенов)**: Финальная доводка с максимальной долей специализированных данных

Общая структура включает:
- Общедоменные данные (FineWeb-Edu, DCLM, DOLMA и др.)
- Мультилингвальные данные
- Математические данные (MegaMath, FineMath, SwallowMath и др.)
- Данные кода (OpenCoder, StarCoder и др.)

### Качество и оценка

В таблице представлена мультидоменная производительность смешанных наборов данных после промежуточной подготовки 50B токенов:

| Набор данных | Общее | Код | Математика | Средний ранг ↓ |
|--------------|-------|------|-----|----------------|
| SmolLM-Corpus | 59.13 | 21.01 | 9.14 | 31.33 |
| Nemotron-Pretrain | 57.67 | 28.35 | 16.12 | 36 |
| **DeMix Corpora** | **58.77** | **22.49** | **15.76** | **24** |

DeMix Corpora демонстрирует превосходный баланс между общими и специализированными возможностями, обеспечивая лучший средний ранг 24.00.

## Пайплайн подготовки данных

### Сбор данных

Собранные данные охватывают:
- Общедоменные источники: FineWeb-Edu, DCLM-Baseline, DOLMA-v1.7, Ultra-FineWeb, NVIDIA Nemotron corpus
- Математические источники: FineMath, MegaMath, SwallowMath
- Кодовые источники: OpenCoder, SwallowCode
- Мультилингвальные и рассуждающие данные

### Процесс очистки

1. **Дедупликация**:
   - Глобальная точная дедупликация
   - Приблизительная дедупликация с использованием MinHash (24-граммы, 260 функций, 90% схожесть)

2. **Фильтрация по перплексии**:
   - Использование базовой модели Qwen3-0.6B как оценочной модели
   - Удаление образцов с экстремально низкой перплексией (~2% данных)
   - Ручная проверка высокоперплексных образцов для определения специфических порогов

3. **Фильтрация по FastText**:
   - Бинарный классификатор качества данных на основе FastText
   - Положительный набор: случайные данные, данные с низкой перплексией, высококачественные подмножества ELI5 и OpenHermes-2.5
   - Отрицательный набор: частично из Falcon-RefinedWeb и данные с высокой перплексией
   - Удаляет ~3% англоязычного корпуса

4. **Фильтрация качества китайских общедоменных корпусов**:
   - Оценка и выборка для китайских общедоменных веб-корпусов
   - Образовательные сигналы и сигналы с высокой информационной плотностью рассматриваются как суррогаты высококачественного текста
   - Пять уровней качества: неопределенный, крайне низкий, низкий, высокий, крайне высокий

5. **Маркировка данных на уровне экземпляров**:
   - Трехуровневая иерархическая таксономия
   - Маркировка с использованием Qwen3-235B-A22B
   - Использование 3.63M экземпляров с высокой достоверностью для обучения 4B-модели

## Примеры применения

1. **Прямоеприменение для преподготовки LLM** - благодаря проверенным составам, данные можно использовать без дополнительной оптимизации
2. **Бенчмаркинг новых методов преподготовки** - для оценки новых подходов к преподготовке
3. **Исследования влияния состава данных** - для изучения взаимосвязи между составом данных и производительностью моделей
