# DeMix: Decouple Searching from Training для оптимизации смешивания данных в преподготовке LLM

## Краткое описание

DeMix (Decouple Searching from Training Mix) - это новая фреймворковая система для оптимизации смешивания данных в преподготовке больших языковых моделей (LLM), которая использует слияние моделей для предсказания оптимальных соотношений данных. Вместо обучения прокси-моделей для каждой выборки смешивания данных, DeMix обучает компонентные модели на кандидатских наборах данных в масштабе и получает прокси для смешивания данных через взвешенное слияние моделей.

## Основная информация

### Проблема, которую решает DeMix

Определение эффективного состава данных является ключевым фактором в преподготовке LLM, где модели должны сбалансировать общую компетентность с показателями на сложных задачах, таких как математика и программирование. Однако идентификация оптимального состава остается открытой проблемой, поскольку существующие подходы либо полагаются на ненадежные эксперименты на мини-масштабе, либо требуют запредельно дорогого исследования на большом масштабе.

Существующие подходы:
- RegMix и CLIMB требуют обширных прокси-экспериментов
- Крошечные прокси-модели часто ненадежны из-за значительного разрыва в возможностях между прокси- и целевыми моделями
- Эти автоматизированные стратегии часто не обобщаются на сложные задачи, такие как математика и код

### Методология DeMix

1. **Подготовка кандидатских наборов данных**:
   - Сбор больших наборов данных из различных источников (общедоменные корпуса, математические данные, коллекции кода)
   - Применение строгой очистки данных, включающей дедупликацию, фильтрацию по перплексии, фильтрацию по FastText и т.д.
   - Выполнение оценки на уровне данных и категоризация очищенного корпуса в несколько кандидатских наборов данных

2. **Подготовка компонентных моделей**:
   - Для N кандидатских наборов данных создается N компонентных моделей, каждая из которых обучается индивидуально на одном из N кандидатских наборов данных
   - Все компонентные модели инициализируются из общей базовой модели, обученной с нуля на общедоменном наборе данных
   - Каждая компонентная модель дополнительно обучается на соответствующем доменно-специфичном кандидатском наборе данных (например, математика или код), смешанном с общими данными с фиксированным соотношением β

3. **Слияние моделей как прокси**:
   - Вместо обучения новых прокси-моделей для каждой выборки смешивания данных, DeMix использует слияние моделей
   - Компонентные модели объединяются, чтобы синтезировать практически неограниченное количество прокси-моделей почти без дополнительных затрат
   - Слияние происходит с использованием взвешенного арифметического среднего параметров моделей

4. **Оптимизация весов смешивания**:
   - Использование обученного предиктора (LightGBM) для отображения весов смешивания в оценки производительности
   - Итеративное выполнение процесса для уточнения прогнозов для высокорейтинговых соотношений

### Теоретическая основа

DeMix опирается на допущение о малых изменениях параметров: величина обновлений параметров Δ(D) остается относительно малой по сравнению с масштабом инициализации. При условии, что δ ≪ 1, сумма весовых дельт от моделей, обученных на отдельных наборах данных, близко аппроксимирует весовую дельту, полученную при обучении на их объединении:

Θ_mix ≈ Σ α_i Θ_i

Это позволяет использовать взвешенное слияние компонентных моделей как приближение к модели, обученной на соответствующем смешивании данных.

## Новые концепции и термины

1. **Компонентные модели** - отдельные модели, каждая из которых обучена на одном кандидатском наборе данных
2. **Прокси-модели** - модели, созданные путем взвешенного слияния компонентных моделей, используемые для оценки производительности различных смешиваний данных
3. **Слияние моделей как прокси** - подход, при котором вместо тренировки новых моделей используются арифметические операции над параметрами существующих моделей
4. **Децепляция поиска от обучения** - отделение процесса поиска оптимального смешивания от затрат на фактическое обучение моделей

## Примеры применения

1. **Оптимизация преподготовки LLM** - для поиска оптимальных соотношений данных до запуска дорогостоящего процесса обучения
2. **Поиск эффективных комбинаций данных** - для определения лучшего сочетания общих, математических и кодовых наборов данных
3. **Исследования в области преподготовки** - для проведения систематических исследований влияния состава данных на производительность моделей
