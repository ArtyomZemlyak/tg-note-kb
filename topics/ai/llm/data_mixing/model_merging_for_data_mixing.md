# Слияние моделей для оптимизации состава данных: технические аспекты DeMix

## Краткое описание

Этот файл описывает технические аспекты использования слияния моделей в рамках фреймворка DeMix для оптимизации состава данных в преподготовке LLM. В нем рассматриваются различные стратегии слияния, их эффективность и сравнительные характеристики.

## Основная информация

### Концепция прокси-моделей через слияние

Вместо тренировки прокси-моделей для каждого состава данных, DeMix использует компонентные модели, обученные на отдельных кандидатских наборах данных. Затем создаются прокси-модели путем взвешенного слияния этих компонентных моделей, где веса слияния представляют целевые соотношения состава данных.

Математически, смешенная модель M_j^mix вычисляется как:
M_j^mix = Σ α_j^i Θ_i

где Θ_i представляет компонентную модель соответствующего кандидатского набора данных D_i.

### Сравнительный анализ методов слияния

Были протестированы несколько методов слияния:

| Метод | Без гиперпараметров | ρ | Восстановление способностей |
|-------|-------------------|----|-----------------------|
| Linear | ✅ | 0.787 | 0.845 |
| Multi-SLERP | ✅ | 0.785 | 0.813 |
| Breadcrumbs | ✅ | 0.735 | 0.831 |
| DARE | ❌ | 0.757 | 0.835 |
| DELLA | ❌ | 0.784 | 0.778 |
| TIES | ❌ | 0.783 | 0.786 |

Linear merging оказался простым, эффективным и не требующим гиперпараметров методом, достигающим наилучшего показателя восстановления способностей и среднего ρ.

### Эффективность прокси-моделей

DeMix обеспечивает точные прокси-модели при значительно более низких затратах:
- При использовании компонентных моделей, обученных на 30B токенах, DeMix достигает среднего ρ 0.81 и top-25% ρ 0.59, потребляя всего 212B токенов
- В сравнении, подход на основе обучения достигает только 0.53 и 0.20 при сопоставимом бюджете
- Для достижения аналогичного уровня производительности традиционному подходу требуется запредельные 1344B токенов, что соответствует 6.4× увеличению затрат по сравнению с методом DeMix

### Пропорции кандидатских наборов данных

Исследование показало важность включения общих данных в кандидатские наборы:
- 50% общих данных: ρ 0.787, восстановление способностей 0.845
- 25% общих данных: ρ 0.667, восстановление способностей 0.796
- 0% общих данных: ρ 0.652, восстановление способностей 0.795

Отсутствие или недостаточная доля общих данных приводит к резкому снижению как ρ, так и показателя восстановления способностей.

### Метрики оценки

#### Согласованность прокси-моделей (Proxy Consistency)
1. **Точность прокси-моделей** - измерение согласованности рейтинга между прокси-моделями и эталонными моделями (ground-truth reference models), рассчитываемое как коэффициент корреляции Спирмена ρ между оценками бенчмарков прокси- и эталонных моделей

2. **Восстановление способностей** - количественная оценка степени сохранения производительности в объединенных моделях, определяемая как частное от средней оценки бенчмарка прокси-модели к соответствующей эталонной модели

#### Качество состава (Mixture Quality)
- Оценка финального соотношения состава путем обучения модели на 50B токенах с этим составом и оценки на бенчмарках общих, математических и кодовых задач
- Использование относительных рейтингов по сравнению с 96 эталонными моделями
- Применение усредненного по макроуровню рейтинга по бенчмаркам общего понимания языка, математического мышления и генерации кода как финальной метрики рейтинга

## Новые концепции и термины

1. **Модель-слияние как прокси** - использование арифметических операций над параметрами моделей для создания приближения к модели, обученной на смешивании данных
2. **Согласованность прокси-моделей** - степень соответствия ранжирования между прокси-моделями и эталонными моделями
3. **Восстановление способностей** - мера сохранения абсолютной производительности в объединенных прокси-моделях по сравнению с эталонными
4. **Коэффициент корреляции Спирмена** - непараметрическая мера ранговой ассоциации, используемая для оценки согласованности между прокси- и эталонными моделями

## Примеры применения

1. **Оптимизация состава данных без дополнительного обучения** - использование уже обученных компонентных моделей для тестирования множества различных соотношений данных
2. **Снижение вычислительных затрат на поиск оптимального состава** - значительное сокращение вычислительных затрат по сравнению с традиционными подходами
3. **Создание точных прокси-моделей для оценки состава** - генерация приближенных моделей для быстрой оценки производительности различных составов данных
