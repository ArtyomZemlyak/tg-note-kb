# T-Wix датасет

## Описание

T-Wix - это крупнейший на сегодняшний день открытый датасет русскоязычных гибридных рассуждений, созданный для тонкой настройки модели T-pro 2.0. Датасет содержит около 500,000 образцов и покрывает различные типы задач, включая общее следование инструкциям, задачи с длинным контекстом и цепочки рассуждений, сгенерированные учителем.

## Структура и содержание

### Объем и состав
- Приблизительно 500,000 образцов
- Основной язык: русский (около 90%)
- Сохранение небольшого количества английских данных (около 10%) для поддержания билингвальной компетентности

### Категории задач
- **Математика** - решение математических задач с пошаговыми объяснениями
- **Код** - программирование и анализ кода
- **Наука** - задачи из естественных наук
- **Общие инструкции** - различные задачи на следование инструкциям
- **Общие знания** - вопросы на энциклопедические знания
- **Письмо** - задачи на генерацию текста

### Уровни сложности
- **Школьный** - базовый уровень, соответствующий школьной программе
- **Студенческий** - средний уровень, соответствующий университетским знаниям
- **Профессорский** - продвинутый уровень, требующий экспертных знаний

## Процесс создания

### Источники данных
- 14 миллионов исходных инструкций из open-source корпусов
- Снижение до 468,000 образцов с помощью дедупликации и фильтрации
- Многоступенчатый процесс фильтрации для обеспечения качества

### Генерация ответов
- Использование учителей: Qwen3-235B-A22B и DeepSeek-V3
- 8 кандидатских завершений для каждой инструкции
- Отбор через RM-направленный (Reward Model) процесс

## Применение

### Обучение T-pro 2.0
- Использование в Supervised Fine-Tuning (SFT)
- Общий и рассуждающий компоненты обучения
- Поддержание баланса между различными доменами и уровнями сложности

### Оценка моделей
- Бенчмаркинг русскоязычных LLM
- Оценка способностей к рассуждению и следованию инструкциям

## Значение

T-Wix представляет собой важный ресурс для:
- Разработки русскоязычных LLM
- Исследования гибридных рассуждений
- Создания специализированных приложений на русском языке
- Стандартизации оценки русскоязычных моделей
