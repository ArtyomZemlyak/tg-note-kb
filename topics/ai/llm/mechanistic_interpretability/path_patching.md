# Path Patching

## Общее описание

Path Patching - метод механистической интерпретируемости (mechanistic interpretability), используемый для анализа влияния конкретных активаций в модели на конечный вывод. Суть метода заключается в замене активаций одной модели активациями другой модели или теми же активациями после некоторого изменения, вычислении логитов и анализе разницы.

## Принцип работы

1. **Извлечение активаций**: Извлекаются активации из определённых слоёв и модулей модели в процессе инференса
2. **Замена активаций**: Активации из одного состояния (например, базовой модели) заменяются на активации из другого состояния (например, модели после RL)
3. **Вычисление логитов**: Модель прогоняется с заменёнными активациями и вычисляются логиты
4. **Анализ разницы**: Сравниваются логиты до и после замены активаций
5. **Интерпретация**: Если разница значительна, то заменённая часть модели важна для изменения логитов и, соответственно, для формирования результата

## Применение

- **Анализ влияния компонентов модели**: Определение того, какие слои, головы внимания или MLP-блоки наиболее важны для формирования ответа
- **Выявление функциональных областей**: Обнаружение областей модели, ответственных за определённые вычисления
- **Сравнение моделей**: Анализ различий между моделями до и после обучения

## Примеры использования

### В контексте Spurious Rewards Paradox
- Сравнение двух моделей: до и после spurious RL
- Замена активаций базовой модели активациями модели после RLVR
- Наблюдение, что замена активаций из аттеншна вытягивает меньше скора, чем замена активаций MLP (то есть, MLP действительно хранит в себе знания)
- Обнаружение пиков на 18-20 слоях, названных "Functional Anchor"

## Преимущества

- **Направленный анализ**: Позволяет изолировать влияние конкретных компонентов модели
- **Интерпретируемость**: Результаты легко интерпретируются в терминах вклада компонентов
- **Гибкость**: Может применяться к различным частям архитектуры (внимание, MLP, резидуальные соединения)

## Ограничения

- **Вычислительная стоимость**: Требует множества прогонов модели
- **Сложность интерпретации**: Результаты могут быть сложны для интерпретации в случае сложных взаимодействий
- **Требует понимания архитектуры**: Эффективное использование требует глубокого понимания архитектуры модели

## Связь с другими методами

- **Activation Patching**: Более общий термин, включающий Path Patching как специфический вариант
- **Interventional Methods**: Path Patching относится к классу причинно-обусловленных методов анализа
