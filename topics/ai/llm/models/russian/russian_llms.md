# Русскоязычные языковые модели (Russian LLMs)

## Обзор

Русскоязычные языковые модели представляют собой класс моделей, оптимизированных для обработки и генерации текста на русском языке. Эти модели решают проблему недостаточной эффективности многоязычных моделей при работе с русским текстом, особенно касающуюся токенизации и культурного контекста.

## История развития

### Ранние разработки
- **ruGPT** - одна из первых русскоязычных моделей на основе GPT
- **YandexGPT** - коммерческая система с русскоцентричным предобучением
- **GigaChat** - семейство моделей от Сбер с адаптацией для русского языка

### Современные разработки
- **Saiga** - адаптация LLaMA с использованием self-instruct
- **RuAdapt** - адаптация Qwen для русского языка
- **Vikhr** - русскоязычная модель с акцентом на специфические задачи
- **T-pro 2.0** - современная гибридная модель с режимами рассуждений
- **T-pro 2.1** - улучшенная версия с акцентом на следование инструкциям и вызов инструментов

## Типы архитектур

### Монолитное предобучение
- Обучение с нуля на русскоязычных корпусах
- Пример: YandexGPT-5-Lite

### Адаптация многоязычных моделей
- Продолжение предобучения на русскоязычных данных
- Пример: T-pro 1.0, RuAdapt

## Особенности русскоязычных моделей

### Проблема токенизации
- Систематическая недо-токенизация русского текста в многоязычных моделях
- Плотные кириллические токенизаторы (как в T-pro 2.0) решают эту проблему
- Улучшение сжатия: снижение токенов на слово с 3.63 до 2.71

### Культурный и лингвистический контекст
- Лучшее понимание русской культуры, истории и лингвистических особенностей
- Повышенная точность в задачах, специфичных для русскоязычного пространства

## Бенчмарки для русскоязычных моделей

### Общие знания
- MERA - мультитасковый русскоязычный бенчмарк
- MaMuRAMu - бенчмарк для логических рассуждений
- ruMMLU-Pro - адаптация MMLU для русского языка

### Математические рассуждения
- ruAIME - адаптация AIME для русского языка
- ruMATH-500 - адаптация MATH-500
- T-Math - бенчмарк с задачами из российских олимпиад

### Диалоговые способности
- Arena Hard Ru - бенчмарк для диалоговых способностей
- WildChat Hard Ru - русскоязычные запросы от носителей языка

## Современные тенденции

### Гибридные рассуждения
- Поддержка обоих режимов: прямой ответ и цепочки рассуждений
- Пример: T-pro 2.0 с возможностью переключения между режимами

### Эффективность вывода
- Спекулятивное декодирование (EAGLE) для ускорения русскоязычного вывода
- Адаптация Multi-Token Prediction для русского языка

### Открытость и воспроизводимость
- Публикация весов моделей с открытым исходным кодом
- Предоставление датасетов и бенчмарков
- Интерактивные демонстрации моделей

## Значимые проекты

### T-pro 2.0
- Гибридная модель с кириллическим плотным токенизатором
- Поддержка гибридных рассуждений
- Интерактивная веб-демонстрация
- Бенчмарки и датасеты: T-Wix, T-Math
