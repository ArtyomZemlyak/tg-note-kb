# T-pro 2.0: Эффективная гибридная русскоязычная модель для рассуждений

## Описание

T-pro 2.0 - это русскоязычная LLM (Large Language Model), открытая модель для гибридных рассуждений и эффективного вывода, разработанная командой Gen-T из T-Tech, Москва, Россия. Модель поддерживает прямой ответ и генерацию цепочек рассуждений, использует плотный кириллический токенизатор и адаптированный EAGLE-пайплайн спекулятивного декодирования для уменьшения задержки.

## Архитектура и особенности

### Гибридные режимы рассуждений
- **Прямой ответ** - быстрый режим для простых задач
- **Цепочки рассуждений** - режим пошагового анализа для сложных задач
- Возможность переключения между режимами для балансировки скорости и точности

### Кириллический плотный токенизатор
- Модификация токенизатора Qwen3 с заменой 34k низкочастотных ненадписных токенов на кириллические
- Повышение эффективности токенизации русского языка: доля русских слов, токенизируемых в 2 токена и менее, увеличилась с 38% до 60%
- Сокращение среднего количества токенов на слово для русского языка с 3.63 до 2.71

### EAGLE-стиль спекулятивного декодирования
- Интеграция EAGLE-модуля спекулятивного декодирования
- Легковесная драфтовая модель на основе одного слоя Llama-2 с компонентом FR-Spec
- Ускорение вывода в 1.85× в стандартном режиме и 1.83× в режиме рассуждений
- Лучшая производительность в STEM-доменах (1.99×) по сравнению с гуманитарными (1.62×)

## Компоненты проекта

### T-Wix
- Наибольший открытый датасет русскоязычных гибридных рассуждений на сегодня (около 500k образцов)
- Покрывает общее следование инструкциям, задачи с длинным контекстом и генерируемые учителем цепочки рассуждений

### T-Math
- Бенчмарк русскоязычных задач по математике на уровне олимпиад для старших классов
- Содержит 331 задачу из Всероссийских и Московских олимпиад (1998-2025)
- Предназначен для оценки математических и аналитических способностей на русском языке

### Интерактивная веб-демонстрация
- Публичный веб-демо, доступный по адресу http://t-pro-2-0.streamlit.app
- Поддерживает сравнение режимов рассуждений и безних
- Включает телеметрию производительности (латентность, пропускная способность, коэффициенты принятия спекулятивных токенов)

## Обучение

### Промежуточное обучение инструкциям (instructional midtraining)
- 40B токенов из курируемых open-source инструкций, синтетических задач и параллельных корпусов
- 49% - русский текст, 36% - английский
- 34.6% - рассуждения, 28.8% - общие вопросы, 16.2% - математика

### Общее пост-обучение
- Общее и рассуждающее SFT (Supervised Fine-Tuning)
- DPO (Direct Preference Optimization) на 100k инструкциях
- Смешанные русско- и англоязычные данные для поддержания билингвальной компетентности

## Оценка производительности

### Общие знания и диалог
- 0.66 на MERA
- 0.697 на ruMMLU-Pro
- 91.1 на Arena Hard Ru
- 72.6 на WildChat Hard Ru

### Рассуждения
- Поддержка математических, научных и логических задач
- Высокая производительность как на русскоязычных, так и на англоязычных бенчмарках

## Значение

T-pro 2.0 представляет собой важный вклад в экосистему русскоязычных LLM, предоставляя:
- Открытую систему для изучения рассуждений на русском языке
- Набор инструментов для расширения и адаптации модели
- Платформу для воспроизводимых и расширяемых исследований
- Бенчмарки и датасеты для оценки русскоязычных моделей
