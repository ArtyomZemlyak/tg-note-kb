# Multi-Token Prediction (MTP) в Xiaomi MiMo-V2-Flash

## Общее описание

Multi-Token Prediction (MTP) - это технология, используемая в Xiaomi MiMo-V2-Flash для ускорения инференса и обучения. В отличие от традиционных методов, где декодирование ограничено пропускной способностью памяти из-за низкой арифметической интенсивности, MTP генерирует несколько черновых токенов за раз, которые затем валидируются основной моделью параллельно.

## Принцип работы

### Генерация нескольких токенов
- **Основная идея**: вместо предсказания одного следующего токена модель генерирует несколько черновых токенов за один проход
- **Параллельная валидация**: основная модель валидирует сгенерированные токены одновременно
- **Ускорение**: чистое ускорение инференса в 2,0–2,6 раза без увеличения операций ввода-вывода KV-кэша

### Архитектура MTP-блока
- **Легковесная структура**: MTP-блок в MiMo-V2-Flash спроектирован как легковесный компонент (0.33B параметров на блок)
- **Плотная сеть**: использует плотную сеть прямого распространения (FFN) вместо MoE
- **Механизм внимания**: опирается на такое же внимание скользящего окна, как и основная модель
- **Количество слоев**: используется 3-слойный MTP

## Технические детали

### Сравнение с традиционными методами
- **Традиционное декодирование**: ограничено пропускной способностью памяти
- **Низкая арифметическая интенсивность**: приводит к узким местам в производительности
- **MTP подход**: генерирует черновики и валидирует их параллельно, увеличивая арифметическую интенсивность

### Измерения эффективности
- **Длина принятой последовательности**: при использовании 3-слойного MTP составляет от 2,8 до 3,6 токенов
- **Ускорение**: чистое ускорение инференса в 2,0–2,6 раза
- **Операции KV-кэша**: без увеличения операций ввода-вывода

### Применение в обучении
- **Ускорение RL**: используется для ускорения rollouts в обучении с подкреплением
- **Обучение с предсказанием нескольких токенов**: позволяет модели планировать на несколько шагов вперед
- **Эффективность**: снижает время обучения за счет более информативных обновлений

## Сравнение с другими подходами

| Метод | Описание | Эффективность | Сложность |
|-------|----------|---------------|-----------|
| Традиционное декодирование | Один токен за шаг | Низкая | Низкая |
| MTP в MiMo-V2-Flash | Несколько токенов с параллельной валидацией | **Очень высокая** | Средняя |
| Speculative decoding | Использование меньшей модели для предварительной генерации | Высокая | Высокая |

## Преимущества

### Производительность
- **Увеличение скорости**: MTP в MiMo-V2-Flash выдает 150 токенов в секунду по API
- **Снижение узких мест**: устраняет проблемы с пропускной способностью памяти
- **Параллельная обработка**: повышает арифметическую интенсивность вычислений

### Эффективность использования ресурсов
- **Меньше операций ввода-вывода**: без увеличения операций KV-кэша
- **Легковесная реализация**: 0.33B параметров на блок
- **Оптимизация памяти**: использование SWA вместо GA в MTP-блоке

### Совместимость с архитектурой
- **Совместимость**: использует ту же архитектуру внимания, что и основная модель
- **Интеграция**: легко встраивается в существующую архитектуру MoE
- **Масштабируемость**: может быть адаптирован для разных размеров моделей

## Связь с другими технологиями

### В сочетании с MoE
- MTP особенно эффективен в Mixture-of-Experts архитектурах
- Позволяет лучше использовать разреженные вычисления
- Совместим с динамической маршрутизацией экспертов

### В пост-обучении
- Ускоряет процессы валидации при пост-обучении
- Повышает эффективность метода Multi-Teacher Online Policy Distillation
- Упрощает реализацию self-speculative decoding

## Значение и инновации

MTP в Xiaomi MiMo-V2-Flash представляет собой важную инновацию в области ускорения инференса LLM. Технология решает ключевую проблему - узкое место в пропускной способности памяти - путем увеличения арифметической интенсивности вычислений. Это позволяет достичь высокой скорости инференса при сохранении качества генерации.
