# Физика языковых моделей: Часть 2.1, Математическое мышление в школе и скрытый процесс рассуждения

## Краткое описание
Этот документ представляет собой резюме научной статьи "Physics of Language Models: Part 2.1, Grade-School Math and the Hidden Reasoning Process", посвященной изучению того, как языковые модели решают математические задачи на уровне начальной школы. Исследование использует синтетические данные для изучения процессов рассуждения моделей без проблем с загрязнением данных.

## Основная информация

### Ключевые вопросы исследования
1. Могут ли языковые модели по-настоящему развивать навыки рассуждения или просто запоминают шаблоны?
2. Каков скрытый (ментальный) процесс рассуждения модели?
3. Решают ли модели математические задачи с использованием навыков, аналогичных или отличающихся от человеческих?
4. Развивают ли модели, обученные на наборах данных GSM8K, навыки рассуждения, выходящие за рамки решения GSM8K?
5. Какой ментальный процесс вызывает ошибки в рассуждениях?
6. Насколько большой или глубокой должна быть модель для эффективного решения математических задач уровня GSM8K?

### Основные результаты
#### Результат 2: Обобщение
- Модель GPT2, предварительно обученная на синтетическом наборе данных iGSM, не только достигает 99% точности в решении математических задач из того же распределения, но и обобщается на задачи с более длинными рассуждениями, чем те, что были во время обучения.
- Это указывает на то, что модель действительно может изучать навык рассуждения, а не просто запоминать шаблоны решений.

#### Результат 3: Кратчайшие решения
- Модель учится генерировать кратчайшие решения, почти всегда избегая ненужных вычислений.
- Это предполагает, что модель составляет план до генерации, чтобы избежать вычисления величин, которые не нужны для решения задачи.

#### Результат 4: Ментальный процесс
- Модель (мысленно!) предварительно обрабатывает полный набор необходимых параметров до начала генерации.
- Люди тоже делают такую предварительную обработку, хотя записывают это на черновиках.

#### Результат 5: Ненужные, но важные навыки
- Модель также изучает ненужные, но важные навыки после предварительного обучения, такие как все-парные зависимости.
- До того как задан вопрос, она уже (мысленно!) вычисляет с хорошей точностью, какие параметры зависят от каких, даже если некоторые из них не нужны для решения математической задачи.
- Это первые доказательства того, что языковая модель может изучать полезные навыки, выходящие за рамки необходимых для соответствия предварительным обучающим данным.

#### Результат 6: Объяснение ошибок
- Модель совершает систематические ошибки, которые можно объяснить путем зондирования внутренних состояний.
- Иногда эти ошибки можно предсказать до того, как модель начнет генерировать ответы, что делает их независимыми от случайного процесса генерации.
- GPT-4/4o также совершает подобные ошибки (хотя мы не можем зондировать их внутренние состояния).

#### Результаты 7 и 8: Глубина модели
- Глубина языковой модели имеет критическое значение для способности к рассуждению.
- Например, 16-слойная, 576-мерная трансформерная модель решает более сложные задачи (по длине рассуждений), чем 4-слойная, 1920-мерная модель, несмотря на то, что последняя вдвое больше.
- Это справедливо даже при использовании Chain-of-Thought (CoT).

## Новые концепции и термины

### iGSM (infinite GSM)
- Синтетический набор данных для генерации разнообразных математических задач начальной школы.
- Используется параметры ip (количество экземпляров параметров) и op (количество операций решения) для контроля сложности.
- Сложность данных увеличивается как функция от них: iGSM_op ≤ op, ip ≤ ip

### V-зондирование (V-Probing)
- Почти линейный метод зондирования для проверки, знает ли предварительно обученная модель произвольную функцию func(A) для параметра A, описанного в тексте.
- Использует небольшое обновление низкого ранга на уровне встраивания для учета изменения задачи.
- Позволяет исследовать скрытые рассуждения модели.

### Уровни навыков рассуждения
- **Уровень 0**: вычисление всех параметров во время генерации (механическое вычисление)
- **Уровень 1**: вычисление только необходимых параметров для получения кратчайших решений (рассуждение с планированием)
- **Уровень 2**: вычисление всех парных зависимостей даже для ненужных параметров (рассуждение, выходящее за рамки необходимого)

### Задачи зондирования
- **nece(A)**: является ли параметр A необходимым для вычисления ответа
- **known(A)**: вычислен ли параметр A
- **dep(A,B)**: рекурсивно зависит ли параметр A от параметра B
- **value(A)**: значение параметра A (число от 0 до 22)
- **can_next(A)**: можно ли вычислить A в следующем предложении решения
- **nece_next(A)**: удовлетворяет ли параметр A обоим условиям can_next(A) и nece(A)

## Структура задач
Исследование использует сложную структуру задач:
1. **Иерархическая категоризация**: 4 предопределенных иерархических категорий (например, [Школа, Класс, Рюкзак, Канцелярия])
2. **Структурный граф**: описывает, какие подэлементы могут появляться под каким элементом
3. **Граф зависимостей**: направленный ациклический граф, описывающий зависимости между параметрами
4. **Проблемные зависимости**: три типа - прямая зависимость (A = 5 × (X + Y)), зависимость экземпляра ('в каждом классе X стульев, и есть Y классов'), и неявная зависимость ('Боб имеет в 3 раза больше фруктов, чем Алиса')

## Пример задачи и решения
Проблема (простая):
"The number of each Riverview High's Film Studio equals 5 times as much as the sum of each Film Studio's Backpack and each Dance Studio's School Daypack. The number of each Film Studio's School Daypack equals 12 more than the sum of each Film Studio's Messenger Backpack and each Central High's Film Studio. The number of each Central High's Film Studio equals the sum of each Dance Studio's School Daypack and each Film Studio's Messenger Backpack. The number of each Riverview High's Dance Studio equals the sum of each Film Studio's Backpack, each Film Studio's Messenger Backpack, each Film Studio's School Daypack and each Central High's Backpack. The number of each Dance Studio's School Daypack equals 17. The number of each Film Studio's Messenger Backpack equals 13. How many Backpack does Central High have?"

Решение:
"Define Dance Studio's School Daypack as p; so p = 17. Define Film Studio's Messenger Backpack as W; so W = 13. Define Central High's Film Studio as B; so B = p + W = 17 + 13 = 7. Define Film Studio's School Daypack as g; R = W + B = 13 + 7 = 20; so g = 12 + R = 12 + 20 = 9. Define Film Studio's Backpack as w; so w = g + W = 9 + 13 = 22. Define Central High's Backpack as c; so c = B * w = 7 * 22 = 16. Answer: 16."
