# SDFT: Self-Distillation Fine-Tuning

## Краткое описание

Self-Distillation Fine-Tuning (SDFT) — это метод машинного обучения, который позволяет осуществлять on-policy обучение напрямую из экспертных демонстраций. SDFT использует возможности in-context learning модели, применяя модель, условленную на демонстрации эксперта, в качестве собственного учителя, генерируя сигналы on-policy обучения, которые сохраняют предыдущие навыки модели при освоении новых.

## Основные концепции и термины

### Проблема off-policy обучения
- **Supervised Fine-Tuning (SFT)** — доминирующая парадигма для инструкт-тюнинга, но страдает от off-policy природы
- **Катастрофическое забывание** — проблема, при которой модель, обученная новым задачам, теряет предыдущие навыки
- **Compounding errors** — накопление ошибок, возникающее когда модель отклоняется от распределения состояний, покрытых в демонстрациях

### On-policy обучение
- **On-policy обучение** — обучение на траекториях, индуцированных самой моделью
- **Преимущества on-policy методов** — лучшая обобщающая способность и меньшее забывание по сравнению с off-policy подходами

### Self-Distillation Framework
- **Student Model** — основная модель, получающая только запрос x, π_θ(·|x)
- **Teacher Model** — та же модель, но условленная на запрос и демонстрацию, π(·|x, c)
- **On-policy distillation** — процесс обучения студента на траекториях, сгенерированных самим студентом

## Архитектура и методология

### Основной процесс
SDFT работает по следующему принципу:

1. **Student Mode**: Студентская модель генерирует ответ y, основываясь исключительно на запросе x
2. **Teacher Mode**: Учительская модель обрабатывает тот же запрос x, но к нему в контекст добавляется релевантная экспертная демонстрация c

Обучающий сигнал получается через минимизацию **обратной дивергенции Кульбака-Лейблера (reverse KL)** между распределениями студента и учителя на токенах, сгенерированных студентом:

`L(θ) = D_KL(π_θ(·|x) || π(·|x, c)) = E_{y ~ π_θ(y|x)}[log(π_θ(y|x) / π(y|x, c))]`

### EMA-учитель для стабильности
Ключевое инженерное решение — параметризация учителя. Использование замороженной базовой модели в качестве учителя дает плохие результаты, а использование "живых" параметров студента для учителя вызывает нестабильность из-за петель обратной связи. Оптимальное решение — использование экспоненциального скользящего среднего (EMA) весов студента для параметров учителя:

`φ ← αθ + (1 - α)φ`

Это обеспечивает стабильную, но адаптивную цель, которая производит валидные цепочки рассуждений, оставаясь достаточно близкой к распределению студента для полезного сигнала.

### Self-Distillation как Inverse RL
SDFT можно интерпретировать в рамке IRL (Inverse Reinforcement Learning). Основная идея — предположение о том, что сильная предобученная модель, условленная на качественной демонстрации c, аппроксимирует оптимальную политику:
`π*(y|x) ≈ π(y|x, c)`

Цель состоит в обучении политики студента π_θ(·|x) так, чтобы она соответствовала распределению политики учителя π(·|x, c). Критически важно, что это выравнивание происходит на траекториях, семплированных из *студента*, что обеспечивает on-policy режим.

## Примеры применения

### Sequential Learning
SDFT особенно эффективен в сценариях последовательного обучения:
- **Science Q&A**: Научное рассуждение на уровне бакалавриата
- **Tool Use**: Использование API-инструментов
- **Medical**: Клиническое рассуждение

В отличие от SFT, SDFT может осваивать новые навыки, не теряя предыдущие:

```
Sequential Learning Experiment:
- Модель обучается последовательно трем задачам
- SDFT способен обучаться каждой, сохраняя производительность на других
- SFT показывает падение производительности на предыдущих задачах при обучении следующим
```

### Chain-of-Thought обучение
SDFT может научить цепочкам рассуждений, даже если обучающие данные содержат только финальные ответы. Это происходит потому, что учитель, видя правильный ответ, естественным образом "додумывает" валидный путь рассуждения, который затем учится имитировать студент.
