# Обнаружение смещений в LLM с помощью топологического анализа данных

## Общее описание

Обнаружение смещений в больших языковых моделях (LLM) с помощью топологического анализа данных (TDA) представляет собой новаторский подход к идентификации и количественной оценке предвзятости, присутствующей в моделях. В отличие от традиционных методов, которые измеряют смещение с помощью вероятностей, присваиваемых различным предложениям, или вложений слов, TDA позволяет выявлять, какие именно части модели ответственны за смещения по отношению к конкретным группам идентичности.

## Методы и подходы

### 1. Метрика Wasserstein Bias

Метрика, основанная на топологических особенностях, измеряет различия между:
- Стереотипными продолжениями (stereotype continuations)
- Анти-стереотипными продолжениями (anti-stereotype continuations)
- Нерелевантными продолжениями (irrelevant continuations)

Метрика вычисляется как:

S_l,h,k = σ²_A,l,h,k - σ²_S,l,h,k / σ²_I,l,h,k

Где:
- σ²_A,l,h,k: k-мерная дисперсия кластера анти-стереотипов для слоя l и головки h
- σ²_S,l,h,k: k-мерная дисперсия кластера стереотипов
- σ²_I,l,h,k: k-мерная дисперсия кластера нерелевантных продолжений

### 2. Фильтрация ε и диаграммы устойчивости

- Используется для создания симплициальных комплексов из графов внимания
- Применяется фильтрация по пороговому значению ε для создания бинарных графов
- Диаграммы устойчивости представляют топологические особенности как точки (b_i, d_i) на плоскости, где b_i - время рождения, d_i - время смерти

### 3. Приближенное распределение псевдообратной функции

- Используется приближение с параметром сглаживания N для упрощения вычислений
- Позволяет рассчитать приближенное расстояние Wasserstein между двумя графами

## Основные результаты исследований

### 1. Горячие точки смещения

Исследования показали, что смещения для определенных категорий (например, гендер или профессия) сосредоточены в специфических головках внимания, действующих как "горячие точки":
- Смещения по гендеру и расе наиболее выражены в этих "горячих точках"
- Горячие точки для гендера и профессии часто находятся рядом друг с другом
- Это указывает на то, что искаженное представление этих категорий может быть связано

### 2. Классификация смещений по категориям

- **Гендер**: В категориях, связанных с гендером, наиболее негативно представлены такие группы, как "Sister" и "Herself"
- **Профессия**: "Psychologist" и "Commander" показали более негативные представления, в то время как "Software Developer" и "Assistant" - менее негативные
- **Раса**: "Sierra Leone" и "Cape Verde" были представлены более негативно, а "Lebanon" и "Norway" - более позитивно
- **Религия**: "Brahmin" и "Muslim" показали более позитивные значения, в то время как "Bible" - более негативное

### 3. Паттерны внутри категорий

- Среднее значение метрики для каждой группы не значительно отличается от 0, что указывает на отсутствие систематического смещения в целом
- Однако стандартное отклонение между классами внутри каждой категории смещения на порядок больше, чем среднее, что указывает на неравномерное распределение смещения между подгруппами

## Техническая реализация

### 1. Набор данных и модели

- Использовалась модель GPT-2 для оценки
- Применялся датасет StereoSet, содержащий 2123 примера межпредложенийного формата
- Датасет включает данные для смещений по гендеру, профессии, расе и религии

### 2. Определения и обозначения

- D_source, D_S, D_A, D_I: наборы контекстных предложений, стереотипных, анти-стереотипных и нерелевантных продолжений
- M_l,h_S, M_l,h_A, M_l,h_I: матрицы внимания из l-го слоя и h-й головки для различных типов продолжений
- Θ_l,h,k_S, Θ_l,h,k_A, Θ_l,h,k_I: наборы псевдообратных распределений k-мерных топологических особенностей

### 3. Перестановочный тест

- Используется для оценки статистической значимости результатов
- Позволяет определить вероятность получения статистики, превышающей наблюдаемое значение
- Рассчитывается p-значение для определения статистической значимости

## Практические применения

### 1. Целенаправленный дебиасинг

- Позволяет идентифицировать конкретные головки внимания, которые вносят вклад в искаженное представление конкретных групп
- Может использоваться для настройки только этих головок с целью уменьшения смещения без снижения общей производительности модели
- Предоставляет геометрический критерий для определения, какие головки должны быть нацелены на дебиасинг

### 2. Количественная оценка эффективности дебиасинга

- Предоставляет объективную метрику для оценки эффективности методов дебиасинга
- Позволяет сравнивать различные подходы к устранению смещений
- Может использоваться для мониторинга смещений в различных моделях

### 3. Анализ трансформеров

- Метод может быть применен к различным архитектурам трансформеров
- Позволяет анализировать, как смещения распределены по различным слоям и головкам
- Может использоваться для сравнения смещений в разных моделях

## Ограничения метода

### 1. Ограничения датасета

- Использование датасета StereoSet, который может не включать все релевантные группы
- Датасет имеет известные ограничения, описанные другими исследователями
- Результаты могут не быть всеобъемлющими из-за ограничений датасета

### 2. Приближение распределений

- Использование приближения для псевдообратных распределений топологических особенностей
- Приближение может вносить ошибки в статистику
- Однако это необходимо для обеспечения вычислительной осуществимости

### 3. Интерпретация метрик

- Метрика напрямую не связана с реальными выходами модели
- Не должна использоваться как абсолютно точная мера смещения в одной группе
- Должна использоваться для сравнения смещений между группами

- Исследование причин увеличенного искаженного представления в начальных и конечных головках слоя

### 2. Расширение на другие датасеты

- Применение метода к другим датасетам, содержащим различные группы идентичности
- Использование более длинных входных предложений или даже абзацев
- Расширение метрики на датасеты на других языках

### 3. Комбинация с другими методами

- Интеграция с другими методами обнаружения и устранения смещений
