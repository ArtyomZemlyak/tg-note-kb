# Text-to-LoRA: Мгновенная адаптация трансформеров через описания задач

## Краткое описание

**Text-to-LoRA** — это комплементарная система к Doc-to-LoRA, которая генерирует LoRA-адаптеры из натурально-языковых описаний задач. Метод решает проблему адаптации моделей, заменяя дорогие пайплайны тонкой настройки одним прямым проходом.

## Основная информация

### Архитектура: Генерация адаптеров из текста

Text-to-LoRA использует ту же философию **амортизации стоимости обновлений**, что и Doc-to-LoRA:

| Фаза | Стоимость | Частота | Что происходит |
|------|-----------|---------|----------------|
| **Мета-обучение** | Дорого | Один раз | Обучение гиперсети для генерации LoRA из описаний задач |
| **Развертывание** | Дешево | Часто | Описание задачи → Гиперсеть → LoRA-адаптер (один прямой проход) |

### Конвейер Text-to-LoRA

```
Описание задачи → Task Embedding → Гиперсеть → LoRA-адаптер → Адаптированная LLM
```

**Процесс работы:**

1. Натурально-языковое описание задачи кодируется в task embedding
2. Гиперсеть выдает все веса LoRA за один прямой проход
3. Сгенерированный адаптер направляет замороженную базовую модель к описанному поведению

## Технические детали

| Компонент | Спецификация |
|-----------|--------------|
| **Базовая модель** | Mistral-7B-Instruct |
| **LoRA цель** | q_proj и v_proj, ранг 8, все слои (~3.4M параметров) |
| **Данные обучения** | Lots-of-LoRAs collection (479 задач из SNI) |
| **Объективы обучения** | Reconstruction loss ИЛИ Supervised Fine-Tuning (SFT) loss |

## Ключевые возможности

### Мгновенная генерация

- **Один прямой проход** — генерация адаптеров мгновенно из описаний задач
- **Zero-shot возможность** — генерация полезных адаптеров для невиданных задач
- **Масштабируемость** — производительность улучшается с большими гиперсетями и большими данными обучения

### Модульные обновления

- Компактные, сменяемые адаптеры для разных задач
- Быстрая адаптация к новым форматам вывода и стилям
- Возможность экспериментирования без повторных jobs тонкой настройки

## Применение

| Сценарий использования | Преимущество |
|------------------------|--------------|
| **Быстрое прототипирование задач** | Написание описания вместо сбора данных и тонкой настройки |
| **Адаптация формата/стиля** | Быстрая адаптация моделей к новым форматам вывода |
| **Специализированные задачи** | Генерация адаптеров для конкретных задач по требованию |
| **Экспериментирование** | Более быстрая итерация без повторных jobs тонкой настройки |

## Преимущества

### Эффективность

- **Замена дорогого пайплайна**: Избегание сбора данных, разметки и многоступенчатого обучения
- **Мгновенное развертывание**: Адаптеры генерируются за субсекунды
- **Гибкость**: Легкое переключение между задачами через смену адаптеров

### Масштабирование

- Производительность улучшается с:
  - Большими размерами гиперсетей
  - Большими объемами данных обучения
  - Разнообразием задач в обучающей выборке

## Ограничения

1. **Реконструкция vs. Обобщение**: Воспроизведение известных адаптеров ≠ робастное описание-в-LoRA отображение
2. **Зависимость от качества описания**: Результат зависит от точности и полноты описания задачи
3. **Ограниченная глубина адаптации**: Может не достигать качества полноценной тонкой настройки на специфичных задачах
4. **Требует разнообразных данных обучения**: Нужна большая коллекция задач для хорошего обобщения

## Сравнение Doc-to-LoRA и Text-to-LoRA

| Аспект | Doc-to-LoRA | Text-to-LoRA |
|--------|-------------|--------------|
| **Проблема** | Дорогая контекстная дистилляция | Дорогой пайплайн тонкой настройки |
| **Вход** | Документ (текст или визуальный через VLM) | Натурально-языковое описание задачи |
| **LoRA хранит** | Фактологические знания из документа | Поведение/навык для конкретной задачи |
| **Применение** | Долгосрочная память | Адаптация модели |
| **Базовая модель** | Gemma-2-2b-it | Mistral-7B-Instruct |
| **LoRA цель** | MLP слои | q_proj и v_proj |

## Будущее видение: Unified Update Generator

Авторы видят **фундаментальную гиперсеть**, которая объединяет оба подхода:

- Единая система, поглощающая описания задач, документы или опыт
- Общий «update API» для LLM
- Модульные, компонуемые адаптеры из разных источников супервизии
