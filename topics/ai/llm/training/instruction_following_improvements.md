# Улучшения следования инструкциям (Instruction Following) в современных LLM

## Определение

Следование инструкциям (Instruction Following, IF) - это способность LLM точно и последовательно выполнять пользовательские инструкции, а не просто генерировать правдоподобный текст. Типичные примеры включают: "ответить строго в формате JSON", "не добавлять объяснения", "следовать заданной схеме", "оставаться в рамках ограничения по длине" и т.д.

## Подходы к улучшению

### Синтетическая цепочка генерации данных (AutoIF-approach)

Для улучшения способности моделей следовать инструкциям разработаны специализированные синтетические цепочки генерации данных на основе подхода AutoIF:

- Генерация и валидация инструкций на основе семян IFEval
- Генерация проверяемых функций, которые автоматически проверяют правильность следования инструкции
- Сопоставление сгенерированных инструкций с образцами из датасета SFT
- Генерация и валидация завершений, удовлетворяющих ограничениям IF
- Балансировка данных по доменам и уровням сложности

### GRPO (Generative Reward Policy Optimization)

Для усиления способностей следования инструкциям используется GRPO, при котором:

- Каждый образец имеет набор функций проверки, позволяющих автоматически проверять корректность ответа
- Базовое вознаграждение - это точность следования инструкции
- Возможна проблема "взлома вознаграждения", когда модель адаптируется к функциям проверки вместо выполнения инструкций

### Решение проблемы взлома вознаграждения

Для решения проблемы взлома вознаграждения экспериментировались различные комбинации верифицируемых и семантических вознаграждений, включая:

- Усиленный штраф KL-дивергенции
- Штраф за длину ответа
- Штраф на основе модели вознаграждения
- Штраф на основе LLM-as-a-Judge

Лучшим решением оказалась комбинация функций проверки с штрафом на основе модели вознаграждения, что позволяло:
- Поддерживать строгий контроль над выполнением инструкций
- Предотвращать деградацию качества и осмысленности ответов

## Применение в T-Pro 2.1

В T-Pro 2.1 улучшения следования инструкциям были достигнуты с помощью:
- Специальной синтетической цепочки генерации данных
- Использования GRPO с проверочными функциями
- Комбинации верифицируемых вознаграждений с штрафом на основе модели вознаграждения

## Оценка

Оценка способностей следования инструкциям осуществляется с помощью локализованных версий бенчмарков, таких как IF-eval на русском языке.

## Значение

Улучшения следования инструкциям особенно важны для:
- Агентских сценариев, где требуется строгое соблюдение формата
- Приложений, где критична точность выполнения команд
- Систем, взаимодействующих с внешними инструментами
