# Semantic Tube Prediction (STP): Прорыв в эффективности данных для LLM через JEPA

## Обзор

**Semantic Tube Prediction (STP)** — это вспомогательная целевая функция для self-supervised learning, которая заставляет скрытые состояния (hidden states) LLM двигаться по плавным, локально линейным траекториям (геодезическим линиям) во время обучения. Ограничивая эволюцию скрытых состояний узкой «трубой» вокруг этих линий, STP отделяет истинный семантический сигнал от статистического шума, при этом не требуя ручной аугментации данных, характерной для предыдущих архитектур типа JEPA.

**Авторы:** Hai Huang (Atlassian), Yann LeCun (NYU), Randall Balestriero (Brown)

**Ключевое достижение:** LLM достигает точности стандартного файнтюнинга на всём датасете, используя **в 16 раз меньше данных** на датасете NL-RX-SYNTH.

## Ключевые концепции

### 🚧 Проблема следующего токена

Авторегрессионное обучение упирается во врождённые недостатки стандартного лосса кросс-энтропии для предсказания следующего токена (Next Token Prediction, NTP):

- **Локальная целевая функция** жёстко смешивает глобальный семантический смысл последовательности с поверхностным статистическим шумом сэмплирования дискретных токенов
- **Exposure bias**: На инференсе модель становится уязвимой к дрейфу скрытых состояний в неестественные области и, в конечном итоге, к **коллапсу мод (mode collapse)**
- Предыдущие попытки решения через **LLM-JEPA** добавили серьёзные сложности: необходимость ручного создания пар «вопрос-ответ», вспомогательные сети-предикторы, вычислительные издержки на дополнительные forward pass'ы

### 🌌 Геодезическая гипотеза

Авторы предлагают **Геодезическую Гипотезу**, которая рассматривает генерацию текста как непрерывную физическую систему:

1. **Дискретные токены проецируются в непрерывное векторное пространство** (векторы x_t), формируя последовательность скрытых состояний h_t
2. **Оптимальная последовательность токенов образует гладкое многообразие (manifold)** в этом пространстве
3. **Латентная траектория описывает геодезическую линию** — кратчайший путь между двумя семантическими концептами
4. **Геодезические линии локально линейны почти везде** (поскольку многообразие гладкое)

**Следствие:** Истинный семантический сигнал последовательности движется по прямой, а любые ортогональные отклонения от этого пути представляют собой бесполезный статистический шум.

### 🧮 Семантическая труба (Semantic Tube)

**Семантическая труба** — это энергетическая граница, которая заставляет репрезентации плотно группироваться вокруг идеальной прямолинейной траектории.

#### Математическая формулировка

Для индексов s < r < t определяется:

- **Шум (noise):** `(h_r - h_s) ⊥ (h_t - h_s)` — компонента h_r - h_s, перпендикулярная h_t - h_s
- **Сигнал (signal):** `(h_r - h_s) ∥ (h_t - h_s)` — компонента, параллельная h_t - h_s

**STP loss:**
```
L = L_NTP + λ * L_STP
L_STP = E[1 - cos(h_t - h_r, h_r - h_s)]
```

где:
- `L_NTP` — стандартный кросс-энтропийный лосс для предсказания следующего токена
- `λ` — гиперпараметр, контролирующий силу STP loss (оптимально λ ≈ 0.02)
- `cos()` — косинусное сходство между векторами

#### Связь с JEPA

STP черпает вдохновение из **Joint-Embedding Predictive Architecture (JEPA)**:
- В отличие от LLM-JEPA, STP **не требует явных multi-view аугментаций**
- Любой сегмент последовательности токенов выравнивается с глобальной траекторией
- **Предиктор сводится к тождественной функции** (identity function) благодаря локальной линейности
- Это устраняет необходимость в ручном создании структур данных с двумя представлениями

## Архитектура и реализация

### Обучение (Training)

**Формулировка через ODE:**
Процесс обучения LLM моделируется как решение обыкновенного дифференциального уравнения (ODE) в пространстве последовательностей токенов R^(T × d_model):

```
dx_≤t/dt = ũ ∘ f̃(x_≤t)
```

где `f̃` и `ũ` — функции сошедшейся сети.

**Теорема Пикара-Линделёфа** гарантирует, что если ũ ∘ f̃(·) и её частные производные непрерывны, ODE допускает единственное решение для заданного начального условия. Следовательно, последовательности, сгенерированные из различных промптов, не могут пересекаться, что теоретически исключает mode collapse.

### Инференс (Inference)

На инференсе процесс моделируется как **Стохастическое Дифференциальное Уравнение (SDE)** с членом броуновского движения:
- Траектория дрейфует в конус, радиус которого масштабируется как `∝ σ_t * √t`
- STP минимизирует этот дрейф, улучшая SNR

### Практические аспекты

- **Минимальные вычислительные издержки:** STP loss требует только вычисления косинусного сходства между скрытыми состояниями
- **Не требует дополнительных forward pass'ов:** В отличие от LLM-JEPA, все необходимые h_s, h_r, h_t вычисляются в одном проходе
- **Случайный выбор индексов:** Индексы s < r < t выбираются случайно, что устраняет необходимость в ручном scaffolding
- **Применяется только при обучении:** На инференсе STP loss не используется

## Эмпирические результаты

### Улучшение точности

**На различных датасетах** (Llama-3.2-1B-Instruct):
- NL-RX-SYNTH, NL-RX-TURK — синтаксические задачи
- GSM8K — математические задачи
- Spider — text-to-SQL
- NQ-Open — open-domain QA
- HellaSwag — commonsense reasoning

STP показывает значительное улучшение по сравнению с regular fine-tuning и LLM-JEPA.

**На различных семействах моделей:**
- Llama-3, Gemma-2-2b-it, OpenELM-1B-Instruct, OLMo-2-0425-1B-Instruct
- Qwen3-1.7B, DeepSeek-R1-Distill-Qwen-1.5B

**На различных размерах моделей:**
- Llama-3 1B, 3B, 8B — STP масштабируется с размером модели

### Эффективность данных

**Ключевой результат на NL-RX-SYNTH:**
- При уменьшении датасета в **2 раза** — незначительное падение точности
- При уменьшении датасета в **16 раз** — точность соответствует full-dataset standard fine-tuning
- В contrast, regular fine-tuning suffers significant drop immediately when halved

Это прямо нарушает **data term Chinchilla-style scaling laws**, демонстрируя, что геометрические априорные предположения могут обходить прямолинейное наращивание данных.

### Ландшафт лосса

**Наблюдения:**
1. `L_NTP` alone не минимизирует автоматически `L_STP`
2. С Semantic Tube, `L_STP` продолжает уменьшаться даже после plateau `L_NTP`
3. Увеличение `λ` на логарифмической шкале линейно уменьшает `L_STP`, в то время как `L_NTP` остаётся стабильным
4. При `λ = 0` (regular fine-tuning), `L_STP ≈ 1.4` — траектория напоминает erratic Brownian motion
5. При `λ = 0.08`, `L_STP drops to 0.6` — существенно более гладкий путь

## Ограничения и предостережения

### ⚠️ Ограничения локальной линейности

Главное ограничение STP проистекает из базового предположения о **локальной линейности**:

1. **Глобально язык остаётся сложным неевклидовым многообразием**
   - Геодезические линии прямые только в достаточно малых окрестностях
   - При переходе между разными семантическими темами (длинный контекст) предположение нарушается

2. **Риск «срезания углов» на многообразии**
   - Принудительное навязывание коллинеарности на макроскопических семантических сдвигах
   - Может вредить способности модели ориентироваться в сложных, извилистых цепочках рассуждений

3. **Требует тщательной настройки:**
   - Гиперпараметр `λ` должен быть мал (λ ≪ 1)
   - Ограничения на дистанцию сэмплирования между индексами s и t

### ⚠️ Завышенные показатели на синтетических данных

- **16× прирост эффективности** наиболее ярко выражен на **NL-RX-SYNTH**
- Это домен, где базовая семантическая структура (регулярные выражения) **чище**, чем открытый естественный язык
- Возможно завышение показателей по сравнению с более «грязными» сценариями предобучения на реальных данных

## Связь с другими работами

### JEPA Family

STP является эволюционным развитием семейства JEPA:

- **I-JEPA** (Image-based JEPA) — foundational архитектура для изображений
- **V-JEPA** (Video JEPA) — расширение на временные последовательности
- **VL-JEPA** (Vision-Language JEPA) — мультимодальное расширение
- **LLM-JEPA** — применение к языку, но с ручными костылями
- **STP** — устраняет ограничения LLM-JEPA через геодезическую гипотезу

### Связанные гипотезы

1. **Linear Representation Hypothesis (LRH)**
   - Простые концепты кодируются как направления в пространстве репрезентаций
   - Векторная арифметика (v_Paris - v_France + v_Italy ≈ v_Rome) естественно возникает из линейности пути

2. **Manifold Hypothesis**
   - Learned representations form a simple and smooth manifold
   - Under Geodesic Hypothesis, эта структура — естественное следствие Principle of Least Action

3. **Curvature Straightening Phenomenon**
   - Training process straightens curvature между consecutive tokens
   - Интерпретируется как проявление underlying geodesic

### Теоретические основы

- **Principle of Least Action** (Lanczos, 1966) — путь минимизирует интеграл Лагранжиана
- **Energy Based Models (EBMs)** — STP обобщает state-wise energy minimization до trajectory-wise action minimization
- **Neural Tangent Kernel (NTK)** — совместимость с width ≫ depth режимом современных LLM

## Практическое применение

### Когда использовать STP

1. **Ограниченный доступ к высококачественным данным** — лаборатории с дефицитом данных
2. **Пост-трейн пайплайны** — улучшение existing моделей через additional regularization
3. **AI alignment** — геометрические априорные ограничения для стабильности генерации
4. **Домены с чистой семантической структурой** — код, математика, формальные языки

### Гиперпараметры

- **λ (lambda):** Оптимально ≈ 0.02 (диапазон 0.01–0.08)
- **Выбор индексов:** Случайный s < r < t
- **Ограничение дистанции:** |t - s| ≤ τ для обеспечения локальной линейности

### Интеграция с HuggingFace Transformers

```python
# Псевдокод реализации
def compute_stp_loss(hidden_states, lambda_=0.02):
    # hidden_states: [batch, seq_len, hidden_dim]
    s, r, t = random_indices(seq_len)  # s < r < t
    h_s = hidden_states[:, s, :]
    h_r = hidden_states[:, r, :]
    h_t = hidden_states[:, t, :]
    
    cos_sim = cosine_similarity(h_t - h_r, h_r - h_s)
    l_stp = 1 - cos_sim
    
    return l_ntp + lambda_ * l_stp
```
