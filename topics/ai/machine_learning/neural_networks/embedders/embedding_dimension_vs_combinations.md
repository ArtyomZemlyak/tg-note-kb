# Связь размерности эмбеддингов и количества возможных комбинаций

## Краткое описание

Исследование показывает математическую зависимость между размерностью векторных эмбеддингов и количеством комбинаций топ-k документов, которые могут быть представлены без ошибок. Эта связь выражается полиномиальной функцией и устанавливает теоретический предел для всех моделей с фиксированной размерностью эмбеддингов.

## Математическая основа

### Row-wise order-preserving rank

Исследование формализует понятие "row-wise order-preserving rank" (ранг сохранения порядка по строкам) для бинарной матрицы релевантности A ∈ {0,1}^(m×n):

rank_rop A = min { rank B | B ∈ R^(m×n), such that для всех i, j, k, если A_{ij} > A_{ik}, то B_{ij} > B_{ik} } 

Это минимальная размерность, необходимая для того, чтобы любая векторная модель эмбеддингов возвращала релевантные документы до нерелевантных для всех запросов.

### Знаковый ранг (Sign Rank)

Знаковый ранг матрицы M ∈ {-1, 1}^(m×n) — это минимальное целое d, такое что существует матрица ранга d, элементы которой имеют тот же знак, что и элементы M:

sign-rank(M) = min { rank(B) | B ∈ R^(m×n), sign(B_{ij}) = M_{ij} }

### Цепочка неравенств

Для бинарной матрицы A ∈ {0,1}^(m×n) справедлива следующая цепочка неравенств:

rank_rt A ≤ rank_gt A ≤ sign-rank(2A - 1_{m×n}) ≤ rank_rt A + 1

Где:
- rank_rt A: row-wise thresholdable rank
- rank_gt A: globally thresholdable rank
- sign-rank(2A - 1_{m×n}): знаковый ранг преобразованной матрицы

## Эмпирические результаты

### Эксперименты с "свободными" эмбеддингами

Для проверки теории исследователи провели эксперименты с "свободными" эмбеддингами, где векторы напрямую оптимизировались с помощью градиентного спуска без ограничений языковой модели. Они создавали случайные документы и запросы, а затем постепенно увеличивали количество документов, пока оптимизация не переставала справляться с задачей.

### Полиномиальная зависимость

Результаты показали, что критическое количество документов (n), которое может быть представлено с заданной размерностью (d), следует полиномиальной зависимости:

**Формула для k=2:**
y = -10.5322 + 4.0309d + 0.0520d² + 0.0037d³ (r² = 0.999)

Где:
- y — критическое количество документов (n_critical)
- d — размерность эмбеддинга

### Примеры экстраполированных значений

- 500k документов при размерности 512
- 1.7M документов при размерности 768
- 4M документов при размерности 1024
- 107M документов при размерности 3072
- 250M документов при размерности 4096

## Практические последствия

### Ограничения для веб-масштабного поиска

Даже с самыми большими эмбеддингами с идеальной оптимизацией на тестовом наборе, количество комбинаций для веб-масштабного поиска превышает теоретический лимит. Например, для датасета QUEST с 325k документами и 20 релевантными документами на запрос C(325000, 20) ≈ 7.1e+91, что больше оценки атомов во Вселенной (~10^82), в то время как в QUEST всего 3k запросов.

### Влияние на архитектуру моделей

Поскольку размерности эмбеддингов не могут расти бесконечно, это указывает на необходимость:
- Много-векторных архитектур (например, ColBERT)
- Разреженных моделей (например, BM25)
- Кросс-энкодеров для переоценки результатов
- Новых математических подходов к представлению знаний

## Эмпирические подтверждения

### Экспериментальные настройки

Исследователи создавали случайную матрицу документов (размер n) и случайную матрицу запросов с топ-k наборами (все комбинации, т.е. размер m = C(n,k)), обе с единичными векторами. Затем они напрямую оптимизировали решение ограничений с помощью оптимизатора Adam с функцией потерь InfoNCE.

### Результаты оптимизации

Эксперименты показали, что:
- Свободные эмбеддинги действительно достигают критической точки, после которой задача становится неразрешимой
- Кривая зависимости критического n от размерности d хорошо аппроксимируется полиномиальной функцией
- Даже в "лучшем случае" (без ограничений языковой модели), существуют фундаментальные ограничения

## Сравнение с реальными моделями

### Плотность графа релевантности

Исследование вводит две метрики для измерения плотности графа релевантности:
1. **Graph Density**: отношение количества рёбер в графе к максимальному возможному количеству
2. **Average Query Strength**: средняя сила связи между запросами на основе общих релевантных документов

LIMIT показывает значительно более высокие значения по этим метрикам по сравнению с другими датасетами, что подтверждает его сложность.

## Новые концепции и термины

- **Row-wise order-preserving rank**: минимальная размерность для сохранения порядка релевантности по строкам
- **Sign-rank (знаковый ранг)**: математическая концепция, лежащая в основе теоретических ограничений
- **Critical-n (критическое n)**: максимальное количество документов, которое может быть представлено при заданной размерности
- **Free embedding optimization**: оптимизация векторов без ограничений языковой модели
- **Graph Density**: метрика плотности графа релевантности запрос-документ
- **Average Query Strength**: метрика средней силы связи между запросами
