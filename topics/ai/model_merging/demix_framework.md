# DeMix: Фреймворк для масштабирования смешивания данных через слияние моделей

## Краткое описание

DeMix (Decouple Searching from Training Mix) - это новаторский фреймворк для оптимизации соотношений данных при предобучении больших языковых моделей (LLM), который использует слияние моделей для прогнозирования оптимальных пропорций данных. Вместо обучения прокси-моделей для каждой выборки смеси, DeMix обучает компонентные модели на кандидатских наборах данных в масштабе и получает прокси-смеси данных через взвешенное слияние моделей.

## Основные особенности

- **Разделение поиска и обучения**: DeMix разъединяет поиск оптимальной смеси данных от затрат на обучение, позволяя оценивать неограниченное количество смешиваний без дополнительной нагрузки на обучение
- **Эффективность**: Существенно снижает вычислительные затраты на оптимизацию смешивания данных
- **Точность**: Обеспечивает высокую корреляцию с реальными результатами обучения на смешанных данных
- **Масштабируемость**: Позволяет использовать неограниченное количество моделей-прокси без дополнительных затрат на обучение

## Методология

### Подготовка компонентных моделей

1. Сбор и очистка кандидатских наборов данных (общедоступные, математические, код и т.д.)
2. Обучение компонентных моделей на каждом кандидатском наборе данных с использованием двухэтапного протокола:
   - Инициализация из общей базовой модели
   - Дообучение на специфичном для домена наборе данных с фиксированным соотношением

### Слияние моделей как прокси

- Вместо обучения новых моделей для каждой комбинации данных используется взвешенное арифметическое слияние параметров компонентных моделей
- Математически обосновано, что слияние компонентных моделей дает приближение к модели, обученной на соответствующей смеси данных
- Позволяет получить эффективно неограниченное количество прокси-моделей без затрат на обучение

### Оптимизация весов смешивания

1. Случайная выборка большого набора соотношений смешивания
2. Строительство прокси-моделей через взвешенное слияние компонентов
3. Оценка прокси-моделей на бенчмарках
4. Обучение предиктора (LightGBM), который отображает веса смешивания в оценки производительности
5. Итеративная оптимизация для поиска оптимальных соотношений

## Преимущества

- **Экономия вычислительных ресурсов**: Значительно снижает затраты на поиск оптимальных смесей данных (в 6.4 раза по сравнению с традиционными методами)
- **Высокая точность прокси-моделей**: Слияние моделей обеспечивает высокую корреляцию с реальными результатами (до 0.81 среднего ρ Спирмена)
- **Создание репрезентативной корпуса**: DeMix Corpora содержит 22T токенов качественных данных с проверенными соотношениями смешивания

## DeMix Corpora

- **Размер**: 22T токенов (15T исходных + 7T смешивания)
- **Состав**: Многоязычные, математические и кодовые данные с проверенными соотношениями смешивания
- **Преимущество**: Единственный крупный корпус с проверенными соотношениями смешивания, готовый для использования в предобучении LLM

## Экспериментальные результаты

- DeMix достигает лучшего ранга производительности (24.00) по сравнению с RegMix и CLIMB при значительно меньшем бюджете обучения
- Метод показывает устойчивое улучшение качества смеси по мере увеличения количества прокси-моделей до определенного порога
- Лучшие результаты достигаются с линейным методом слияния (наиболее простым и эффективным)
