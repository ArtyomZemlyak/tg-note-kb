# Слияние моделей в предобучении LLM (Model Merging in LLM Pre-training)

## Общее описание

Слияние моделей (model merging) - это технология безградиентного обучения, которая комбинирует несколько языковых моделей с одинаковой архитектурой в новую модель с использованием различных арифметических операций.

## Типы слияний

### 1. Линейное слияние (Linear Merging)
- Наиболее простой и эффективный метод
- Взвешенное арифметическое сложение параметров: `θ_merged = α₁θ₁ + α₂θ₂ + ... + αₙθₙ`
- Без гиперпараметров и с хорошими результатами на практике

### 2. Многоуровневое SLERP (Multi-SLERP)
- Обобщение SLERP для нескольких моделей
- Сохраняет нормы параметров при слиянии
- Гиперпараметр-свободный метод

### 3. DARE (Dataset Adaptive Representation Editing)
- Оставляет только самые значимые изменения параметров
- Требует настройки гиперпараметров
- Позволяет контролировать степень слияния

### 4. TIES (Task Incremental Ensemble Selection)
- Решает интерференцию при слиянии моделей
- Комбинирует маскирование и масштабирование параметров
- Требует настройки гиперпараметров

### 5. Breadcrumbs
- Использование разреженных масок для масштабирования слияния
- Гиперпараметр-свободный метод
- Позволяет масштабировать слияние нескольких задач

## Применение в предобучении LLM

### Оптимизация смешивания данных
- DeMix фреймворк использует модельное слияние для создания неограниченного числа прокси-моделей
- Позволяет эффективно исследовать пространство возможных соотношений данных
- Значительно уменьшает вычислительные затраты

### Преимущества перед традиционными подходами
- **Экономия ресурсов**: Не требуется обучение новых моделей для каждой комбинации данных
- **Масштабируемость**: Можно легко оценивать миллионы возможных комбинаций
- **Точность**: Слияние моделей дает высокую корреляцию с результатами фактического обучения

## Теоретические основы

### Предположение о малом обновлении
- В предобучении изменение параметров обычно составляет около 10% от начальной модели
- Это позволяет использовать линейные приближения при слиянии моделей
- Формально: `Δ(D_mix) ≈ Σ αᵢ Δ(Dᵢ)` для смеси данных `D_mix = Σ αᵢ Dᵢ`

### Аппроксимация обучения смесью данных
- Обучение на взвешенной смеси данных можно аппроксимировать сложением параметров обученных моделей
- `Θ_mix ≈ Θ_base + Σ αᵢ Δ(Dᵢ) = Σ αᵢ Θᵢ`, где `Θᵢ` - компонентные модели

## Применения

- **Оптимизация состава тренировочных данных**: как в DeMix и RegMix
- **Объединение экспертизы из разных доменов**
- **Регуляризация моделей**
- **Улучшение обобщающей способности**
- **Смягчение забывания при непрерывном обучении**
