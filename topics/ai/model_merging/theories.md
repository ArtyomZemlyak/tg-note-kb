# Теоретические основы слияния моделей (Theories)

## Общее описание

Теоретические основы слияния моделей объясняют, **почему и при каких условиях** слияние параметров нескольких моделей приводит к работоспособной объединённой модели с сохранёнными или улучшенными характеристиками.

## Ключевые теоретические концепции

### 1. Linear Mode Connectivity (LMC)

**Linear Mode Connectivity** — это фундаментальное свойство ландшафта функций потерь, объясняющее возможность успешного слияния моделей.

#### Основные положения:
- **Определение:** Два минимума функции потерь называются линейно связными, если существует линейный путь между ними, вдоль которого функция потерь остаётся низкой
- **Формально:** Для моделей с параметрами θ₁ и θ₂, LMC существует если `L(αθ₁ + (1-α)θ₂) ≈ min(L(θ₁), L(θ₂))` для всех α ∈ [0, 1]
- **Следствие:** Если модели линейно связны, их линейное слияние сохранит низкие потери

#### Условия возникновения LMC:
1. **Общая инициализация:** Модели должны быть инициализированы из одинаковых начальных весов
2. **Одинаковая архитектура:** Структура моделей должна быть идентичной
3. **Fine-tuning из общей базы:** Модели должны быть fine-tuned из одной предобученной модели

#### Источники:
- Garipov et al., 2018 — Loss Surfaces, Mode Connectivity
- Entezari et al., 2021 — The Role of Permutation Invariance in Linear Mode Connectivity
- Nagarajan and Kolter, 2019 — Batch normalization и LMC

### 2. Перестановочная эквивариантность (Permutation Equivariance)

#### Основная идея:
- Нейронные сети инвариантны к перестановкам нейронов в скрытых слоях
- Разные модели могут иметь **переставленные версии** одних и тех же признаков
- Перед слиянием необходимо **выровнять перестановки** нейронов

#### Механизм выравнивания:
1. Поиск оптимальной перестановки π для каждой модели
2. Применение перестановки к весам: `θ' = π(θ)`
3. Слияние выровненных моделей: `θ_merged = αθ₁' + (1-α)θ₂'`

#### Алгоритмы выравнивания:
- **Git Re-Basin:** Использование активаций для поиска соответствий между нейронами
- **Activation-based matching:** Сравнение паттернов активации
- **Weight-based matching:** Сравнение статистик весов

#### Источники:
- Ainsworth et al., 2022 — Git Re-Basin: Merging Models without Retaining
- Stoica et al., 2023 — ZipIt! Merging Models from Different Tasks without Training
- Verma and Elbayad, 2024 — Permutation methods for model merging

### 3. Теория интерференции параметров

#### Проблема интерференции:
При слиянии моделей, обученных на разных задачах, может возникать **конфликт параметров**:
- Одни и те же параметры могут иметь противоположные знаки в разных моделях
- Это приводит к взаимной компенсации и потере способностей

#### Механизмы интерференции:
1. **Знаковая интерференция:** Противоположные знаки градиентов
2. **Масштабная интерференция:** Разные масштабы изменений параметров
3. **Структурная интерференция:** Конфликты на уровне архитектурных компонентов

#### Решения:
- **TIES:** Маскирование и разрешение конфликтов знаков
- **DARE:** Селективное сохранение только значимых изменений
- **Task Arithmetic:** Контролируемое масштабирование векторов задач

### 4. Предположение о малом обновлении (Small Update Assumption)

#### Основная идея:
В предобучении LLM изменения параметров обычно составляют **~10%** от начальной модели, что позволяет использовать линейные приближения.

#### Формальное представление:
- `Δ(D_mix) ≈ Σ αᵢ Δ(Dᵢ)` для смеси данных `D_mix = Σ αᵢ Dᵢ`
- `Θ_mix ≈ Θ_base + Σ αᵢ Δ(Dᵢ) = Σ αᵢ Θᵢ`

#### Следствия:
- Линейное слияние даёт хорошую аппроксимацию обучения на смеси данных
- Позволяет использовать слияние моделей для оптимизации смешивания данных
- Объясняет эффективность Model Soups и линейного усреднения

### 5. Теория/task vectors

#### Концепция:
- **Вектор задачи:** Разность между fine-tuned моделью и базовой моделью
- `τ = θ_finetuned - θ_base`
- Векторы задач кодируют "навыки" или "способности" модели

#### Свойства:
- **Композиционность:** Векторы задач можно складывать и вычитать
- **Масштабируемость:** Можно масштабировать влияние задачи через λ·τ
- **Интерпретируемость:** Позволяют анализировать, что модель "выучила"

#### Применения:
- Комбинирование множественных способностей
- Отмена нежелательных свойств (например, токсичности)
- Перенос навыков между моделями

#### Источник:
- Ilharco et al., 2023 — Editing Models with Task Arithmetic

### 6. Теория разреженности (Sparsity Theory)

#### Основная идея:
Только небольшая часть параметров критически важна для каждой задачи, что позволяет:
- Создавать неперекрывающиеся маски для разных задач
- Масштабировать слияние на множество задач
- Избегать интерференции через разреженность

#### Методы:
- **Breadcrumbs:** Разреженные маски для каждого компонента
- **DARE:** Статистическая идентификация важных параметров
- **Magnitude pruning:** Отсечение малых по величине параметров

## Теоретические ограничения

### 1. Требование идентичной архитектуры
- Большинство методов требуют одинаковой архитектуры моделей
- Исключения: методы на уровне logits или представлений

### 2. Требование общей инициализации
- Модели должны происходить из общей базовой модели
- Слияние независимо обученных моделей сложнее

### 3. Линейные приближения
- Теория работает лучше при малых изменениях параметров
- При больших fine-tuning отклонения от линейности растут
