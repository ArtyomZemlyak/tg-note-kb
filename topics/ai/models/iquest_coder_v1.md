# IQuest-Coder-V1: Инновационная модель кодирования с Code-Flow обучением

## Обзор

IQuest-Coder-V1 - это серия кодовых языковых моделей, разработанных китайской компанией IQuestLab (九坤投资). Модель представлена в различных размерах: 7B, 14B и 40B параметров. Выделяется применением нового подхода Code-Flow обучения, который фокусируется на динамическом развитии кода вместо традиционного статического обучения на кодовых файлах.

## Ключевые характеристики

### Code-Flow обучение
- **Фокус на динамике кода**: Модель обучается не статическим файлам, а на эволюции кода во времени
- **Принципы развития**: Обучение на реальных изменениях (commit) из GitHub, особенно из фазы зрелости проекта (40%-80% жизненного цикла)
- **Формат данных**: старый_код → патч → новый_код (для понимания изменений)
- **Цель**: Научить модель понимать не только синтаксис, но и процессы разработки: как и почему вносятся изменения, как развивается архитектура

### LoopCoder архитектура
- **Циклическая трансформер-декодер архитектура**: Использование одних и тех же блоков трансформера дважды с общими параметрами
- **Две итерации**: Позволяет обрабатывать данные в два прохода для более глубокого понимания контекста при меньшем числе параметров
- **Global Attention**: Queries из второй итерации обращаются ко всем key-value парам из первой итерации
- **Local Attention**: Queries обращаются только к предшествующим токенам внутри второй итерации
- **Gating Mechanism**: Комбинирует оба типа внимания через обученный gate (output = gate * global_attention + (1 - gate) * local_attention)

### Технические характеристики
- **Поддержка контекста**: до 128K токенов
- **Тип внимания**: Grouped Query Attention (GQA) для повышения эффективности вывода
- **Размер словаря**: 76,800 токенов
- **Архитектура**: Пользовательский код через auto_map функцию Hugging Face
- **Рекомендуемая версия Transformers**: ≥4.52.4

## Оценка производительности

IQuest-Coder-V1 40B показывает впечатляющие результаты на бенчмарках:
- Превосходит Claude Sonnet 4.5 и GPT-5.1 на нескольких бенчмарках
- Оригинальный отчет указывает на 81.4 баллов на SWE-bench (хотя метрики на Hugging Face могут колебаться)
- Показывает лидерские результаты в 8 тестах оценки кода
- Лучшие скоры на SWE-bench, BigCodeBench и других отраслевых тестах

### Основные версии
- **7B, 14B, 40B параметров**: Для разных потребностей разработки
- **Instruct версии**: Для следования инструкциям
- **Thinking версии**: Для рассуждений и планирования
- **Loop версии**: С циклической архитектурой (например, 40B-Loop-Instruct)

## Применение

Модель предназначена для:
- Автоматизированного программирования
- Понимания кода
- Задач программной инженерии
- Планирования, исправления ошибок и выполнения кода
- Интеграции с существующими процессами разработки
