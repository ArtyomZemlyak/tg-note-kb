# CliffordNet: Геометрическая Алгебра в Глубоком Обучении

## Обзор

CliffordNet — это семейство архитектур нейронных сетей для компьютерного зрения, основанных исключительно на **геометрической алгебре** (алгебре Клиффорда). В отличие от традиционных подходов, которые полагаются на инженерные эвристики (стекирование CNN блоков, attention механизмов, FFN слоёв), CliffordNet использует единую математически обоснованную операцию — **геометрическое произведение Клиффорда**.

## Ключевая идея

Современные архитектуры компьютерного зрения (от CNN до Transformers) используют раздельные модули:
- **Пространственные миксеры** (Attention/Conv) — для смешивания пространственной информации
- **Канальные миксеры** (FFN) — для обработки и хранения информации в каналах

CliffordNet заменяет эту схему **единой операцией геометрического произведения**:

```
uv = u · v + u ∧ v
```

где:
- `u · v` — обобщённое скалярное произведение (когерентность признаков, схожесть)
- `u ∧ v` — внешнее произведение (бивектор, структурные вариации, ортогональность)

## Основные преимущества

### 1. Алгебраическая полнота
Стандартные нейросетевые операции используют только симметричную скалярную компоненту (`u · v`), отбрасывая антисимметричную бивекторную компоненту (`u ∧ v`). CliffordNet явно моделирует **обе компоненты**, обеспечивая алгебраическую полноту взаимодействия признаков.

### 2. Отсутствие необходимости в FFN
Геометрическое взаимодействие настолько информативно, что стандартные FeedForward Networks становятся избыточными. Это позволяет drastically сократить количество параметров.

### 3. Линейная сложность O(N)
Благодаря стратегии **разрежённого скользящего взаимодействия** (Sparse Rolling Interaction), модель имеет строгую линейную сложность по длине последовательности и каналам.

### 4. Нативная 2D топология
В отличие от ViT (которые "сплющивают" изображение в 1D последовательность) и SSM (которые используют сканирование), CliffordNet работает непосредственно с **изотропными 2D сетками признаков**, сохраняя пространственную топологию.

## Архитектура CliffordNet

### Изотропный дизайн
После начального патч-эмбеддинга размеры карты признаков `(h × w × D)` остаются **постоянными** на протяжении всех L слоёв. Это соответствует формулировке обучения признаков как непрерывного геометрического потока в фиксированном фазовом пространстве.

### DualStream Geometric Block
Один поток захватывает высокочастотные детали, другой агрегирует локальный контекст. Их взаимодействие моделируется через геометрическое произведение для обновления признаков.

### Контекстная инстанциация
Геометрический контекст `C(H)` может быть:
- **Локальным** (через свёртки, лапласиан) — для эффективности
- **Глобальным** (через глобальное среднее) — для максимальной производительности
- **Комбинированным** (суперпозиция локального и глобального)

### Sparse Rolling Interaction
Вместо вычисления полной матрицы внешнего произведения `D × D` (квадратичная сложность `O(D²)`), используется **циклический сдвиг каналов** с разрежённым набором смещений, обеспечивая линейную сложность `O(D)`.

## Результаты

### CIFAR-100
| Модель | Параметры | Точность |
|--------|-----------|----------|
| **CliffordNet Nano** | 1.4M | 77.82% |
| **CliffordNet Lite** | 2.6M | 79.05% |
| ResNet-18 | 11.2M | ~78% |
| MobileNetV2 | ~3.5M | ~74% |
| ViT-Tiny | ~5.7M | ~75% |

CliffordNet Nano достигает точности ResNet-18 с **в 8 раз меньшим количеством параметров**.

## Философия дизайна

### От инженерного эмпиризма к математическому принципу
Вместо стекования эвристических блоков, CliffordNet следует **математически обоснованному анзацу**: эволюция латентных представлений должна управляться полным спектром геометрических отношений — как скалярным выравниванием (схожесть), так и бивекторной структурой (ортогональность).

### Глобальность как эмерджентное свойство
Вместо явного глобального контекста (как в Global Self-Attention), CliffordNet показывает, что **глобальное понимание возникает из строгой локальной обработки** благодаря плотному "запутыванию" признака с его окрестностью через геометрическую алгебру.
