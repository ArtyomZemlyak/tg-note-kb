# Геометрическое Произведение Клиффорда

## Определение

**Геометрическое произведение** (Clifford Geometric Product) — это фундаментальная операция в алгебре Клиффорда, которая объединяет два вектора в произведение, содержащее как скалярную, так и бивекторную компоненты:

```
uv = u · v + u ∧ v
```

где:
- `u · v` — **внутреннее (скалярное) произведение** (inner product)
- `u ∧ v` — **внешнее произведение** (exterior/wedge product)

## Геометрическая интерпретация

### Скалярная компонента (u · v)
- Измеряет **когерентность** (согласованность) между векторами
- Показывает степень **выравнивания** (alignment)
- Физически: проекция одного вектора на другой
- В нейросетях: работает как **гейт-механизм**, регулирующий величину признаков

### Бивекторная компонента (u ∧ v)
- Представляет **ориентированную площадь** плоскости, натянутой на векторы
- Измеряет **ортогональность** и **структурные различия**
- Физически: **геометрический момент** или **вихрь** (vorticity)
- В нейросетях: выделяет границы, текстуры, места где локальный контекст отличается от центра

## Алгебраическая полнота

### Проблема стандартных подходов
Современные нейросетевые операции используют **только скалярную компоненту**:
- Dot-product attention: `Attention(Q,K,V) = softmax(QK^T/√d)V`
- Полносвязные слои: матричное умножение + нелинейность
- Свертки: взвешенная сумма (скалярное произведение в скользящем окне)

Это **геометрически потерянно** (geometrically lossy) — отбрасывается информация о структурных отношениях.

### Решение через геометрическое произведение
CliffordNet и другие геометрические архитектуры используют **полное произведение**:
- Одновременно захватывают **схожесть** (через `u · v`)
- И **структурное различие** (через `u ∧ v`)
- Это обеспечивает **алгебраическую полноту** взаимодействия признаков

## Математические свойства

### Ассоциативность
Геометрическое произведение ассоциативно:
```
(uv)w = u(vw)
```

### Дистрибутивность
Дистрибутивно относительно сложения:
```
u(v + w) = uv + uw
```

### Связь с другими операциями

#### Для ортогональных векторов
Если `u ⊥ v`, то `u · v = 0`:
```
uv = u ∧ v  (чистый бивектор)
```

#### Для коллинеарных векторов
Если `u ∥ v`, то `u ∧ v = 0`:
```
uv = u · v  (чистый скаляр)
```

#### Квадрат вектора
```
u² = u · u = |u|²  (скаляр, квадрат длины)
```

## Базис бивекторов

Для пространства с базисом `{e₁, e₂, ..., e_D}` внешнее произведение раскладывается:

```
u ∧ v = Σᵢ<ⱼ (uᵢvⱼ - uⱼvᵢ)(eᵢ ∧ eⱼ)
```

где каждый `eᵢ ∧ eⱼ` представляет **единичную ориентированную плоскость** через измерения `i` и `j`.

### Размерность пространства бивекторов
Полное пространство бивекторов имеет размерность `C(D,2) = D(D-1)/2`:
- Для D=2: 1 бивектор (одна плоскость)
- Для D=3: 3 бивектора (плоскости xy, yz, zx)
- Для D=64: 2016 бивекторов
- Для D=512: 130,816 бивекторов

**Проблема**: Прямое вычисление всех компонент квадратично `O(D²)`.

**Решение CliffordNet**: Разрежённое вычисление через циклические сдвиги каналов.

## Применение в нейронных сетях

### Clifford Interaction Ansatz

В CliffordNet взаимодействие между признаком `H` и контекстом `C` определяется как:

```
F(H, C) = P(HC) = P(H · C + H ∧ C)
```

где `P` — обучаемый проекционный оператор, отображающий многовекторное пространство обратно в `R^D`.

### Реализация через Hadamard product

На практике вычисляется эффективно:

1. **Скалярная часть** (Generalized Inner Product):
   ```
   D(H, C) = LinearMix(H ⊙ C)
   ```
   где `⊙` — поэлементное произведение Адамара

2. **Бивекторная часть** (Exterior Product через сдвиги):
   ```
   W_s(H, C) = H ⊙ T_s(C) - C ⊙ T_s(H)
   ```
   где `T_s` — оператор циклического сдвига на `s` позиций

3. **Объединение**:
   ```
   F(H, C) = Projection([D(H, C); W_s(H, C)])
   ```
   где `[;]` — конкатенация по каналам

### Sparse Rolling Strategy

Вместо вычисления всех `D(D-1)/2` бивекторных компонент:
- Выбирается **разрежённый набор сдвигов** `S = {s₁, s₂, ..., s_k}`
- Вычисляются только бивекторы для этих сдвигов
- Сложность: `O(k·D)` вместо `O(D²)`, где `k << D`

## Физическая интерпретация

### Дифференциальная геометрия
Геометрическое произведение можно рассматривать как **дискретизацию непрерывного геометрического потока**:

```
∂H/∂t = F(H, C(H))
```

где эволюция признака `H` во "времени" (глубине сети) управляется геометрическим взаимодействием с контекстом.

### Режимы работы

#### Дифференциальный режим (λ=1)
Контекст как дискретный лапласиан: `C ≈ ΔH`
- Выступает как **геометрический фильтр высоких частот**
- Подавляет базовую интенсивность признаков
- Оптимально для моделей с ограниченной ёмкостью

#### Абсолютный режим (λ=0)
Контекст сохраняет энергию: `C = C_loc`
- Сохраняет информацию об интенсивности признаков
- `H · C ≈ |H|² + H · ΔH`

## Глобальное геометрическое взаимодействие

### geometric FFN-Global (gFFN-G)
Альтернатива стандартному FFN через глобальный контекст:

```
C_glo = GlobalAvg(H)
gFFN-G(H) = P(H · C_glo + H ∧ C_glo)
```

- **Wedge компонента** (`H ∧ C_glo`): выделяет признаки, отклоняющиеся от глобального фона (детекция салиентности)
- **Inner компонента** (`H · C_glo`): усиливает признаки, согласованные с глобальной сценой

### Суперпозиция локального и глобального

```
∂H/∂t = α · F(H, C_loc) + β · F(H, C_glo)
```

где `β ∈ {0, 1}` — структурный переключатель:
- `β = 0`: только локальная геометрическая диффузия (экстремальная эффективность)
- `β = 1`: добавлено глобальное взаимодействие для дальних зависимостей

## Историческая справка

Уильям Кингдон Клиффорд (1878) осознал, что:
> "Две системы [алгебра кватернионов Гамильтона и алгебра расширений Грассмана] не только согласуются друг с другом, но фактически являются частями большего целого."

Современное глубокое обучение невольно повторило этот исторический раскол, полагаясь преимущественно на скалярное произведение (Attention) и пренебрегая внешним произведением. CliffordNet восстанавливает это алгебраическое единство.
