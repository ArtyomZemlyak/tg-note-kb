# Гиперсети (Hypernetworks)

## Обзор

**Гиперсети** — это нейронные сети, которые генерируют параметры (веса) для других нейронных сетей. Вместо того чтобы обучать фиксированные веса, гиперсеть обучается генерировать веса динамически на основе входных данных.

## Основная концепция

```
Вход → Гиперсеть → Параметры основной сети → Основная сеть → Выход
```

## Ключевые преимущества

1. **Динамическая адаптация** — веса генерируются под каждый входной пример
2. **Амортизация стоимости** — дорогое мета-обучение один раз, дешевая генерация при инференсе
3. **Избегание конфликтов** — разные входы получают разные параметры, нет интерференции градиентов
4. **Компактность** — хранение гиперсети вместо множества отдельных моделей
