# Нейронные архитектуры (Neural Architectures)

## Обзор

Раздел посвящен архитектурам нейронных сетей, их компонентам и специализированным конструкциям.

## Подразделы

### [[hypernetworks/index.md]] - Гиперсети
Гиперсети генерируют параметры для других нейронных сетей. Включает методы динамической генерации LoRA-адаптеров:
- **Doc-to-LoRA** — интернализация документов в LLM
- **Text-to-LoRA** — адаптация через описания задач
- **Tencent HY-WU** — динамические LoRA для редактирования изображений

### [[cliffordnet/]] - CliffordNet
Архитектуры на основе алгебры Клиффорда.

### [[geometric_deep_learning/]] - Геометрическое глубокое обучение
Методы глубокого обучения на геометрических структурах.

### [[autoresearch_rl.md]] - AutoResearch-RL: Автономное исследование архитектур с RL
Фреймворк, в котором RL-агент на базе PPO проводит перпетуальное исследование нейронных архитектур и гиперпараметров без человеческого надзора. Агент предлагает диффы к train.py, запускает обучение на фиксированный бюджет времени (300s), получает награду через val-bpb и обновляет политику. Модуль самооценки предсказывает финальный bpb каждые 30s и прерывает бесперспективные запуски досрочно — **2.4× больше экспериментов** за то же время. На single H100 за ночь достигает val-bpb 2.681, превзойдя human expert (2.847) и greedy LLM baseline (2.734).
