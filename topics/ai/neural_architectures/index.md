# Нейронные архитектуры (Neural Architectures)

## Обзор

Раздел посвящен архитектурам нейронных сетей, их компонентам и специализированным конструкциям.

## Подразделы

### [[hypernetworks/index.md]] - Гиперсети
Гиперсети генерируют параметры для других нейронных сетей. Включает методы динамической генерации LoRA-адаптеров:
- **Doc-to-LoRA** — интернализация документов в LLM
- **Text-to-LoRA** — адаптация через описания задач
- **Tencent HY-WU** — динамические LoRA для редактирования изображений

### [[cliffordnet/]] - CliffordNet
Архитектуры на основе алгебры Клиффорда.

### [[geometric_deep_learning/]] - Геометрическое глубокое обучение
Методы глубокого обучения на геометрических структурах.
