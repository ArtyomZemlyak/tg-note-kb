# Датасет LIMIT: Тестирование теоретических ограничений моделей извлечения

## Краткое описание

Датасет LIMIT (Linguistic Multitask Instruction-following with Theoretical underpinnings) — это специально разработанный датасет для проверки теоретических ограничений векторных эмбеддингов в задачах информационного поиска. Он был создан командой Google DeepMind для эмпирической проверки того, что фиксированные размеры эмбеддингов ограничивают способность моделей представлять все возможные комбинации релевантных документов.

## Принцип работы

### Конструкция датасета

Для создания естественно-языковой версии датасета исследователи выбрали простую схему: атрибуты, которые кто-то может любить (например, "Джон любит гавайскую пиццу, спортивные автомобили и т.д."). Они накладывают два ограничения для реализма:
1. Пользователи не должны иметь слишком много атрибутов, чтобы держать документы короткими (менее 50 на пользователя)
2. Каждый запрос должен запрашивать только один элемент, чтобы задача оставалась простой (например, "кто любит X")

### Количество документов и запросов

- **50,000 документов** - для создания достаточно сложного корпуса, но не настолько большого, чтобы быть вычислительно недоступным
- **1,000 запросов** - для статистической значимости при быстрой оценке
- **k=2** - для каждого запроса выбираются два релевантных документа, как в других бенчмарках (NQ, HotpotQA и т.д.)

### Матрица релевантности

Исследователи используют матрицу с максимальным количеством документов, для которых все комбинации будут только выше 1000 запросов для топ-2 (46 документов, так как C(46,2) = 1035, минимальное значение выше 1000). Затем случайным образом назначаются натуральные языковые атрибуты запросам и добавляются эти атрибуты к соответствующим релевантным документам.

## Результаты тестирования

Несмотря на тривиальную простоту задачи ("Кто любит яблоки?" против "Джон любит яблоки, ..."), современные модели сильно страдают:

- **Современные эмбеддинговые модели**: менее 20% точности @100 на полной версии
- **Модели с малой размерностью**: особенно низкая производительность
- **BM25 (лексические)**: 93% на LIMIT благодаря эффективно более высокой размерности
- **GTE-ModernColBERT (multi-vector)**: 62% на LIMIT
- **Gemini 2.5 Pro (cross-encoder)**: 100% на LIMIT, но не масштабируется для первоначального поиска

## Ключевые находки

### Влияние размерности эмбеддингов

Производительность модели зависит от размерности эмбеддингов — лучшие результаты достигаются с большими размерностями. Однако даже с высокими размерностями модели не могут решить задачу полностью, когда количество возможных комбинаций превышает теоретический лимит для данной размерности.

### Отсутствие доменного сдвига

Тренировка на обучающем наборе LIMIT не дает значительного улучшения, что указывает на то, что проблема не в доменном сдвиге. Только обучение на тестовом наборе позволяет модели "переобучиться" на конкретные токены, что подтверждает теоретические ограничения.

### Эффекты паттернов релевантности

Исследование сравнивает различные паттерны релевантности:
- **Случайные выборки из всех комбинаций**
- **Циклический подход** - следующий запрос релевантен одному документу из предыдущего запроса и следующему документу
- **Дизъюнктный паттерн** - каждый запрос релевантен двум новым документам
- **Плотный паттерн** - максимизирует количество соединений (C(n,k)) для максимального количества документов

Плотный паттерн значительно труднее других, что подтверждает гипотезу о том, что более "связанные" матрицы релевантности труднее представляются векторными эмбеддингами.

## Значение для теории поиска

Датасет LIMIT демонстрирует, что даже простые естественно-языковые задачи могут быть непреодолимыми для эмбеддинговых моделей из-за фундаментальных математических ограничений, а не из-за сложности модели или объема данных. Это ставит под сомнение подход "все задачи могут быть решены с помощью больших эмбеддингов" и требует рассмотрения альтернативных архитектур поиска.

## Новые концепции и термины

- **LIMIT (Linguistic Multitask Instruction-following with Theoretical underpinnings)**: специальный датасет для проверки теоретических ограничений эмбеддингов
- **Qrel Graph Density**: метрика плотности графа релевантности запрос-документ
- **Average Query Strength**: метрика средней силы связи между запросами на основе общих релевантных документов
- **Free embedding validation**: эксперименты с прямыми оптимизациями векторов без ограничений языковой модели

## Примеры применения

- **Исследование влияния размерности эмбеддингов** на способность представлять релевантные комбинации
