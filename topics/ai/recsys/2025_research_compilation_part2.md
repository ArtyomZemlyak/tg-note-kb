# Подборка статей 2025 по рекомендательным системам (часть 2)

## Описание

Этот документ представляет собой продолжение подборки статей и исследований по рекомендательным системам, представленных в 2025 году. Подборка охватывает два основные области: фундаментальные модели для рекомендаций и мультимодальные рекомендательные системы с использованием семантических идентификаторов.

## Структура документа

Документ разделен на две основные категории, отражающие ключевые направления исследований в области рекомендательных систем:

1. **Фундаментальные модели** - работы, посвященные созданию универсальных моделей для рекомендаций
2. **Мультимодальность и Semantic IDs** - исследования, связанные с интеграцией визуального и текстового контента в рекомендательные системы и использованием семантических идентификаторов

## 1. Фундаментальные модели

### PinFM: Foundation Model for User Activity Sequences at a Billion-scale Visual Discovery Platform

PinFM - фундаментальная модель для понимания пользовательских последовательностей активности на визуальной платформе масштаба миллиардов. Модель адаптирует парадигму предобучения-дообучения (pretraining-finetuning) для обработки длинных последовательностей пользовательской активности. Поддерживает унификацию предыдущих достижений в области ранжирования Pinterest. Модель была успешно развернута на платформе Pinterest с демонстрацией значительных улучшений в ключевых метриках.

См. также: [[pinnerformer_pinrec_architectures.md]], [[PinSage.md]], [[transformer_based_models.md]]

### Large Foundation Model for Ads Recommendation (LFM4Ads)

LFM4Ads - это All-Representation Multi-Granularity transfer framework для рекламных рекомендаций. Модель интегрирует представления из разных доменов (реклама и контент) и применяет мультигранную передачу знаний. Представления только из ветви рекламы передаются для рекламных рекомендаций. Модель обучается на десятках миллиардов ежедневных примеров (80% контент, 20% реклама). Поддерживает адаптацию под новые домены без дополнительных данных.

См. также: [[gem_model.md]], [[advertising_recsys.md]]

### Foundation Model for Personalized Recommendation

Фундаментальная модель для персонализованных рекомендаций, разработанная для решения проблемы разнородности и разрыва между представлениями в традиционных рекомендательных системах. Модель использует архитектуру трансформера с адаптерами, позволяя интегрировать знания из разных доменов и задач. Поддерживает нулевое обучение (zero-shot) и обучение с учителем (few-shot) для новых сценариев.

См. также: [[llm_based/main.md]], [[transfer_learning.md]]

### Meta's Generative Ads Model (GEM): The Central Brain Accelerating Ads Recommendation AI Innovation

Центральная генеративная модель рекламы от Meta (GEM), описывающая архитектуру центрального мозга, ускоряющего инновации в области рекомендаций. Модель внедрена и показала значительный рост конверсии в рекламе, становясь центральным элементом AI-инноваций в рекламе. GEM использует гибридную архитектуру трансформера, вдохновленную LLM-архитектурами. Модель показала +5% в Instagram и +3% в Facebook за второй квартал.

См. также: [[gem_model.md]], [[transformer_based_models.md]], [[advertising_recsys.md]]

### Realizing Scaling Laws in Recommender Systems: A Foundation–Expert Paradigm for Hyperscale Model Deployment

Новое исследование, предлагающее парадигму "фундамент-эксперт" для развертывания сверхмасштабных моделей рекомендаций. Работа исследует законы масштабирования в контексте рекомендательных систем и предлагает подход, при котором фундаментальные модели обслуживают общие паттерны, а экспертизы - специфичные сценарии. Это позволяет достичь эффективности при масштабировании до триллионов параметров.

См. также: [[scaling_generative_recsys.md]], [[transformer_based_models.md]]

### External Large Foundation Model: How to Efficiently Serve Trillions of Parameters for Online Ads Recommendation

Исследование, посвященное проблеме эффективного обслуживания триллионов параметров для онлайн рекламных рекомендаций с использованием внешних фундаментальных моделей. Работа предлагает подходы к управлению вычислительными ресурсами, кэшированию и латентности при интеграции фундаментальных моделей в рекламные рекомендательные системы. Решает проблему производительности при использовании моделей с очень большим количеством параметров.

См. также: [[gem_model.md]], [[advertising_recsys.md]], [[model_optimization.md]]

### Meta Lattice: Model Space Redesign for Cost-Effective Industry-Scale Ads Recommendations

Meta Lattice представляет собой комплексную фреймворк-архитектуру, перепроектировывающую пространство моделей для экономически эффективных промышленных рекламных рекомендаций. Lattice фокусируется на перепроектировании модели с целью масштабирования обучения с несколькими доменами и несколькими целями (MDMO) за пределы моделей и целей обучения. Использует всестороннее перепроектирование пространства моделей и достигает значительных улучшений в эффективности затрат при сохранении качества рекомендаций.

См. также: [[gem_model.md]], [[advertising_recsys.md]], [[transformer_based_models.md]]

## 2. Мультимодальность и Semantic IDs

### VL-CLIP: Enhancing Multimodal Recommendations via Visual Grounding and LLM-Augmented CLIP Embeddings

VL-CLIP - фреймворк, улучшающий CLIP-эмбеддинги путем интеграции визуального "grounding" для детального понимания визуального контента и LLM-аугментации. Модель решает ограничения традиционных CLIP-моделей, которые не понимают тонкие визуальные семантики. VL-CLIP улучшает мультимодальное выравнивание, точность поиска и качество рекомендаций. Визуальный "grounding" позволяет получать детальные визуальные признаки, которые затем аугментируются с помощью LLM для лучшего соответствия с пользовательскими предпочтениями.

См. также: [[multimodal_recsys.md]], [[transformer_based_models.md]], [[clip_models.md]]

### Enhancing Embedding Representation Stability in Recommendation Systems with Semantic ID

Исследование, посвященное улучшению стабильности представления эмбеддингов в рекомендательных системах с использованием семантических идентификаторов. Работа рассматривает проблему дрейфа эмбеддингов и предлагает методы стабилизации с использованием дискретных семантических ID. Стабильность представлений улучшает долгосрочную производительность и упрощает поддержку промышленных рекомендательных систем.

См. также: [[semantic_ids_in_recsys.md]], [[embedding_stability.md]]

### Progressive Semantic Residual Quantization for Multimodal-Joint Interest Modeling in Music Recommendation

Прогрессивная семантическая остаточная квантизация для мультимодального совместного моделирования интересов в музыкальных рекомендациях. Подход позволяет эффективно кодировать сложные мультимодальные представления аудио- и текстовой информации для музыкальных айтемов. Квантизация происходит прогрессивно, с итеративным уточнением представлений для лучшего отражения пользовательских интересов.

См. также: [[multimodal_recsys.md]], [[music_recsys.md]], [[vector_quantization_in_recsys.md]]

### QARM: Quantitative Alignment Multi-Modal Recommendation at Kuaishou

QARM (Quantitative Alignment Multi-Modal Recommendation) - подход от Kuaishou, реализующий количественное выравнивание мультимодальных рекомендаций. Модель решает проблему выравнивания различных модальностей (визуальных, текстовых, аудио) для более точного представления айтемов. QARM использует количественные метрики для выравнивания представлений различных модальностей, что улучшает качество рекомендаций. Подход особенно эффективен в сценариях коротких видео.

См. также: [[multimodal_recsys.md]], [[cikm_25.md]], [[transformer_based_models.md]]

### BiListing: Modality Alignment for listings

BiListing - архитектура, предлагающая выравнивание модальностей для рекомендаций листингов (например, жилья, товаров). Модель объединяет текстовую, визуальную и структурную информацию о листингах для создания более полных представлений. BiListing решает проблему ассиметричного качества между различными модальностями и позволяет эффективно использовать доступную информацию независимо от полноты данных.

См. также: [[multimodal_recsys.md]], [[listing_recsys.md]]

### DAS: Dual-Aligned Semantic IDs Empowered Industrial Recommender System

DAS (Dual-Aligned Semantic IDs) - промышленная рекомендательная система, которая использует семантические идентификаторы, обучаемые с учетом как семантического смысла, так и коллаборативного сигнала. В отличие от традиционных подходов, DAS использует совместное обучение для выравнивания семантических и коллаборативных представлений. Система работает через новую одностадийную фреймворк, который одновременно оптимизирует генерацию семантических ID и коллаборативную фильтрацию. Позволяет предсказывать все токены параллельно, улучшая эффективность.

См. также: [[das_dual_aligned_semantic_ids.md]], [[semantic_ids_in_recsys.md]], [[multimodal_recsys.md]]

### Sparse Meets Dense: Unified Generative Recommendations with Cascaded Sparse-Dense Representations

Исследование, объединяющее разреженные и плотные представления для унифицированных генеративных рекомендаций. Подход использует каскадные разреженно-плотные представления, позволяя эффективно использовать как коллаборативный сигнал (разреженные данные взаимодействий), так и семантические признаки (плотные вектора). Это позволяет создать более выразительные представления для генеративных рекомендательных моделей.

См. также: [[generative_retrieval_models.md]], [[end_to_end_generative_recommendation_systems.md]]

### MOON Embedding: Multimodal Representation Learning for E-commerce Search Advertising

MOON - комплексная система мультимодальных представлений для поисковой рекламы в e-commerce, разработанная Alibaba и полностью развернутая во всех стадиях системы поисковой рекламы Taobao, включая поиск, релевантность, ранжирование и т.д. MOON улучшает мультимодальное представление товаров и рекламных материалов, интегрируя текстовую, визуальную и структурную информацию. Поддерживает эффективное обучение на больших масштабах.

См. также: [[multimodal_recsys.md]], [[advertising_recsys.md]], [[e-commerce_recsys.md]]

### MOON2.0: Dynamic Modality-balanced Multimodal Representation Learning for E-commerce Product Understanding

MOON2.0 - улучшенная версия MOON с динамическим балансом модальностей для понимания e-commerce продуктов. В отличие от оригинального MOON, MOON2.0 динамически адаптирует веса различных модальностей в зависимости от доступности данных и качества представлений. Это особенно полезно для продуктов с неполными мультимодальными описаниями. Подход показал значительные улучшения в промышленных условиях.

См. также: [[multimodal_recsys.md]], [[e-commerce_recsys.md]]

### LEMUR: Large scale End-to-end MUltimodal Recommendation

LEMUR - первая сверхмасштабная мультимодальная рекомендательная система, обучаемая сквозным образом (end-to-end) на сырых данных. Разработана командой ByteDance и развернута на платформе Douyin. В отличие от традиционных подходов, LEMUR объединяет мультимодальные и рекомендательные компоненты в единую модель, оптимизируя которые совместно, достигается лучшее выравнивание с целевыми метриками. Устраняет разрыв между предварительной обработкой и рекомендациями.

См. также: [[multimodal_recsys.md]], [[generative_retrieval_models.md]], [[end_to_end_generative_recommendation_systems.md]]

### STORE: Semantic Tokenization, Orthogonal Rotation and Efficient Attention for Scaling Up Ranking Models

STORE - подход к масштабированию моделей ранжирования через семантическую токенизацию, ортогональное вращение и эффективное внимание. Модель решает проблему масштабирования традиционных моделей ранжирования при сохранении интерпретируемости и эффективности. Семантическая токенизация позволяет лучше кодировать признаки, ортогональное вращение улучшает выразительность, а эффективное внимание снижает вычислительные затраты. Через эти три компонента STORE достигает лучшей масштабируемости модели.

См. также: [[ranking.md]], [[transformer_based_models.md]], [[semantic_ids_in_recsys.md]]

### Multi-Aspect Cross-modal Quantization for Generative Recommendation

Многоаспектная кросс-модальная квантизация для генеративных рекомендаций, предлагающая метод для эффективного кодирования мультимодальных признаков в дискретные представления. Подход учитывает различные аспекты (визуальные, текстовые, аудио) и создает квантованные представления, которые можно использовать в генеративных моделях. Это позволяет эффективно моделировать сложные пользовательские предпочтения с учетом различных модальностей.

См. также: [[generative_retrieval_models.md]], [[multimodal_recsys.md]], [[vector_quantization_in_recsys.md]]

### Personalized Multi Modal Alignment Encoding for CTR-Recommendation in WeChat

Персонализованное много модальное выравнивание кодирования для CTR-рекомендаций в WeChat. Работа описывает подход к персонализованному выравниванию различных модальностей в контексте предсказания CTR. Модель учитывает персонализованные предпочтения пользователей и адаптирует выравнивание модальностей индивидуально для каждого пользователя. Это особенно эффективно в социальных рекомендательных сценариях.

См. также: [[multimodal_recsys.md]], [[ctr_prediction.md]], [[social_recsys.md]]

### Generative Recommendation with Semantic IDs: A Practitioner's Handbook

Практическое руководство по генеративным рекомендациям с использованием семантических идентификаторов. Работа охватывает все аспекты внедрения SIDs в промышленные рекомендательные системы - от токенизации айтемов до интеграции с генеративными моделями. Предоставляет практические рекомендации по обучению, развертыванию и оптимизации систем, использующих SIDs.

См. также: [[semantic_ids_in_recsys.md]], [[generative_retrieval_models.md]], [[end_to_end_generative_recommendation_systems.md]]

### CoFiRec: Coarse-to-Fine Tokenization for Generative Recommendation

CoFiRec (Coarse-to-Fine Tokenization for Generative Recommendation) - подход к постепенной токенизации айтемов для генеративных рекомендаций. Модель использует иерархический подход к токенизации - сначала грубая сегментация айтемов, затем уточнение. Это позволяет создать более структурированные и интерпретируемые представления, подходящие для генеративных моделей.

См. также: [[generative_retrieval_models.md]], [[tokenization_strategies_for_items.md]]

### Generating Long Semantic IDs in Parallel for Recommendation

Исследование, посвященное генерации длинных семантических идентификаторов параллельно для рекомендаций. Работа решает проблему последовательной генерации длинных SIDs, предложив параллельный подход, который значительно ускоряет процесс токенизации. Это особенно важно для промышленных систем с высокими требованиями к латентности.

См. также: [[semantic_ids_in_recsys.md]], [[tokenization_strategies_for_items.md]]

### A Simple Contrastive Framework Of Item Tokenization For Generative Recommendation

Простой контрастный фреймворк для токенизации айтемов в генеративных рекомендациях. Подход использует контрастное обучение для создания более качественных дискретных представлений айтемов. Метод эффективно обучает токенизацию с учетом пользовательских предпочтений и коллаборативного сигнала, улучшая качество генеративных рекомендаций.

См. также: [[generative_retrieval_models.md]], [[tokenization_strategies_for_items.md]]

### Learnable Item Tokenization for Generative Recommendation

Исследование обучаемой токенизации айтемов для генеративных рекомендаций, где процесс токенизации становится частью обучаемой системы, а не фиксированным этапом предварительной обработки. Подход позволяет модели адаптивно изменять способ представления айтемов в зависимости от контекста и задачи, улучшая общую эффективность системы.

См. также: [[generative_retrieval_models.md]], [[tokenization_strategies_for_items.md]]

### SIDE: Semantic ID Embedding for effective learning from sequences

SIDE (Semantic ID Embedding) - подход к эффективному обучению из последовательностей с использованием семантических идентификаторов. В отличие от традиционных методов, SIDE использует специальные эмбеддинги семантических ID, оптимизированные для работы с последовательностями. Это позволяет лучше учитывать долгосрочные зависимости в пользовательских историях и улучшает качество рекомендаций, особенно в сценариях с динамическими предпочтениями.

См. также: [[semantic_ids_in_recsys.md]], [[sequence_modeling.md]]

### ActionPiece: Contextually Tokenizing Action Sequences for Generative Recommendation

ActionPiece - подход к контекстной токенизации последовательностей действий для генеративных рекомендаций. Модель учитывает контекст взаимодействий при токенизации последовательностей действий пользователей, что позволяет более точно кодировать пользовательские интересы. Подход особенно эффективен при работе с разнородными действиями (клик, просмотр, покупка и т.д.).

См. также: [[generative_retrieval_models.md]], [[sequence_modeling.md]], [[tokenization_strategies_for_items.md]]
