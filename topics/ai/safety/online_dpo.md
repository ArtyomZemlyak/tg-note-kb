# Online DPO: Online Direct Preference Optimization

## Краткое описание

Online Direct Preference Optimization (Online DPO) - это адаптация метода Direct Preference Optimization (DPO) для онлайн-обучения, при котором модель обучается на потоке предпочтений пользователей вместо использования статичных офлайн датасетов. Метод использует два модуля с разными скоростями оптимизации (fast и slow) для имитации внутривидовой конкуренции, что способствует быстрой адаптации модели к изменяющимся потребностям.

## Основные инновации и улучшения

### Онлайн-обучение с предпочтениями
- В отличие от традиционного DPO, который работает с оффлайн датасетами, Online DPO способен адаптироваться к потоку предпочтений в реальном времени
- Исключает необходимость в сложных системах вознаграждений, как в RLHF
- Обеспечивает более эффективное выравнивание с человеческими ценностями в условиях изменяющихся данных

### Fast-Slow модульная архитектура
- Введены два идентичных модуля с Low-rank Adaptive (LoRA) настройкой, обучающихся с разными скоростями
- Имитирует внутривидовую конкуренцию для улучшения адаптивности модели
- Быстрый модуль (F-module) адаптируется к новым данным, медленный модуль (S-module) обеспечивает стабильность

### Регуляризационный термин
- Введен новый регуляризационный термин для измерения разницы вероятностей предпочтений между быстрым и медленным модулями
- Направляет обучение и обеспечивает эффективную оптимизацию через "погоню" между модулями

## Технические детали

### OFS-DPO (Online Fast-Slow Chasing DPO)
- Использует два LoRA-модуля с разными скоростями оптимизации
- Вводит регуляризационный термин для измерения разницы в предпочтениях между модулями
- Чередует оптимизацию на разных частотах для достижения "погони" между модулями

### Формулировка функции потерь
- Сохраняет основную функцию потерь DPO как основной компонент
- Заменяет π_θ в целевой функции DPO на π_θ_F и π_θ_S для быстрого и медленного модулей соответственно
- Вводит регуляризационный термин с коэффициентом α для управления разницей между модулями

### COFS-DPO (Cross-domain Online Fast-Slow Chasing DPO)
- Расширение OFS-DPO для кросс-доменных сценариев
- Использует линейные комбинации быстрых модулей из разных доменов задач
- Полностью использует историческую информацию для достижения постоянного выравнивания ценностей

### Теоретические гарантии
- Доказано достижение более низкой эмпирической границы потерь по сравнению со стандартным DPO
- Обеспечивает более стабильную градиентную оптимизацию и более быструю сходимость
- Теоретически обоснована эффективность в условиях сдвига распределений данных

## Применения

### Внутридоменные задачи
- Генерация текста с контролируемым настроением
- Суммаризация документов
- Диалоги в один ход

### Кросс-доменные сценарии
- Постоянный адаптивный отбор знаний из разных доменов
- Обучение с предпочтениями в нескольких задачах одновременно
- Защита от катастрофического забывания при обучении на потоках данных разных типов

## Преимущества Online DPO

### Более устойчивое обучение
- Метод достигает более низкой границы эмпирических потерь
- Обеспечивает более стабильную градиентную оптимизацию
- Имеет более быструю сходимость по сравнению со стандартным DPO

### Обработка кросс-доменных сценариев
- Эффективно решает проблему катастрофического забывания
- Полностью использует историческую информацию из разных доменов
- Обеспечивает постоянное выравнивание ценностей в разных задачах

### Ресурсная эффективность
- Сохраняет ресурсно-эффективные характеристики DPO
- Не требует сложных архитектур систем вознаграждений
- Использует эффективную LoRA-настройку для двух модулей

## Экспериментальные результаты

### Сравнение с DPO
- OFS-DPO превосходит стандартный DPO в задачах внутридоменного выравнивания
- COFS-DPO значительно превосходит конкурентные методы в кросс-доменных сценариях
- В задачах контролируемой генерации настроения: win rate 57.1% против 49.4% для DPO (LoRA rank 256)

### Сравнение с другими методами
- Превосходит SFT, DPO и PPO в задачах контролируемой генерации, суммаризации и одиночных диалогах
- В задачах суммаризации: 23.4% win rate против 21.1% для DPO
- В задачах одиночных диалогов: 25.3% win rate против 20.3% для DPO

## Сравнение с альтернативными методами

### Отличия от традиционного DPO
- Работает с потоками данных онлайн, а не с оффлайн датасетами
- Использует внутривидовую конкуренцию через fast-slow модули
- Обеспечивает постоянное обучение и адаптацию к новым предпочтениям

### Отличия от RLHF
- Исключает необходимость в сложных системах вознаграждений
- Сохраняет вычислительную эффективность DPO
- Обеспечивает более прямое обучение на предпочтениях пользователей
