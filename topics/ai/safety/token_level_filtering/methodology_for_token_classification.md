# Методология для классификации токенов с использованием разреженных автоэнкодеров

## Краткое описание

Этот файл описывает методологию, использованную в исследовании "Shaping capabilities with token-level data filtering" для создания классификаторов токенов на основе разреженных автоэнкодеров (SAE). Методология позволяет помечать токены как относящиеся к "области забвения" (например, медицинские знания), что затем используется для фильтрации данных предварительного обучения.

## Основная информация

Авторы используют разреженные автоэнкодеры (SAE), обученные на модели Gemma 2 9B, для автоматического создания аннотаций токенов. Подход преобразует задачу фильтрации данных в задачу слабой сходимости (weak-to-strong generalization), где классификатор обучается на шумных метках, но в результате обобщается и учится "правильному" направлению истинности.

### Основные шаги методологии:

1. **Сбор "областных" латентных представлений из SAE**: Идентификация признаков, соответствующих задаче (например, медицинским знаниям).

2. **Маркировка токенов как медицинские, если они имеют высокую активацию на определенном количестве этих латентных представлений**: Требуется активация нескольких латентных признакей из-за разделения признаков (feature splitting) и высокой вариативности качества автособеседования (autointerp).

3. **Итерационно маркировать смежные токены как медицинские, если они имеют положительную активацию хотя бы на одном из этих латентных представлений**: Это помогает классифицировать целые последовательности токенов, а не только ключевые слова.

4. **Обучение легковесного бидирекционного классификатора**: Создание двунаправленной языковой модели (BiLM) размером 224M параметров, которая получает лучший F1-скор (0.894) на задаче классификации токенов по сравнению с другими подходами. Архитектура бидирекционной модели оправдана тем, что для предсказания "медицинности" текущего токена требуется будущий контекст (например, слово "вирус" имеет разные значения в контекстах "компьютерный вирус" и "вирус гриппа").

5. **Оптимизация баланса между точностью (precision) и полнотой (recall)**: Показано, что фильтрация чувствительна к балансу precision и recall. Агрессивный фильтр (высокий recall, низкий precision) необходим, чтобы полностью удалить способность к определенной области знаний. Это согласуется с различием между "знаниями" и "способностями": нужно удалить достаточно гранулированной информации (атомарных фактов), чтобы схлопнулась высокоуровневая способность.

6. **Решение проблемы шумных меток**: Даже с SAE метки не идеальны. Авторы показывают, что фильтрация может быть устойчивой к шумным меткам при достаточном объеме вычислений предварительного обучения.

## Новые концепции и термины

- **Sparse autoencoder (SAE)**: Нейронная сеть, которая учится эффективно кодировать входные данные с использованием разреженного представления, где только небольшое подмножество нейронов активируется для каждого входа.
- **Autointerp (automatic interpretation)**: Автоматическое создание естественно-языковых описаний для признакей (нейронов) языковой модели.
- **Feature splitting**: Явление, при котором одна концепция может быть разделена на несколько различных признаков в модели.
- **Weak-to-strong generalization**: Феномен, при котором модель, обученная на слабом или шумном сигнале, может обобщаться для выполнения сильной или точной задачи.
- **BiLM (Bidirectional Language Model)**: Двунаправленная языковая модель, которая может использовать как предыдущий, так и последующий контекст для принятия решений о принадлежности токена к целевой области.
- **Aggressive filtering**: Стратегия фильтрации с акцентом на высокий recall (полноту), необходимый для полного удаления нежелательных способностей.
- **Noise labels**: Метки, содержащие ошибки или неточности, часто получающиеся при автоматическом аннотировании с помощью SAE.
- **Feature attribution**: Процесс определения, какие признаки (нейроны, SAE-компоненты) активируются при определенных входных данных для принятия решения о принадлежности к целевой области.

## Примеры применения

- Создание классификаторов для фильтрации медицинского контента из обучающих данных
- Автоматическая идентификация вредоносного кода в обучающих данных
- Фильтрация политически предвзятого контента
- Обнаружение и удаление персональных данных (PII) из корпуса
