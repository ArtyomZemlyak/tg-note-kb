# Формирование возможностей с использованием фильтрации данных на уровне токенов

## Краткое описание

Статья "Shaping capabilities with token-level data filtering" исследует подход к формированию возможностей языковых моделей путем фильтрации данных на уровне токенов во время предварительного обучения. Этот метод направлен на удаление нежелательных возможностей (например, медицинских знаний), сохраняя при этом желательные возможности (например, биологические знания). Авторы Neil Rathi и Alec Radford демонстрируют, что фильтрация на уровне токенов более эффективна, чем фильтрация на уровне документов, достигая равного снижения нежелательных возможностей при меньшей стоимости для доброкачественных возможностей.

## Основная информация

Текущие подходы к уменьшению нежелательных возможностей в языковых моделях в значительной степени являются пост-фактум и могут быть легко обойдены злоумышленниками. Естественной альтернативой является формирование возможностей непосредственно во время предварительного обучения. На задаче удаления медицинских возможностей показывается, что простое вмешательство в виде фильтрации данных предварительного обучения является высокоэффективным, надежным и недорогим в масштабе. Вдохновленные работой по атрибуции данных, авторы демонстрируют, что фильтрация токенов более эффективна, чем фильтрация документов, достигая одинакового воздействия на нежелательные возможности при более низкой стоимости для доброкачественных возможностей. Обучая модели, охватывающие два порядка величины, затем демонстрируется, что фильтрация становится более эффективной с увеличением масштаба: для самых больших моделей фильтрация токенов приводит к 7000-кратному замедлению вычислений в области "забвения". Также показывается, что модели, обученные с фильтрацией токенов, все еще могут быть приведены к соответствию в области "забвения". В процессе разработана методология для маркировки токенов с помощью разреженных автоэнкодеров и дистилляции дешевых, качественных классификаторов. Также продемонстрировано, что фильтрация может быть устойчивой к шумным меткам при достаточном объеме вычислений предварительного обучения.

### Ключевые новшества и подходы

1. **Фильтрация на уровне токенов**: В отличие от традиционной фильтрации на уровне документов, фильтрация на уровне токенов позволяет более точно удалять нежелательные возможности, сохраняя при этом другие знания.

2. **Классификаторы на основе SAE**: Использование разреженных автоэнкодеров (SAE) для создания классификаторов, которые могут определять, связан ли токен с нежелательной областью знаний (например, медициной).

3. **Масштабирование эффективности**: Фильтрация становится более эффективной с увеличением масштаба модели, что делает этот подход особенно привлекательным для крупномасштабных языковых моделей.

4. **Снижение вычислительной эффективности**: Для моделей с 1.8 млрд. параметров фильтрация токенов приводит к 7000-кратному замедлению вычислений в области "забвения".

5. **Новый парадигмальный сдвиг**: Подход представляет переход от безопасности "постфактум" (RLHF/Unlearning) к безопасности "ab initio" (изначальной). Вместо борьбы с уже существующими знаниями в весах модели, фильтрация данных гарантирует, что опасная информация не будет усвоена в первую очередь.

6. **Техническая реализация**: Используется маскировка потерь (loss masking) для предотвращения обновления весов модели на основе нежелательных токенов. Формула потерь: `L = -∑(m_t * log P(x_t | x_<t))`, где `m_t = 0` для токенов, классифицированных как "запрещенные". Это эффективно зануляет градиент для опасных токенов, не позволяя модели обновлять веса на основе этой информации.

7. **Создание классификатора**: Используется хитрый пайплайн weak-to-strong с применением разреженных автоэнкодеров (SAE) на предобученной модели (Gemma 2 9B), чтобы найти латентные признаки, активирующиеся на нежелательных концептах. Эти признаки служат "ground truth" для обучения легковесного бидирекционного классификатора (BERT-подобного на 224M параметров), способного предсказывать принадлежность токена к "запретной" области знаний.

### Методы фильтрации токенов

Рассматриваются две стратегии фильтрации токенов:
- **Loss masking** (маскировка потерь): удаляются градиенты, вычисленные для токенов "забвения" из обратного прохода. Модель по-прежнему может видеть токен в окне контекста.
- **Removal** (удаление): токены "забвения" заменяются специальным токеном `<|hidden|>`. 

## Новые концепции и термины

- **Capability shaping** (формирование возможностей): целенаправленное уменьшение нежелательных возможностей языковой модели без вреда для желательных возможностей.
- **Forget domain** (область "забвения"): нежелательная область знаний, которую стремятся удалить из модели.
- **Retain domain** (область сохранения): желательная область знаний, которую стремятся сохранить в модели.
- **Token-level filtering** (фильтрация на уровне токенов): процесс фильтрации отдельных токенов из обучающих данных.
- **Document-level filtering** (фильтрация на уровне документов): классический подход к фильтрации, при котором целые документы удаляются из набора данных.
- **Loss masking**: техника, при которой бинарная маска зануляет градиенты для нежелательных токенов во время обратного распространения.
- **Weak-to-strong pipeline**: подход, при котором шумные метки, полученные от SAE, используются для обучения более точного классификатора.
- **SAE (Sparse Autoencoder)**: нейронная сеть, которая учится эффективно кодировать входные данные с использованием разреженного представления, где только небольшое подмножество нейронов активируется для каждого входа.
- **BiLM (Bidirectional Language Model)**: двунаправленная языковая модель, способная использовать контекст как из прошлого, так и из будущего для предсказания принадлежности токена к определенной категории.
- **Scalpel vs Sledgehammer**: метафора, описывающая разницу между точной фильтрацией токенов (скальпель) и грубым удалением целых документов (кувалда).

## Примеры применения

- Удаление медицинских знаний из языковой модели, чтобы она не могла помочь в создании биооружия
- Предотвращение формирования политических предпочтений, которые могут быть нежелательны для универсальной модели
- Уменьшение способностей к генерации дезинформации или других вредоносных форматов контента
- Формирование моделей, которые будут более устойчивыми к jailbreak-атакам и другим формам злоупотребления
- Предотвращение накопления знаний о способах синтеза биологического оружия или других опасных технологиях
