# Сравнение фильтрации на уровне токенов и на уровне документов

## Краткое описание

Этот файл содержит подробное сравнение между фильтрацией данных на уровне токенов и фильтрацией на уровне документов, как это было исследовано в статье "Shaping capabilities with token-level data filtering". Фильтрация на уровне токенов показывает превосходство по Парето над фильтрацией на уровне документов, достигая равного снижения нежелательных возможностей при более низкой стоимости для доброкачественных возможностей.

## Основная информация

### Фильтрация на уровне документов (Document-level filtering):
- **Принцип**: Удаляет целые документы из обучающей выборки, если они содержат нежелательный контент
- **Преимущества**: Простота реализации, легче понять и контролировать
- **Недостатки**: 
  - Может удалить много ценного контента вместе с нежелательным
  - Снижает точность по отношению к нежелательному контенту
  - Может привести к потере полезных знаний в смешанных документах

### Фильтрация на уровне токенов (Token-level filtering):
- **Принцип**: Идентифицирует и удаляет/маскирует конкретные токены, связанные с нежелательными возможностями
- **Преимущества**:
  - Более точное удаление нежелательного контента
  - Сохраняет больше ценного контента в документах
  - Лучший баланс между удалением вредных и сохранением полезных возможностей
  - Превосходство по Парето (Pareto dominance) над документной фильтрацией

### Сравнительные характеристики:

1. **Точность (Precision)**: Фильтрация токенов имеет более высокую точность, так как удаляет только действительно нежелательные элементы, а не целые документы.

2. **Полнота (Recall)**: Фильтрация токенов достигает той же полноты, что и фильтрация документов, эффективно удаляя нежелательный контент.

3. **Воздействие на доброкачественные возможности**: Фильтрация токенов оказывает меньшее негативное воздействие на доброкачественные (retain) возможности по сравнению с фильтрацией документов.

4. **Масштабируемость**: Эффективность фильтрации токенов увеличивается с масштабом модели, что делает её особенно привлекательной для современных крупномасштабных языковых моделей.

## Технические детали

### Методы фильтрации токенов:
1. **Loss masking**: Удаление градиентов для нежелательных токенов из обратного прохода, позволяя модели видеть эти токены во время прямого прохода.
2. **Removal**: Замена нежелательных токенов специальным токеном `<|hidden|>` и маскировка потерь на этих токенах.

### Стратегии классификации:
- Использование модели-классификатора для определения, принадлежит ли токен к "области забвения"
- Сравнение с классификацией на уровне документов при помощи документно-уровневого классификатора

## Новые концепции и термины

- **Pareto dominance**: Ситуация, при которой одна стратегия превосходит другую по одному или нескольким критериям, не уступая по другим критериям.
- **Forget loss / Retain loss**: Метрики, используемые для измерения эффективности фильтрации - потеря (loss) на нежелательных данных (forget) и на доброкачественных данных (retain).
- **High recall / High precision**: Термины, описывающие баланс между полнотой (recall) и точностью (precision) классификатора, используемого для фильтрации.

## Примеры применения

- Выбор между двумя подходами при разработке методов безопасности для новых языковых моделей
- Оценка влияния фильтрации на производительность модели в различных задачах
- Планирование стратегии удаления нежелательного контента из обучающих данных
