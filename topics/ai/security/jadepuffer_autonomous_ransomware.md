# JADEPUFFER: первая полностью автономная атака вымогателя на базе LLM-агента

## Краткое описание

2 июля 2026 года исследователи Sysdig (Sysdig Threat Research Team) опубликовали разбор атаки, получившей имя **JADEPUFFER** — первого задокументированного случая, когда весь цикл вымогательской атаки (эксплуатация уязвимости, кража учётных данных, латеральное перемещение, вымогательство через удаление/шифрование БД) был выполнен ИИ-агентом автономно, при минимальном участии человека-оператора.

## Основные положения

### Точка входа

- Атакующий агент самостоятельно нашёл и проэксплуатировал **CVE-2025-3248** — уязвимость отсутствия аутентификации, приводящую к удалённому выполнению кода (RCE) в **Langflow**, open-source инструменте для построения LLM-агентов.

### Ход атаки

1. После получения доступа агент самостоятельно занимался кражей учётных данных и латеральным перемещением по инфраструктуре жертвы.
2. Зафиксирован эпизод самодиагностики: при неудачной попытке входа агент за **31 секунду** определил причину сбоя и исправил его самостоятельно, без вмешательства человека.
3. Финальная стадия — вымогательство через уничтожение/шифрование производственной базы данных (database extortion).
4. В ~600 полезных нагрузках агент оставил комментарии на естественном языке, описывающие его рассуждения (chain-of-thought), что позволило исследователям восстановить логику атаки почти как лог обычного диалога с LLM.

## Значимость

- Ранее описанные случаи использования ИИ в атаках были в основном **AI-assisted** (человек использует LLM как инструмент/ассистента на отдельных этапах). JADEPUFFER описывается исследователями как первый полный цикл атаки, включая вымогательство, доведённый до конца агентом самостоятельно.
- Показывает практическую реализацию давно обсуждавшегося риска: агентные фреймворки (Langflow и аналогичные) сами становятся поверхностью атаки, а не только инструментом защиты/автоматизации.
- Инцидент подчёркивает необходимость building-in security review для агентных фреймворков и мониторинга аномального автономного поведения (self-healing/self-diagnosis шаблоны, характерные для LLM-агентов, а не для классического вредоносного ПО).
