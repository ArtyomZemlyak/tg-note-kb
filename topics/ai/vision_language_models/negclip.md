# NegCLIP: Улучшение контрастивного обучения для визуально-языковых моделей

## Краткое описание

**NegCLIP** — это метод улучшенного контрастивного обучения для визуально-языковых моделей (VLM), предложенный для решения проблемы bags-of-words (BoW) поведения. Метод был представлен в работе "When and why vision-language models behave like bags-of-words, and what to do about it?" как способ заставить модели понимать структуру текста, отношения между объектами и порядок слов, а не просто ловить поверхностные совпадения слов.

NegCLIP достигает этого за счёт введения более "жёстких" негативных примеров (hard negatives) в процесс контрастивного обучения, что вынуждает модель учиться более тонким и содержательным представлениям.

## Проблема стандартного контрастивного обучения

### InfoNCE Loss и его ограничения

Стандартное контрастивное обучение в CLIP использует InfoNCE loss:

```
L = -log(exp(sim(q, d+)/τ) / Σ(d_i ∈ D_N ∪ {d+}) exp(sim(q, d_i)/τ))
```

**Проблемы**:
- Слишком легко проходит на поверхностных совпадениях
- Модель учится находить простые корреляции между словами и визуальными паттернами
- Нет необходимости понимать структуру предложения или отношения между объектами
- Простые негативы не требуют от модели глубокого понимания

### Последствия

- Модели ведут себя как bags-of-words
- Игнорируют порядок слов
- Не понимают отношения между объектами ("horse eats grass" vs "grass eats horse")
- Плохо справляются с атрибуцией (связыванием атрибутов с объектами)

## Решение NegCLIP

### Основная идея

NegCLIP вводит два типа "жёстких" негативов для улучшения обучения:

### 1. Strong Alternative Images

**Описание**:
- Самые похожие картинки по эмбеддингам CLIP
- Добавляются как сильные негативные примеры
- Визуально близки к позитивному примеру, но семантически отличаются

**Как это работает**:
- Для каждой пары (изображение, текст) находятся визуально похожие изображения
- Эти изображения служат негативами для текстового запроса
- Модель вынуждена учиться тонким визуальным различиям

**Преимущества**:
- Заставляет модель различать визуально похожие, но семантически разные сцены
- Улучшает качество визуальных представлений
- Требует более глубокого понимания содержания изображения

### 2. Targeted Negative Captions

**Описание**:
- Подписи, где слова специально переставлены или подменены
- Создают "жёсткие" негативные примеры для текстовой модальности
- Сохраняют те же слова, но меняют смысл

**Типы искажений**:
- **Перестановка существительных и прилагательных**: "white road" → "paved road"
- **Перестановка почти всех слов**: "dog sits on mat" → "mat sits on dog"
- **Перестановка внутри триграмм**: локальные перестановки для нарушения синтаксиса

**Как это работает**:
- Для каждой правильной подписи создаётся несколько искажённых версий
- Искажённые подписи служат негативами для изображения
- Модель вынуждена учитывать порядок слов и структуру предложения

**Преимущества**:
- Требует понимания синтаксиса и семантики
- Учит модель различать семантически разные предложения с одинаковыми словами
- Улучшает чувствительность к порядку слов

## Архитектура обучения NegCLIP

### Процесс обучения

1. **Подготовка данных**:
   - Базовые пары (изображение, текст)
   - Strong alternative images для каждого изображения
   - Targeted negative captions для каждого текста

2. **Контрастивное обучение**:
   - Позитивные пары: оригинальное изображение + оригинальный текст
   - Негативы типа 1: похожие изображения
   - Негативы типа 2: искажённые тексты

3. **Функция потерь**:
   - Модифицированный InfoNCE loss с учётом всех типов негативов
   - Больший вес на hard negatives для улучшения обучения

### Отличия от стандартного CLIP

| Аспект | CLIP | NegCLIP |
|--------|------|---------|
| Негативы | Случайные из батча | Strong alternatives + targeted negatives |
| Текстовые негативы | Другие тексты из батча | Переставленные версии тех же текстов |
| Визуальные негативы | Другие изображения из батча | Визуально похожие изображения |
| Требование к пониманию | Поверхностное | Глубокое (структура, отношения) |

## Результаты и оценка

### Бенчмарк ARO

NegCLIP оценивался на бенчмарке ARO (Attribution, Relation, Order):

#### VG-Relation
- **Задача**: Понимание отношений между объектами
- **Пример**: "horse eats grass" vs "grass eats horse"
- **Результат NegCLIP**: Значительное улучшение по сравнению с базовым CLIP

#### VG-Attribution
- **Задача**: Правильное связывание атрибутов с объектами
- **Пример**: "paved road" vs "white road"
- **Результат NegCLIP**: Улучшенная точность атрибуции

#### COCO-Order
- **Задача**: Чувствительность к порядку слов
- **Типы искажений**: Перестановка существительных/прилагательных, перемешивание слов
- **Результат NegCLIP**: Лучшая устойчивость к перестановкам

#### Flickr-Order
- **Задача**: Оценка на другом датасете
- **Результат NegCLIP**: Подтверждение обобщающей способности метода

### Ключевые метрики

- **Accuracy на тестах отношений**: Улучшение на X% (см. оригинальную статью)
- **Accuracy на тестах атрибуции**: Улучшение на Y%
- **Чувствительность к порядку**: Значительное улучшение по сравнению с базовыми моделями

## Применение NegCLIP

### Для исследователей

1. **Улучшение существующих моделей**:
   - Интеграция hard negative mining в процесс обучения
   - Генерация targeted negative captions для ваших датасетов

2. **Оценка моделей**:
   - Использование ARO бенчмарка для тестирования
   - Сравнение с базовыми моделями CLIP

### Для практиков

1. **Поиск изображений**:
   - Улучшение качества поиска на сложных запросах
   - Лучшее понимание отношений между объектами

2. **Мультимодальные приложения**:
   - Более точное сопоставление текста и изображений
   - Улучшенная обработка сложных описаний

## Ограничения

### Вычислительная сложность
- Поиск strong alternative images требует дополнительных вычислений
- Генерация targeted negative captions увеличивает время подготовки данных

### Требования к данным
- Необходимость в большом количестве данных для эффективного hard negative mining
- Качество негативов влияет на результат обучения

### Обобщающая способность
- Метод показывает лучшие результаты на бенчмарках понимания структуры
- Может быть менее эффективен на задачах, где достаточно поверхностного совпадения

## Связь с другими методами

### Hard Negative Mining

NegCLIP относится к семейству методов hard negative mining:
- **В поиске**: Использование сложных негативов для улучшения качества поиска
- **В контрастивном обучении**: InfoNCE с улучшенными негативами
- **В машинном обучении**: Общий принцип обучения на сложных примерах

### Контрастивное обучение

NegCLIP развивает идеи контрастивного обучения:
- [[contrastive_learning.md]] - Общие принципы контрастивного обучения
- [[../applications/computer_vision/multimodal_models.md]] - CLIP и SigLIP используют контрастивное обучение
- **InfoNCE Loss**: Базовая функция потерь, улучшенная в NegCLIP

## Новые концепции и термины

- **Hard Negative Mining**: Техника выбора сложных негативных примеров для обучения
- **Strong Alternative Images**: Визуально похожие изображения как сложные негативы
- **Targeted Negative Captions**: Текстовые негативы с намеренно искажённой структурой
- **Contrastive Learning Enhancement**: Улучшение контрастивного обучения через лучшие негативы
