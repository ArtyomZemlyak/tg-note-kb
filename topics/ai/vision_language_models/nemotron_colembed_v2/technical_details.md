# Nemotron ColEmbed V2: Технические детали архитектуры

## Архитектурные особенности

### 3B модель (llama-nemotron-colembed-vl-3b-v2)

Модель основана на NVIDIA Eagle 2 визуально-языковой модели, расширяющей свою первую версию. Архитектура включает:
- Динамическое разбиение изображений (dynamic image tiling) для поддержки входных данных различных разрешений
- SigLIP-2 визуальный энкодер для извлечения признаков изображений
- Llama 3.2 3B LLM бэкбон
- Механизм late-interaction для fine-grained взаимодействия между запросом и документом

**Параметры разбиения изображений**:
- Для обучения: max_input_tiles = 2 (включая дополнительный миниатюрный тайл) для обеспечения эффективности памяти
- Для инференса: max_input_tiles = 8 для более тонкой визуальной детализации
- Каждый тайл изображения генерирует 256 визуальных токенов

### 4B и 8B модели (nemotron-colembed-vl-4b-v2 / 8b-v2)

Модели основаны на архитектуре Qwen3-VL 4B и 8B VLM, которая включает:
- SigLIP-2 визуальный энкодер
- Двух-слойный MLP-based модуль слияния визуально-языковой информации
- Qwen3 LLM бэкбон
- Three-module архитектура для поддержки многомодальных входов и длительного контекста

## Механизмы Late Interaction

### Основной принцип
Классические подходы pooling-эмбеддингов сжимают последовательности в один вектор, что ограничивает выразительность тонких лексических, визуальных или зависящих от компоновки признаков. Механизм late interaction сохраняет expressiveness от cross-encoder архитектур, но позволяет предварительно вычислять multi-векторные эмбеддинги документов.

### MaxSim операция
- Для каждого токена запроса вычисляется сходство с каждым токеном документа
- Для каждого токена запроса выбирается максимальное значение сходства
- Полученные значения суммируются для получения окончательной оценки релевантности

### Преимущества перед pooling-подходами
- Fine-grained взаимодействие между токенами запроса и документа
- Повышенная точность поиска по сравнению с усреднением или last-token pooling
- Возможность точного соответствия конкретных токенов запроса и документа

## Обучение моделей

### Контрастное обучение
Модели плотного поиска обычно обучаются с использованием контрастного обучения для максимизации сходства между запросом и позитивным пассажем, минимизируя сходство между запросом и негативной корой. Используется InfoNCE контрастная потеря:

L = -log(exp(sim(q, d+)/τ) / Σ(d_i ∈ D_N ∪ {d+}) exp(sim(q, d_i)/τ))

где:
- q - эмбеддинг запроса
- d+ - эмбеддинг позитивного документа
- D_N - набор негативных пассажей
- τ - температурный параметр
- sim(·) - функция сходства (cosine similarity, dot product или late interaction similarity)

### Hard-negative mining
Процесс включает:
1. Использование внешней "учительской" модели поиска для нахождения top-k похожих документов
2. Фильтрация похожих документов по порогу: отбираются k самых похожих негативных примеров, чье сходство с запросом ниже 95% от сходства запроса-позитивного документа
3. Обеспечение того, чтобы отобранные негативные примеры были близки к границе решения, но не были бы неправильными (фальшивые позитивы)

### Кластеризация данных
Для балансировки доменов обучения:
1. Генерация эмбеддингов изображений документов с помощью внутренней модели Llama-Eagle VLM
2. Применение PCA для снижения размерности до 50 из 3072-мерного пространства
3. K-Means кластеризация с использованием gap statistics для выбора оптимального числа кластеров
4. Равномерная выборка из 14 обнаруженных кластеров для обеспечения разнообразия доменов

## Модельное слияние (Model Merging)

Техника, объединяющая веса нескольких моделей с одинаковой архитектурой, но обученных на разных данных или гиперпараметрах. Используется простое взвешенное усреднение весов.

**Результаты улучшения точности**:
- llama-nemotron-colembed-vl-3b-v2: +0.8% после слияния 8 моделей
- nemotron-colembed-vl-4b-v2: +1.0% после слияния 4 моделей
- nemotron-colembed-vl-8b-v2: +1.5% после слияния 4 моделей

## Сравнение с другими моделями

- **ColPali**: VLM эмбеддинговая модель, использовавшая early late interaction подход для улучшения точности поиска
- **NV-Embed**: Одна из ранних высокопроизводительных текстовых эмбеддинговых моделей
- **Jina CLIP**: Визуальная документо-ретривальная модель на основе CLIP
- **Nomic Embed Vision**: Контрастивная эмбеддинговая модель для визуального поиска

## Техники оптимизации

- **Knowledge distillation**: Передача знаний из моделей высокой емкости меньшим моделям
- **Quantization**: Снижение требований к памяти за счет уменьшения точности представления
- **Matryoshka Representation Learning**: Подход, позволяющий одной модели создавать эмбеддинги, которые можно срезать до нескольких меньших размеров
