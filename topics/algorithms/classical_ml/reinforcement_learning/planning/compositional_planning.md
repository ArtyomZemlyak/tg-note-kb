# Композиционное планирование в обучении с подкреплением

## Общее описание

**Композиционное планирование (Compositional Planning)** в обучении с подкреплением — это подход к решению сложных задач с длинным горизонтом через композицию (комбинирование) предобученных политик как временно расширенных действий. Вместо рассуждения над примитивными действиями шаг за шагом, агент планирует на уровне навыков (skills), которые уже объединяют множество действий в осмысленные последовательности.

Ключевая идея: способность планировать с временными абстракциями является центральной для интеллектуального принятия решений.

## Мотивация

### Проблема примитивного планирования

Традиционные агенты планируют, рассуждая над примитивными действиями, одно за другим. Это работает для коротких задач, но для длинных и сложных целей:
- Навигация в здании
- Манипуляция объектами
- Сложные последовательности действий

...небольшие ошибки предсказаний быстро накапливаются, и планирование перестаёт работать.

### Человеческая аналогия

Люди избегают этой проблемы через мышление "чанками" (блоками):
- "Сесть в машину"
- "Поехать по шоссе"
- "Припарковаться"

Каждый из этих навыков состоит из множества примитивных действий, но мы планируем на уровне навыков.

### Вызов композиционного планирования

Композиционное планирование остаётся сложной проблемой, потому что:
- **Накопление ошибок**: При цепочке политик compounding errors в long-horizon предсказаниях делают сложной оценку visitation distribution
- **Предсказание результатов**: Сложно предсказать, где агент окажется после выполнения последовательности политик
- **Оценка ценности**: Трудно оценить ценность последовательности без предварительной практики этой точной последовательности

## Фреймворк композиционного планирования

### Базовые политики

Агент оснащён репертуаром предобученных политик {π_z}_{z∈Z}, индексированных z:
- **Goal-conditioned политики**: z ∈ S представляет целевое состояние
- **Latent-conditioned политики**: z — латентная переменная, параметризующая разнообразные поведения

### Цели

1. **Обучение предсказательной модели**: Модель поведения политик для планирования downstream задач
2. **Zero-shot планирование**: Решение новых задач без дополнительного взаимодействия со средой или fine-tuning
3. **Гибкая композиция**: Комбинирование существующих политик для решения сложных long-horizon задач

## Jumpy World Models для планирования

### Policy-conditioned GHM

Обучается **policy и horizon conditioned jumpy world model**, который захватывает распределение будущих состояний для всех параметризованных политик над континуумом геометрически затухающих временных горизонтов.

### Temporal Difference Horizon Consistency

Новый **consistency objective** усиливает coherence между предсказаниями на разных временных масштабах, последовательно улучшая long-horizon predictive accuracy.

### Оценка последовательностей

С помощью обученных GHM, агент может:
- Комбинировать генеративные предсказания для оценки ценности произвольных последовательностей политик
- Оценивать последовательности с переменными временными масштабами
- Планировать без предварительной практики точных последовательностей

## Geometric Switching Policies

### Формализм

**Geometric Switching Policy (GSP)** — последовательность политик с геометрическим переключением:

```
ν := π_{z_1} →^{α_1} π_{z_2} →^{α_2} ... →^{α_{n-1}} π_{z_n}
```

где α_i ∈ [0,1] — вероятность переключения после π_{z_i}.

### Эффективные дисконт-факторы

Для политики π_{z_k} в GSP:

```
β_k := γ * (1 - α_k)
```

где γ — глобальный дисконт-фактор MDP.

### Разложение Successor Measure

Successor measure GSP разлагается как смесь распределений:

```
m^γ_ν(·|s,a) = Σ_{k=1}^{n} w_k * E[m^{β_k}_{π_{z_k}}(·|S_{k-1},A_{k-1})]
```

где w_k — веса, отражающие относительный вклад каждой политики.

### Monte Carlo оценка

Single-sample monte-carlo estimator:

```
Q̂^γ_ν = Σ_{k=1}^{n} w_k * r(S^+_k)
```

является несмещённой оценкой Q^γ_ν(s,a), где S^+_k сэмплируются последовательно через композицию GHM предсказаний.

## Процедура планирования

### Оптимизационная задача

Дана reward function r: S → R, цель:

```
maximize Q^γ_ν(s,a) over (a_1, z_1, ..., z_n)
```

где ν := π_{z_1} →^{α_1} ... →^{α_{n-1}} π_{z_n}

### Random shooting

Для больших или непрерывных Z, оптимизация через random shooting:

1. **Proposal distribution**: Генерация m кандидатных последовательностей {(z^(i)_1, ..., z^(i)_n)} из GHM
2. **Оценка**: Вычисление Q^{ν^(i)}_γ(s,a^(i)_1) для каждой кандидатной switching policy
3. **Выбор**: Селекция последовательности (a*_1, z*_1, ..., z*_n) с наивысшей ценностью Q^{ν*}_γ

### Proposal distribution через GHM

Для goal-conditioned политик (Z = S):
-给定 цель g ∈ S, генерируем waypoints из z_0 := s через композицию m^{β_i}_{π_g}
- Альтернативно: сэмплирование из unconditional GHM, предсказывающего plausible successor states

### Replanning

После идентификации оптимальной последовательности:
1. Выполняем первое действие a*_1
2. Выполняем политику π_{z*_1}
3. Replanning в будущих состояниях по мере необходимости

## Унификация существующих подходов

Композиционное планирование унифицирует несколько подходов через варьирование {α_i}:

| Подход | Настройки α_i | Описание |
|--------|---------------|----------|
| **ActionPlan** (MPC) | α_1 = ... = α_n = 1 | Model-Predictive Control с горизонтом n |
| **GPI** | α_1 = 1, α_2 = ... = α_n = 0 | Generalized Policy Improvement (Barreto et al., 2017) |
| **GGPI** | α_1 = ... = α_{n-1} = α | Geometric GPI (Thakoor et al., 2022) |
| **CompPlan** | α_1, ..., α_{n-1} ∈ (0,1) | Полное композиционное планирование |

### Ключевое отличие

CompPlan позволяет **различным вероятностям переключения** α_1, ..., α_{n-1} ∈ (0,1), обеспечивая более гибкое планирование.

## Эмпирические результаты

### Экспериментальная установка

- **Бенчмарк**: OGBench (Park et al., 2025a)
- **Задачи**:
  - Ant navigation в лабиринтах (medium, large, giant)
  - Multi-cube robotic arm manipulation
- **Датасеты**: Standard navigate и play offline datasets

### Основные результаты

1. **Zero-shot улучшение**: Compositional planning значительно улучшает zero-shot performance across wide range of base policies

2. **Среднее улучшение**: ~200% relative improvement над планированием с примитивными действиями на long-horizon задачах

3. **Сравнение с baseline'ами**:
   - Превосходит state-of-the-art hierarchical методы
   - Превосходит альтернативные подходы к планированию
   - Planning with jumpy world models > action-level planning with one-step world model

4. **Эффект consistency loss**: TD-HC objective последовательно улучшает model accuracy и planning performance

## Преимущества композиционного планирования

1. **Zero-shot обобщение**: Решение новых задач без дополнительного обучения

2. **Масштабируемость**: Эффективное планирование на длинных горизонтах

3. **Гибкость**: Унификация action-level и policy-level планирования

4. **Точность**: Улучшенная long-horizon predictive accuracy через consistency objective

5. **Off-policy обучение**: Планирование из offline датасетов

## Ограничения

1. **Зависимость от базовых политик**: Качество планирования зависит от качества и разнообразия предобученных политик

2. **Вычислительная сложность**: Random shooting требует множественных оценок Q-value

3. **Гиперпараметры**: Switching probabilities {α_i} трактуются как гиперпараметры

4. **Пространство поиска**: Для больших Z требуется эффективная proposal distribution

## Применения

### Навигация

- Долгосрочная навигация в сложных средах
- Планирование маршрутов через композицию навыков
- Zero-shot обобщение на новые конфигурации лабиринтов

### Робототехническая манипуляция

- Сложные задачи манипуляции с объектами
- Последовательности действий с множеством степеней свободы
- Адаптация к новым конфигурациям задач

### Автономные системы

- Планирование в средах с высокой неопределённостью
- Композиция предобученных навыков
- Zero-shot решение новых задач
