# K-Means Кластеризация

## Общее описание

**K-Means (K-средних)** — один из самых классических и широко используемых алгоритмов кластеризации в машинном обучении. Алгоритм решает задачу разбиения набора данных на K кластеров, минимизируя внутрикластерную дисперсию.

## Математическая формулировка

Для данных X ∈ R^(N×d) и центроидов C ∈ R^(K×d), Euclidean k-means минимизирует целевую функцию:

L = Σ(i=1 to N) Σ(k=1 to K) a_ik ||x_i - c_k||²₂

где a_ik = 1, если точка x_i назначена кластеру k, и 0 в противном случае.

## Алгоритм Ллойда

Стандартный алгоритм K-Means (алгоритм Ллойда) состоит из чередующихся этапов:

### 1. Этап назначения (Assignment Stage)
Вычисляет матрицу расстояний D ∈ R^(N×K) и назначает каждую точку ближайшему центроиду:
- D_ik = ||x_i - c_k||²₂
- a_i = argmin_k D_ik

### 2. Этап обновления центроидов (Centroid Update Stage)
Агрегирует точки, назначенные каждому кластеру, для вычисления новых центроидов:
- c_k = (Σ a_ik * x_i) / (Σ a_ik)

На практике квадрат расстояния раскладывается как:
||x_i - c_k||²₂ = ||x_i||²₂ + ||c_k||²₂ - 2x_i^T c_k

что позволяет переиспользовать нормы и сводит вычисление к матричным умножениям.

## Проблемы производительности на GPU

Современные реализации K-Means на GPU сталкиваются с тремя основными проблемами:

### 1. IO-ограничение на этапе назначения
- Стандартные реализации явно материализуют матрицу расстояний D ∈ R^(N×K) в HBM (High Bandwidth Memory)
- При N=65536, K=1024, d=128:
  - Вычисление расстояний: 2.6 мс
  - Запись/чтение матрицы D: 23 мс
- Материализация D требует Θ(NK) операций записи и Θ(NK) операций чтения на итерацию

### 2. Конкуренция атомарных операций на этапе обновления
- Стандартные реализации используют scatter-обновления с атомарными операциями
- Множество потоков одновременно пытаются обновить один центроид (особенно для несбалансированных кластеров)
- Измеренная пропускная способность: только 50 GB/s на NVIDIA H200

### 3. Системные ограничения
- При больших размерах батчей данные не помещаются в VRAM
- Chunk-wise выполнение вводит накладные расходы на коммуникацию CPU-GPU
- Динамические формы данных увеличивают затраты на компиляцию и настройку

## Применение в современных AI workload

K-Means переживает смену парадигмы — от офлайн-инструмента к онлайн-оператору:

1. **Обработка данных и поиск**:
   - Веб-масштабная семантическая дедупликация
   - Квантование эмбеддингов для late-interaction поиска

2. **Большие языковые модели (LLM)**:
   - Динамическая маршрутизация токенов для sparse attention
   - Слияние семантических состояний для компрессии KV cache

3. **Генеративные видео модели**:
   - Семантически-осознанная перестановка токенов в Diffusion Transformers
   - Экстремальное низкоразрядное квантование KV-cache
