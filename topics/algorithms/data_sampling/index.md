# Data Sampling Algorithms

This section contains information about various algorithms used for data sampling, subset selection, and smart data curation in machine learning and AI systems.

## Available Topics

- [[gist_greedy_independent_set_thresholding|GIST: Greedy Independent Set Thresholding]] - Google Research algorithm for smart data sampling with theoretical guarantees for balancing diversity and utility

## Overview

Data sampling algorithms are crucial for efficiently managing large datasets in machine learning workflows. They help select representative subsets that maintain the diversity and utility of the original data while reducing computational costs and training times.
