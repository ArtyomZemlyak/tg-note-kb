# Gecko: Бесконечный контекст без потери памяти

## Описание

Gecko — это архитектура нейронной сети с 7 миллиардами параметров, предложенная в статье "Gecko: An Efficient Neural Architecture Inherently Processing Sequences with Arbitrary Lengths" (Ma et al., 2026). Архитектура построена на основе Megalodon, используя Gated Attention и экспоненциальное скользящее среднее. Она решает проблему ограниченного контекста в трансформерах, предлагая способ обработки последовательностей произвольной длины без потери информации.

## Ключевые улучшения

Gecko внедряет три ключевых улучшения для стабилизации линейного внимания:

1. **Timestep Decay Normalization** — стабилизация статистик во времени, что позволяет модели адаптироваться к локальным сдвигам распределения на поздних этапах обучения.
2. **Sliding Chunk Attention (SCA)** — устранение артефактов на границах чанков. В отличие от посимвольных скользящих окон, SCA рассчитывает внимание совместно по текущему и предыдущему чанку ([K_{s-1}, K_s] и [V_{s-1}, V_s]), что обеспечивает, что токены в начале текущего чанка могут "смотреть" в непосредственное прошлое.
3. **Adaptive Working Memory (AWM)** — сжатие истории в фиксированное состояние без принудительного забывания, типичного для SSM (State Space Models). Это позволяет модели сжимать всю историю в фиксированное состояние M_s, не отбрасывая информацию явно.

## Теоретический фундамент

Основой для Gecko является Complex Exponential Moving Average (CEMA), унаследованный от Mega и Megalodon. Эта архитектура использует комплекснозначную рекуррентность, где атомарной единицей обработки состояния является не простое скалярное обновление, а комплекснозначное вычисление.

Правило обновления для скрытого состояния h:
```
h_t = α ⊙ u_t + (1 - α ⊙ δ)(cos θ + i sin θ) ⊙ h_{t-1}
```

Где:
- u — расширенные входные признаки
- α и δ — факторы затухания и демпфирования
- операции выполняются в комплексной области (C)

## Архитектурные особенности

### Скользящие чанки и адаптивная память

Gecko обрабатывает входную последовательность, сначала прогоняя её через улучшенный слой нормализации, а затем разделяя вычисления на локальный и глобальный контексты. Для обработки бесконечной истории, предшествующей чанку s-1, используется Adaptive Working Memory (AWM), который использует механизм линейного внимания, оснащённый позиционно-зависимым online softmax ядром.

Правило обновления для состояния памяти M_s:
```
M_s = (z_{s-1}/z_s) ⊙ M_{s-1} + (w_s/z_s) ⊙ φ(K_s)^T (V_s - ψ(K_s)M_{s-1})
```

Где:
- z_s — кумулятивная сумма экспоненциальных ключей вплоть до чанка s
- w_s — сумма для текущего чанка
- φ и ψ — функции активации

### Нормализация с затуханием

Для решения проблемы ригидности кумулятивных статистик (среднее и дисперсия) в авторегрессионной нормализации на поздних этапах обучения Gecko вводит факторы затухания β_1, β_2 в расчёт кумулятивных статистик:

```
m_t = β_1 m_{t-1} + (1 - β_1)μ_t
```

Это напоминает механику моментума в оптимизаторе Adam, позволяя статистикам нормализации динамически адаптироваться на длинных последовательностях.

### Параллельные ассоциативные сканирования

С системной точки зрения авторы предоставили высокооптимизированную CUDA-реализацию для рекуррентности CEMA. Рекуррентность переформулирована как параллельное ассоциативное сканирование (parallel associative scan), отображая комплексную аффинную алгебру на бинарный ассоциативный оператор. Это снижает сложность с линейной O(L) до логарифмической O(log L) на параллельном железе.

## Результаты

### Предобучение
- Gecko-7B достигает валидационного лосса 1.68 на 2 триллионах токенов
- Превосходит Llama2-7B (1.75) и Megalodon-7B (1.70)
- Почти догоняет Llama2-13B (1.67)

### Долгий контекст
- Модель успешно извлекает информацию из контекста длиной до 4 миллионов токенов
- Монотонное снижение перплексии вплоть до длины последовательности в 4 миллиона токенов
- Практически идеальная точность поиска ключей (passkeys) вплоть до длины контекста 16k без файнтюнинга

### Бенчмарки
- На бенчмарке Scrolls Gecko-7B превосходит Megalodon-7B и Llama2-7B на задачах NarrativeQA (27.3 vs 23.9) и Qasper (34.2 vs 28.0)

## Приложения

Gecko особенно полезна для приложений, требующих:
- Обработки очень длинных последовательностей данных
- Извлечения информации из больших объемов текста
- Постоянного доступа к истории без потерь
- Агентских пайплайнов, требующих огромных окон контекста
- RAG-систем (Retrieval Augmented Generation)

### Трансформеры
В отличие от трансформеров с квадратичной сложностью, Gecko предлагает линейную эффективность, сопоставимую с рекуррентными нейросетями и моделями пространства состояний, но с лучшей точностью благодаря своим адаптивным механизмам памяти.

## Преимущества

- Врожденная способность работать с длинным контекстом без специального файнтюнинга
- Стабильность при обработке длинных последовательностей
- Эффективность при сохранении качества
- Отсутствие искусственного "забвения" информации

## Недостатки и ограничения

- Сложность компонентов Gecko создает барьер для внедрения по сравнению с простотой обычных трансформеров
- Механизм AWM включает в себя комплекснозначные рекуррентности и специализированные реализации ядер, которые могут быть хрупкими при портировании на другие аппаратные ускорители
- Адаптивная память, хотя и "адаптивная", все же состояние фиксированной ёмкости, что может привести к "коллизиям памяти" при экстремально длинных последовательностях
