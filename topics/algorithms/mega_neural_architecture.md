# Mega: Moving Average Equipped Gated Attention

## Описание

Mega (Moving Average Equipped Gated Attention) — это нейронная архитектура, представленная в статье "Mega: Moving Average Equipped Gated Attention" (Ma et al., 2022). Это простая, эффективная и эффективная нейронная архитектура, используемая в качестве замены для обычного многоголового внимания (multi-head attention). Mega объединяет концепции рекуррентности, структурированного внимания и экспоненциального скользящего среднего для эффективного моделирования последовательностей.

## Основные характеристики

### Комплексное экспоненциальное скользящее среднее (CEMA)
Mega вводит CEMA как основной строительный блок для последовательного моделирования. Это обобщение экспоненциального скользящего среднего, которое работает в комплексной области и позволяет модели захватывать как осцилляторную динамику, так и длинные зависимости.

### Структурированное затухание
Архитектура использует структурированное затухание для управления влиянием предыдущих элементов на текущее представление, позволяя модели контролировать масштабы памяти.

### Гейтированное внимание
Mega включает механизмы гейтирования, которые позволяют модели адаптивно регулировать силу внимания и памяти в зависимости от входных данных.

## Математическое описание

Mega реализует правило обновления состояния:
```
h_t = g_t ⊙ (α_t ⊙ x_t) + (1 - α_t) ⊙ (β_t cos(θ_t) + i β_t sin(θ_t)) ⊙ h_{t-1}
```

Где:
- g_t — гейт обновления
- α_t — вес текущего ввода 
- β_t — параметр затухания
- θ_t — параметр угловой частоты
- h_t — скрытое состояние на шаге t
- i — мнимая единица (работа в комплексной области)

## Преимущества

- Эффективность линейного времени и пространства
- Способность моделировать длинные зависимости
- Устойчивость к проблемам градиентного потока
- Объединение рекуррентности и внимания в едином фреймворке

## Применения

- Моделирование длинных последовательностей
- Задачи, требующие эффективного использования памяти
- Сценарии с ограниченными вычислительными ресурсами
- Основа для более продвинутых архитектур (например, Megalodon и Gecko)

## Связь с другими архитектурами

### Связь с Transformers
Mega предлагает решение для квадратичной сложности трансформеров, обеспечивая линейную сложность.

### Связь с Recurrent Networks
В отличие от традиционных рекуррентных сетей, Mega использует более богатые механизмы памяти и регулирования.
