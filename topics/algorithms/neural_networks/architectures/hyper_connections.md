# Hyper-Connections (HC)

## Краткое описание

Hyper-Connections (HC) — это архитектурный подход, расширяющий парадигму residual connection, принятую за последнее десятилетие. HC расширяет ширину residual stream и разнообразяет паттерны связности, позволяя увеличить топологическую сложность без изменения вычислительных затрат в терминах FLOPs. HC был предложен как способ улучшить производительность нейронных сетей за счет увеличения топологической сложности архитектуры.

## Назначение

- **Расширение топологической сложности**: Увеличение сложности архитектуры без пропорционального увеличения вычислительных затрат
- **Улучшение производительности**: Повышение качества моделей за счет более богатых схем соединений
- **Управление информационным потоком**: Лучшее управление распространением информации между слоями

## Технические детали

### Структура Hyper-Connections

В традиционной residual connection, односторонняя архитектура одного слоя может быть сформулирована как:

x_{l+1} = x_l + F(x_l)

где x_l и x_{l+1} обозначают вход и выход l-го слоя соответственно, а F представляет собой residual функцию.

В архитектуре HC односторонняя архитектура одного слоя определяется как:

x_{l+1} = H_post^l * F(H_pre^l * x_l) + x_l

где x_l и x_{l+1} обозначают вход и выход l-го слоя. В отличие от формулировки в стандартной архитектуре, размерность признаков x_l и x_{l+1} расширена с C до n × C, где n — коэффициент расширения. 

HC вводит три обучаемых линейных отображения:
- H_pre^l ∈ R^(1×n) - для агрегации признаков из nC-мерного stream в C-мерный вход слоя
- H_post^l ∈ R^(1×n) - для отображения выхода слоя обратно на stream
- H_res^l ∈ R^(n×n) - для смешивания признаков внутри residual stream

### Компоненты HC

HC вычисляет коэффициенты с использованием двух типов отображений:
1. **Динамические отображения** - зависящие от входа
2. **Статические отображения** - глобальные параметры

Формально HC вычисляет коэффициенты следующим образом:

```
H_pre^l = α_pre^l * RMSNorm(x_l) * θ_pre^l + b_pre^l
H_post^l = α_post^l * RMSNorm(x_l) * θ_post^l + b_post^l
H_res^l = α_res^l * RMSNorm(x_l) * θ_res^l + b_res^l
```

где RMSNorm(·) применяется к последнему измерению, а α - обучаемые факторы гейминга, инициализированные небольшими значениями.

## Преимущества

- **Расширяемость топологии**: Возможность увеличения топологической сложности без пропорционального увеличения вычислительных затрат
- **Улучшенная производительность**: Практически доказанный потенциал производительности
- **Декуплинг емкости и сложности**: Эффективное разделение информационной емкости residual stream от размерности входа слоя

## Проблемы и ограничения

- **Нестабильность обучения**: HC компрометирует свойство тождественного отображения, что вызывает серьезную нестабильность обучения
- **Ограниченная масштабируемость**: Проблемы с масштабированием на больших моделях
- **Накладные расходы памяти**: Увеличенные накладные расходы на доступ к памяти из-за расширенной ширины residual stream
- **Проблемы с нормализацией сигналов**: Композитное отображение может отклоняться от тождественного отображения, вызывая взрыв или затухание сигналов

## Решения проблем

- **Manifold-Constrained Hyper-Connections (mHC)** - ограничение пространства residual соединений на определенном многообразии для восстановления свойства тождественного отображения
- **Sinkhorn-Knopp алгоритм** - энтропийная проекция на биркгофово многообразие
- **Двойные стохастические матрицы** - использование матриц с равной суммой строк и столбцов для стабилизации

## Применение

- **Трансформер архитектуры**: Использование для улучшения топологической сложности
- **Большие языковые модели**: Потенциальное применение для улучшения информационного потока
- **Глубокие нейронные сети**: Где важна топологическая сложность архитектуры
