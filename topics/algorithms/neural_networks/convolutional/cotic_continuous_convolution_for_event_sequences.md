# COTIC: Continuous Convolution для обработки неравномерных событийных рядов

## Описание

COTIC (Continuous Time Convolutional Networks) - это новая архитектура CNN, которая работает с непрерывным временем для обработки событийных рядов без потерь. В отличие от традиционных CNN, которые требуют дискретизации данных, COTIC использует свертки, работающие в непрерывном времени, что позволяет модели "ощущать" точные временные промежутки и не терять информацию.

## Ключевые особенности

- **Работает с raw-данными**: Может обрабатывать необработанные данные событий без необходимости дискретизации
- **Учет длинных зависимостей**: Способна понимать сложные зависимости во времени без рекурсивных сложностей, характерных для RNN
- **Универсальные эмбеддинги**: Создает универсальные представления, которые можно использовать для прогнозирования, классификации или поиска аномалий

## Применение

COTIC была протестирована на стандартных датасетах предсказания следующего события и продемонстрировала превосходство над популярными подходами:
- RNN-архитектурами
- Transformer-моделями  
- Традиционными CNN-подходами

Это подтверждается на финансовых и рекомендательных данных, где эмбеддинги COTIC показали хорошие результаты.

## Преимущества перед традиционными подходами

Традиционные CNN отлично работают на равномерных сетках (например, изображения), но "ломаются" при работе с событийными данными, имеющими разные временные интервалы, из-за необходимости дискретизации. COTIC решает эту проблему, позволяя работать с неравномерными временными данными напрямую.

## Архитектура

COTIC использует мульти-слоевые непрерывные свертки (Multilayer Continuous Convolution), что позволяет:
- Обрабатывать события с точным учетом времени
- Сохранять информацию о временных отношениях между событиями
- Избегать потерь при дискретизации
