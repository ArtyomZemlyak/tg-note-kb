# Lookup Transformations (LUT) в спайковых нейросетях

## Описание

Lookup Transformations (LUT) - это ключевая концепция в новом подходе к спайковым нейросетям, представленном в Spiking Manifesto от Eugene Izhikevich. Вместо традиционного перемножения матриц (MatMul), LUT заменяет вычисления на операции поиска в таблицах на основе временных задержек спайков.

## Принцип работы

### 1. Векторы задержек как вход
- Вместо вектора амплитуд, входом является вектор задержек (latencies) спайков
- Каждый элемент вектора x_i представляет время срабатывания нейрона i

### 2. Формирование индексов
- Трансформация использует набор из n_t таблиц
- Для каждой таблицы система назначает n_c пар «якорных нейронов», случайно выбранных из входа
- Обозначим индексы этих якорей векторами a и b
- Система вычисляет попарные разности задержек: u = x_a - x_b

### 3. Бинаризация и индексация
- Критический шаг — хеширование: разности бинаризуются (проверка условия x_{a_k} > x_{b_k}?)
- Бинаризованные значения конкатенируются, образуя дискретный индекс j
- Этот индекс указывает на конкретную строку в хранимой таблице S_i
- Извлекается вектор S_{ij}

### 4. Финальное сложение
- Финальный выход y — это сумма извлеченных векторов по всем таблицам: y = sum(S_{i, H_i(x)})
- «Синаптические веса» здесь — это не множители, а аддитивные временные сдвиги
- Прямой проход (forward pass) фактически превращается в серию разреженных чтений памяти и сложений

## Преимущества LUT

1. **Снижение вычислительной сложности**: Устранение матричных операций в пользу поиска в таблицах
2. **Энергоэффективность**: Разреженные операции чтения и сложения потребляют меньше энергии
3. **Эффективность памяти**: Только активные индексы загружаются, а не вся матрица весов
4. **Теоретическое снижение пропускной способности памяти**: в 10,000 раз по сравнению с традиционными подходами

## Проблемы и решения

### Проблема дифференцируемости
- Индекс j скачет дискретно при смене порядка спайков (когда x_{a_k} - x_{b_k} пересекает ноль)
- Решение: метод суррогатного градиента, заточенный под LUT

### Обучение
- Метод находит пару якорных нейронов, наиболее близкую к смене порядка (минимальный |x_a - x_b|)
- Правило обновления использует непрерывную функцию «неопределенности» U(u), пикующую в нуле
- Градиент подталкивает времена спайков x_a и x_b либо ближе, либо дальше друг от друга, в зависимости от лосса
- Это позволяет сети «подглядывать» в соседнюю строку таблицы и плавно интерполировать во время обучения, сохраняя строгий дискретный доступ на инференсе

## Сравнение с традиционными методами

| Характеристика | Традиционные нейросети | Lookup Transformations |
|---------------|------------------------|-------------------------|
| Операции | Умножение и сложение | ЧТЕНИЕ из таблицы + сложение |
| Память | Загрузка всей матрицы весов | Только активные строки таблицы |
| Вычисления | Плотные | Разреженные |
| Энергоэффективность | Ниже | Потенциально выше |
| Пропускная способность памяти | O(n²) | Теоретически O(1) на активный индекс |

## Примеры использования

- **SNN Трансформеры**: Замена проекций Q, K, V на LUT
- **Внимание на основе индексов**: Конкатенация закешированных индексов эмбеддингов query и key для прямого доступа к LUT значений
