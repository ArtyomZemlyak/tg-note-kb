# X-Coder: Модель генерации кода на синтетических данных

## Краткое описание

**X-Coder** — это 7B модель для генерации кода, разработанная совместной командой Microsoft и Tsinghua University, которая обучается **исключительно на синтетических данных** и превосходит более крупные модели (14B), обученные на реальных данных соревнований. Модель демонстрирует результат 62.9% на бенчмарке LiveCodeBench v5, используя нуль реальных соревновательных задач [[x_coder_sft_376k_dataset.md]].

## Ключевые достижения

| Параметр | Значение |
|----------|----------|
| **Размер модели** | 7 миллиардов параметров |
| **LiveCodeBench v5** | 62.9% (8 попыток) |
| **LiveCodeBench v6** | 55.8% (8 попыток) |
| **Обучающие данные** | 100% синтетические |
| **Превосходство** | beat 14B модели (DeepCoder, AReal-boba2) |

## Архитектура обучения

### Двухфазный процесс обучения

**1. Supervised Fine-Tuning (SFT):**
- **Ресурсы:** 128 GPU H20
- **Время:** 220 часов
- **Датасет:** X-Coder-SFT-376k (синтетический)
- **Назначение:** Холодный старт, основы рассуждений

**2. Reinforcement Learning (RL):**
- **Ресурсы:** 32 GPU H200
- **Время:** 7 дней
- **Датасет:** X-Coder-RL-40k
- **Прирост:** +4.6 процентных пункта к производительности
- **Устойчивость:** Эффективно даже при ~5% ошибок в синтетических тестовых случаях

## Пять контринтуитивных находок

### 1. Разнообразие задач > Разнообразие ответов
**Нахождение:** При равном вычислительном бюджете:
- **64k задач × 1 ответ** > 16k задач × 4 ответа > 8k задач × 8 ответов

**Обоснование:** Разнообразие задач обеспечивает более богатые градиенты для обучения, чем множественные решения одних и тех же задач.

### 2. Long-CoT того стоит
**Нахождение:** Длинные цепи рассуждений (Chain-of-Thought) дают **+17.4%** прироста производительности.

**Характеристики:**
- Средняя длина цепи рассуждений: **17,700 токенов** (vs. 8,000 у других датасетов)
- Требуется **8-10 эпох** для сходимости (vs. 2-3 для коротких цепей)
- Окупается после полной сходимости

### 3. Сложные задачи > Легкие задачи
**Нахождение:** Задачи, требующие интенсивных рассуждений, дают лучшие градиенты на всех этапах обучения.

**Применение:** Приоритизация сложных алгоритмических задач в синтетической генерации.

### 4. RL устойчив к шуму
**Нахождение:** Обучение с подкреплением остается эффективным даже при **5-8% неправильных тестовых случаев**.

**Значение:** Не требуется идеальная валидация синтетических данных для RL-фазы.

### 5. Длинные рассуждения ≠ Высокая точность
**Нахождение:** Цепи рассуждений >20k токенов имеют **14.3% pass rate**.

**Вывод:** Сложность задачи опосредует точность, а не длина рассуждений сама по себе.

## SynthSmith: Конвейер генерации синтетических данных

### Четырехэтапный процесс

| Этап | Описание |
|------|----------|
| **1. Извлечение признаков** | Извлечение и эволюция программных признаков из 10,000 существующих примеров кода (алгоритмы, структуры данных, техники оптимизации) |
| **2. Генерация задач** | Создание задач и решений с помощью LLM |
| **3. Генерация тестов** | Создание тестовых случаев с помощью LLM |
| **4. Двухэтапная валидация** | Majority voting + валидация на holdout наборе |

### Эволюция признаков
- **Начало:** 27,400 записей алгоритмов
- **Конец:** ~177,000 записей

### Контроль качества

**Этап 1 (Majority Voting):**
- Множественные кандидаты решений генерируются
- Правильные выходы определяются голосованием

**Этап 2 (Holdout Validation):**
- Валидация на отдельном тестовом наборе
- Предотвращение переобучения

## Датасеты X-Coder

Основной датасет: **X-Coder-SFT-376k** — 887,321 синтетических записей across 423,883 уникальных запросов.

### Подмножества

| Подмножество | Записей | Уникальных запросов | Ответов/запрос | Размер |
|--------------|---------|---------------------|----------------|--------|
| **Hybrid** | 376,491 | 176,935 | 2.13 (avg) | 24.3 GB |
| **Unique-Prompt** | 202,128 | 202,125 | 1.00 | 13.1 GB |
| **Multiple-Solution** | 218,686 | 33,571 | 6.51 (avg) | 13.6 GB |
| **Verified** | 90,016 | 11,252 | 8.00 | 5.2 GB |

**Общий размер:** ~56 GB

### Генерация данных

| Компонент | Модель |
|-----------|--------|
| **Синтез запросов** | OpenAI GPT-o3-mini |
| **Генерация решений** | DeepSeek-R1-0528, Qwen3-235B-A22B-Thinking-2507 |

### Особенности
- **100% синтетические** — никаких человеческих данных
- Включает **процесс рассуждений** (теги <think>...</think>) для большинства подмножеств
- Полный пайплайн доступен на GitHub

## Практическое применение

### Загрузка датасета

```python
from datasets import load_dataset

# Загрузить гибридное подмножество
dataset = load_dataset("IIGroup/X-Coder-SFT-376k", split="hybrid")

# Или уникальные запросы
dataset = load_dataset("IIGroup/X-Coder-SFT-376k", split="unique-prompt")
```

### Формат данных

```json
{
  "query": "Описание задачи или программистский вызов...",
  "response": "Решение с опциональным процессом рассуждений <think>...</think>..."
}
```
