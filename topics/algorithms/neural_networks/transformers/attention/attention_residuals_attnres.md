# Attention Residuals (AttnRes): Селективное накопление представлений слоев

## Общее описание

**Attention Residuals (AttnRes)** — это новая архитектурная техника, предложенная исследователями из Moonshot AI, которая переосмысливает принцип работы residual connections в глубоких нейронных сетях. Вместо фиксированного накопления выходов слоев через обычное сложение, AttnRes использует механизм внимания для селективного агрегирования представлений из предыдущих слоев с обучаемыми, зависящими от входа весами.

## Проблема традиционных residual connections

### Стандартный подход

В современных LLM residual connections с PreNorm стали стандартом:
- Каждый слой добавляет свой выход к предыдущим слоям через **фиксированное накопление с единичными весами**
- Все выходы слоев накапливаются с одинаковыми весами

### Проблемы фиксированного накопления

1. **Неконтролируемый рост скрытого состояния** с глубиной сети
2. **Прогрессирующее "размывание" вклада** каждого слоя
3. **Затрудненное извлечение важных представлений** из прошлых слоев
4. **Неэффективное использование глубины сети** — все слои вносят одинаковый вклад независимо от их полезности

## Решение: Attention Residuals

### Основная концепция

AttnRes заменяет фиксированное накопление на **softmax-внимание над выходами предыдущих слоев**:
- Каждый слой может **селективно агрегировать** более ранние представления
- Веса внимания **обучаемые и зависят от входа** (input-dependent)
- Модель сама решает, к каким слоям прошлого стоит "вернуться"

### Механизм работы

```
Стандартные residual connections:
    output = layer_output + previous_output  (фиксированные веса = 1)

Attention Residuals:
    output = Σ(attention_weights_i × layer_output_i)  (обучаемые веса)
```

## Block AttnRes: Масштабирование для больших моделей

### Проблема масштабирования

Прямое применение AttnRes к большим моделям создает проблемы:
- **Накладные расходы памяти** при внимании ко всем предыдущим выходам слоев
- **Коммуникационные overhead** при распределенном обучении

### Решение: Block Attention Residuals

**Block AttnRes** решает эти проблемы через:

1. **Разбиение на блоки**: Слои группируются в блоки
2. **Внимание на уровне блоков**: Attention применяется к блочным представлениям, а не к каждому слою отдельно
3. **Сжатое представление**: Уменьшение размерности для эффективного внимания

### Технические характеристики

- **Снижение использования памяти**: с O(L·d) до O(L/B·d_block), где L — количество слоев, B — размер блока
- **Сохранение преимуществ**: Block AttnRes сохраняет большинство преимуществ полного AttnRes
- **Практическая применимость**: Становится practical drop-in replacement для стандартных residual connections

### Оптимизации реализации

- **Cache-based pipeline communication**: Кэширование для снижения коммуникационных overhead
- **Двухфазная стратегия вычислений**: Разделение на фазы для оптимизации производительности
- **Минимальные накладные расходы**: <2% увеличение latency на инференсе

## Экспериментальные результаты

### Scaling Laws

Эксперименты подтверждают **согласованное улучшение across model sizes**:
- Улучшение масштабируется с размером модели
- Ablation studies подтверждают пользу content-dependent depth-wise selection

### Интеграция с Kimi Linear

AttnRes интегрирован в архитектуру **Kimi Linear** от Moonshot AI:

**Параметры модели:**
- **48B общих параметров**
- **3B активных параметров** (MoE архитектура)
- **1.4T токенов** предобучения

**Результаты:**

1. **Смягчение PreNorm dilution**:
   - Более равномерные выходные магнитуды по глубине
   - Улучшенное распределение градиентов

2. **Улучшение downstream производительности**:
   - Стабильный рост качества на всех оцениваемых задачах
   - Улучшения на задачах с длинным контекстом

3. **Вычислительная эффективность**:
   - **~1.25× выигрыш** по вычислениям
   - **<2% увеличение latency** на инференсе
   - Эффективное использование глубины сети

## Преимущества AttnRes

### Архитектурные преимущества

| Аспект | Стандартные Residual | Attention Residuals |
|--------|---------------------|---------------------|
| **Агрегация** | Фиксированная, с единичными весами | Селективная, с обучаемыми весами |
| **Рост hidden state** | Неконтролируемый | Контролируемый через attention |
| **Использование глубины** | Неэффективное | Оптимизированное |
| **Адаптивность** | Отсутствует | Input-dependent |

### Практические преимущества

1. **Селективное извлечение представлений**:
   - Модель учится выбирать наиболее релевантные представления из предыдущих слоев
   - Уменьшение "шума" от менее полезных слоев

2. **Уменьшение эффекта "размывания" информации**:
   - Важные представления сохраняются через механизм внимания
   - Предотвращение деградации информации с глубиной

3. **Контроль роста скрытых состояний**:
   - Attention веса нормализуют совокупный вклад
   - Предотвращение экспоненциального роста magnitudes

4. **Эффективное использование глубины**:
   - Глубокие слои могут напрямую обращаться к наиболее релевантным ранним представлениям
   - Улучшенный градиентный поток через глубину

## Сравнение с другими методами

### Value Residual Learning (VRL)

**VRL** добавляет остаточные соединения от **значений первого слоя** ко всем последующим слоям:
- **Сходство**: Обе техники решают проблему деградации информации в глубоких сетях
- **Различие**: VRL использует фиксированные residual из первого слоя, AttnRes — обучаемое внимание ко всем предыдущим слоям
- **Применение**: VRL фокусируется на смягчении концентрации внимания, AttnRes — на селективной агрегации

### Cross-Layer Attention

**Cross-Layer Attention** соединяет отдельные ранние и поздние слои:
- **Сходство**: Обе техники обеспечивают прямые связи между не-соседними слоями
- **Различие**: AttnRes использует softmax-внимание для взвешенной комбинации всех предыдущих слоев
- **Вычислительная стоимость**: AttnRes более эффективен благодаря Block AttnRes оптимизации

### DenseNet (Dense Connections)

**DenseNet** конкатенирует выходы всех предыдущих слоев:
- **Сходство**: Обе техники используют информацию из всех предыдущих слоев
- **Различие**: DenseNet использует конкатенацию (рост размерности), AttnRes — взвешенную сумму (фиксированная размерность)
- **Эффективность**: AttnRes более эффективен по памяти

## Архитектурная схема

![Overview of Attention Residuals](../../../../../media/img_1773643860_aqadxrrrgxqlwel_image_technical_report.jpg)

**Описание изображения:** Схема сравнивает три подхода: (a) Standard Residuals с равномерным аддитивным накоплением, (b) Full AttnRes с селективной агрегацией всех предыдущих выходов через обучаемые веса внимания, (c) Block AttnRes с группировкой слоев в блоки для уменьшения памяти с O(L·d) до O(L/B·d_block).

**Описание изображения:**
- **(a) Standard Residuals**: Стандартные residual connections с равномерным аддитивным накоплением
- **(b) Full AttnRes**: Каждый слой селективно агрегирует все предыдущие выходы через обучаемые веса внимания
- **(c) Block AttnRes**: Слои группируются в блоки, уменьшая память с O(L·d) до O(L/B·d_block)

## Применение и совместимость

### Совместимость с архитектурами

AttnRes совместим с:
- **Transformer architectures**: Decoder-only, Encoder-only, Encoder-Decoder
- **MoE архитектуры**: Интеграция с Mixture of Experts
- **Гибридные архитектуры**: Комбинация с линейным вниманием (как в Kimi Linear)
- **PreNorm и PostNorm**: Работает с обоими подходами к нормализации

### Drop-in Replacement

Block AttnRes разработан как **практическая замена**:
- Минимальные изменения в существующем коде
- Сохранение интерфейса стандартных residual connections
- Небольшой overhead на инференсе (<2%)

- **Иерархическое внимание**: Многоуровневое внимание (слои → блоки → группы блоков)

- **Cross-block attention**: Прямые связи между не-соседними блоками
