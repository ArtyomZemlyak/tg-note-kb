# Multi-Head Attention

## Общее описание

Multi-Head Attention (многоглавое внимание) - это расширение базового механизма внимания, которое позволяет модели одновременно обрабатывать информацию из разных подпространств. Вместо одного вычисления внимания, модель использует несколько "голов", каждая из которых может захватывать разные типы зависимостей между токенами.

## Архитектура

### Структура
Multi-Head Attention состоит из h независимых голов внимания, каждая из которых:
1. Проецирует вход в более низкоразмерное пространство
2. Выполняет стандартное scaled dot-product attention
3. Проектирует результат обратно в исходное пространство

### Формула
```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h)W_O

где head_i = Attention(QW_Q^i, KW_K^i, VW_V^i)
```

Где:
- W_Q^i, W_K^i, W_V^i - весовые матрицы для i-й головы
- W_O - финальная проекционная матрица
- Concat - конкатенация по последней оси

## Преимущества

### Разнообразие представлений
Каждая голова может специализироваться на разных аспектах внимания:
- Синтаксические зависимости
- Семантические связи
- Позиционные отношения
- Ролевые отношения

### Улучшенная выразительность
- Позволяет модели параллельно обрабатывать разные типы информации
- Увеличивает емкость модели без значительного увеличения параметров
- Повышает способность модели к обобщению

### Устойчивость к переобучению
- Регуляризация через усреднение нескольких представлений
- Сокращает влияние шума в отдельных головах

## Вариации

### Multi-Query Attention (MQA)
- Использует один общий W^K и W^V для всех голов запроса
- Значительно уменьшает KV-кеширование при генерации
- Используется в PaLM и других больших моделях

### Grouped-Query Attention (GQA)
- Группирует головы запроса, используя общие K и V внутри групп
- Компромисс между стандартным MHA и MQA
- Используется в Llama 2 и других архитектурах

### Multi Latent Head Attention (MLA)
- Сжимает K и V до латентного пространства
- Используется в DeepSeek-V3 для экономии памяти
- Сохраняет эффективность при уменьшении вычислительных требований

## Вычислительные аспекты

### Сложность
- Стандартное MHA: O(h × n² × d_k) для вычислений, O(h × n × d_k) для памяти
- Сравнение: h одиночных голов vs. одна объединенная голова с h×d_k размерностью

### Параллелизм
- Головы могут вычисляться независимо, что позволяет эффективно использовать GPU
- Может быть оптимизировано через reshape операции

## Эмпирические наблюдения

### Роль отдельных голов
Исследования показывают, что разные головы выполняют разные функции:
- Некоторые головы специализируются на синтаксисе
- Другие фокусируются на длинных зависимостях
- Некоторые головы отвечают за позиционные отношения

### Избыточность
- Не все головы одинаково важны для всех задач
- Некоторые головы могут быть удалены с минимальным влиянием на качество
