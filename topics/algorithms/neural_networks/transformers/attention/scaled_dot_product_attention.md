# Scaled Dot-Product Attention

## Общее описание

Scaled Dot-Product Attention является фундаментальным компонентом механизма внимания в трансформерах. Это основной вычислительный блок, который реализует архитектуру "Attention is All You Need".

## Формула

Механизм вычисляет внимание по следующей формуле:

```
Attention(Q, K, V) = softmax(QK^T / √d_k)V
```

Где:
- Q (Query) - матрица запросов
- K (Key) - матрица ключей  
- V (Value) - матрица значений
- d_k - размерность ключей
- √d_k - масштабирующий фактор

## Компоненты

### 1. Вычисление схожести
```
QK^T
```
Вычисляет скалярное произведение между запросами и ключами, определяя степень соответствия между ними.

### 2. Масштабирование
```
/ √d_k
```
Масштабирование необходимо для стабилизации градиентов. Без масштабирования скалярные произведения могут принимать большие значения, что приводит к чрезмерно малым градиентам после softmax.

### 3. Нормализация
```
softmax(...)
```
Преобразует схожести в вероятностное распределение, сумма которого равна 1. Это гарантирует, что внимание правильно взвешивается.

### 4. Взвешенное суммирование
```
...V
```
Применяет вычисленные веса внимания к значениям, создавая итоговое представление.

## Реализация

В реальных моделях Q, K, V получаются из входного эмбеддинга X через линейные преобразования:

```
Q = XW_Q
K = XW_K  
V = XW_V
```

Где W_Q, W_K, W_V - обучаемые весовые матрицы.

## Применения

Scaled Dot-Product Attention используется во многих архитектурах:
- Self-attention в энкодерах и декодерах
- Cross-attention между энкодером и декодером
- Multi-head attention (как отдельная голова)

## Вариации

### Gated Attention
Добавляет обучаемый гейт после SDPA для стабилизации обучения и устранения "attention sinks":

```
Output = Gated(Attention(Q, K, V))
```

### Normalized Attention
Применяет нормализацию к Q, K, V перед вычислением внимания:

```
Attention_Norm(Q, K, V) = softmax(LN(Q)LN(K)^T / √d_k)LN(V)
```
