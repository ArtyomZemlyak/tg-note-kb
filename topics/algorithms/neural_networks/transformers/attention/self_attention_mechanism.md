# Self-Attention Mechanism

## Общее описание

Self-attention (самовнимание) - это особый тип механизма внимания, при котором последовательность обращается к самой себе, чтобы определить, какие части последовательности наиболее важны для понимания каждого токена. Это ключевая особенность архитектуры трансформеров, позволяющая моделям учитывать контекст при обработке каждого элемента последовательности.

## Определение

В self-attention каждый токен в последовательности выступает в трех ролях:
- Query: определяет, какую информацию искать
- Key: определяет, что может быть полезной информацией
- Value: предоставляет фактическую информацию для интеграции

## Формула

Self-attention вычисляется следующим образом:

```
SelfAttention(X) = Attention(XW_Q, XW_K, XW_V) = softmax((XW_Q)(XW_K)^T / √d_k)(XW_V)
```

Где:
- X - входная матрица эмбеддингов
- W_Q, W_K, W_V - обучаемые весовые матрицы
- d_k - размерность ключей

## Работа механизма

### 1. Линейные проекции
Входной вектор X проецируется в три пространства:
- Query: XW_Q
- Key: XW_K
- Value: XW_V

### 2. Вычисление весов внимания
Создается матрица схожести между всеми парами токенов:
- Каждый запрос (Query) сравнивается с каждым ключом (Key)
- Результат проходит через softmax для получения вероятностного распределения

### 3. Взвешенное суммирование
Значения (Values) комбинируются с использованием вычисленных весов внимания.

## Свойства Self-Attention

### Глобальный контекст
Каждый токен может напрямую обращаться к любому другому токену в последовательности, позволяя эффективно захватывать длинные зависимости.

### Параллелизуемость
В отличие от RNN, где токены обрабатываются последовательно, self-attention позволяет параллельно обрабатывать все токены.

### Асимметрия
Самовнимание может быть асимметричным: токен A может больше обращать внимание на токен B, чем наоборот.

## Типы Self-Attention

### Causal/Decoder Self-Attention
- Используется в decoder-only архитектурах (например, GPT)
- Применяется маска, предотвращающая обращение к будущим токенам
- Обеспечивает каузальность в генерации текста

### Bidirectional/Encoder Self-Attention  
- Используется в encoder-only архитектурах (например, BERT)
- Позволяет каждому токену обращаться ко всем другим токенам
- Эффективно для задач понимания текста

### Cross-Attention
Хотя не является самовниманием, тесно связано:
- Используется в encoder-decoder архитектурах (например, T5, BART)
- Query из декодера, Key и Value из энкодера

## Применения

Self-attention используется в различных архитектурах:
- Encoder-only: BERT, RoBERTa, ELECTRA
- Decoder-only: GPT, LLaMA, Mistral
- Encoder-decoder: T5, BART, ProphetNet

## Оптимизации

### Multi-Head Self-Attention
Разделяет self-attention на несколько голов для захвата различных типов зависимостей.

### Sparse Self-Attention
Ограничивает количество токенов, между которыми вычисляется внимание, уменьшая вычислительную сложность.

### Linear Self-Attention
Использует приближенные вычисления для снижения квадратичной сложности до линейной.
