# GRAPE: Групповое представительное позиционное кодирование (Group Representational Position Encoding)

## Краткое описание

GRAPE (Group RepresentAtional Position Encoding) — это унифицированный фреймворк для позиционного кодирования, основанный на теории групп. Работа GRAPE отмечает момент взросления исследований позиционных кодировок, когда разговор смещается с "какая функция работает лучше?" на "какую групповую симметрию нам моделировать?". Фреймворк объединяет два различных семейства механизмов: мультипликативные вращения (воспроизводит RoPE через группу SO(d)) и аддитивные смещения (воспроизводит ALiBi и Forgetting Transformer через унипотентные действия в GL(d+k)).

## Математическая основа

### Основной принцип

GRAPE формализует позиции как элементы группы Ли, действующей на пространстве репрезентаций токенов. Фундаментальной единицей в GRAPE становится генератор однопараметрической подгруппы. Вместо того чтобы произвольно определять функцию позиции f(n), GRAPE определяет позицию n как результат применения группового действия G(n) = exp(n · ω · Gen) к вектору состояния. Выбор генератора определяет геометрию механизма внимания.

### Две основные ветви GRAPE

#### 1. Мультипликативный GRAPE (GRAPE-M)

**Математическое представление:**
- Действует в специальной ортогональной группе SO(d)
- Позиция n действует как G(n) = exp(nωL) с генератором L
- Используется кососимметричный генератор ранга 2: L = abᵀ - baᵀ
- Векторы a и b задают плоскость вращения

**Ключевые свойства:**
- Сохранение нормы (ортогональные преобразования)
- Точное соблюдение относительного закона: G(i)ᵀG(j) = G(j-i)
- Инвариантность к сдвигу

**Формула Родрига для вычислений:**
```
exp(nωL) = I + (sin(nωs)/s)L + ((1 - cos(nωs))/s²)L²
```
где s = √(||a||²||b||² - (aᵀb)²), что позволяет избежать дорогих матричных операций

**Связь с RoPE:**
- RoPE воспроизводится точно, когда векторы b = Ja, где J - канонический оператор поворота на 90°
- Результат - углы поворота на плоскости nω||a||²
- RoPE соответствует фиксированным координатным плоскостям с лог-равномерными частотами

**Расширения beyond RoPE:**
- Изучаемые, потенциально неортогональные плоскости
- Возможности для связи признаков между подпространствами
- Блочно-диагональные матрицы вращения для кодирования нескольких подпространств

#### 2. Аддитивный GRAPE (GRAPE-A)

**Математическая основа:**
- Основан на унипотентных действиях в общей линейной группе GL(d+k)
- Использует генераторы низкого ранга
- Создает аддитивные смещения логитов
- Восстанавливает ALiBi и Forgetting Transformer (FoX) как точные частные случаи

**Свойства:**
- Сохранение точного относительного закона
- Возможность потоковой обработки и кэширования
- Сохранение численной стабильности

## Объединение RoPE и ALiBi

GRAPE демонстрирует, что RoPE и ALiBi являются частными случаями более общей теоретико-групповой основы:
- RoPE → Частный случай мультипликативного GRAPE с конкретными геометрическими ограничениями
- ALiBi → Частный случай аддитивного GRAPE со специфическими свойствами генератора
- Оба сохраняют точные относительные позиционные отношения через различные действия групп

## Вычислительная сложность

- **GRAPE-M**: O(d) на голову вычисления (по сравнению с O(d³) для плотных кососимметричных матриц)
- Эффективная реализация потоковой обработки возможна
- Ключи вращаются один раз при прибытии, запросы вращаются на лету

## Практические преимущества реализации

1. **Поддержка потоковой обработки/тонкой настройки**: Контекстные расширения, где параметры вращения зависят от содержания токена

2. **Численная стабильность**: Собственные значения лежат на единичной окружности, нулевые показатели Ляпунова

3. **Масштабируемость**: Разложение ранга 2 по сравнению с плотными подходами

4. **Пространство проектирования**: Принципиальное расширение изучаемых подпространств и несовместимых вращений

## Значение для области

GRAPE олицетворяет момент зрелости исследований позиционных кодировок. Теперь разговор перемещается с "какая функция работает лучше?" на "какую групповую симметрию нам моделировать?". Доказав, что RoPE и ALiBi — это по сути две стороны одной теоретико-групповой медали, авторы предоставили мощное пространство для дизайна будущих архитектур. Возможность фреймворка бесшаблонно интегрировать контекстное гейтирование и механизмы забывания подразумевает, что будущие модели с "бесконечным контекстом", вероятно, следует рассматривать именно через призму динамических групповых действий.

## Сравнение с альтернативами

| Метод | Групповая основа | Сохранение нормы | Относительный закон | Сложность | Особенности |
|-------|------------------|------------------|---------------------|-----------|-------------|
| **RoPE** | Нет (частный случай) | Да | Да | O(d) | Канонические плоскости вращения |
| **ALiBi** | Нет (частный случай) | Нет | Да | O(n) | Аддитивные смещения |
| **GRAPE-M** | Да (SO(d)) | Да | Да | O(d) | Обучаемые плоскости вращения |
| **GRAPE-A** | Да (GL(d+k)) | Нет | Да | O(n) | Аддитивные логиты через унипотенты |

## Применения

### Длинноконтекстное моделирование
- Улучшенная экстраполяция на последовательности, превышающие длину обучения
- Надежное моделирование долгосрочных зависимостей
- Улучшенная стабильность обучения

### Архитектуры трансформеров будущего
- Принципиальная основа для дизайна новых архитектур
- Возможность комбинирования преимуществ RoPE и ALiBi
- Поддержка динамических механизмов гейтирования и забывания

## Будущие направления

### Гибридные подходы
- Комбинация мультипликативных и аддитивных компонентов
- Адаптивные архитектуры, меняющие стратегию в зависимости от входных данных
- Метаобучение для автоматического выбора оптимального подхода

### Групповая теория для архитектур
- Расширение теоретико-группового подхода на другие компоненты трансформеров
- Исследование других групп Ли, помимо SO(d) и GL
- Интеграция с механизмами внимания для моделирования сложных геометрий

### Практические реализации
- Эффективные аппаратные реализации групповых действий
- Оптимизация для конкретных задач и доменов
- Интеграция с методами масштабирования контекста
