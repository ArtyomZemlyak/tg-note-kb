# Block Verification Accelerates Speculative Decoding

## Описание

Block Verification — это алгоритм спекулятивного декодирования, который предлагает новый подход к процессу верификации. В отличие от традиционных методов, где токены проверяются поэлементно с использованием rejection sampling, Block Verification осуществляет проверку на уровне целого предсказанного блока токенов.

## Принцип работы

Вместо проверки каждого токена отдельно, Block Verification:
1. Использует быструю модель для генерации блока токенов
2. Проверяет весь блок целиком параллельно основной моделью
3. Предоставляет гарантии, что выходное распределение соответствует оригинальному процессу генерации
4. Обеспечивает дополнительное ускорение в реальном времени

## Преимущества

- **Более эффективная проверка**: Вместо поэлементного сэмплирования с отклонением, осуществляется проверка целого блока
- **Параллельная проверка**: Возможность проверять несколько токенов одновременно
- **Сохранение корректности**: Гарантии, что распределение выходов не изменяется по сравнению с обычным декодированием
- **Дополнительное ускорение**: Обеспечивает дополнительное ускорение к базовому спекулятивному декодированию

## Отличие от стандартного подхода

| Подход | Уровень проверки | Параллелизм | Гарантии корректности |
|--------|------------------|-------------|---------------------|
| Стандартный | На уровне каждого токена | Ограниченный | Есть |
| Block Verification | На уровне целого блока | Высокий | Есть |

## Результаты

- Значительное ускорение по сравнению со стандартным спекулятивным декодированием
- Улучшение wall-clock скорости (реального времени)
- Поддержание качества генерации
