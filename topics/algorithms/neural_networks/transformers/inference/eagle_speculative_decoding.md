# EAGLE спекулятивное декодирование

## Описание

EAGLE (Efficient Accelerated Generation by LEarning) - это метод спекулятивного декодирования, который ускоряет автогрессивный вывод в больших языковых моделях. Метод использует легковесную драфтовую модель для генерации деревьев предполагаемых токенов, которые затем проверяются параллельно, достигая ускорения 2-3×.

## Принцип работы

### Архитектура
- Основная модель (верификатор) остается замороженной
- Легковесная драфтовая модель генерирует предполагаемые токены
- Драфтовая модель состоит из одного декодирующего слоя на основе Llama-2 с компонентом FR-Spec
- Обучается на задачах восстановления скрытых состояний и выравнивания токенного распределения

### Процесс декодирования
1. Драфтовая модель генерирует несколько предполагаемых токенов
2. Верификатор параллельно проверяет предполагаемые токены
3. Принимаются только те токены, которые верифицированы
4. Оставшаяся часть генерации продолжается обычным способом

## Применение в T-pro 2.0

### Адаптация для русскоязычного вывода
- Интеграция EAGLE-модуля спекулятивного декодирования в T-pro 2.0
- Адаптация для ускорения русскоязычного вывода
- Использование динамического дерева драфтов через SGLang

### Результаты производительности
- Среднее ускорение 1.85× в стандартном режиме
- Среднее ускорение 1.83× в режиме рассуждений
- STEM-домены показывают лучший результат (1.99×) по сравнению с гуманитарными (1.62×)
- Средняя длина принятых последовательностей: 3.39 для стандартного режима, 3.33 для режима рассуждений

## Преимущества

- Сокращение общей задержки вывода
- Сохранение качества генерации
- Улучшенная производительность при сохранении точности
- Эффективность как для стандартных ответов, так и для цепочек рассуждений
