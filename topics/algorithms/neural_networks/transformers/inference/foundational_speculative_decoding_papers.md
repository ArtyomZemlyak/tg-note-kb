# Основополагающие работы в спекулятивном декодировании: Medusa, Eagle 1-3

## Описание

Этот файл охватывает основополагающие работы в области спекулятивного декодирования, включая оригинальные статьи, Medusa, и серию Eagle (Eagle 1, 2, 3), которые заложили фундамент для современных подходов, включая те, что описаны в других файлах.

## Оригинальное спекулятивное декодирование

Первоначальный подход к спекулятивному декодированию заключался в использовании маленькой "вспомогательной" (draft) модели для предсказания нескольких токенов, которые затем проверялись основной "целевой" (target) моделью. Это стало основой для всех последующих разработок.

## Medusa

### Описание
Medusa — это фреймворк, предложивший подход к ускорению инференса LLM без необходимости во внешней вспомогательной модели. Вместо этого, он добавляет специальные "головы" (heads) к основной модели.

### Основные особенности:
- **One Model подход**: Использование одной модели вместо вспомогательной пары
- **Добавление голов предсказания**: Несколько дополнительных голов для параллельного предсказания токенов
- **Упрощение архитектуры**: Нет необходимости в отдельных вспомогательных моделях

### Преимущества:
- Упрощение развертывания (deployment)
- Сохранение согласованности модели
- Удобство в настройке и использовании

## Eagle серия (Eagle 1, 2, 3)

### Eagle 1
- Первое предложение о подходе с восстановлением скрытых состояний
- Использование одного слоя декодера на основе Llama-2
- Обучение вспомогательной модели через задачи восстановления скрытых состояний

### Eagle 2
- Улучшения в архитектуре вспомогательной модели
- Оптимизации в процессе обучения и инференса
- Повышенная эффективность по сравнению с Eagle 1

### Eagle 3
- Масштабирование подхода для достижения большего ускорения
- Замена предсказания векторов признаков на другие методы
- Дальнейшие улучшения эффективности (до 2-6x ускорения)

### Общие особенности серии Eagle:
- Обучение вспомогательной модели через восстановление скрытых состояний
- Использование замороженной целевой модели для генерации обучающих данных
- Эффективное ускорение (Eagle 3 обеспечивает 2-6x ускорение)

## Сравнение подходов

| Метод | Подход | Архитектура | Ускорение | Сложность |
|-------|--------|--------------|-----------|-----------|
| Оригинальное SpecDec | Внешняя вспомогательная модель | Две модели | 1.5-2x | Средняя |
| Medusa | Доп. головы к основной модели | Одна модель | 2-3x | Низкая |
| Eagle 1 | Восстановление скрытых состояний | Вспомогательная модель | 2-3x | Высокая |
| Eagle 2 | Улучшенные вспомогательные модели | Вспомогательная модель | 2.5-3.5x | Высокая |
| Eagle 3 | Масштабированные методы | Вспомогательная модель | 2-6x | Высокая |
