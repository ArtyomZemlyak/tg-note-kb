# FR-Spec: Accelerating Large-Vocabulary Language Models via Frequency-Ranked Speculative Sampling

## Описание

FR-Spec (Frequency-Ranked Speculative Sampling) — это фреймворк спекулятивного декодирования, предназначенный для ускорения больших языковых моделей с большими словарями. FR-Spec решает проблему, связанную с тем, что при использовании маленьких вспомогательных моделей в спекулятивном декодировании, голова языковой модели (language head) занимает существенную часть времени инференса.

## Проблема

В современных подходах к спекулятивному декодированию:
- Вспомогательные модели делаются маленькими для максимального ускорения
- Однако, даже маленькие модели требуют вычислений на большой словарь
- Language head становится узким местом при генерации

## Решение FR-Spec

FR-Spec предлагает:
- Сжатие словарного пространства за счет удаления редких токенов
- Использование усеченных словарей для вспомогательной модели
- Frequency-ranked (частотно-ранжированные) подходы к выбору кандидатов в токены

### Принцип работы

1. Создание сжатого словаря с сохранением наиболее частотных токенов
2. Обучение вспомогательной модели с использованием усеченного словаря
3. Частотно-ранжированный подход к спекулятивной выборке токенов
4. Проверка предсказаний основной моделью с полным словарем

## Результаты

- Значительное ускорение для моделей с большими словарями
- Улучшенная эффективность вспомогательной модели
- Сохранение качества генерации
- FR-Spec часто используется в открытых коллекциях, таких как популярная коллекция от RedHat для EAGLE3

## Сравнение с другими подходами

| Метод | Сфокусирован на | Основная оптимизация | Эффективность для больших словарей |
|-------|------------------|---------------------|----------------------------------|
| FR-Spec | Сжатие словарного пространства | Удаление редких токенов | Высокая |
| Standard SpecDec | Общая архитектура | Общие оптимизации | Ограниченная |
| Vocabulary Pruning | Сжатие | Удаление токенов | Средняя |
