# GRIFFIN: Effective Token Alignment for Faster Speculative Decoding

## Описание

GRIFFIN (GRadient-free Inference Framework For Improving Natural language generation) — это метод спекулятивного декодирования, направленный на решение проблемы несоответствия между обучением и инференсом (training-inference misalignment) в спекулятивном декодировании. Проблема возникает из-за того, что во время обучения вспомогательная модель получает все токены из целевой модели, в то время как во время инференса токены генерируются автогрессивно из вспомогательной модели.

## Проблема training-inference misalignment

В традиционном подходе к обучению вспомогательных моделей для спекулятивного декодирования:
- **На этапе обучения**: все токены поступают из целевой (target) модели
- **На этапе инференса**: токены генерируются автогрессивно из вспомогательной (draft) модели

Это приводит к несоответствию, которое снижает эффективность спекулятивного декодирования, поскольку модель, обученная на данных целевой модели, сталкивается с другими паттернами данных во время инференса.

## Решение GRIFFIN

GRIFFIN предлагает подход, основанный на прогрессивном обучении, которое имитирует поведение вспомогательной модели во время декодирования:
- Вводятся токены, которые корректируют несогласованности в генерируемых признаках
- Прогрессивная стратегия обучения, отражающая операции декодирования
- Token-alignable архитектура, позволяющая более точную синхронизацию между вспомогательной и целевой моделями

## Результаты

Эксперименты на моделях LLaMA, Vicuna, Qwen и Mixtral показали:
- Улучшение средней длины принимаемой последовательности более чем на 8%
- Повышение общей эффективности спекулятивного декодирования
- Снижение влияния training-inference misalignment

## Сравнение с другими методами

| Метод | Подход к решению misalignment | Улучшение производительности |
|-------|-------------------------------|-----------------------------|
| GRIFFIN | Progressive training + token alignment | >8% улучшение длины акцепта |
| Standard SpecDec | Без специального решения | - |
| Block Verification | Joint block verification | - |
