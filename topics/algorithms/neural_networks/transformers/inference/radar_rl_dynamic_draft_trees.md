# RADAR: Accelerating Large Language Model Inference With RL-Based Dynamic Draft Trees

## Описание

RADAR (Reinforcement learning-based dynamic dRAft tRee) — это метод спекулятивного декодирования, который использует динамическую генерацию деревьев предложений с помощью методов обучения с подкреплением (RL). В отличие от традиционных подходов, где токены предсказываются в виде одной цепочки, RADAR строит деревья вариантов, которые затем проверяются основной моделью.

## Проблема

В традиционном спекулятивном декодировании:
- Вспомогательные токены предсказываются в виде одной цепочки
- Все возможные продолжения не рассматриваются эффективно
- Может быть неоптимальное использование вычислительных ресурсов

## Решение RADAR

RADAR предлагает:
- Генерирование деревьев вариантов предсказаний, а не линейных последовательностей
- Использование обучения с подкреплением для оптимизации процесса построения деревьев
- Динамическое принятие решений о том, какие ветви дерева исследовать

### Принцип работы

1. Формулировка генерации дерева предложений как задача принятия решений в марковском процессе (MDP)
2. Использование обучения с подкреплением для оптимизации дерева
3. Динамическое принятие решений о вызовах вспомогательной модели
4. Эффективное уменьшение избыточных вычислений и ускорение инференса

### Архитектура

- **Прогнозная модель (prediction model)**: Принимает решения о вызовах вспомогательной модели в реальном времени
- **Вспомогательная модель (draft model)**: Генерирует узлы дерева предложений
- **Алгоритм RL**: Обучается на основе эффективности генерации для оптимизации дерева

## Преимущества

- **Динамическая оптимизация**: Лучшее использование вспомогательной модели
- **Уменьшение избыточности**: Сокращение ненужных вычислений
- **Повышенная эффективность**: Дальнейшее ускорение по сравнению с линейным спекулятивным декодированием
- **Адаптивность**: Способность адаптироваться к различным задачам и текстам

## Технические вызовы

- **Tree Mask Attention**: Для эффективного прохода через все цепочки из дерева за один forward pass модели требуется использование специальной tree mask attention
- **Обучение RL**: Требуется значительное обучение модели с подкреплением
- **Реализация**: Сложная архитектура требует специализированной реализации
