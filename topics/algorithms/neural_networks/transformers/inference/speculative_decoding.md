# Спекулятивное декодирование (Speculative Decoding)

## Описание

Спекулятивное декодирование (Speculative Decoding) — это метод ускорения генерации текста в больших языковых моделях, при котором используется вспомогательная модель для предварительного предсказания нескольких токенов, которые затем проверяются основной моделью. Этот подход позволяет частично параллелизовать процесс генерации, что приводит к значительному ускорению без потерь качества.

## Принцип работы

### Общая схема
1. Вспомогательная (draft) модель генерирует последовательность из N предполагаемых токенов
2. Основная (target/verifier) модель параллельно проверяет предложенные токены
3. Принимаются только те токены, которые совпадают с предсказаниями основной модели
4. Процесс продолжается до тех пор, пока не будет найдено несовпадение или последовательность не будет полностью принята
5. После последнего принятого токена генерация продолжается обычным автогрессивным способом

### Математическое обоснование

Пусть:
- `q(x)` — вероятность токенов из модели-черновика (draft)
- `p(x)` — вероятность этих же токенов для модели-верификатора (target)

**Стратегия принятия решений:**

1. **Если q(x) ≤ p(x)** → принимаем драфт
2. **Иначе** → реджект с вероятностью `p(x)/q(x)`
3. **Если отклонён** → остаток добирается из распределения разницы: `norm(max(0, p(x) - q(x)))`

**Логика:** Для каких-то токенов разница будет 0, остальные из хвоста top-K будут давать положительную разницу. Её нормируем и принимаем за вероятности, затем выбираем оттуда. Это сродни `x ~ p(x)` с сходимостью по вероятности.

### Преимущества
- Значительное ускорение процесса генерации (часто 2-3x)
- Сохранение качества и распределения вероятностей основной модели
- Потенциальное улучшение latency при сохранении perplexity

### Ограничения
- Требуется эффективная вспомогательная модель
- Сложность согласования моделей (training-inference misalignment)
- Эффективность зависит от качества предсказаний вспомогательной модели

## Варианты реализации

### EAGLE
[[eagle_speculative_decoding.md]] - продвинутая реализация спекулятивного декодирования, использующая обучение на восстановлении скрытых состояний

### GRIFIN
[[griffin_effective_token_alignment.md]] - метод, направленный на устранение проблемы с training-inference misalignment

### DistillSpec
[[distillspec_knowledge_distillation.md]] - подход, использующий knowledge distillation для лучшего согласования вспомогательной и основной моделей

### FR-Spec
[[fr_spec_frequency_ranked_sampling.md]] - оптимизация, использующая сжатие словарного пространства для ускорения генерации

### Block Verification
[[block_verification_speculative_decoding.md]] - метод, проверяющий целые блоки токенов вместо поэлементной проверки

### Speculative Diffusion Decoding
[[speculative_diffusion_decoding.md]] - использование диффузионных моделей в качестве вспомогательного механизма

### RADAR
[[radar_rl_dynamic_draft_trees.md]] - метод, использующий RL для динамическую генерацию деревьев предложений

### LK Losses
[[lk_losses_speculative_decoding.md]] - метод прямой оптимизации acceptance rate вместо минимизации KL-дивергенции, +8-10% improvement

### SSD / Saguaro
[[ssd_saguaro_speculative_speculative_decoding.md]] — **Speculative Speculative Decoding**: инновационный алгоритм от Tri Dao и соавторов (март 2026), который **параллелизует спекуляцию и верификацию** на разном оборудовании. Saguaro достигает ускорения до **2x быстрее vLLM/SGLang + SpecDec** и до **5x быстрее авторегрессивного декодирования**. Ключевые инновации: геометрический fan-out для кэша (90% accuracy предсказания бонус-токена), cache-aware sampling, адаптивный fallback по batch size.
