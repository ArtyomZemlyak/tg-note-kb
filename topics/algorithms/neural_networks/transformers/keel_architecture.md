# Архитектура Keel: Возвращение Post-LN с устойчивым, выразительным и глубоким обучением

## Краткое описание

Keel - это новая архитектура трансформеров, разработанная для стабилизации обучения глубоких языковых моделей. Архитектура возвращает Post-LayerNorm (Post-LN) формулировку, которая была вытеснена Pre-LN в современных LLM из-за нестабильности при масштабировании. Keel заменяет ResNet-подобный остаточный путь на соединение в стиле Highway, что позволяет обучать модели с глубиной более 1000 слоев устойчиво.

## Концепция и основные идеи

### Проблема масштабирования LLM

- **Ширина моделей** дает убывающую отдачу
- **Расширение длины контекста** не улучшает фундаментальную выразительность
- **Масштабирование по глубине** теоретически предлагает превосходную выразительность
- Текущие архитектуры трансформеров испытывают трудности с надежным обучением на экстремальных глубинах

### Исторический контекст Post-LN и Pre-LN

- **Оригинальный Transformer** использовал Post-LN (Post-LayerNorm)
- **Современные LLM** преобладающе используют Pre-LN (Pre-LayerNorm) из-за стабильности обучения
- Pre-LN стабилизирует раннее обучение, нормализуя вход каждого подслоя
- Однако Pre-LN ослабляет передачу градиентов и уменьшает эффективный вклад более глубоких слоев

### Основные компоненты Keel

1. **Highway-style остаточное масштабирование**
   - Введение скалярного α для взвешивания skip-соединения, создание highway-подобной структуры
   - α устанавливается равным L (общее количество подслоев), что критично для стабильности

2. **Нормализация в остаточной ветви**
   - Добавление дополнительного шага Layer Normalization во входную часть функции F
   - Это обеспечивает стабилизацию потока градиентов через остаточную ветвь

## Архитектурные изменения

### Формулировка Keel

Прямое распространение для l-го слоя в Keel определяется как:

`x_{l+1} = LN(x_l + α · F(LN(x_l)))`

где:
- `x_l` - вход l-го слоя
- `F` - функция преобразования (Attention или FFN)
- `LN` - Layer Normalization
- `α` - масштабирующий коэффициент, обычно `α = L`

### Сравнение с Post-LN и Pre-LN

**Post-LN:**
`x_{l+1} = LN(x_l + F(x_l))`

**Pre-LN:**
`x_{l+1} = x_l + F(LN(x_l))`

**Keel:**
`x_{l+1} = LN(x_l + α · F(LN(x_l)))`

## Теоретическая основа

### Проблема исчезающих градиентов в Post-LN

В стандартной Post-LN архитектуре градиентный сигнал экспоненциально затухает при распространении к нижним слоям:

`||grad|| ~ (γ)^L`

где L - количество слоев, γ - норма градиента.

### Решение в Keel

Keel предотвращает исчезновение градиентов за счет:
- Масштабирования остаточного пути на `α = L`
- Дополнительной нормализации в функции преобразования

### Теоретические гарантии

При `α = L`, асимптотическое поведение при L→∞ дает:

`lim (L→∞) ||grad|| = const ≈ 1`

Это подтверждает, что формулировка Keel предотвращает исчезновение градиентов.

## Применение и реализация

### Инициализация входного слоя

Для самых первых слоев внимания и FFN:
- Удаляется финальный Post-LN и фактор масштабирования α
- Эффективно деградируют до стандартных Pre-LN блоков
- Обеспечивают стабильную инициализацию сигнала из эмбеддинг-слоя

### Гиперпараметры

- Keel позволяет использовать и получает выгоду от более высоких скоростей обучения по сравнению с Pre-LN базовыми линиями
- Все операции Layer Normalization используют обучаемые аффинные веса (γ), но опускают аддитивный смещающий член (β = 0)

## Экспериментальные результаты

### Стабильность обучения

Keel consistently поддерживает плавную сходимость при агрессивных скоростях обучения, в то время как Pre-LN демонстрирует серьезную нестабильность. 

**Сравнение максимальных допустимых скоростей обучения:**
- 64 слоя: Keel - 1.01×10⁻², Pre-LN - 7.65×10⁻³
- 512 слоя: Keel - 6.31×10⁻³, Pre-LN - 4.67×10⁻³

### Выразительность

Keel демонстрирует превосходящую производительность во всех доменах возможностей, особенно в математике и кодировании (+16.5%).

### Масштабирование по глубине

Keel consistently превосходит Pre-LN на всех глубинах (64-1024 слоя). При увеличении глубины разрыв в производительности становится более выраженным.

## Сравнение с другими методами

### Keel vs DeepNorm

- **DeepNorm** полагается на масштабирование прямого прохода для предотвращения взрыва значений
- **Keel** решает проблему исчезающих градиентов в обратном пути
- DeepNorm зависит от специфической инициализации весов
- Keel встраивает механизм стабилизации в архитектуру

### Keel vs Hybrid варианты

- **HybridNorm** чередует Post-LN и Pre-LN блоки
- **Mix-LN** применяет Post-LN в нижних слоях и переходит к Pre-LN в верхних
- Эти гибридные подходы не решают фундаментально проблему деградации градиентов при очень больших глубинах

## Преимущества архитектуры Keel

- **Устойчивое обучение при экстремальных глубинах** (>1000 слоев)
- **Нет необходимости в специальной инициализации или сложных трюках оптимизации**
- **Улучшенные характеристики масштабирования по глубине**
- **Повышенная выразительность по сравнению с Pre-LN**
- **Позволяет использовать более высокие скорости обучения**
- **Особенно эффективен для задач математики и кодирования**

## Применение для обучения с учителем

Преимущества Keel сохраняются и после обучения с учителем (SFT), включая задачи типа MMLU-Pro и BBH, которые проверяют пределы рассуждений модели.

## Ограничения и будущая работа

- Keel требует значительных объемов обучающих данных для эффективности
- Может быть менее эффективен в условиях ограниченных данных
- Влияние масштабирования по ширине (а не глубине) требует дальнейшего изучения
