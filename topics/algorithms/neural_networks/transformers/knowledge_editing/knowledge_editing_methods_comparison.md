# Сравнение методов редактирования знаний в языковых моделях

## Обзор

Редактирование знаний в языковых моделях представляет собой набор методов, позволяющих изменять знания, хранящиеся в предварительно обученных моделях, без полной переобучки. Эти методы особенно полезны для обновления устаревшей информации или исправления ошибок, не требуя вычислительно затратной процедуры полной дообучки.

## Классификация методов

### 1. Методы изменения параметров (Parameter-modifying methods)

#### Определение
- Изменяют небольшое подмножество параметров модели
- Напрямую воздействуют на веса модели
- Более перманентные изменения

#### Подкатегории

##### 1.1. Методы локализации-затем-редактирования (Locate-then-edit methods)
- Сначала находят влияющие параметры
- Затем редактируют их, внося возмущение ∆

**ROME (Rank-One Model Editing)**
- Цель: обновить конкретные ассоциации фактов в LLM
- Метод: идентифицирует ключевые активации нейронов в промежуточных слоях сетей Feed-Forward (FFN), влияющие на предсказания фактов
- Изменяет веса FFN напрямую для редактирования этих ассоциаций
- Применение: эффективно для редактирования конкретных фактов

**MEMIT (Mass-Editing Memory in a Transformer)**
- На основе ROME
- Целевой алгоритм для множественного слоев
- Настраивает веса трансформеров, действующие как хранилища ключ-значение для извлечения знаний
- Позволяет MEMIT вставлять тысячи новых ассоциаций
- Применение: масштабное редактирование памяти

**AlphaEdit**
- Использует ограничение в нулевом пространстве
- Проектирует возмущения на нулевое пространство сохраняемых знаний
- Обеспечивает неизменность вывода при запросах о сохраняемых знаниях
- Улучшает баланс между обновлением и сохранением знаний

##### 1.2. Методы на основе метаобучения (Meta-learning methods)
- Используют гиперсеть для адаптации параметров модели
- Обучаются на задачах редактирования

**MEND (Model Editors Neural Networks)**
- Метод для эффективного редактирования больших предварительно обученных моделей
- Использует небольшие вспомогательные сети для быстрых локальных изменений
- Применяет низкоранговую декомпозицию к градиенту от стандартного дообучения
- Превосходит ROME по метрикам специфичности и плавности

**InstructEdit**
- Расширяет MEND с помощью специальных инструкций
- Обучает редактор с различными тщательно подготовленными инструкциями
- Может выполнять редактирование нескольких задач

#### 1.3. Другие методы изменения параметров
**PRUNE**
- Каркас редактирования моделей для сохранения общих возможностей LLM при последовательном редактировании
- Применяет ограничения числа обусловленности к редактируемой матрице
- Ограничивает возмущения к сохраненным знаниям модели

**RECT**
- Метод для смягчения непреднамеренных побочных эффектов редактирования модели
- Регуляризует обновления весов в процессе редактирования
- Предотвращает чрезмерные изменения, ведущие к переобучению

### 2. Методы сохранения параметров (Parameter-preserving methods)

#### Определение
- Используют дополнительные модули
- Не изменяют оригинальные параметры
- Более временные изменения

#### Подкатегории

**SERAC (Semi-Parametric Editing with a Retrieval-Augmented Counterfactual Model)**
- Хранит редактирования в явной памяти
- Рассуждает над ними для коррекции поведения модели
- Превосходит существующие методы в задачах ответов на вопросы, проверки фактов и генерации диалогов

**GRACE (Aging with GRACE)**
- Каркас пожизненного редактирования модели
- Использует локальный кодбук в латентном пространстве
- Обрабатывает тысячи последовательных редактирований без деградации производительности

**MELO (Enhancing Model Editing with Neuron-Indexed Dynamic LoRA)**
- Плагин-метод динамической активации блоков LoRA
- Достигает эффективного редактирования поведения модели
- Адаптируемый к различным LLM

**T-Patcher**
- Дизайн инструкций для редактирования: "один нейрон - одно слово"
- Использует специальные коды сброса для коррекции поведения
- Позволяет более точное и контролируемое редактирование

## Метрики оценки

### Эффективность (Efficacy)
- Средняя точность на редактируемых образцах
- Успех обновления целевых знаний
- Высокие показатели желательны

### Обобщение (Generalization)
- Производительность на эквивалентных запросах (переформулированных утверждениях)
- Успех на парфразах целевых знаний
- Высокие показатели желательны

### Специфичность (Specificity)
- Успех на знаниях, не связанных с редактируемыми случаями
- Сохранение смежных знаний без влияния
- Высокие показатели желательны

### Плавность (Fluency)
- Измерение чрезмерных повторений в выводе модели
- Использует энтропию n-грамм
- Более высокие значения лучше

### Последовательность (Consistency)
- Оценка согласованности выводов модели
- Косинусное сходство с эталонным текстом
- Высокие значения желательны

## Проблемы и вызовы

### Компромисс между обновлением и сохранением
- Сложность поддержания баланса между e1 (редактируемые знания) и e0 (сохраняемые знания)
- Текущие методы фокусируются на e1, недостаточно контролируя e0
- Может привести к переобучению на обновляемых знаниях

### Последовательное редактирование
- Аккумуляция ошибок при множественных редактированиях
- Постепенное разрушение способностей модели
- Может привести к забыванию и коллапсу модели

### Сдвиг распределения скрытых представлений
- Изменения в распределении скрытых состояний после редактирования
- Влияние на общие возможности модели
- Проблема особенно актуальна для последовательного редактирования

## Новейшие разработки

### AlphaEdit
- Новейший метод, решающий компромисс между обновлением и сохранением
- Использует проекцию в нулевое пространство
- Обеспечивает минимальное разрушение знаний

### Методы масштабного редактирования
- Поддержка тысяч последовательных редактирований
- Улучшение обобщающей способности
- Снижение вычислительной стоимости
