# Архитектурные особенности моделей Ettin

## Общая архитектура

Модели Ettin построены на основе рецепта обучения от ModernBERT, но с упрощениями:
- Без мержинга моделей
- Без использования разных theta для локального и глобального RoPE
- Стандартная архитектура трансформера для обоих типов моделей (энкодерные и декодерные)
- Возможность прямого сравнения благодаря идентичным условиям обучения

## Варианты моделей

### Ettin-encoder
- **Архитектура**: Encoder-only (как BERT)
- **Обучение**: Masked Language Modeling (MLM)
- **Параметры**: От 17M до 1B
- **Применение**: Задачи понимания текста, классификация, семантическое сопоставление

### Ettin-decoder  
- **Архитектура**: Decoder-only (как GPT)
- **Обучение**: Causal Language Modeling (CLM)
- **Параметры**: От 17M до 1B
- **Применение**: Задачи генерации, автодополнения, языковое моделирование

## Архитектурное сравнение с другими моделями

| Модель | Архитектура | Обучение | Применение |
|--------|-------------|----------|------------|
| Ettin-encoder | Encoder-only | MLM | Понимание, классификация |
| Ettin-decoder | Decoder-only | CLM | Генерация, моделирование |
| BERT | Encoder-only | MLM | Понимание, классификация |
| GPT | Decoder-only | CLM | Генерация, моделирование |
| T5 | Encoder-decoder | Prefix LM | Текст-в-текст задачи |

## Особенности архитектуры для сопоставимости

### Идентичные параметры
- Одинаковая размерность скрытого состояния (hidden dimension)
- Одинаковое количество слоев (для моделей одного размера)
- Одинаковые методы нормализации
- Одинаковые функции активации

### Упрощения по сравнению с современными архитектурами
- Отсутствие Mixture of Experts (MoE)
- Отсутствие специализированных улучшений, таких как в современных версиях RoPE
- Относительно стандартная архитектура для возможности честного сравнения

## Преимущества сопоставимой архитектуры

### Возможность прямого сравнения
- Одинаковые вычислительные требования
- Одинаковые затраты на обучение
- Возможность сравнения только влияния архитектуры на результаты

### Валидация конвертации
- Проверка гипотез о возможности прямой конвертации между архитектурами
- Возможность проведения экспериментов по изменению задачи обучения
- Эмпирическая проверка теоретических предположений
