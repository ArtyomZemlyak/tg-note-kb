# NVIDIA Nemotron-ColeEmbed V2: Семейство моделей для визуального поиска документов

## Краткое описание

NVIDIA Nemotron-ColeEmbed V2 представляет собой коллекцию передовых мультимодальных эмбеддинговых моделей для задач визуального поиска документов. Эти модели сочетают возможности обработки изображений и текста, чтобы эффективно находить релевантные документы на основе их визуального и текстового содержания.

## Архитектура и особенности

Модельный ряд ColeEmbed-V2 включает три основные реализации с различным количеством параметров:

1. **NVIDIA/NEMOTRON-COLEMBED-VL-8B-V2** - 8.8B параметров (9B общего размера), наиболее мощная версия
2. **NVIDIA/NEMOTRON-COLEMBED-VL-4B-V2** - 4.8B параметров (5B общего размера), сбалансированный вариант
3. **NVIDIA/LLAMA-NEMOTRON-COLEMBED-VL-3B-V2** - 4.4B параметров (4B общего размера), наиболее эффективная версия

### Общая архитектура

Все модели семейства ColeEmbed-V2 построены на основе трехкомпонентной архитектуры:

- **Визуальный энкодер**: На основе архитектуры SigLIP (например, SigLIP2-SO-400M) для обработки визуальной информации
- **Модуль слияния**: MLP (Multi-Layer Perceptron) для объединения визуальных и языковых представлений
- **Языковая модель**: LLM (Large Language Model) для обработки текстовой информации

Эта архитектура использует подход "late interaction" (позднее взаимодействие), при котором обработка разных модальностей происходит до финальных слоев, где происходит их интеграция для создания эмбеддингов.

### Технические спецификации

- **Максимальная длина контекста**: 10,240 токенов
- **Обработка изображений**: Изображения разбиваются на тайлы размером 512x512 пикселей, каждый тайл занимает 256 токенов
- **Ограничения на изображения**: До 8 тайлов + 1 миниатюра (максимум 9 тайлов на изображение)
- **Размерность эмбеддинга**:
  - 8B версия: 4096-мерные векторы
  - 4B версия: 2560-мерные векторы  
  - 3B версия: 3072-мерные векторы
- **Формат вывода**: Списки числовых значений с плавающей точкой в формате [batchsize x seq length x embedding_dim]
- **Поддерживаемые форматы**: RGB изображения и строковый текст

## Производительность и бенчмарки

### Рейтинг ViDoRe (Visual Document Retrieval)

- **ViDoRe V3 (NDCG@10)**:
  - 8B версия: 63.54 (ранг #1 среди моделей)
  - 4B версия: 61.42 (ранг #3 среди моделей)
  - 3B версия: 59.70 (улучшен по сравнению с v1)

- **ViDoRe V2 (NDCG@5)**:
  - 8B версия: 65.16
  - 4B версия: 64.49
  - 3B версия: 63.38

- **ViDoRe V1 (NDCG@5)**:
  - 8B версия: 92.65
  - 4B версия: 91.62
  - 3B версия: 91.74

Модели демонстрируют отличные результаты в задачах визуального поиска документов по сравнению с конкурентами.

## Методология обучения

- **Данные для обучения**: Около 500 тысяч изображений для всех моделей
- **Наборы данных**: DocMatix-IR, VDR, Vidore-ColPali-Training, VisRAG-Ret-Train-Synthetic-data, VisRAG-Ret-Train-In-domain-data, Wiki-SS-NQ
- **Типы данных**: Гибридный метод (автоматический, человеческий, синтетический)
- **Методика тонкой настройки**: Fine-tuning для задач поиска запрос-документ
- **Инженерные приемы**: 
  - объединение моделей после пост-тренировки для объединения сильных сторон различных чекпоинтов
  - синтетическое расширение данных с разнообразным многокомпонентным содержанием
  - передовые методы объединения моделей для стабильности точности без увеличения задержки инференса

## Целевые применения

- **Поиск по визуальным документам**: Нахождение релевантных документов на основе визуального и текстового содержания
- **Мультимодальные поисковые системы**: Приложения, требующие понимания как изображений, так и текста
- **Системы управления документами**: Анализ и управление документами, содержащими визуальные элементы
- **Системы обнаружения контента**: Системы, которые должны понимать визуальные документы
- **Мультимодальные RAG-системы**: Системы с расширенным извлечением, где текстовые запросы используются для поиска по изображениям документов
- **Приложения с преобразованием речи в текст**: Системы с богатым пониманием ввода

## Технические требования

- **Зависимости**: transformers v5.0.0rc0, flash-attn v2.6.3 (для 8B версии)
- **Аппаратное обеспечение**: NVIDIA Ampere (A100 40GB/80GB) и Hopper (H100 80GB)
- **Операционные системы**: Linux
- **Точность вычислений**: BF16 (Brain Floating Point 16)
- **Интеграция программного обеспечения**: Совместимость с библиотекой MTEB 2 для оценки
