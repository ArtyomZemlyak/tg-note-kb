# NVIDIA Llama-Nemotron-ColeEmbed-VL-3B-V2: Эффективная модель для визуального поиска документов

## Краткое описание

NVIDIA Llama-Nemotron-ColeEmbed-VL-3B-V2 - это наиболее эффективная модель в семействе ColeEmbed-V2 с 4.4 миллиардами параметров, предназначенная для задач визуального поиска документов. В отличие от своих собратьев, построенных на архитектуре Qwen, эта модель основана на архитектуре Meta Llama 3.2, что делает её уникальной в семействе ColeEmbed-V2.

## Архитектура

Модель построена на основе объединения компонентов Google siglip2-giant-opt-patch16-384 (визуальный компонент) и Meta-Llama/Llama-3.2-3B (языковой компонент):

- **Визуальный энкодер**: Google siglip2-giant-opt-patch16-384 для обработки визуальных данных
- **Большая языковая модель**: Meta Llama 3.2 (3B) для обработки текстовой информации
- **Модуль слияния**: MLP (Multi-Layer Perceptron) для объединения двух модальностей

Эта архитектура сочетает передовые компоненты от Google и Meta, адаптируя их под задачи мультимодального поиска документов.

## Технические характеристики

- **Общее количество параметров**: ~4.4B (4B общий размер модели в BF16 формате)
- **Тип архитектуры**: Transformer-based мультимодальная эмбеддинговая модель
- **Тип взаимодействия**: late interaction (позднее взаимодействие) для задач поиска документов
- **Базовые компоненты**: Google SigLIP (визуальный) + Meta Llama 3.2 (языковой)
- **Формат ввода**: Изображение (RGB) и текст (строка)
- **Максимальная длина контекста**: 10,240 токенов
- **Обработка изображений**: 
  - Изображения масштабируются до тайлов 512x512 пикселей
  - Каждый тайл потребляет 256 токенов
  - Поддержка до 8 тайлов + 1 миниатюра (максимум 9 тайлов на изображение)
- **Размерность эмбеддинга**: 3072-мерные векторы для каждого входного токена
- **Формат вывода**: Float эмбеддинги в формате [batchsize x seq length x embedding_dim]

## Производительность

### Рейтинг ViDoRe (Visual Document Retrieval)

Модель продемонстрировала сильные результаты в бенчмарке ViDoRe:

#### Сравнение v2 против v1:
- **ViDoRe V1**: 0.9174 (v2) vs 0.9100 (v1) [NDCG@5]
- **ViDoRe V2**: 0.6338 (v2) vs 0.6332 (v1) [NDCG@5]
- **ViDoRe V3**: 0.5970 (v2) vs 0.5707 (v1) [NDCG@10]

Новая версия v2 показывает лучшую точность поиска по всем бенчмаркам ViDoRe по сравнению с предыдущей версией.

#### В сравнении с другими моделями ColeEmbed:
- **ViDoRe V3**: 0.5970 (занимает 4-5 место среди лидеров)
- **ViDoRe V2**: 0.6338
- **ViDoRe V1**: 0.9174

## Методология обучения

- **Наборы данных для полуобучения**: HotpotQA, MIRACL, Natural Questions, SQuAD, DocMatix-IR, VDR и другие
- **Объем данных для обучения**:
  - Текст: Полуобучение на 12 миллионов примеров + fine-tuning на 1.5 миллиона примеров
  - Визуальное: Fine-tuning на ~500k изображениях
- **Тип тонкой настройки**: Fine-tuning для задачи поиска текст-визуальный документ (T→VD)
- **Методы**: Использует передовое объединение моделей для комбинации нескольких fine-tuned чекпоинтов
- **Расширения**: Обогащена многоязычными синтетическими запросами, ориентированными на сложные макеты документов и сценарии межъязыкового поиска

## Целевые применения

- **Поиск по визуальным документам**: Основное приложение для текст-к-визуальный-документ поиска (T→VD)
- **Мультимодальные RAG-системы**: Системы с расширенным извлечением для корпоративных приложений
- **Межмодальный поиск**: Поиск между текстовыми запросами и изображениями документов
- **Мультимедийные поисковые движки**: Системы с ограниченными вычислительными ресурсами
- **Конверсационный ИИ с богатым пониманием ввода**: Приложения с бюджетными требованиями к ресурсам
- **Многоязычные приложения**: Поддержка нескольких языков благодаря синтетическим данным

## Технические требования и зависимости

- **Требуемые зависимости**: Transformers v4.49.0, Flash Attention v2.6.3
- **Поддерживаемое оборудование**: NVIDIA Ampere и Hopper архитектуры (A100 40GB/80GB, H100 80GB)
- **Операционные системы**: Linux
- **Тип точности**: BF16 (Brain Floating Point 16)
- **Интеграция ПО**: Совместимость с библиотекой MTEB 2 для оценки

## Лицензирование

- **Лицензия**: NSCL v1 (некоммерческое/исследовательское использование)
- **Ограничения**: Customized NSCL v1 лицензия (не коммерческое/исследовательское использование)
- **Этические соображения**: Пользователи должны иметь соответствующие права для содержимого ввода; модель не защищает приватность людей, попавших на изображения

## Особенности

- **Уникальная архитектура**: Единственная модель в семействе ColeEmbed-V2, построенная на основе Llama 3.2
- **Улучшенная версия**: v2 показывает лучшие результаты по сравнению с v1 по всем бенчмаркам
- **Многоязычная поддержка**: Расширена синтетическими данными, ориентированными на межъязыковые сценарии поиска
- **Сложные макеты документов**: Оптимизирована для документов с таблицами, графиками, инфографикой

## Сравнение с другими моделями семейства

- **Архитектурные различия**: Базируется на Llama 3.2, а не на Qwen, что делает её уникальной
- **Размерность эмбеддинга**: 3072 vs 4096 (8B) и 2560 (4B), обеспечивая баланс между точностью и эффективностью
- **Производительность**: Немного ниже чем у 8B и 4B версий, но компенсируется архитектурной гибкостью
- **Использование ресурсов**: Наиболее эффективна по сравнению с другими моделями семейства
