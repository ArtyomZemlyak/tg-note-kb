# NVIDIA Nemotron-ColeEmbed-VL-8B-V2: Мощная модель для визуального поиска документов

## Краткое описание

NVIDIA Nemotron-ColeEmbed-VL-8B-V2 - это самая мощная модель в семействе ColeEmbed-V2 с 8.8 миллиардами параметров, предназначенная для задач визуального поиска документов. Модель достигает высочайших результатов в бенчмарке ViDoRe и оптимизирована для сложных задач, связанных с пониманием визуальных документов.

## Архитектура

Модель построена на базе архитектуры Qwen3-VL-8B-Instruct и имеет трехкомпонентную структуру:

- **Визуальный энкодер**: Вариант SigLIP2-SO-400M для обработки визуальных данных
- **Модуль слияния визуального и языкового**: MLP (Multi-Layer Perceptron) для объединения двух модальностей
- **Большая языковая модель (LLM)**: Qwen3-VL-8B для обработки текстовой информации

Эта архитектура обеспечивает эффективное взаимодействие между визуальными и текстовыми представлениями на этапе формирования эмбеддингов.

## Технические характеристики

- **Общее количество параметров**: ~8.8B (9B общий размер модели в BF16 формате)
- **Тип архитектуры**: Transformer-based мультимодальная эмбеддинговая модель
- **Тип взаимодействия**: late interaction (позднее взаимодействие) для задач поиска документов
- **Формат ввода**: Изображение (RGB) и текст (строка)
- **Максимальная длина контекста**: 10,240 токенов
- **Обработка изображений**: 
  - Изображения масштабируются до тайлов 512x512 пикселей
  - Каждый тайл потребляет 256 токенов
  - Поддержка до 8 тайлов + 1 миниатюра (максимум 9 тайлов на изображение)
- **Размерность эмбеддинга**: 4096-мерные векторы для каждого входного токена
- **Формат вывода**: Список массивов чисел с плавающей точкой в формате [batchsize x seq length x embedding_dim]

## Производительность

### Рейтинг ViDoRe (Visual Document Retrieval)

Модель занимает **#1 место** в ViDoRe V3 бенчмарке на момент 26 января 2026 года:

#### ViDoRe V3 (NDCG@10):
- **Общий балл**: 63.54 среднее значение по 8 публичным задачам
- **Оценки по доменам**:
  - Компьютерные науки: 79.30
  - Энергетика: 69.82
  - Финансы (английский): 67.29
  - Финансы (французский): 51.54
  - HR: 66.32
  - Промышленность: 56.03
  - Фармацевтика: 67.19
  - Физика: 50.84

#### ViDoRe V2 (NDCG@5):
- **Средний балл**: 65.16
- Превзошла предыдущие передовые модели

#### ViDoRe V1 (NDCG@5):
- **Средний балл**: 92.65
- Демонстрирует почти идеальные баллы по нескольким задачам (Synthetic AI: 100.00, Syn-Government: 98.89, Syn-Health: 99.63)

## Методология обучения

- **Тип тонкой настройки**: Fine-tuning для задачи поиска запрос-документ
- **Объем данных для обучения**: Примерно 500k изображений
- **Наборы данных для тренировки**: DocMatix-IR, VDR, Vidore-ColPali-Training, VisRAG-Ret-Train-Synthetic-data, VisRAG-Ret-Train-In-domain-data, Wiki-SS-NQ
- **Метод сбора данных**: Гибридный метод (Автоматический, Человеческий, Синтетический)
- **Ключевые техники**:
  - Объединение нескольких fine-tuned чекпоинтов для получения устойчивых характеристик
  - Расширение данными с разнообразным многокомпонентным содержанием
  - Передовой метод объединения моделей с сохранением точности без увеличения задержки инференса

## Целевые применения

- **Поиск по визуальным документам**: Основное приложение для систем межмодального поиска
- **Мультимодальные RAG-системы**: Текстовые запросы с изображениями документов
- **Мультимедийные поисковые движки**: Системы, понимающие как текст, так и визуальные элементы
- **Системы межмодального поиска**: Системы, связывающие визуальные и текстовые представления
- **Конверсационный ИИ с богатым пониманием ввода**: Приложения, понимающие сложные формы ввода
- **Предприимчивые системы поиска**: Разработаны для задач поиска с комплексными типами документов

## Технические требования и зависимости

- **Требуемые зависимости**: transformers v5.0.0rc0, flash-attn v2.6.3
- **Поддерживаемое оборудование**: NVIDIA Ampere (A100 40GB/80GB) и Hopper (H100 80GB)
- **Операционные системы**: Linux
- **Тип точности**: BF16 (Brain Floating Point 16)
- **Интеграция ПО**: Совместимость с библиотекой MTEB 2 для оценки
