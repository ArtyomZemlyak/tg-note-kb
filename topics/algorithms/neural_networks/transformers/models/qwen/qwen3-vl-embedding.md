# Qwen3-VL-Embedding: Модель мультимодальных эмбеддингов

## Краткое описание

Qwen3-VL-Embedding - это модель для генерации векторных представлений (эмбеддингов) для задач мультимодального поиска. Модель может обрабатывать как текстовые, так и визуальные входные данные, создавая единое векторное пространство для поиска и сопоставления.

## История разработки

Qwen3-VL-Embedding стала продолжением успеха текстовых Qwen3-Embedding/Reranker, выпущенных ещё летом 2025 года. В январе 2026 года команда Qwen представила новые модели, адаптировав архитектуру VLM (Vision-Language Model) для решения задач мультимодального поиска и ранжирования.

## Архитектура

### Основные компоненты

- **Мультимодальный энкодер**: Способен обрабатывать как текстовые, так и визуальные входные данные
- **Инструкционный интерфейс**: Принимает инструкции для настройки поведения модели
- **Векторный выход**: Генерирует эмбеддинги фиксированной размерности для документов и запросов

### Архитектурные особенности

- Основана на архитектуре VLM (Vision-Language Model)
- Модифицированный выходной слой для генерации эмбеддингов
- Инференс до последнего слоя (hidden state перед проекцией в вероятности словаря возвращается как эмбеддинг)
- Только стадия prefill (обработка входного контекста), без стадии декодирования
- Многократно более быстрый инференс по сравнению с полноценными VLM

## Применение

### Функция эмбеддинга
```
def embedding(instruction: str, query_or_doc: str | Image) -> list[float]
```

### Области применения

- **Мультимодальный поиск**: Поиск документов, которые могут быть текстовыми, визуальными или комбинацией обоих
- **Интеграция с RAG-системами**: Использование в системах извлечения ответов на вопросы с использованием внешней информации
- **Рекомендательные системы**: Создание векторных представлений для рекомендаций, учитывающих мультимодальный контент

## Особенности

- **Единое пространство представлений**: Создает эмбеддинги как для текста, так и для изображений в одном векторном пространстве
- **Поддержка инструкций**: Модель может адаптировать свое поведение на основе инструкции
- **Высокая скорость инференса**: Быстрая обработка без этапа генерации токенов
- **Доступные размеры**: Модель доступна в двух вариантах: 2 и 8 миллиардов параметров
