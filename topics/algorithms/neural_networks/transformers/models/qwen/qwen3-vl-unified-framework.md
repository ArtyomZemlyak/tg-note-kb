# Qwen3-VL-Embedding и Qwen3-VL-Reranker: Единая фреймворк-система для мультимодального поиска и ранжирования

## Краткое описание

Qwen3-VL-Embedding и Qwen3-VL-Reranker - это единая фреймворк-система моделей для решения задач мультимодального поиска и ранжирования. Система сочетает в себе модель эмбеддингов для быстрого поиска кандидатов и модель реранжирования для точной оценки релевантности.

**Изображение показывает:** Обзор архитектуры моделей Qwen3-VL-Embedding и Qwen3-VL-Reranker, демонстрирующий как они обрабатывают мультимодальные входные данные для генерации эмбеддингов и оценки релевантности.

### Этапы обработки

1. **Мультимодальный вход**: Обработка текста, изображений или их комбинации
2. **Генерация эмбеддингов**: Создание векторных представлений запросов и документов
3. **Вычисление схожести**: Быстрая оценка схожести в векторном пространстве
4. **Реранжирование**: Точная оценка релевантности пар "запрос-документ"

## Особенности фреймворка

### Мультимодальный поиск
- **Текст-текст**: Классический семантический поиск
- **Текст-изображение**: Поиск изображений по текстовому запросу
- **Изображение-текст**: Поиск текстовых документов по изображению
- **Изображение-изображение**: Поиск похожих изображений
- **Смешанные запросы**: Комбинации текста и изображений

### Использование инструкций
- **Фокусировка на стиле**: Инструкция может направлять модель на сопоставление по стилю изображения
- **Фокусировка на содержимом**: Инструкция может направлять модель на сопоставление по содержимому
- **Контекстно-зависимое сравнение**: Поведение модели адаптируется под конкретные задачи

### Технологии оптимизации
- **Quantization-aware обучение**: Эмбеддинги можно квантовать в int8 с минимальной потерей качества
- **Matryoshka Representation Learning**: Поддержка эмбеддингов разных размеров из одного вектора
- **Длинный контекст**: Обработка до 32K токенов (10-20 страниц изображений + текст)
- **Ускорение инференса**: Только этап prefill, без декодирования

## Пайплайн мультимодального поиска

### Двухэтапный подход
1. **Быстрый поиск кандидатов** - использование эмбеддингов для быстрой фильтрации
2. **Точное ранжирование** - реранкер для точной оценки релевантности топ-N кандидатов

### Обучение в системе
- **LoRA адаптация**: Модели обучаются как LoRA к Qwen3-VL для сохранения способностей бэкбона
- **Многоэтапное обучение**: s0 → s1 → s2 → финальная модель
- **Взаимное обучение**: Эмбеддинги и реранкер обучают друг друга
- **Фильтрация данных**: Использование одного этапа для фильтрации данных для следующего

## Применение

### Решаемые задачи
- **Поиск по изображениям**: Найти изображения, похожие на заданное
- **Визуальный документальный поиск**: Найти документы по визуальному или текстовому запросу
- **Мультимодальные рекомендации**: Рекомендация контента на основе многомодальных предпочтений
- **Поиск в RAG-системах**: Расширение возможностей поиска за счет визуальной информации

### Области применения
- **Электронная коммерция**: Поиск товаров по изображениям
- **Медицинская диагностика**: Поиск похожих медицинских изображений
- **Научные исследования**: Поиск научных работ по изображениям результатов
- **Мультимодальная RAG**: Поиск релевантных документов по тексту и изображениям

## Архитектурные особенности

### Qwen3-VL-Embedding
- Возвращает вектор признаков в соответствии с инструкцией
- `def embedding(instruction: str, query_or_doc: str | Image) -> list[float]`
- Отдает скрытое состояние до проекции в словарь как эмбеддинг
- Только prefill стадия инференса

### Qwen3-VL-Reranker
- Оценивает степень соответствия запроса документу (0-1)
- `def reranker(instruction: str, query: str | Image, document: str | Image) -> float`
- Использует соотношение вероятностей токенов "yes"/"no" для оценки
- Полный инференс VLM с измененной интерпретацией выхода

## Сравнение с другими фреймворками

### Преимущества
- **Единая архитектура**: Оба компонента основаны на VLM (Vision-Language Model)
- **Мультимодальность**: Работа с разными комбинациями текста и изображений
- **Инструкционное обучение**: Адаптация поведения под конкретные задачи
- **Производительность**: Быстрый инференс за счет отсутствия этапа декодирования
- **Гибкость**: Поддержка различных размеров эмбеддингов через MRL

### Отличия от традиционных подходов
- **Классические эмбеддинги CLIP**: Фиксированная архитектура, ограниченная настройка
- **Текстовые эмбеддинги**: Не работают с изображениями
- **Отдельные модели**: Qwen3-VL-Embedding и Qwen3-VL-Reranker работают как единая система
