# Multi-Token Prediction (MTP): Многотокенное предсказание для улучшения обучения языковых моделей

## Общее описание

Multi-Token Prediction (MTP) - это вспомогательный объект обучения, предложенный для улучшения задачи предсказания следующего токена (Next-Token Prediction, NTP) в тренировке языковых моделей. В отличие от традиционного подхода, где модель предсказывает только один следующий токен, MTP обучает модель предсказывать несколько будущих токенов одновременно, что улучшает как производительность обучения, так и качество модели.

## История и развитие

MTP был предложен как способ преодоления ограничений стандартного обучения с предсказанием следующего токена. Это расширение подхода от простого предсказания одного токена к предсказанию k токенов за один шаг обучения, что позволяет модели лучше понимать долгосрочные зависимости и структуру последовательности.

## Технические особенности

### Основной принцип

Вместо предсказания только следующего токена (x_t → ŷ_{t+1}), MTP обучает модель предсказывать следующие k токенов одновременно (x_t → ŷ_{t+1}, ŷ_{t+2}, ..., ŷ_{t+k}). Это позволяет модели:

- **Лучше захватывать зависимости**: Модель учится предсказывать не только ближайший токен, но и более удаленные
- **Планировать вперед**: Развивается способность модели к долгосрочному планированию
- **Улучшить сходимость**: В некоторых случаях обучение становится более устойчивым

### Обучающая функция

В традиционном NTP функция потерь определяется как:

```
L_NTP = -Σ log p(x_{t+1}|x_≤t)
```

В MTP функция потерь расширяется для учета предсказания нескольких токенов:

```
L_MTP = -Σ Σ log p(x_{t+i}|x_≤t)
```

Где внутренняя сумма идет по i от 1 до k (количества предсказываемых токенов).

## Архитектурные особенности

### Многоголовое предсказание

- **Несколько голов предсказания**: Модель может использовать несколько голов для предсказания разных будущих токенов
- **Разделение параметров**: Общие параметры используются для получения представления, но отдельные головы для каждого предсказываемого токена
- **Прогнозирование с различной дальностью**: Модель может иметь разную степень уверенности для ближних и дальних токенов

### Варианты реализации

- **Последовательное MTP**: Модель предсказывает токены подряд, начиная с t+1
- **Стратегическое пропускание**: Модель может предсказывать токены с пропусками (например, t+1, t+3, t+5)
- **Адаптивное количество**: Количество предсказываемых токенов может варьироваться в зависимости от контекста

## Преимущества

### Улучшение обучения

- **Улучшенная сходимость**: Позволяет модели быстрее обучаться, предоставляя больше сигналов
- **Лучшее понимание структуры**: Модель учится видеть более длинные паттерны в данных
- **Повышение эффективности**: Может ускорить обучение за счёт лучшего использования контекста

### Повышение качества

- **Улучшенные результаты**: Как показывают эксперименты, MTP приводит к улучшению точности на нескольких задачах
- **Лучшее понимание длинных зависимостей**: Модель лучше захватывает связи между удаленными частями текста
- **Повышение устойчивости**: Модель становится более устойчивой к шуму и вариациям в данных

## Экспериментальные результаты

### На 8B MoE модели

Исследования, представленные в контексте NVIDIA Nemotron 3, показали улучшения на различных задачах:

| Категория задач | Метрика | Без MTP | С MTP | Улучшение |
|-----------------|---------|---------|-------|-----------|
| Общие знания | MMLU | 70.06 | 71.26 | +1.2 |
| Рассуждения | MMLU-Pro | 45.05 | 47.84 | +2.79 |
| Программирование | MBPP-Sanitized | 65.58 | 66.89 | +1.31 |
| Пониманиеcommonsense | ARC-Challenge | 86.43 | 88.05 | +1.62 |
| Понимание текста | RACE | 84.02 | 85.36 | +1.34 |
| Математика | GSM8K | 82.49 | 84.46 | +1.97 |

### Влияние на кодовые данные

Эксперименты показали, что MTP особенно эффективен при обучении на кодовых данных:

- **Улучшенные предсказания до 1M токенов**: Nemotron 3 Nano показал улучшенные предсказания до 1M токенов в кодовых данных
- **Снижение среднего отрицательного логарифма**: Постепенное снижение при увеличении позиции токена в кодовых данных

## Применения

### NVIDIA Nemotron 3

- **Улучшение архитектуры**: Использование MTP как вспомогательного объекта при обучении
- **Нативная "черновая модель"**: MTP работает как встроенная "черновая модель" для спекулятивного декодирования
- **Улучшение точности**: Повышение точности на +2.4% в среднем по различным задачам

### Другие применения

- **Обучение коду**: Особенно эффективен при обучении на кодовых данных
- **Математические задачи**: Помогает захватывать логические зависимости
- **Генерация текста**: Улучшает последовательность и согласованность генерации

## Вариации и улучшения

### Leap Multi-Token Prediction (L-MTP)

- **Стратегическое пропускание**: В отличие от обычного MTP, который генерирует токены в соседних позициях, L-MTP стратегически пропускает промежуточные токены
- **Увеличенное покрытие**: Позволяет модели охватывать более широкий диапазон будущего контекста
- **Улучшенное понимание**: Помогает модели захватывать более сложные зависимости

### Curriculum MTP

- **Поэтапное обучение**: Начинается с малого k и постепенно увеличивается
- **Адаптивность**: Количество предсказываемых токенов может адаптироваться в процессе обучения
- **Стабильность**: Позволяет более стабильно обучать модели

## Сравнение с другими методами

| Метод | Прогнозирование | Комплексность | Эффективность | Применение |
|-------|-----------------|---------------|---------------|------------|
| Next-Token Prediction | 1 токен | Низкая | Базовая | Общее обучение |
| Multi-Token Prediction | k токенов | Средняя | Высокая | Долгосрочные зависимости |
| Span Corruption | Промежутки | Средняя | Высокая | MLM задачи |
| Fill-in-the-Middle | Центральные части | Высокая | Высокая | Контекстуальное обучение |

## Ограничения и вызовы

### Вычислительная стоимость

- **Увеличенная сложность**: Предсказание нескольких токенов требует больше вычислений
- **Требования к памяти**: Более высокие требования к памяти для хранения активаций
- **Баланс между k и эффективностью**: Необходимость найти оптимальное значение k

### Архитектурные ограничения

- **Сложность реализации**: Требует модификации архитектуры модели
- **Подбор гиперпараметров**: Необходимость тщательного подбора количества предсказываемых токенов
- **Совместимость**: Не все архитектуры легко адаптируются к MTP

## Будущие направления

### Алгоритмические улучшения

- **Адаптивное k**: Алгоритмы для динамического определения количества предсказываемых токенов
- **Селективное MTP**: Предсказание только тех токенов, которые важны для задачи
- **Гибридные подходы**: Комбинация MTP с другими методами обучения

### Применение в новых областях

- **Мультимодальные задачи**: Применение MTP в мультимодальных моделях
- **Рассуждение**: Использование для улучшения способности к цепочечным рассуждениям
- **Долгосрочная память**: Помощь моделям в управлении долгосрочной информацией
