# Механизм внимания PaTH: Позиционное кодирование через накопление преобразований Хаусхолдера

## Краткое описание

PaTH (Position encoding via Accumulating Householder Transformations) — это гибкая схема позиционного кодирования, зависящая от данных, основанная на накопленных произведениях преобразований Хаусхолдера (или подобных им), каждое из которых зависит от данных, т.е. является функцией входных данных. PaTH решает ограничения традиционного метода RoPE (Rotary Position Embedding), который использует статические преобразования, зависящие только от относительной позиции.

## Технические детали

### Основная идея
В отличие от RoPE, где ключевые/запросные преобразования между двумя элементами последовательности зависят только от их относительной позиции и не зависят от фактического входа, PaTH использует преобразования, которые зависят от данных. Матрица перехода H<sub>ij</sub> ∈ R<sup>d×d</sup> получается через накопленное произведение матриц, зависящих от данных, вдоль пути между позициями j и i.

### Математическая формулировка
PaTH использует матрицы с подобной Хаусхолдеру структурой "единичная плюс ранг-один":
H<sub>t</sub> = I - β<sub>t</sub> w<sub>t</sub> w<sub>t</sub><sup>T</sup>

где w<sub>t</sub> ∈ R<sup>d</sup> и β<sub>t</sub> = 2 × sigmoid(u<sup>T</sup> x<sub>t</sub> + b) ∈ (0, 2) являются функциями от текущего входа x<sub>t</sub>.

### Преимущества
- **Адаптивность к данным**: Может динамически адаптироваться к входным данным
- **Улучшенное отслеживание состояния**: Превосходит RoPE в задачах, требующих отслеживания состояния
- **Теоретическая выразительность**: Может решать задачи NC<sup>1</sup>-complete, выходя за пределы класса сложности TC<sup>0</sup>
- **Эффективность**: Разработан с использованием алгоритма, аналогичного FlashAttention, для эффективного параллельного обучения

## Сравнение с другими методами

| Метод | Зависимость от данных | Выразительность | Эффективность | Отслеживание состояния |
|-------|----------------------|------------------|---------------|------------------------|
| RoPE | Нет | Ограниченная | Высокая | Ограниченное |
| ALiBi | Нет | Ограниченная | Высокая | Ограниченное |
| PaTH | Да | Высокая | Высокая | Высокое |
| PaTH-FoX | Да (гибрид) | Наивысшая | Высокая | Наивысшее |

## Экспериментальные результаты

### Синтетические задачи
- **Flip-flop языковое моделирование**: PaTH достигает 0% ошибок (по сравнению с ~7% для RoPE)
- **Multi-query Repeated Associative Recall с N-назад (MQRAR-N)**: Лучше справляется с задачами N-назад до N<4
- **Задачи на работу со словами (A5)**: Превосходит RoPE в решении задач NC<sup>1</sup>-complete

### Реальные задачи
- Улучшенное моделирование языка на различных бенчмарках
- Лучшая экстраполяция по длине (до 64K токенов)
- Повышенная производительность на задачах с длинным контекстом (RULER, BABILONG, LongBench-E)

## Техническая реализация

### Обучение
Разработан блочная алгоритмическая структура, аналогичная FlashAttention, с использованием компактного представления произведений матриц Хаусхолдера. Это позволяет избежать материализации полной матрицы внимания в медленной памяти DRAM.

### Вывод (инференс)
Можно эффективно обновлять исторические ключи на месте с помощью матрицы перехода текущего временного шага, что позволяет совместить с существующими ядрами вывода, такими как FlashDecoding и PagedAttention.

## Комбинация с другими методами

### PaTH-FoX
PaTH совместим с другими модификациями softmax-внимания, такими как Forgetting Transformer (FoX). Комбинация PaTH-FoX показывает дополнительные улучшения, особенно в экстраполяции по длине.
