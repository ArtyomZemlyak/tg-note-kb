# KVZap: Быстрое и адаптивное прунинг KV-кэшей

## Описание

KVZap (Fast, Adaptive, and Faithful KV Cache Pruning) - это метод сжатия KV-кэшей в языковых моделях для снижения потребления памяти и ускорения инференса. Метод предлагает эффективный способ удаления наименее информативных токенов из кэша ключ-значение без значительной потери качества.

## Проблема

Традиционные языковые модели сталкиваются с проблемой роста KV-кэшей пропорционально длине последовательности. Это приводит к:
- Линейному росту требований к памяти
- Увеличению стоимости инференса
- Ограничениям при работе с длинными контекстами

Человечество разработало различные техники сжатия KV-кэшей, включая прунинг токенов, квантование и низкоранговые проекции, но идеального баланса между качеством, производительностью и удобством интеграции не существовало.

## Метод

### Основа: KVZip

Метод KVZap строится на основе алгоритма KVZip, который:
- Дублирует входной промпт следующим образом:
  ```
  user: <prompt>
  Repeat the previous context exactly.
  assistant: <prompt>
  ```
- На основе внимания отбирает наиболее важные пары ключей и значений
- Показывает хорошее качество, но требует двух проходов по сети
- Подходит только для сжатия префикса

### Улучшение: KVZip+

Авторы предлагают модификацию KVZip+, которая учитывает:
- Влияние, что внимание домножается на value и выходную проекцию O
- Получает более точную оценку важности данного токена

### Конечный метод: KVZap

Метод KVZap включает:
- Обучение небольшой нейросети (линейный слой или MLP) для предсказания оценок из KVZip+
- Использование предсказаний для выбрасывания токенов
- Экономию времени за счет предсказания, которое стоит заметно меньше, чем выгрузка большого KV-кэша
- Порог важности на инференсе: токены выше порога принимаются, ниже - выбрасываются

### Обучение

- Используется выборка из 1.2M пар hidden/метрика из датасета Nemoton-CC
- Для гарантированного сохранения ближайших токенов всегда сохраняются последние 128 токенов
- Обучение позволяет получить модель, способную предсказывать важность токенов без необходимости в повторных вычислениях

## Эксперименты

### Модели
- Qwen3-8B
- Llama-3.1-8B-Instruct
- Qwen3-32

### Бенчмарки
- RULER/LongBench - бенчмарки длинного контекста
- AIME25 - задачи рассуждения с длинным контекстом

### Результаты
- Двуслойный MLP превосходит линейный слой по квадратичной ошибке
- KVZap по качеству равен или немного хуже KVZip, но значительно превосходит другие бейзлайны
- Позволяет достичь сжатия в 2-4 раза без просадки качества

### Ablation study
- Фиксированный порог лучше, чем top-k pruning, потому что разные тексты могут иметь разную информационную нагрузку
- Скользящее окно важно для хорошего качества

## Выводы

- KVZap - рабочий и сравнительно легко применимый на практике подход с небольшим пост-обучением
- Подходит для сценариев, где важна эффективность KV-кэширования
- Сравнивается с AutoJudge, где важность токенов определяется на основе конечной задачи
- Более обобщаем на другие задачи по сравнению с задаче-специфичными методами
