# TinyLoRA: Экстремально параметрически эффективная настройка (TinyLoRA)

## Краткое описание

TinyLoRA — это метод масштабируемой низкоранговой адаптации (LoRA), который позволяет масштабировать размеры обновлений до одного параметра. Метод позволяет дообучать языковые модели с использованием всего 13 параметров, сохраняя при этом высокую точность на задачах логического мышления. TinyLoRA расширяет возможности LoRA-XS за счет дальнейшего уменьшения количества обучаемых параметров.

## Основная информация

### Принцип работы TinyLoRA

TinyLoRA модифицирует LoRA-XS путем замены матрицы r×r на низкоразмерный обучаемый вектор v ∈ R^u, проецируемый через фиксированный случайный тензор P. Это позволяет:

- Уменьшить количество обучаемых параметров до экстремально низких значений
- Использовать параметрическое разделение весов (weight tying) между модулями
- Обучаться даже с 1 параметром при необходимости

### Архитектурные особенности

- Вместо обычной LoRA, где обновления связаны с шириной модели, TinyLoRA позволяет масштабировать обновления до произвольно малых размеров
- Использует разложение по сингулярным числам (SVD) для создания фиксированных направлений и обучаемого вектора
- Позволяет обменивать параметры между модулями (weight tying), что может уменьшить общее количество параметров до одного

### Основные результаты

- Qwen2.5-8B достиг 91% точности на GSM8K с только 13 обучаемыми параметрами (26 байт в bf16)
- Метод восстанавливает 90% улучшения производительности, обучая в 1000 раз меньше параметров на сложных бенчмарках, таких как AIME, AMC и MATH500
- Эффективность особенно высока в сценариях обучения с подкреплением (RL), а не супервизионного fine-tuning (SFT)

### Сравнение с другими методами

| Метод   | Обучаемые параметры   | Минимум   |
|---------|------------------------|-----------|
| Full FT | O(nmd²)               | nmd²      |
| LoRA    | O(nmdr)               | 2nmd      |
| LoRA-XS | O(nmr²)               | nm        |
| TinyLoRA| O(nmu)                | 1         |

Где:
- n — количество слоев
- m — количество модулей на слой
- d — ширина модели
- r — ранг
- u — размерность проекции TinyLoRA

## Новые концепции и термины

- **TinyLoRA**: Экстремально низкоразмерная адаптация, метод для масштабирования низкоранговых адаптеров до размеров одного параметра
- **Параметрическое разделение весов (Weight tying)**: Техника, при которой несколько модулей совместно используют одни и те же обучаемые параметры
- **Frozen SVD rank**: Ранг фиксированного разложения по сингулярным числам
- **Trainable projection dimension (u)**: Размерность обучаемого вектора в TinyLoRA
- **Weight tying factor (n_tie)**: Количество модулей, совместно использующих один вектор параметров

## Примеры применения

TinyLoRA особенно полезен в следующих сценариях:

- **Обучение с ограниченными вычислительными ресурсами**: Когда необходимо минимизировать количество обучаемых параметров
- **Федеративное обучение**: Где требуется передавать минимальные обновления по сети
- **Персонализация**: Где каждая задача требует своего небольшого адаптера
- **Массовое развертывание**: Где необходимо хранить множество адаптеров в ограниченной памяти
- **Обучение с подкреплением по верифицируемым наградам (RLVR)**: Где RL обеспечивает более информативные сигналы при небольшом количестве параметров
