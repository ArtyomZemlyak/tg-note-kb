# SLPO - Shorter Length Preference Optimization

## Краткое описание

SLPO (Shorter Length Preference Optimization) - это новый метод обучения с подкреплением, представленный в рамках фреймворка ORION, который динамически награждает за краткость без ущерба для точности. В отличие от фиксированных штрафов за длину, SLPO использует относительную систему наград, зависящую от сложности конкретной задачи, что позволяет эффективно сжимать рассуждения без ущерба для качества.

## Основная информация

### Основные концепции

1. **SLPO (Shorter Length Preference Optimization)**: Метод RL, который динамически награждает за краткость без ущерба для точности.

2. **Динамическая награда за длину**: Награда за длину зависит от конкретной задачи и вычисляется относительно других правильных ответов в батче.

3. **Относительная система наград**: Модель вознаграждается за близость к минимальной длине *относительно сложности текущей задачи*.

4. **Формула награды**: R_SLPO = R_correct + α * (L_max - L_curr) / (L_max - L_min), где L_min и L_max - минимальная и максимальная длина правильных ответов в батче.

5. **Стабилизация обучения**: SLPO помогает стабилизировать процесс обучения сжатому рассуждению, начатому на этапе SFT.

### Механизм работы

#### Алгоритм вычисления награды
1. Система смотрит на длины всех *правильных* ответов в батче
2. Находит минимальную длину (L_min) и максимальную длину (L_max)
3. Вычисляет награду для конкретного ответа по формуле: R_SLPO = R_correct + α * (L_max - L_curr) / (L_max - L_min)
4. Если задача реально требует много шагов (L_min ≈ L_max), штраф за длину исчезает
5. Если есть короткое решение против длинного, модель получает стимул выбрать короткий путь

#### Преимущества SLPO по сравнению с другими методами
- **Гибкость**: Не штрафует за длину на сложных задачах, где длинные рассуждения необходимы
- **Адаптивность**: Система наград адаптируется к сложности задач в батче
- **Сохранение точности**: Позволяет сокращать рассуждения без ущерба для корректности
- **Устойчивость**: Более устойчивая к градиентным взрывам по сравнению с жесткими штрафами за длину

### Архитектура и методология

#### Интеграция с ORION
1. **Этап SFT**: Сначала модель обучается формату Mentalese через SFT на датасете MentaleseR-40k
2. **Этап SLPO**: Затем применяется RLVR с использованием SLPO для оптимизации длины рассуждений
3. **Гиперпараметр α**: Устанавливается на 0.1, чтобы балансировать между точностью и сжатием

#### Отличия от традиционных методов RL
- **GRPO (Group Relative Preference Optimization)**: Сравнивает ответы внутри батча, но не использует динамическую систему наград за длину
- **L1 штрафы**: Жестко штрафуют за длину, часто заставляя модели "недодумывать" на сложных задачах
- **Стандартный RLVR**: Фокусируется в основном на правильности ответа, а не на эффективности рассуждения

## Новые концепции и термины

- **Group Relative Preference**: Сравнение правильных ответов в батче для определения предпочтений, расширенное в SLPO для учета длины.
- **Относительная оптимизация длины**: Метод, при котором оптимизация длины происходит относительно других правильных решений в батче.
- **Динамический штраф за длину**: Штраф, который изменяется в зависимости от сложности задач в текущем батче.
- **Награда за сжатие**: Составляющая общей награды, поощряющая краткие, но корректные решения.
- **Баланс точность/эффективность**: Компромисс между корректностью решения и длиной рассуждения, который SLPO оптимизирует динамически.

## Примеры применения

- **Математические задачи**: Сокращение длины цепочек рассуждений в задачах по алгебре, геометрии и т.д.
- **Логические задачи**: Устранение избыточных рассуждений при сохранении логической целостности
- **Оптимизация RLVR**: Замена стандартных методов RLVR на более эффективные с учетом длины рассуждений
- **Обучение сжатому мышлению**: Обучение моделей эффективному использованию внутреннего "мышления" при решении задач
