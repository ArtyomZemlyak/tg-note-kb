# RePo: Context Re-Positioning для трансформеров

## Краткое описание

RePo (Context Re-Positioning) - это новая технология от Sakana AI, которая позволяет языковым моделям переупорядочивать контекст динамически на основе семантики, а не только на основании фиксированной позиции в последовательности. Модель получает возможность "перепозиционировать" токены по смыслу, а не по жесткому порядку следования, что улучшает фокусировку на важной информации и снижает влияние шума.

## Основная информация

RePo решает проблему, с которой сталкиваются традиционные трансформеры: когда важные факты находятся глубоко внутри контекста, среди шума или разбросаны по разным частям, модель может их упустить. Вместо того чтобы читать текст как одну длинную ленту, где важность определяется близостью к началу, RePo позволяет модели динамически "переупорядочивать" контекст на основе значения.

### Как работает RePo

В отличие от стандартных подходов, RePo использует дифференцируемый модуль, который назначает позиции токенов, основываясь на семантических зависимостях, а не на их исходной позиции в последовательности. Основные компоненты:

1. **Позиционное представление**: Для каждого токена i на слое k небольшая сеть MLP (`gₚₖ`) проецирует скрытое состояние `hᵢₖ` в более компактный вектор позиционного представления `pᵢₖ`.

2. **Назначение позиции**: Для каждой головы внимания h на слое k другая функция `wₚₖ,ₕ` производит скалярную позицию `zᵢₖ,ₕ` из представления позиции.

3. **Применение**: Вместо использования дискретного индекса i, RePo использует изучаемое вещественное значение `zᵢ` в позиционном кодировании (например, заменяя R(i) на R(zᵢ) в RoPE):
   ```
   qᵢ ← R(zᵢ)qᵢ, kᵢ ← R(zᵢ)kᵢ
   ```

4. **Архитектура**: Применяется с определенной глубины (например, начиная с 5-го слоя), чтобы не нарушать ранние представления токенов.

## Новые концепции и термины

- **Context Re-Positioning**: Техника, позволяющая LLM переупорядочивать контекст по смыслу, а не по позиции
- **Семантическое позиционирование**: Назначение позиций токенов на основе их смысловой значимости, а не порядка ввода
- **Динамическое переупорядочивание**: Возможность модели адаптивно изменять относительное расположение информации в контексте

## Примеры применения

RePo особенно полезен в следующих сценариях:

- Длинные контексты, где важная информация разбросана по разным частям
- Наличие шумных данных, смешанных с важной информацией
- Структурированные данные (таблицы, списки), преобразованные в плоский текст
- Задачи, требующие анализа отношений между удаленными элементами контекста

## Сравнение с RoPE

В отличие от RoPE (Rotary Positional Embeddings), который использует фиксированные позиции токенов, RePo позволяет модели обучаться на том, какие токены должны быть "ближе" друг к другу в пространстве внимания, основываясь на их семантической значимости. Это позволяет:

- Подтягивать важные куски информации ближе друг к другу
- Отодвигать шум и лишний текст
- Помогать механизму внимания фокусироваться на нужном

## Экспериментальные результаты

- **Noisy Context (RULER)**: улучшение на 11.04 пункта по сравнению с RoPE (55.68 против 44.64 средней точности)
- **Структурированные данные**: улучшение на 1.94 EM пункта (27.87 против 25.93 в среднем)
- **Длинные контексты**: согласованные улучшения на бенчмарках RULER и LongBench, преимущества усиливаются при длинах 8K и 16K токенов
- **Общие задачи**: эквивалентная производительность с RoPE на стандартных бенчмарках (53.73 против 53.70 в среднем)
- **Внимание**: значительно больше массы внимания выделяется на дальние, но релевантные токены
