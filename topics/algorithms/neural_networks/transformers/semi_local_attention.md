# Semi-Local Attention (SLA)

## Описание

Semi-Local Attention (SLA) - это механизм разреженного внимания с **линейной сложностью**, разработанный Meta специально для рекомендательных систем в рамках архитектуры ULTRA-HSTU. SLA решает проблему квадратичной сложности стандартного attention механизма, обеспечивая эффективную обработку длинных последовательностей пользовательских взаимодействий.

## Проблема

**Стандартный causal attention** имеет сложность **O(n²)** по длине последовательности, что становится критичным для:
- Длинных историй взаимодействий (тысячи и десятки тысяч событий)
- Масштабных рекомендательных систем с высокой нагрузкой
- Моделей с большим количеством слоёв внимания

Для HSTU-style архитектур это особенно критично, так как они работают с последовательностями длиной до 16,000 событий.

## Архитектурное Решение

SLA использует **комбинацию локального и глобального окон** вместо полной каузальной маски:

### Компоненты SLA

1. **Локальное окно (Local Window)**
   - Обрабатывает недавние взаимодействия пользователя
   - Учитывает **текущие интересы** и краткосрочные паттерны
   - Полное внимание внутри окна фиксированного размера

2. **Глобальное окно (Global Window)**
   - Обрабатывает ключевые события из всей истории
   - Учитывает **долгосрочные интересы** пользователя
   - Разреженное внимание к выбранным глобальным токенам

3. **Механизм комбинации**
   - Объединяет результаты локального и глобального внимания
   - Сохраняет каузальность (не заглядывает в будущее)
   - Обеспечивает линейную сложность O(n)

## Сложность и Эффективность

| Механизм | Сложность | Память | Подходит для длинных последовательностей |
|----------|-----------|--------|------------------------------------------|
| Standard Causal Attention | O(n²) | O(n²) | ❌ Нет |
| **Semi-Local Attention** | **O(n)** | **O(n)** | ✅ Да |
| Sliding Window Attention | O(n) | O(n) | ⚠️ Частично (теряет глобальный контекст) |
| Sparse Attention (общий) | O(n) | O(n) | ⚠️ Зависит от паттерна |

## Результаты в ULTRA-HSTU

В рамках ULTRA-HSTU Semi-Local Attention показал следующие результаты:

| Метрика | Улучшение |
|---------|-----------|
| Training scaling efficiency | **↑ в 2.7 раза** |
| Inference scaling efficiency | **↑ в 5.1 раза** |

**Training scaling efficiency** и **Inference scaling efficiency** - метрики, показывающие, насколько эффективно модель масштабируется при добавлении вычислительных ресурсов.

## Сравнение с Другими Механизмами Внимания

### vs. Flash Attention

- **Flash Attention**: Оптимизация вычислений full attention через I/O-aware алгоритмы
- **SLA**: Архитектурное изменение паттерна внимания
- **Комбинация**: В ULTRA-HSTU используют оба подхода вместе

### vs. Sparse Attention (DSA, HSA, MoSA)

- **DSA/HSA/MoSA**: Общие механизмы для NLP задач
- **SLA**: Специализирован для рекомендательных систем
  - Учитывает специфику пользовательских последовательностей
  - Оптимизирован для causal recommendation setting

### vs. Linear Attention (Mamba, State Space Models)

- **Linear Attention**: Аппроксимация attention через kernel methods или state space
- **SLA**: Сохраняет точный attention в окнах, не аппроксимирует
- **Преимущество SLA**: Лучшее качество при сохранении линейной сложности

## Применение в ULTRA-HSTU

В ULTRA-HSTU Semi-Local Attention используется в комбинации с другими оптимизациями:

1. **На всех 18 STU слоях** модели
2. **Для последовательностей длиной до 16,000** событий
3. **В сочетании с Attention Truncation** для дополнительной оптимизации глубины
4. **С модифицированными ядрами Flash Attention v3** для H100 GPU

## Технические Детали Реализации

### Интеграция с Flash Attention v3

В ULTRA-HSTU используют модифицированные ядра Flash Attention v3:
- Адаптированы для STU-блоков (Sequence Transformer Units)
- Поддержка **FP8** для матмулов
- **BF16** для остальных операций
- Фьюзинг операций для минимизации HBM ↔ SRAM трансферов

### Паттерн Маски

SLA использует специальный паттерн маски, который:
- Разрешает полное внимание в пределах локального окна
- Добавляет разреженные глобальные связи
- Сохраняет каузальность (no peeking into future)

## Преимущества

1. **Линейная сложность**: Масштабируется на длинные последовательности
2. **Сохранение качества**: Не теряет важные зависимости благодаря глобальному окну
3. **Специализация для RecSys**: Учитывает природу пользовательских последовательностей
4. **Совместимость с другими оптимизациями**: Работает с mixed precision, attention truncation, LBSL

## Ограничения

1. **Гиперпараметры окон**: Требует настройки размеров локального и глобального окон
2. **Специфичность**: Оптимизирован для causal recommendation, может требовать адаптации для других задач
