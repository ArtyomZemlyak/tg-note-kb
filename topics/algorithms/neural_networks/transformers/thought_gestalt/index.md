# Модель Thought Gestalt (TG)

## Краткое описание

Модель Thought Gestalt (TG) — это архитектура рекуррентного трансформера, представленная Насимом Боразжанизаде и Джеймсом Макклелландом в статье "Modeling Language as a Sequence of Thoughts" (2025). Она обрабатывает текст на двух уровнях абстракции: токены и предложения. В отличие от традиционных трансформеров, которые оперируют последовательностью токенов, TG сжимает каждое обработанное предложение в единое векторное представление — «гештальт» — и сохраняет его в дифференцируемой памяти.

## Ключевые особенности

### Обработка на уровне предложений
- Основная идея: сжатие контекста до уровня "мыслей" или предложений
- Предложение становится атомарной единицей исторического контекста вместо токена
- Мотивация: когнитивная теория, согласно которой люди не хранят дословную стенограмму прошлого контекста, а создают "ситуационные модели"

### Рекуррентная память
- Использует дифференцируемую память для хранения векторов предложений {m_{t-K}, ..., m_{t-1}}
- Вектор предложения m_t (размерности d) извлекается из скрытого состояния токена <EOS> на промежуточном слое
- Механизм позволяет будущему «учить» прошлое тому, как себя сжимать, через сохранение графа вычислений

### Двухуровневая архитектура
- Нижний уровень: дословная генерация текущего предложения с использованием стандартного causal masking
- Верхний уровень: управление «памятью предложений» — последовательностью векторов

### Cross-attention на память
- Токены внутри текущего предложения смотрят друг на друга через стандартное self-attention
- Эти же токены также делают cross-attention на банк памяти, содержащий гештальт-вектора предыдущих предложений
- В отличие от RAG или Transformer-XL, сохраняется граф вычислений для обучения энд-ту-энд

## Архитектурные детали

### Механизм рекуррентной памяти
- Когда модель обрабатывает поток предложений S_1, S_2, ..., S_n, для каждого предложения S_t происходят две операции:
  1. Токены внутри S_t смотрят друг на друга через стандартное казуальное внимание
  2. Эти же токены делают cross-attention в банк памяти M, содержащий гештальт-вектора предыдущих предложений

### Сжатие и обучение
- m_t извлекается из скрытого состояния токена <EOS> на промежуточном слое (например, l_s=7 в 12-слойной модели)
- Вектор m_t оптимизируется исключительно для минимизации лосса кросс-энтропии будущих токенов
- Благодаря сохранению графа вычислений, градиенты текут назад через механизм cross-attention и позволяют будущему обучать прошлое

### Context Seeding
- Эмбеддинг <BOS> для предложения S_t инициализируется гештальтом предыдущего предложения: e_{t,0} <- m_{t-1}
- Создает прямой, резидуальный "хайвей" для входа исторического контекста
- Дополняет механизм cross-attention

## Сравнение с существующими подходами

### Отличие от Transformer-XL
- В Transformer-XL используется сегментный рекурсивный механизм с фиксированным размером памяти
- В TG сохраняется граф вычислений, что позволяет энд-ту-энд обучение дифференцируемой памяти

### Отличие от RAG
- RAG использует извлечение внешней информации
- TG создает сжатые внутренние репрезентации, обучаемые для.future prediction

## Преимущества

### Эффективность масштабирования
- Показывает улучшенные законы масштабирования по сравнению с аналогичным GPT-2
- Требует на ~5-8% меньше данных для достижения той же перплексии
- Повышение эффективности без увеличения вычислительных затрат на инференсе для текущего окна контекста

### Устранение Reversal Curse
- Показывает улучшенную способность к обратному обобщению
- Сжимая предложение в вектор m_t, модель вынуждена кодировать отношения между сущностями, а не последовательность токенов
- Демонстрирует лучшую семантическую стабильность

## Ограничения

### Масштаб оценки
- Эксперименты проводились на WikiText-103 с моделями ~85M параметров
- Неизвестно, сохранятся ли преимущества на масштабах 7B+ параметров и триллионных датасетов

### Границы предложений
- Предположение, что границы предложений четко совпадают с границами «мыслей», является эвристикой
- Может ломаться в неформальном тексте, коде или диалогах

## Применения и значение

### Теоретическая ценность
- Бросает вызов доминированию статического контекстного окна
- Показывает, что рекуррентность на уровне событий может быть эффективнее по данным
- Указывает путь к моделям, которые не просто предсказывают следующее слово, но непрерывно уточняют внутреннюю модель мира

### Практическая ценность
- Предоставляет конкретный план для тренировки дифференцируемой памяти в режиме end-to-end
- Демонстрирует, что способность предсказывать будущее может эффективно контролировать сжатие прошлого
