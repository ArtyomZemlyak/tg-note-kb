# UL2 Objective (Unifying Language Learning Paradigms)

## Описание

UL2 (Unifying Language Learning Paradigms) - это подход к предобучению языковых моделей, который объединяет различные парадигмы обучения в единый фреймворк. Архитектура UL2 основана на энкодер-декодере и использует смесь функций денойзинга в качестве целевой функции, где модель должна восстанавливать пропущенные подпоследовательности текста.

## Архитектура

### Общая архитектура
- **Энкодер-декодер** структура: содержит как энкодер (для понимания входа), так и декодер (для генерации)
- **Денойзинг задачи**: обучение на задачах, где часть входного текста маскируется или искажается, а модель должна восстановить оригинальный текст
- **Смесь денойзеров**: объединяет различные типы задач денойзинга для более всеобъемлющего обучения

### Типы денойзинга в UL2
1. **R-Denoiser (Рандомный денойзер)**: случайным образом маскирует непрерывные спаны текста с использованием специального символа маскировки
2. **S-Denoiser (Смешанный денойзер)**: использует низкий уровень шума для задач понимания и высокий уровень шума для задач генерации
3. **X-Denoiser**: специализированный денойзер для переноса знаний между различными языками или задачами

## Применение в T5Gemma 2

### Роль в адаптации decoder-only моделей
- В T5Gemma 2 используется в качестве objective для адаптации decoder-only моделей Gemma 3 в энкодер-декодер архитектуру
- Смесь денойзеров работает как мощный регуляризатор, не давая модели забыть каузальное предобучение, пока она учится эффективно использовать репрезентации энкодера
- Позволяет плавно перейти от чисто генеративной позиции к балансу между двунаправленным пониманием и генерацией

### Плюсы при адаптации
- **Сохранение предобученных знаний**: Позволяет сохранить качество каузального предобучения
- **Эффективная адаптация**: Позволяет эффективно адаптировать decoder-only модели в энкодер-декодеры
- **Регуляризация**: Служит как регуляризатор, предотвращающий переобучение

## Преимущества

### Унификация подходов
- **Объединение парадигм**: Сочетает в себе преимущества разных подходов к обучению языковых моделей
- **Гибкость**: Может быть адаптирован для различных задач и размеров моделей
- **Эффективность**: Позволяет обучать универсальные модели, которые работают хорошо на разных типах задач

### Эффективность обучения
- **Сбалансированное обучение**: Смесь разных типов денойзинга обеспечивает сбалансированное обучение
- **Универсальность**: Модель обучается как пониманию, так и генерации в одном процессе
- **Трансфер**: Позволяет лучше переносить знания между задачами

## Сравнение с другими подходами

### В отличие от каузального языкового моделирования (CLM):
- Использует денойзинг задачи вместо предсказания следующего токена
- Требует энкодер-декодер архитектуру, а не decoder-only
- Лучше подходит для задач преобразования текста

### В отличие от замаскированного языкового моделирования (MLM):
- Использует более сложную стратегию маскировки и восстановления
- Не ограничивается только энкодер-только архитектурами
- Включает в себя смесь разных типов задач

## Применение

- **Предобучение энкодер-декодер моделей**: Основной подход для предобучения моделей вроде T5
- **Адаптация моделей**: Используется для адаптации decoder-only моделей в энкодер-декодеры (как в T5Gemma 2)
- **Мультимодальные задачи**: Подходит для задач, требующих понимания и генерации
- **Машинный перевод**: Эффективен для задач преобразования текста
- **Суммаризация**: Подходит для задач, где вход и выход имеют разную структуру
