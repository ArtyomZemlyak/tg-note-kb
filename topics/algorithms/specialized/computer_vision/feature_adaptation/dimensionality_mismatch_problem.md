# Проблема несоответствия размерностей в компьютерном зрении

## Краткое описание

Фундаментальное противоречие между обучением представлений (discriminative models) и генеративным моделированием в современном компьютерном зрении. Предобученные модели для понимания изображений создают высокоразмерные векторные представления, в то время как генеративные модели работают с компактными латентными пространствами.

## Основная информация

### Проблема

В современном компьютерном зрении существует фундаментальное противоречие между обучением представлений (representation learning) и генеративным моделированием:

- **Дискриминативные модели** (классификация, детекция, сегментация):
  - Используют высокоразмерные пространства признаков (например, DINOv2: 1536d)
  - Заточены на формирование гипотез о содержимом изображений
  - Обучены на задачах self-supervised learning (например, masked image modeling)

- **Генеративные модели** (диффузионные, VAE, GAN):
  - Предпочитают компактные низкоразмерные латентные пространства (обычно 32-64d)
  - Требуют гладкую геометрию многообразия для корректного зашумления и денойзинга
  - Оптимизированы для эффективной генерации

### Последствия

- Несовместимость архитектур: сложно использовать предобученные понимающие модели в генеративных задачах
- Потребность в адаптационных слоях: необходимы специальные архитектуры для моста между двумя парадигмами
- Проблема избыточности: высокоразмерные эмбеддинги содержат пространственную избыточность, которая не нужна для генерации

## Технические детали

### Существующие подходы до FAE

- **REPA (Representation Processing for Adaption)**: использовал сложные лоссы выравнивания
- **RAE (Representation Adaption Encoder)**: требовал значительных изменений архитектуры генератора
- **Комплексные архитектуры**: многослойные энкодеры для сжатия высокоразмерных представлений

### Решение FAE

FAE (Feature Auto-Encoder) предлагает радикально новый подход:
- Использование всего одного слоя self-attention
- Стратегия "двойного декодера" (feature decoder + pixel decoder)
- Разделение задач реконструкции признаков и синтеза пикселей

## Новые концепции и термины

- **Dimensionality Mismatch Problem** - проблема несовместимости размерностей между понимающими и генеративными моделями
- **Semantic vs. Generative Paradigm Gap** - разрыв между дискриминативной и генеративной парадигмами
- **Feature Space Alignment** - выравнивание пространств признаков между разными типами моделей

## Примеры применения

- Адаптация DINOv2 для генерации изображений
- Использование SigLIP эмбеддингов в диффузионных моделях
- Переиспользование предобученных энкодеров в генеративных задачах
