# Диффузионные языковые модели (Diffusion Language Models, DLM)

## Общее описание

**Диффузионные языковые модели (DLM)** — это класс неавтогрессивных (NAR) моделей для генерации текста, применяющих принципы диффузионного моделирования к задачам обработки естественного языка. В отличие от традиционных авторегрессивных языковых моделей (AR-LM), которые предсказывают токены последовательно (слева направо), DLM генерируют целые последовательности через итеративное уточнение из шума.

> **Ключевая идея:** DLM представляют собой альтернативу доминирующим авторегрессивным LLM, предлагая параллельную генерацию с лучшим контролем и разнообразием выходных данных.

## Историческая справка

Блог "What Are Diffusion Language Models?" (автор: Xiaochen Zhu, апрель 2025) представляет собой одно из наиболее полных вводных руководств по DLM. Авторская работа "Segment-Level Diffusion (SLD)" принята в основной трек ACL 2025.

## Сравнение парадигм: AR-LM vs DLM

### Авторегрессивные модели (AR-LM)

**Принцип работы:**
- Предсказывают токены последовательно: `P(x) = ∏ P(xₙ | xₙ₋₁)`
- Генерация слева направо (или в заданном порядке)
- Каждый токен зависит от всех предыдущих

**Недостатки AR-LM:**
1. **Распространение ошибок** — ранние ошибки накапливаются в процессе генерации
2. **Косвенное управление** — сложно контролировать длину, стиль, структуру
3. **Вычислительные ограничения** — медленный последовательный декодинг
4. **Невозможность обратного рассуждения** — "Reversal Curse": не могут выводить причину из следствия

### Диффузионные модели (DLM)

**Принцип работы:**
- Итеративно уточняют всю последовательность из шума: `xₜ₋₁ ~ pθ(xₜ₋₁ | xₜ, t)`
- Параллельная/холистическая генерация
- Многошаговый процесс уточнения

**Преимущества DLM:**
1. **Неавтогрессивная генерация** — могут исправлять ошибки на ранних шагах
2. **Управляемость** — естественная поддержка classifier-free guidance, контроля длины, инфиллинга
3. **Разнообразие** — сэмплирование разного начального шума даёт различные выходы
4. **Потенциальная скорость** — параллелизуемый декодинг (в теории)

## Фундаментальная проблема: Дискретное vs Непрерывное

### Природа проблемы

Изображения используют непрерывные значения пикселей (легко добавлять гауссовский шум). Текст состоит из **дискретных токенов** из конечного словаря — нельзя добавить "0.1 шума" к слову "кот".

### Три основных подхода к решению

#### 1. Диффузия на уровне эмбеддингов токенов

**Описание:** Добавление шума к непрерывным векторам эмбеддингов слов.

**Примеры моделей:**
- **Diffusion-LM** (Li et al., 2022) — первая влиятельная DLM на уровне токенов
- **GENIE** (Lin et al., 2022) — первая предобученная DLM с архитектурой encoder-decoder

**Проблема округления:** Отображение зашумленных непрерывных эмбеддингов обратно в дискретные токены подвержено ошибкам.

**Решения:**
- Репараметризационный трюк
- Ограничение до ближайших эмбеддингов
- KNN-поиск в пространстве эмбеддингов

#### 2. Диффузия на уровне скрытых представлений более высокого уровня

**Описание:** Диффузия над семантическими латентами уровня предложений/абзацев.

**Примеры моделей:**
- **PLANNER** — планирование на уровне структуры
- **LD4LG** (Lovelace et al., 2023) — латентная диффузия на уровне абзацев
- **SLD (Segment-Level Diffusion)** (Zhu et al., 2024/2025) — работа автора блога, принята в ACL 2025
- **Large Concept Model** (Meta, 2024) — диффузия на уровне концептов

**Требования к качеству латентных представлений:**
1. Низкая ошибка конвертации (encode→decode сохраняет текст)
2. Локальная гладкость (малые изменения текста → малые изменения латента)
3. Распределительная гладкость (похожие значения кластеризуются)

**SLD (Segment-Level Diffusion):** Решение автора блога — сегментация текста на предложения, применение контрастивного обучения + адверсарного шума для робастности.

#### 3. Дискретная диффузия над токенами

**Описание:** Использование категориальных распределений с маскированием/подстановкой.

**Примеры моделей:**
- **D3PM** (Austin et al., 2021) — дискретная диффузия над категориальными распределениями
- **SEDD** (2024) — **ICML 2024 Best Paper** 🏆
- **Masked Diffusion LM** (Sahoo et al., 2024) — вариант маскированной диффузии
- **LLaDA 8B** (Nie et al., 2025) — 8-миллиардная предобученная DLM с маршрутизацией

**Проблема фиксированных токенов:** После размаскирования токены остаются фиксированными (возвращается проблема распространения ошибок).

**Решение:** Механизм маршрутизации, позволяющий повторное маскирование токенов с низкой уверенностью (LLaDA).

#### 4. Текст-как-изображение

**Описание:** Рендеринг текста как глиф-изображений, применение диффузии изображений.

**Примеры моделей:**
- **GlyphDiffusion** (Li et al., 2023)

## Ключевые технические вызовы

### Для диффузии на уровне эмбеддингов токенов

| Проблема | Описание | Решения |
|----------|----------|---------|
| Округление | Маппинг зашумленных эмбеддингов → дискретные токены | Репараметризация, clamping, KNN |
| Семантическая согласованность | Сохранение смысла при шуме | Контрастивное обучение |

### Для диффузии на уровне латентов

| Проблема | Описание | Решения |
|----------|----------|---------|
| Качество латентов | Нужны гладкие, обратимые представления | Контрастивное обучение, adversarial noise |
| Сегментация | Как разбить текст на единицы диффузии | Предложения, абзацы, концепты |

### Для дискретной диффузии

| Проблема | Описание | Решения |
|----------|----------|---------|
| Фиксированные токены | Размаскированные токены не меняются | Remasking через routing (LLaDA) |
| Ограниченный словарный запас | Дискретное пространство | Категориальные распределения |

## Текущие ограничения и будущие направления

### Главная проблема: Скорость

**Наивные DLM в ~50 раз медленнее AR-базлайнов.**

**Причина:** KV caching (ускорение AR) пока не применим к NAR-моделям.

### Техники ускорения

| Метод | Описание |
|-------|----------|
| **Consistency Models** (OpenAI) | Уменьшение количества шагов сэмплирования |
| **Adaptive Decay Sampling** (Tang et al., 2024) | Адаптивное расписание шума |
| **Diffusion of Thoughts** (Ye et al., 2024) | ODE-солверы для ускорения |
| **Mercury Coder** (Inception Labs) | Первая быстрая коммерческая DLM |

### Исследовательские возможности

1. **Улучшенное рассуждение** — избегание плохих промежуточных шагов CoT
2. **Структурированный вывод** — таблицы, код, логические формы
3. **Аугментация данных** — для low-resource сценариев (Chen et al., 2024)
4. **Оценка неопределённости** — self-consistency
5. **Мультимодальная генерация** — текст + изображения вместе

## Формулы и математические основы

| Концепт | Формула |
|---------|---------|
| **Распределение AR-LM** | `P(x; θ) = ∏ₙ₌₁ᴺ P(xₙ \| xₙ₋₁; θ)` |
| **Обратный процесс DLM** | `xₜ₋₁ ~ pθ(xₜ₋₁ \| xₜ, t)` |
| **Прямая диффузия (DDPM)** | `q(xₜ \| xₜ₋₁) = N(xₜ; √(1-βₜ)xₜ₋₁, βₜI)` |
| **Функция потерь Diffusion-LM** | `L = E[‖μθ(xₜ, t) - μ̂(xₜ, x₀)‖²]` |
| **Classifier Guidance** | `∇log p(xₜ₋₁ \| xₜ, c) = ∇log p(xₜ₋₁ \| xₜ) + ∇log p(c \| xₜ₋₁)` |
| **Дискретная диффузия (D3PM)** | `q(zₜ \| x) = Cat(zₜ; αₜx + (1-αₜ)π)` |

## Практические применения

### Специализированные задачи

- **Генерация с контролем** — длина, стиль, структура
- **Инфиллинг** — заполнение пропусков в тексте
- **Разнообразная генерация** — multiple samples из одного промпта
- **Структурированный вывод** — таблицы (TabDiff, Mario et al., 2024), код, JSON

### Коммерческое применение

- **Mercury Coder** (Inception Labs) — первая быстрая коммерческая DLM

### Рекомендуемые модели для экспериментов

- **GENIE** — первая предобученная DLM
- **LLaDA 8B** — современная 8B модель
- **Large Concept Model** (Meta) — концепт-уровневая диффузия
