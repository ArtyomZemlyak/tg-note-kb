# Интерпретируемость диффузионных моделей

Этот раздел посвящён методам интерпретируемости диффузионных моделей, включая механистическую интерпретируемость и анализ внутренних представлений.

## Методы интерпретируемости

### Sparse Autoencoders (SAE)

- [[dlm_scope_sae.md]] — **DLM-Scope**: первый фреймворк интерпретируемости на основе SAE для диффузионных языковых моделей. Описывает адаптацию SAE для DLM, валидацию через диффузионный loss, steering во времени и перенос признаков между моделями.

## Ключевые особенности интерпретируемости DLM

1. **Временная динамика**: В отличие от авторегрессивных моделей, интерпретируемость DLM требует учёта эволюции активаций во времени (на разных шагах денойзинга).

2. **Валидация через loss**: Осмысленность методов интерпретируемости проверяется через измерение изменения диффузионной функции потерь.

3. **Steering во времени**: Управление поведением модели становится распределённым во времени процессом.
