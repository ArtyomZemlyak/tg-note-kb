# Mercury Coder — диффузионная модель для генерации кода

## Описание

**Mercury Coder** — диффузионная модель для написания кода, основанная на архитектуре Transformer с иным подходом к генерации по сравнению с традиционными авторегрессивными моделями. На Copilot Arena занимала второе место по качеству и первое — по скорости генерации.

В отличие от авторегрессивных моделей, которые генерируют код токен за токеном последовательно, Mercury Coder использует диффузионный подход: модель стартует с зашумлённой версии ответа и на каждом шаге параллельно поправляет много позиций, постепенно «денойзя» последовательность.

## Архитектура

### Основной принцип работы

- **Диффузионный процесс**: Модель начинает с зашумлённой последовательности токенов
- **Параллельная генерация**: На каждом шаге одновременно корректируется множество позиций
- **Итеративное уточнение**: Постепенное удаление шума из последовательности до получения финального результата

### Технические характеристики

| Параметр | Значение |
|----------|----------|
| Длина контекста | 32K токенов (с расширением до 128K) |
| Архитектура | Transformer с диффузионным процессом |
| Подход к генерации | Параллельный денойзинг последовательности |

## Версии модели

Существует две версии Mercury Coder:

| Версия | Скорость генерации |
|--------|-------------------|
| **Mini** | Более 1100 токенов/сек |
| **Small** | Около 700 токенов/сек |

> **Примечание**: Подробные параметры моделей (количество параметров, точная архитектура) в публикации не раскрываются.

### Ключевые преимущества

1. **Скорость генерации**: 
   - Mercury Coder Mini: 109 токенов/сек (в 2-4 раза быстрее конкурентов)
   - Mercury Coder Small: 737 токенов/сек (рекордная скорость)

2. **Fill-in-the-Middle**: Превосходит большинство конкурентов в задачах заполнения кода

3. **Эффективность**: Лучшее соотношение качество/скорость среди speed-optimized моделей

- Отстаёт от крупнейших закрытых моделей (DeepSeek V3, Claude 3.5 Sonnet) в общих бенчмарках

## Применение

### Идеальные сценарии использования

1. **IDE-ассистенты**: Высокая скорость и отличные FIM-результаты делают Mercury идеальным для автодополнения кода
2. **Генерация кода по описанию**: Подходит для создания функций и модулей по текстовому описанию
3. **Рефакторинг**: Параллельная генерация позволяет эффективно изменять существующий код
4. **Заполнение шаблонов**: Отлично справляется с заполнением пропусков в коде

### Ограничения

- Не подходит для задач, требующих максимального качества генерации (лучше использовать Claude 3.5 Sonnet или DeepSeek V3)
- Детали архитектуры и параметры моделей не раскрыты, что затрудняет кастомизацию
