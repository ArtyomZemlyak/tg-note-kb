# GRASP: Gradient Relaxed Stochastic Planner - Параллельный алгоритм планирования для моделей мира

## Краткое описание

**GRASP (Gradient RelAxed Stochastic Planner)** — это новаторский градиентный алгоритм планирования для обученных моделей мира, разработанный для решения задач долгосрочного планирования в высокоразмерных пространствах состояний. Основная идея метода заключается в использовании "виртуальных состояний" (virtual states) как оптимизируемых переменных с мягкими динамическими ограничениями, что позволяет проводить параллельные вычисления и более легкую оптимизацию.

## Ключевые инновации

### 1. Поднятие переменных (Lifted State Planning)

В отличие от стандартного подхода, при котором состояния вычисляются последовательно через роллаут модели (s0 → s1 → s2 → ... → sT), GRASP рассматривает промежуточные состояния s1, ..., sT-1 как независимые оптимизируемые переменные. Это позволяет:

- Параллельно вычислять оценки модели мира
- Избегать глубоких последовательных графов вычислений
- Снижать проблемы с градиентами (exploding/vanishing gradients)

Задача преобразуется из условия:
`s_{t+1} = F_θ(s_t, a_t)` (последовательный роллаут)

в задачу оптимизации "виртуальных состояний" с мягкими ограничениями:
`min ||F_θ(s_t, a_t) - s_{t+1}||²` (нарушение динамики)

### 2. Стохастическая оптимизация через Langevin динамику

Для преодоления локальных минимумов и улучшения исследования пространства, GRASP вводит шум в обновления состояний:

`s_t^{k+1} ← s_t^k - η_s * ∇_s L + σ * ξ_t`, где `ξ_t ~ N(0, I)`

Эта стохастичность позволяет "перепрыгивать" между бассейнами притяжения различных локальных минимумов.

### 3. Управление чувствительностью градиентов (Stop-Gradient по состояниям)

В обученных моделях мира градиенты по входным состояниям могут быть "хрупкими" или "враждебными" (adversarial), позволяя оптимизатору эксплуатировать чувствительные структуры Якобиана вместо открытия физически значимых переходов. GRASP решает эту проблему, используя stop-gradient оператор на входных состояниях:

`L_sg_dyn = Σ ||F_θ(sg(s_t), a_t) - s_{t+1}||²`

где `sg(...)` отключает градиенты по входному состоянию, сохраняя градиенты по действиям.

### 4. Плотная штрафная функция для цели

Для обеспечения прогресса в направлении цели на каждом шаге, GRASP добавляет плотный штраф за отклонение от цели:

`L_goal = Σ γ * ||F_θ(sg(s_t), a_t) - goal||²`

что обеспечивает градиентную информацию для каждого действия `a_t`, одновременно сохраняя stop-gradient на `s_t`.

### 5. Периодическая синхронизация

Периодически (например, каждые K_sync итераций) GRASP выполняет шаг градиентного спуска на оригинальной функции потерь роллаута, чтобы уточнить стокастически оптимизированные траектории:

- Чередует стохастическую оптимизацию (шаги 1-6 алгоритма)
- Периодически применяет GD-шаги на оригинальной цели (шаг 8 алгоритма)

## Алгоритм GRASP

```
Input: Начальное наблюдение o₀, цель o_g, модель мира F_θ, горизонт T, шаги K, скорости обучения η_a, η_s

1: s₀ ← encode(o₀), s_T ← encode(o_g)  // кодирование начального и целевого состояний
2: a ← a₀; s ← init_states(s₀, s_T)     // инициализация действий и виртуальных состояний
3: for k = 0 to K-1 do
4:   Compute L как в Eq. (10)           // вычисление функции потерь
5:   Joint step: (a, s) ← (a, s) - (η_a ∇_a L, η_s ∇_s L)  // совместный шаг градиента
6:   Stochastic state: s_t ← s_t + σ_state * ξ_t, ξ_t ~ N(0, I) для t = 1, ..., T-1  // стохастическое обновление
7:   Sync (periodic): if k mod K_sync = 0, 
                    rollout from s₀; s_{t+1} ← F_θ(s_t, a_t) для t = 0, ..., T-1
                    then take a GD step a ← a - η_sync ∇_a ||s_T - g||²₂  // уточнение действий
8: end for
9: return a* ← a
```

## Преимущества

1. **Параллелизм**: Все оценки модели мира могут вычисляться параллельно, что значительно ускоряет оптимизацию
2. **Робастность**: Алгоритм остается стабильным на длинных горизонтах, избегая нестабильностей при backpropagation через время
3. **Эффективность**: По сравнению с CEM и GD, GRASP показывает до 10% более высокую успешность при менее чем половине времени вычислений
4. **Устойчивость к локальным минимумам**: Стохастическая природа алгоритма помогает избежать ловушек локальных минимумов
5. **Масштабируемость**: Производительность не ухудшается с увеличением горизонта планирования

## Результаты экспериментов

### Долгосрочное планирование (Push-T среда):
- H=40: GRASP 59.0% / 8.5с vs CEM 61.4% / 35.3с vs GD 51.0% / 18.0с
- H=50: GRASP 43.4% / 15.2с vs CEM 30.2% / 96.2с vs GD 37.6% / 76.3с
- H=80: GRASP 10.4% / 58.9с vs CEM 2.8% / 132.2с vs GD 6.4% / 161.3с

### Краткосрочное планирование:
- GRASP демонстрирует сопоставимые результаты с базовыми линиями при более быстром времени выполнения

## Связь с архитектурой JEPA

GRASP рассматривается как недостающий компонент "рассуждений" (reasoning engine) для архитектуры JEPA (Joint Embedding Predictive Architecture) от Яна ЛеКуна. В то время как индустрия сосредоточилась на *обучении* моделей мира (V-JEPA, I-JEPA), эффективное *планирование* внутри этих неевклидовых пространств оставалось хрупким из-за взрывающихся градиентов. GRASP решает проблему, развязывая временные зависимости и предлагает надежный способ управления на длинных горизонтах.

## Связь с другими методами планирования

- **CEM (Cross-Entropy Method)**: Робастный, но вычислительно затратный на длинных горизонтах из-за нулевого порядка оптимизации
- **GD (Gradient Descent)**: Быстрый, но нестабильный на длинных горизонтах из-за backpropagation через время
- **LatCo**: Метод оптимизации в поднятом пространстве, но менее стабильный чем GRASP
- **GRASP**: Объединяет преимущества градиентных и стохастических методов с улучшенной стабильностью

## Ограничения

1. Преимущества более выражены на длинных горизонтах; на коротких горизонтах прирост может быть ограничен
2. Требует дифференцируемой модели мира
3. Введение дополнительных гиперпараметров (уровень шума, частота синхронизации)

## Применения

- Визуальное управление в средах с препятствиями
- Планирование траекторий в робототехнике
- Долгосрочное планирование в сложных средах
- Компонент архитектуры JEPA для рассуждений в моделях мира
