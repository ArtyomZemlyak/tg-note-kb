# Geometric Switching Policies (GSP)

## Общее описание

**Geometric Switching Policies (GSP)** — это класс не-Марковских политик в обучении с подкреплением, которые выполняют последовательности предобученных политик с геометрическим переключением между ними. Для каждой политики π_{z_i} в последовательности, выполнение продолжается с вероятностью (1-α_i) или переключается на следующую политику π_{z_{i+1}} с вероятностью α_i.

GSP были формализованы в работе Thakoor et al. (2022) и являются ключевым компонентом фреймворка композиционного планирования с Jumpy World Models (Farebrother et al., 2026).

## Формальное определение

### Представление GSP

GSP записывается как:

```
ν := π_{z_1} →^{α_1} π_{z_2} →^{α_2} ... →^{α_{n-1}} π_{z_n}
```

где:
- π_{z_i} — i-я политика в последовательности, параметризованная z_i
- α_i ∈ [0, 1] — вероятность переключения после π_{z_i}
- n — количество политик в последовательности

### Поглощающая политика

По определению, финальная политика π_{z_n} является **поглощающей** (absorbing), meaning агент commit'ится к ней до конца эпизода:

```
α_n = 0
```

### Геометрическая длительность

Термин "геометрический" отражает, что каждая политика π_{z_i} выполняется в течение геометрически распределённой длительности:

```
T_i ~ Geom(α_i)
```

где T_i — количество шагов выполнения π_{z_i} перед переключением.

## Взаимодействие с дисконт-фактором

### Глобальный дисконт-фактор γ

В MDP с глобальным дисконт-фактором γ ∈ (0,1):
- γ — вероятность продолжения эпизода на следующем шаге
- (1-γ) — вероятность остановки эпизода

### Эффективный дисконт-фактор β_k

При выполнении политики π_{z_k} в GSP, есть две причины остановки:
1. Эпизод останавливается с вероятностью (1-γ)
2. Политика переключается на π_{z_{k+1}} с вероятностью α_k

Таким образом, продолжение выполнения π_{z_k} ещё на один шаг требует, чтобы ни одно из этих событий не произошло:

```
β_k := γ * (1 - α_k)
```

β_k действует как **эффективный дисконт-фактор** для длительности выполнения π_{z_k}.

Для финальной политики: β_n = γ (поскольку α_n = 0).

## Successor Measure GSP

### Разложение successor measure

**Theorem 1** (Farebrother et al., 2026): Для GSP ν := π_{z_1} →^{α_1} ... →^{α_{n-1}} π_{z_n} с глобальным дисконт-фактором γ, effective discount factors {β_k} и weights {w_k}, successor measure разлагается как:

```
m^γ_ν(·|s,a) = Σ_{k=1}^{n} w_k * E[m^{β_k}_{π_{z_k}}(·|S_{k-1},A_{k-1})]
```

где веса определяются как:

```
w_k = (1-γ)/(1-β_k) * Π_{j=1}^{k-1} (β_j/(1-β_j)) * (1-γ)/(1-β_j)
```

с пустым произведением = 1 (следовательно w_1 = (1-γ)/(1-β_1)).

### Интерпретация весов

w_k захватывает относительный вклад k-й политики в successor measure GSP. Интуитивно:
- w_k отражает вероятность того, что агент:
  1. Выживает в первых (k-1) фазах политики без остановки эпизода
  2. Достигает состояний под политикой π_{z_k}, а не переключается на более позднюю политию

### Chapman-Kolmogorov интерпретация

Каждый компонент может быть рассмотрен как применение уравнения Chapman-Kolmogorov:
- Сохраняет композицию ядер через маргинализацию
- Заменяет одношаговую динамику P(·|s,a) на "прыгающую" динамику через m^{β}_{π}(·|s,a)

## Оценка ценности GSP

### Monte Carlo estimator

**Lemma 1** (Farebrother et al., 2026): Для любой reward function r: S → R и пары (s,a), single-sample monte-carlo estimator:

```
Q̂^γ_ν = Σ_{k=1}^{n} w_k * r(S^+_k)
```

является **несмещённой оценкой** Q^γ_ν(s,a), где:
- (S^+_0, A^+_0) = (s,a)
- Для k = 1,...,n: S^+_k ~ m^{β_k}_{π_{z_k}}(·|S^+_{k-1},A^+_{k-1})
- A^+_k ~ π_{z_{k+1}}(·|S^+_k)

Ожидание берётся по совместному распределению (S^+_1, A^+_1, ..., S^+_n), индуцированному процедурой сэмплирования.

### Последовательное сэмплирование

Ключевое преимущество — возможность **последовательного сэмплирования**:
1. Начинаем с (s,a)
2. Сэмплируем S^+_1 из m^{β_1}_{π_{z_1}}(·|s,a)
3. Сэмплируем A^+_1 из π_{z_2}(·|S^+_1)
4. Сэмплируем S^+_2 из m^{β_2}_{π_{z_2}}(·|S^+_1,A^+_1)
5. Продолжаем до S^+_n

Это использует overlapping sequential structure для эффективного сэмплирования.

## Унификация существующих подходов

GSP обобщает несколько предыдущих результатов:

| Подход | Ограничения | Ссылка |
|--------|-------------|--------|
| **Thakoor et al. (2022)** | Фиксированные вероятности переключения: α_k = α ∀k | Theorem 3.2 |
| **Janner et al. (2020)** | Фиксированная политика: π_{z_k} = π ∀k | Proposition 1 |
| **GSP (общий случай)** | Переменные политики и вероятности переключения | Farebrother et al. (2026) |

Путём разрешения как политикам, так и вероятностям переключения варьироваться, GSP позволяет оценивать более широкий класс switching policies и приближается к фреймворку options (Sutton, 1995; Sutton et al., 1999; Precup, 2000).

## Применение в планировании

### Оптимизация последовательностей

Дана reward function r: S → R, цель композиционного планирования:

```
maximize Q^γ_ν(s,a) over (a_1, z_1, ..., z_n)
```

где ν := π_{z_1} →^{α_1} ... →^{α_{n-1}} π_{z_n}

### Special cases через α_i

Варьирование {α_i} унифицирует несколько подходов:

| Метод | Настройки α_i | Описание |
|-------|---------------|----------|
| **ActionPlan** (MPC) | α_1 = ... = α_n = 1 | Планирование на уровне примитивных действий |
| **GPI** | α_1 = 1, α_2 = ... = α_n = 0 | Generalized Policy Improvement |
| **GGPI** | α_1 = ... = α_{n-1} = α | Geometric Generalized Policy Improvement |
| **CompPlan** | α_1, ..., α_{n-1} ∈ (0,1) | Полное композиционное планирование |

### Random shooting

Для больших или непрерывных Z (например, goal-conditioned политики с Z = S), оптимизация через random shooting:

1. **Proposal distribution**: Генерация кандидатных последовательностей {(z^(i)_1, ..., z^(i)_n)} через GHM
2. **Оценка**: Вычисление Q^{ν^(i)}_γ(s,a^(i)_1) для каждой кандидатной политики
3. **Выбор**: Селекция последовательности с наивысшей ценностью

## Преимущества GSP

1. **Гибкость**: Позволяют варьировать как политики, так и длительности выполнения.

2. **Выразительность**: Обобщают options framework и другие подходы к иерархическому RL.

3. **Эффективная оценка**: Single-sample estimator позволяет эффективно оценивать ценность последовательностей.

4. **Композиционность**: Предсказания GHM могут быть скомпозированы для оценки произвольных последовательностей.

5. **Zero-shot планирование**: Оценка новых последовательностей без предварительной практики.

## Ограничения

1. **Выбор switching probabilities**: α_i трактуются как гиперпараметры, требующие настройки.

2. **Не-Марковость**: GSP являются не-Марковскими политиками, что может усложнять анализ.

3. **Зависимость от качества GHM**: Точность оценки зависит от точности предсказаний Geometric Horizon Models.

4. **Комбинаторная сложность**: Для больших наборов политик пространство последовательностей растёт экспоненциально.
