# Модели обратной динамики (Inverse Dynamics Models)

## Общее описание

**Модели обратной динамики (Inverse Dynamics Models, IDM)** - это компоненты машинного обучения, которые прогнозируют действия или силы, вызвавшие изменение между двумя состояниями. В отличие от прямых динамических моделей, которые предсказывают следующее состояние на основе текущего состояния и действия, IDM выполняет обратную задачу: по текущему и будущему состояниям определяет, какое действие привело к переходу.

## Математическая формулировка

В контексте моделей латентных действий:
- Дано: текущее состояние s_t и будущее состояние s_{t+1}
- Цель: предсказать латентное действие z_t
- Формула: z_t = g(s_t, s_{t+1})

Где:
- s_t - текущее состояние (например, изображение или визуальное представление)
- s_{t+1} - следующее состояние
- z_t - предсказанное латентное действие
- g - нейронная сеть, реализующая IDM

## Архитектура и реализация

### Входы и выходы

**Входы:**
- Текущее состояние s_t (обычно представлено как вектор признаков из энкодера)
- Будущее состояние s_{t+1} (также вектор признаков)

**Выходы:**
- Латентное действие z_t (вектор в низкоразмерном пространстве)
- В некоторых реализациях - параметры распределения (например, μ и σ для VAE-подобной модели)

### Обычные архитектуры

- Полносвязные сети для простых задач
- Сверточные сети для изображений
- Трансформеры для последовательностей и сложных зависимостей
- Графовые нейронные сети для структурированных состояний

## Применения

### В моделях латентных действий

IDM играет ключевую роль в архитектуре латентных действий, так как:

- Учится выявлять, какие изменения в состоянии были вызваны действием
- Создает латентное пространство действий без явных меток
- Позволяет отделить движение от контента сцены

### В робототехнике

- Учиться модели динамики робота по наблюдениям
- Понимать физику взаимодействия с объектами
- Планирование действий для достижения желаемых изменений

### В моделях мира

- Предсказание причин изменений в окружающей среде
- Понимание причинно-следственных связей в визуальных сценах
- Генерация действий для достижения заданной цели

## Регуляризация и ограничения

### Проблема "копирования"

Ключевая проблема IDM - это "копирование": если у латентного действия z_t бесконечная ёмкость, он просто закодирует попиксельную разницу кадров, и модель не выучит никакой физики.

### Методы регуляризации

1. **Информационные бутылочные горлышки**:
   - Ограничение размерности латентного пространства
   - Использование VAE-подобных штрафов

2. **Непрерывная регуляризация**:
   - Noisy подход: штрафы по KL-дивергенции
   - Sparse подход: L1-штрафы и VCM-регуляризация

3. **Дискретизация**:
   - Векторная квантизация (VQ) - более традиционный подход
   - Однако последние исследования показывают, что непрерывные регуляризованные пространства работают лучше

## Сравнение с прямыми динамическими моделями

| Аспект | IDM (обратная динамика) | FDM (прямая динамика) |
|--------|-------------------------|----------------------|
| Направление | s_t, s_{t+1} → a_t     | s_t, a_t → s_{t+1}   |
| Цель | Понимание причин изменений | Прогнозирование последствий |
| Применение | Обучение латентных действий | Прогнозирование будущего |
| Сложность | Может быть проще при частичной наблюдаемости | Может быть сложнее при неопределенности |

## Особенности в контексте "диких" данных

В статье "Learning Latent Action World Models In The Wild":

- IDM обучается на неаннотированных видео из реального мира
- Использует замороженный V-JEPA 2 энкодер для преобразования кадров в семантические репрезентации
- Латентное действие z_t затем используется для предсказания следующего состояния
- Регуляризация применяется к z_t для обеспечения, что вектор кодирует *движение*, а не *контент*

## Архитектурные особенности

### Использование AdaLN-zero

В современных реализациях для обуславливания forward-модели на латентное действие z_t используется AdaLN-zero (как в DiT), при котором:
- Вместо токенизации и конкатенации, вектор действия модулирует слои нормализации трансформера
- Это позволяет глобально влиять на переход состояний через латентное действие

### Временные зависимости

- IDM может принимать во внимание последовательности состояний, а не только пары
- Временные связи помогают лучше понять динамику движения
- Может использовать историю состояний для более точной оценки причин изменения
