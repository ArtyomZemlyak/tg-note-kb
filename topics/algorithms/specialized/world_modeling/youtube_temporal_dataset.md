# YouTube-Temporal-1B датасет

## Общее описание

**YouTube-Temporal-1B** - это крупномасштабный датасет, состоящий из 20 миллионов YouTube видео, охватывающих разнообразные темы, с английскими субтитрами. Датасет содержит около 1 миллиарда кадров и предназначен для обучения моделей, работающих с визуальной и временной информацией. Особенно подходит для обучения временных моделей, обучающихся из неструктурированных "диких" видео.

## Структура датасета

### Размер и содержание

- **20 миллионов видео** с YouTube
- **1 миллиард кадров** в общей сложности
- Видео охватывают **разнообразные темы** и жанры
- Включают **английские субтитры**
- Видео без специальной аннотации действий или событий

### Тип контента

- Видео из реального мира ("in-the-wild")
- Неструктурированный контент
- Разнообразные сцены и действия
- Естественные движения и события
- Без контролируемых условий записи

## Применение в обучении моделей мира

### Обучение на "диких" данных

YouTube-Temporal-1B стал важным ресурсом для:
- Обучения моделей мира на неаннотированных данных
- Изучения естественных движений и динамики сцен
- Разработки моделей, способных обобщать на разнообразные реальные сцены

### Основная статья использования

В статье "Learning Latent Action World Models In The Wild":
- Используется как основной датасет для обучения LAMs
- Демонстрирует возможность обучения латентных действий без меток
- Позволяет моделям познать физику и динамику через интернет-видео

## Преимущества датасета

### Масштаб и разнообразие

- **Масштаб**: 1 миллиард кадров обеспечивают хороший объем для обучения
- **Разнообразие**: Охватывает широкий спектр сцен, движений и ситуаций
- **Естественность**: Видео сняты в естественных условиях, без контролируемых сред

### Отсутствие меток действий

- **Реалистичность**: Большинство реальных данных не имеют меток действий
- **Практическая значимость**: Обучение на таких данных ближе к практическому применению
- **Новый подход**: Позволяет моделировать латентные действия без необходимости вручную аннотировать видео

## Ограничения и вызовы

### Разнообразие плотности информации

- **Переменная плотность**: Некоторые видео (например, шторм) требуют больше битов для описания "действия", чем другие (например, плывущее облако)
- **Статические коэффициенты**: Использование статического коэффициента регуляризации для всех роликов может привести к компромиссам

### Качество и согласованность

- **Естественные артефакты**: Видео могут содержать шумы, сжатия, нестабильные кадры
- **Разное качество**: Видео разного разрешения, качества и фокусировки
- **Непредсказуемая длина**: Видео разной продолжительности и структуры

## Архитектурные особенности обучения

### Видеоэнкодеры

- Использование замороженного V-JEPA 2 энкодера для получения семантических репрезентаций
- Бэкбон ViT-L с Rotary Positional Embeddings (RoPE)
- Извлечение признаков на уровне кадров

### Обработка в моделях мира

- Требует больших вычислительных ресурсов для обработки
- Нуждается в специальных архитектурах для обработки временных последовательностей
- Необходимость методов регуляризации для избежания переобучения

## Сравнение с другими датасетами

### YouTube-8M

- Предшественник с меньшим масштабом
- Более ограниченные метки
- Менее подходящий для изучения латентных действий

### Другие "дикие" датасеты

- YouTube-Temporal-1B превосходит по масштабу многие другие датасеты
- Содержит больше временной информации для изучения динамики

## Результаты использования

### В контексте LAMs

- Демонстрирует успешное обучение латентных действий на неаннотированных данных
- Позволяет моделям изучить физику и динамику через интернет-видео
- Успешный перенос знаний на реальные роботы

### В других исследованиях

- Используется для обучения V-JEPA моделей
- Применяется для изучения временных зависимостей
- Подходит для предобучения визуальных моделей
