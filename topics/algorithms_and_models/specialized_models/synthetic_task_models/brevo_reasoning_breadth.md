# Задача BREVO: Ширина рассуждений

## Краткое описание

Задача BREVO (Mental reasoning breadth) - это синтетическая задача предварительного обучения, разработанная для оценки способности модели одновременно обрабатывать несколько зависимостей. Она оценивает способность модели обрабатывать древовидные структуры и графы зависимостей с параллельным рассуждением.

## Основные характеристики

### Формат задачи
- Каждый экземпляр задачи форматируется как: 2m токенов определяют m рёбер x_i → y_i, представляющих зависимости, где y_i зависит от x_i
- При получении вершины запроса q модель выводит все вершины, рекурсивно достижимые из q, в топологическом порядке, начиная с листьев (например, u → v → q даёт вывод u, затем v)

### Параметры задачи
- N: максимальный размер графа
- DAGs создаются с использованием n ≤ N узлов, каждый степени не более 4
- Обучающие данные подбираются варьированием размеров графа
- Тестирование сосредоточено на самых сложных графах (n = N)

### Варианты BREVO
- **BREVO1**: Названия вершин занимают один токен, с N = 70/90/110, укладывается в 1024 токена
- **BREVO2**: Названия занимают 2-4 токена словаря размером 4, с N = 30/40/50, укладывается в 1536 токенов

## Цель задачи

Задача BREVO изолирует и оценивает способность языковой модели обрабатывать несколько зависимостей одновременно, как это требуется в задачах, связанных с древовидной навигацией или графами зависимостей. Примеры включают решение запросов вроде "Кто является племянниками Алисы?" или примеры типа GSM, требующие параллельного рассуждения по ветвям графа для обработки отношений снизу вверх.

## Особенности задачи

Ключевое открытие заключается в том, что из-за неоднозначности допустимых результатов, языковые модели должны предварительно обработать весь топологический порядок DAG в уме перед генерацией первого токена a1. Это требование строго оценивает ширину рассуждений, требуя от моделей глобальной обработки базовой структуры графа перед созданием выводов.

## Применение в исследовании Canon слоёв

Canon слои значительно улучшают производительность в задачах типа BREVO, увеличивая ширину рассуждений примерно на 30%. Это свидетельствует об улучшенной способности модели обрабатывать несколько зависимостей одновременно за счёт улучшенного горизонтального потока информации.

## Значение для архитектур языковых моделей

- Задача помогает выявлять различия в способности к параллельной обработке зависимостей между разными архитектурами
- Позволяет проводить контролируемые сравнения архитектур в изолированных условиях
- Используется для оценки Canon слоёв, которые улучшают горизонтальный поток информации
