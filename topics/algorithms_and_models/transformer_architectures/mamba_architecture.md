# Архитектура Mamba

См. полное описание в [[../../neural_networks/architectures/mamba_architecture.md|основной статье о Mamba архитектуре]].

Mamba - это архитектура глубокого обучения, разработанная для эффективной обработки длинных последовательностей. Она основана на State Space Models (SSM) с селективными механизмами, которые позволяют модели адаптивно фильтровать информацию. Mamba решает ключевую проблему традиционных трансформеров - квадратичную сложность обработки последовательностей - обеспечивая линейную сложность как при обучении, так и при инференсе.

## Основные свойства Mamba

- **Линейная сложность**: Эффективная обработка длинных последовательностей
- **Выборочность**: Способность фильтровать информацию
- **Эффективный инференс**: Постоянное время при последовательной генерации
- **Масштабируемость**: Возможность создания очень больших моделей

## Связь с трансформерами

Mamba была разработана как альтернатива трансформерам для задач, требующих обработки длинных последовательностей, благодаря своей способности достичь линейной сложности по длине последовательности и лучше масштабироваться по сравнению с квадратичным механизмом внимания в трансформерах.
