# Mentalese - символический формат рассуждения в ORION

## Краткое описание

Mentalese - это компактный, символический формат рассуждения, вдохновленный гипотезой "Язык мысли" (Language of Thought Hypothesis), который кодирует абстрактные рассуждения как ультра-сжатые, структурированные токены. В рамках фреймворка ORION, Mentalese используется для замены традиционных цепочек рассуждений на естественном языке более эффективными символическими представлениями, устраняя избыточность нормального языка и сохраняя логическую суть рассуждения.

## Основная информация

### Основные концепции

1. **Формат Mentalese**: Строгая символическая грамматика, отсекающая лингвистическую шелуху и сохраняющая логику.

2. **Атомарная единица**: Пара шагов s_t = (o_t, c_t), где o_t - оператор (например, SET, EQ, CASE, SOLVE, CALC, DIFF, ANS), а c_t - символическое выражение.

3. **Язык мысли (Language of Thought, LOTH)**: Гипотеза, вдохновляющая формат Mentalese, предполагающая, что человеческое рассуждение оперирует символическим, композиционным языком.

4. **Сжатие рассуждений**: Ключевая цель формата Mentalese - сокращение длины рассуждений без потери логической полноты.

5. **Символическая логика**: Основа формата, позволяющая точно представлять логические операции без многословности естественного языка.

### Структура и синтаксис

#### Базовые операторы
- **SET**: Установка переменной или значения
- **EQ**: Определение уравнения или равенства
- **CASE**: Условие или проверка случая
- **SOLVE**: Решение уравнения или выражения
- **CALC**: Вычисление выражения
- **DIFF**: Нахождение разности или производной
- **ANS**: Окончательный ответ

#### Пример структуры
Вместо многословного формата CoT:
```
Сначала я определю переменную w, затем составлю уравнение, чтобы выразить зависимость между углами...
```

Формат Mentalese:
```
SET: w;
EQ: abs(180 - 5.5 * w) = 110;
SOLVE: w;
ANS: 20 or 320;
```

### Преимущества формата Mentalese

1. **Экономия токенов**: Существенное сокращение количества токенов, необходимых для представления рассуждений
2. **Структурная ясность**: Четкое разделение логических шагов без лишней информации
3. **Интерпретируемость**: Прозрачная структура позволяет легко отслеживать логические шаги
4. **Универсальность**: Подходит для различных типов задач, особенно математических и логических
5. **Эффективность**: Позволяет моделям быстрее генерировать рассуждения и сокращает задержки

### Примеры использования

#### Математическая задача
**Традиционный CoT:**
```
Для решения этой задачи мне нужно сначала определить переменные, которые буду использовать. Пусть x будет количеством яблок... 
Теперь я составлю уравнение, которое выразит общую стоимость...
```

**Mentalese:**
```
SET: x = apples, y = oranges;
EQ: 2x + 3y = 12;
EQ: x + y = 5;
SOLVE: x, y;
ANS: x = 3, y = 2;
```

#### Логическая задача
**Mentalese:**
```
SET: A = true, B = false;
CASE: A AND B;
CALC: A AND B = false;
CASE: A OR B;
CALC: A OR B = true;
ANS: A OR B = true;
```

#### Математическая задача (Пример)
**Задача:** Пусть Sf(x) = ax² - √2 для некоторого положительного a. Если Sf(f(√2)) = -√2, то чему равно a?

**Mentalese:**
```
DEF: Sf(x) = ax² - √2;
EVAL1: Sf(√2) = 2a - √2;
EVAL2: Sf(f(√2)) = a(2a - √2)² - √2;
EXPAND: (2a - √2)² = 4a² - 4a√2 + 2;
EVAL3: Sf(f(√2)) = a(4a² - 4a√2 + 2) - √2 = 4a³ - 4a²√2 + 2a - √2;
SET: 4a³ - 4a²√2 + 2a - √2 = -√2;
ADD: 4a³ - 4a²√2 + 2a = 0;
FACTOR: 2a(2a² - 2a√2 + 1) = 0;
SOLVE: 2a² - 2a√2 + 1 = 0;
SOLVE2: a = (2√2 ± √(8 - 8))/4;
ANS: a = √2/2;
```

## Новые концепции и термины

- **Символическая цепочка рассуждений**: Формат, при котором рассуждения представлены в виде последовательности символических логических шагов.
- **Сжатые рассуждения (Compressed Reasoning)**: Метод рассуждения, который устраняет избыточность без потери логической полноты.
- **Структурный якорь**: Роль, которую формат Mentalese играет в обучении, обеспечивая синтаксическую основу для рассуждений.
- **Токены мысли**: Условное название символических элементов в формате Mentalese, представляющих логические операции.

## Примеры применения

- **Математические задачи**: Представление уравнений, вычислений и решений в компактной форме
- **Логические задачи**: Выражение условий, проверок и выводов
- **Научные рассуждения**: Формализация гипотез, экспериментов и выводов
- **Образовательные задачи**: Помощь в обучении логике и математике через структурированные рассуждения
