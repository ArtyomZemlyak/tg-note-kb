# Darwinian Evolver: Эволюционный фреймворк для оптимизации кода и промптов

## Краткое описание

**Darwinian Evolver** — это эволюционный фреймворк с открытым исходным кодом от компании Imbue, который использует большие языковые модели (LLM) для оптимизации кода и промптов. Фреймворк трактует кандидатные решения как организмы в популяции и применяет дарвиновские принципы эволюции для их постепенного улучшения.

## Основная информация

### Как работает Darwinian Evolver

Фреймворк реализует следующий эволюционный цикл:

1. **Поддержание пула решений** — система хранит популяцию кандидатных решений (код, промпты, алгоритмы)

2. **LLM-предложенные мутации** — большая языковая модель предлагает целевые изменения (мутации) для существующих решений

3. **Оценка приспособленности** — каждое мутировавшее решение оценивается с помощью функции скоринга

4. **Естественный отбор** — сохраняются только наиболее приспособленные решения

5. **Итеративное повторение** — процесс повторяется для накопления полезных изменений в поколениях

### Ключевые особенности

- **Универсальность** — фреймворк не зависит от конкретной задачи и работает с любым кодом, который LLM может прочитать, и любой функцией оценки
- **Отказоустойчивость** — не требует, чтобы LLM успешно выполняла задачу каждый раз; достаточно, чтобы полезные изменения накапливались со временем
- **Проблемно-независимый** — может применяться к широкому спектру задач оптимизации
- **Open-source** — исходный код доступен для сообщества

## Применение к ARC-AGI-2

Imbue продемонстрировала возможности Darwinian Evolver на notoriously сложном бенчмарке визуального рассуждения **ARC-AGI-2** (Abstraction and Reasoning Corpus).

### Результаты

Эволюционный подход показал впечатляющие улучшения:

| Модель | Базовый результат | С Evolver | Улучшение |
|--------|-------------------|-----------|-----------|
| **Kimi K2.5** (open-weights) | 12% | **34%** | ~3× улучшение |
| **Gemini 3 Flash** | 34% | **61%** | ~1.8× улучшение |
| **Gemini 3.1 Pro** | — | **95%** | приближается к SOTA |

### Значение результатов

- **Kimi K2.5 34%** — лучший результат среди всех open-weights моделей на ARC-AGI-2
- **Gemini 3.1 Pro 95%** — результат, приближающийся к текущему state-of-the-art
- Дарвиновская эволюция позволяет значительно превзойти базовые возможности моделей без изменения их архитектуры

## Архитектура и компоненты

### Основные принципы

1. **Популяция решений** — поддерживается разнообразный набор кандидатных решений
2. **LLM как мутатор** — языковая модель выступает в роли источника вариаций
3. **Функция приспособленности** — автоматическая оценка качества каждого решения
4. **Селекция** — отбор лучших решений для следующего поколения

### Преимущества подхода

- **Масштабируемость** — работает с моделями разного размера
- **Гибкость** — адаптируется к различным типам задач
- **Надёжность** — устойчив к отдельным неудачам LLM
- **Кумулятивный эффект** — полезные изменения накапливаются в поколениях

## Сравнение с другими системами

### Darwinian Evolver vs AlphaEvolve

| Характеристика | Darwinian Evolver | AlphaEvolve |
|----------------|-------------------|-------------|
| **Фокус** | Оптимизация кода и промптов | Открытие научных алгоритмов |
| **Подход** | Дарвиновская эволюция популяции | Генетическое программирование с LLM |
| **Оценка** | Проблемно-независимая функция скоринга | Оценка на научных задачах |
| **Результаты** | ARC-AGI-2: до 95% | Математическая оптимизация |

### Darwinian Evolver vs FunSearch

| Характеристика | Darwinian Evolver | FunSearch |
|----------------|-------------------|-----------|
| **Эволюция** | Популяция решений с мутациями | Эволюция одиночных функций |
| **LLM роль** | Предложение целевых мутаций | Программирование с подсказками |
| **Применение** | Код, промпты, ARC-AGI | Комбинаторная оптимизация |
