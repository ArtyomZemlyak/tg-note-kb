# OpenSeeker: Полностью открытый поисковый агент уровня SOTA

## Описание

**OpenSeeker** - это первый полностью открытый поисковый агент (модель + данные), достигающий производительности уровня frontier, разработанный чисто академической командой для демократизации исследований в области глубокого поиска. OpenSeeker демонстрирует, что эффективность важнее масштаба: производительность поискового агента уровня frontier достижима всего с 11.7k высококачественных синтезированных образцов и простым SFT, разрушая «корпоративный ров данных», который долгое время доминировал в этой области.

![OpenSeeker: Сравнение с другими моделями по открытости и размеру](../../../media/img_1773803714_aqad4xprgyp7yel_openseeker_ours_fully_open_source.jpg)

**Изображение показывает:** Сравнительная таблица OpenSeeker с другими моделями по критериям открытости (Fully Open-Source, Model Open-Source, Closed-Source) и размеру модели (~30B, >30B). OpenSeeker позиционируется как полностью открытая модель с открытым исходным кодом, в отличие от смешанных или закрытых решений от других разработчиков. На таблице также показаны бенчмарки: BrowseComp-2H, BrowseComp, xbench, WideSearch.

## Архитектура и модель

| Аспект | Детали |
|--------|--------|
| **Размер модели** | ~30B параметров (31B) |
| **Название модели** | OpenSeeker-v1-30B-SFT |
| **Метод обучения** | Однократное Supervised Fine-Tuning (SFT) |
| **Без RL или continual pre-training** | В отличие от индустриальных конкурентов |

## Обучающие данные

| **Размер датасета** | **11.7k синтезированных образцов** |
| **Тип данных** | Высоко-сложные QA + траектории |
| **Открытость** | ✅ Полный датасет открыт |
| **Ссылка на датасет** | https://huggingface.co/datasets/OpenSeeker/OpenSeeker-v1-Data |

## Ключевые технические инновации

### 1. Масштабируемый контролируемый синтез QA с фактологическим заземлением

- **Реверс-инжиниринг веб-графа** через топологическое расширение
- **Обфускация сущностей** для генерации сложных многошаговых задач на рассуждение
- **Контролируемое покрытие и сложность** задач
- Позволяет создавать задачи с известными свойствами и контролируемой сложностью

### 2. Денойзинг синтезированных траекторий

- **Ретроспективный механизм суммаризации** для денойзинга траекторий
- **Асимметричное контекстное обучение**: обучает модель предсказывать экспертные действия из сырого, зашумленного HTML
- Стимулирует teacher LLM генерировать высококачественные действия
- Обеспечивает робастное извлечение информации

## Сравнение с Tongyi DeepResearch

| Аспект | OpenSeeker | Tongyi DeepResearch |
|--------|------------|---------------------|
| **Пайплайн обучения** | Только SFT | CPT + SFT + RL (обширный) |
| **Образцы для обучения** | 11.7k | Не раскрыто (вероятно, миллионы) |
| **BrowseComp-ZH** | **48.4%** | 46.7% |
| **Разработчик** | Чисто академическая команда | Alibaba (индустриальный) |
| **Открытость** | Полная (модель + данные) | Частичная |

**Ключевой инсайт:** OpenSeeker превосходит Tongyi DeepResearch на BrowseComp-ZH, несмотря на использование только простого SFT против их обширного пайплайна.

## Сравнение с DeepDive (вторым лучшим полностью открытым агентом)

- **OpenSeeker:** 29.5% на BrowseComp
- **DeepDive:** 15.3% на BrowseComp
- **Улучшение:** ~93% относительного прироста

## Авторы

Yuwen Du, Rui Ye, Shuo Tang, Xinyu Zhu, Yijun Lu, Yuzhu Cai, Siheng Chen

## Ключевые выводы

1. **Эффективность важнее масштаба**: OpenSeeker демонстрирует, что frontier-производительность достижима с минимальным количеством данных (11.7k образцов)
2. **Качество данных критично**: Высококачественные синтезированные данные с денойзингом траекторий обеспечивают превосходные результаты
3. **Простота обучения**: Только SFT без RL или continual pre-training может достичь SOTA результатов
4. **Демократизация исследований**: Полная открытость модели и данных позволяет академическому сообществу конкурировать с индустриальными решениями
5. **Разрушение корпоративного рва**: Традиционное преимущество корпораций в доступе к большим данным преодолевается через умный синтез данных
