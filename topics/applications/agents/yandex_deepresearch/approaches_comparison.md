# Сравнение подходов к глубоким исследованиям: Yandex DeepResearch vs DR TULU vs Qwen DeepResearch

## Обзор систем

### Yandex DeepResearch (Deep Agent Yandex Team Ru)

- Внутренняя система Яндекса для корпоративных данных и кодовой базы
- Использует свободную архитектуру без жестких рабочих процессов
- Делает итеративные поисковые запросы для сбора информации
- Основан на подходе "Code Execution" вместо "Tool Calling" для эффективности
- Использует LLM-as-a-judge для оценки ответов
- Доступен только сотрудникам Яндекса

### DR TULU (Deep Research Tulu)

- Открытый агент для глубоких исследований от Allen Institute
- Использует подход RLER (Reinforcement Learning with Evolving Rubrics)
- Имеет доступ к инструментам поиска: google_search, web_browse, paper_search
- Поддерживает цитирование источников в ответах
- Использует dr-agent-lib - библиотеку агентов с открытым исходным кодом
- Выпускается под открытой лицензией

### Qwen DeepResearch 2511

- Коммерческая система от Alibaba Cloud
- Встроена в чат-бот Qwen
- Имеет два режима работы: Normal и Advanced
- Поддерживает загрузку файлов и интеграцию с веб-данными
- Обеспечивает структурированные исследовательские отчеты
- Обладает длиной контекста в 1,000,000 токенов

## Архитектурные особенности

### Подходы к агентству

- **Yandex DeepResearch**: Свободная архитектура с минимальными ограничениями, предоставляет агенту значительную свободу действий
- **DR TULU**: Определенная структура с этапами планирования, поиска, сбора и адаптации глубины
- **Qwen DeepResearch**: Структурированный рабочий процесс с фазами анализа, уточнения, планирования, поиска и генерации

### Методы обучения

- **Yandex DeepResearch**: Эмпирический подход с начальным прототипом, улучшаемым итеративно; использует дообучение (fine-tuning) после исчерпания возможностей инструментальных улучшений
- **DR TULU**: Использует SFT (Supervised Fine-Tuning) и RLER (Reinforcement Learning with Evolving Rubrics)
- **Qwen DeepResearch**: Вероятно, использует SFT и RLHF, как и другие модели Qwen

### Подходы к использованию инструментов

- **Yandex DeepResearch**: Преимущественно использует "Code Execution" (Python-блоки), что более эффективно, чем "Tool Calling"
- **DR TULU**: Использует систему инструментов через MCP (Model Context Protocol) с возможностью смены компонентов
- **Qwen DeepResearch**: Поддерживает инструменты через веб-поиск, анализ документов и другие методы

## Оценка и эффективность

### Методы оценки

- **Yandex DeepResearch**: Использует тестовые наборы вопросов ("баскеты") и подход LLM-as-a-judge
- **DR TULU**: Использует эволюционирующие критерии (RLER) с положительными и отрицательными критериями
- **Qwen DeepResearch**: Вероятно, использует оценку через внутренние метрики качества и benchmarks

### Результаты

- **Yandex DeepResearch**: Сокращение времени поиска с 20 минут до 1 минуты (95%), ~240 сэкономленных рабочих часов в день, ~50% успеха на сложных вопросах о коде
- **DR TULU**: Значительно превосходит открытые базовые модели, сопоставим с проприетарными системами, низкая стоимость запуска (~0.00008$ за запрос)
- **Qwen DeepResearch**: Улучшенные метрики анти-галлюцинации, полноты, надежности цитирования и следованию инструкциям

## Области применения

### Yandex DeepResearch
- Внутренний корпоративный поиск
- Анализ внутренней кодовой базы
- Ответы на сложные вопросы о внутренних процессах и документации

### DR TULU
- Академические исследования
- Научные базы данных и публикации
- Длинные исследовательские задачи с требованием цитирования источников

### Qwen DeepResearch
- Коммерческие исследования
- Бизнес-анализ
- Технические исследования
- Информационный синтез из различных источников
