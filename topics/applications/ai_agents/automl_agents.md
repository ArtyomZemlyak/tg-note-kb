# AutoML Агенты

## Краткое описание

AutoML агенты — это специализированные ИИ-агенты для автоматизации полного цикла разработки моделей машинного обучения: от анализа задачи и проектирования архитектуры до обучения, настройки гиперпараметров и развёртывания. Эти агенты используют языковые модели для генерации кода, итеративного улучшения моделей и создания готовых к использованию ML-решений.

## Основная информация

AutoML (Automated Machine Learning) агенты представляют собой эволюцию традиционных AutoML-инструментов, объединяя возможности современных языковых моделей с автоматизацией ML-процессов. В отличие от классических AutoML-систем, которые фокусируются на автоматическом подборе гиперпараметров и архитектур, AutoML-агенты способны:

- **Анализировать проблему** на естественном языке
- **Проектировать решения** с учётом контекста задачи
- **Генерировать код** для обучения и инференса
- **Итеративно улучшать** модели на основе результатов
- **Создавать документацию** и отчёты о проделанной работе

## Ключевые возможности

### Автоматизация ML-цикла
- Полный цикл от задачи до готовой модели
- Автоматическая предобработка данных
- Выбор и обучение моделей
- Валидация и оценка качества

### Генерация кода
- Написание обучающих скриптов
- Создание inference-скриптов
- Генерация пайплайнов обработки данных
- Автоматическое документирование кода

### Итеративное улучшение
- Многократное улучшение моделей
- Настройка гиперпараметров
- Архитектурный поиск
- Анализ ошибок и корректировка

### Визуализация и отчётность
- Генерация PDF-отчётов о прогрессе
- Визуализация метрик обучения
- Сравнение кандидатов моделей
- Документирование результатов

## Архитектура AutoML агентов

### Цикл агента

1. **Анализ задачи**
   - Парсинг описания задачи
   - Определение типа проблемы (классификация, регрессия, и т.д.)
   - Анализ входных данных

2. **Проектирование решения**
   - Выбор подхода к решению
   - Проектирование архитектуры модели
   - Планирование экспериментов

3. **Генерация кода**
   - Написание кода модели
   - Создание скриптов обучения
   - Подготовка пайплайнов данных

4. **Обучение и оценка**
   - Запуск обучения моделей
   - Оценка производительности
   - Сравнение кандидатов

5. **Итеративное улучшение**
   - Анализ результатов
   - Корректировка подхода
   - Повторение цикла

### Компоненты системы

| Компонент | Назначение |
|-----------|------------|
| Планировщик | Координация цикла агента, управление задачами |
| Генератор кода | Создание ML-кода на основе описания задачи |
| Обучающий модуль | Управление процессом обучения моделей |
| Оценщик | Анализ производительности моделей |
| Оптимизатор | Настройка гиперпараметров и архитектур |
| Отчётность | Генерация визуальных отчётов и документации |

## Примеры реализации

### AI-Build-AI

**AI-Build-AI** — передовой AutoML-агент с открытым исходным кодом, занимающий #1 в рейтинге OpenAI MLE-Bench.

**Ключевые характеристики:**
- Полная автоматизация разработки ML-моделей
- Итеративное улучшение моделей
- Генерация готовых inference-скриптов
- Визуальные PDF-отчёты
- TUI-интерфейс для интерактивной настройки

**Технологический стек:**
- Язык: Python (79.1%), Shell (20.9%)
- API: Anthropic API (Claude)
- Платформа: Linux x86_64
- Лицензия: Apache License 2.0

**Результаты работы:**
- `candidate_*/` — сгенерированные скрипты обучения и чекпоинты
- `checkpoint.pth` — лучшая модель
- `inference.py` — готовый скрипт для предсказаний
- `submission.csv` — предсказания на тестовых данных
- `progress.pdf` — визуальный отчёт о прогрессе

**Пример использования:**
```bash
aibuildai --task-name protein-ec-prediction \
  --data-dir data/protein-ec-prediction \
  --model claude-opus-4-6 \
  --max-agent-calls 8 \
  --run-budget-minutes 60 \
  --num-candidates 3
```
