# Qwen3-ASR: Многоязычная система распознавания речи от Alibaba

## Краткое описание

**Qwen3-ASR** — это серия передовых моделей автоматического распознавания речи (ASR), разработанных Alibaba, состоящая из нескольких вариантов, включая Qwen3-ASR-1.7B и Qwen3-ASR-0.6B. Модели поддерживают распознавание речи на 52 языках и диалектах, обеспечивая конкурентоспособное качество по сравнению с коммерческими решениями.

## Основная информация

### Модельные варианты

- **Qwen3-ASR-1.7B**: Флагманская модель с 1.7 миллиардами параметров, обеспечивающая высокое качество распознавания
- **Qwen3-ASR-0.6B**: Компактная и очень быстрая версия с 0.6 миллиардами параметров, оптимизированная для эффективности и низкой задержки

### Архитектура и подход

- Основана на фундаментальной модели Qwen3-Omni
- Обучена на массивных мультимодальных данных и десятках миллионов часов данных автоматического распознавания речи
- Поддерживает как потоковую (streaming), так и оффлайн инференс в одной модели
- Использует более сжатое представление в аудиомодальности (фреймы по 80 мс вместо 40 мс) с более сильным фактором downsampling

### Основные характеристики

- **Поддержка языков**: До 52 языков и диалектов, включая:
  - Китайский (мандаринский, диалекты Сычуань, Кантон, Миньнань, У, др.)
  - Английский (американский, британский и др.)
  - Французский, немецкий, русский, итальянский, испанский, португальский
  - Японский, корейский, арабский, и другие
- **Языковая идентификация**: Автоматическое определение языка на основе аудио
- **Качество распознавания**: Конкурентоспособное качество с передовыми коммерческими моделями
- **Эффективность**: Qwen3-ASR-0.6B обеспечивает 2000x пропускную способность при параллелизме 128

## Технические особенности

### Потоковая обработка

- Поддержка потоковой обработки аудио для сценариев реального времени
- Единая архитектура для обоих режимов (потокового и оффлайн)
- Эффективные методы inferencing для обоих вариантов

### Робастность

- Высокая точность в сложных акустических условиях
- Устойчивость к шумам, акцентам и диалектам
- Обработка сложных аудио-сценариев (песни, фоновая музыка, перекрывающиеся разговоры)

### Контекстная настраиваемость

- Поддержка пользовательского контекста для точной настройки распознавания
- Применение контекстной настройки непосредственно в распознавании
- Повышение точности для ключевых терминов и именованных сущностей

## Модели в семействе Qwen3-ASR

### Qwen3-ASR-1.7B

- **Размер модели**: 1.7 миллиарда параметров
- **Тип**: Флагманская модель с передовым качеством
- **Преимущества**: Высочайшая точность, конкурентоспособна с коммерческими API
- **Применение**: Сценарии, где ключевым является максимальная точность

### Qwen3-ASR-0.6B

- **Размер модели**: 0.6 миллиарда параметров
- **Тип**: Компактная версия для производительности
- **Преимущества**: Высокая эффективность, до 2000x пропускной способности при параллелизме 128
- **Применение**: Реал-тайм сценарии с высокими требованиями к задержке

## Сравнение с другими моделями

Qwen3-ASR демонстрирует превосходные результаты по сравнению с конкурентами, включая Whisper, Gemini-2.5-Pro и GPT-4o-Transcribe. Особенно сильна модель в следующих аспектах:

- **Языковая идентификация**: Qwen3-ASR-1.7B достигает 97.9% точности по сравнению с 94.1% у Whisper-large-v3
- **Песенное распознавание**: Низкий уровень ошибок при распознавании песен и вокального исполнения
- **Многоязычность**: Превосходное покрытие и качество для 52 языков и диалектов

## Применение

- **Многоязычные встречи**: Транскрибирование встреч на различных языках
- **Новостные интервью**: Высококачественная транскрипция интервью
- **Онлайн-образование**: Распознавание речи преподавателей и студентов
- **Интеллектуальный клиентский сервис**: Автоматическое обслуживание клиентов
- **Медицинская документация**: Формирование записей из голосовых заметок врачей
- **Игровые комментарии**: Транскрипция игровых стримов
- **Распознавание музыки и текстов песен**: Обработка музыкального контента

## Технические детали

### Поддерживаемые форматы аудио

- aac, mp3, wav, flac и другие основные форматы
- Поддержка потоковой обработки аудио
- Обработка аудио разной продолжительности

### Поддерживаемые функции

- Автоматическое определение языка
- Предсказание знаков препинания
- Нормализация текста
- Потоковый вывод
- Фильтрация неконвертируемых звуков (тишина, фоновый шум)

### Производительность и масштабируемость

- Поддержка пакетной обработки
- Асинхронное обслуживание
- Оптимизация для vLLM и torch.bfloat16/torch.float16
- Поддержка FlashAttention 2 для уменьшения потребления GPU памяти
