# Classification

Classification is a supervised learning task where the goal is to categorize input data into predefined classes or categories.

## Overview

Classification algorithms learn from labeled training data to predict the class labels of new, unseen data. This is one of the most common tasks in machine learning with applications in many domains.

## Types of Classification

- Binary Classification - Two-class problems (e.g., spam detection)
- Multiclass Classification - Multiple exclusive classes (e.g., image recognition)
- Multilabel Classification - Multiple non-exclusive labels (e.g., tagging)

## Common Algorithms

- Logistic Regression
- Support Vector Machines (SVM)
- Decision Trees and Random Forests
- Naive Bayes
- Neural Networks
- K-Nearest Neighbors

## Applications

- Email spam detection
- Medical diagnosis
- Image recognition
- Sentiment analysis
- Fraud detection

## Evaluation Metrics

- Accuracy
- Precision, Recall, F1-score
- ROC-AUC
- Confusion matrix
