# Clustering

Clustering is an unsupervised learning task that involves grouping similar data points together based on their characteristics.

## Overview

Clustering algorithms find hidden patterns or groupings in data without prior knowledge of class labels. The goal is to partition data into groups where members of the same group are more similar to each other than to members of other groups.

## Types of Clustering

- Partitioning Clustering - Divides data into non-overlapping clusters
- Hierarchical Clustering - Builds a tree of clusters
- Density-Based Clustering - Finds clusters of varying shapes
- Grid-Based Clustering - Divides space into finite grids
- Model-Based Clustering - Assumes a model for each cluster

## Common Algorithms

- K-Means
- Hierarchical Clustering
- DBSCAN
- Gaussian Mixture Models (GMM)
- Spectral Clustering
- Mean Shift

## Applications

- Customer segmentation
- Image segmentation
- Anomaly detection
- Social network analysis
- Document clustering
- Market research

## Evaluation Metrics

- Silhouette Score
- Calinski-Harabasz Index
- Davies-Bouldin Index
- Adjusted Rand Index (with ground truth)
- Mutual Information (with ground truth)
