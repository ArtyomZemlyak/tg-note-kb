# 3AM: Сегментация всего с геометрической согласованностью в видео

## Обзор

3AM (3EGMENT ANYTHING WITH GEOMETRIC CONSISTENCY IN VIDEOS) - это метод сегментации видеообъектов, который улучшает SAM2 за счет интеграции 3D-ориентированных признаков из MUSt3R. Метод сохраняет согласованные треки объектов при больших изменениях точки обзора, загруженных сценах и вариациях условий захвата. 3AM решает ограничения традиционных 2D методов сегментации видеообъектов (VOS), которые испытывают трудности при изменениях точки обзора.

### Основные особенности
- **Геометрическая согласованность**: Сохраняет идентичность объекта при больших изменениях точки обзора, где традиционные 2D VOS методы терпят неудачу
- **Отсутствие необходимости в позиции камеры**: Работает только с RGB-входом во время инференса, без необходимости в позициях камеры или картах глубины
- **3D-ориентированная интеграция**: Комбинирует 3D-ориентированные признаки из MUSt3R с визуальными признаками SAM2
- **Обучение с учетом поля зрения**: Стратегия обучения, обеспечивающая наблюдение кадрами пространственно согласованных областей объекта
- **Сегментация 3D-инстансов без учителя**: Может выполнять сегментацию 3D-инстансов без явного 3D-супервизора

## Технические детали

### Архитектура
- **Подход к интеграции**: Интегрирует 3D-ориентированные признаки из MUSt3R в SAM2 через легковесный слияние функций (Feature Merger)
- **Слияние признаков**: Объединяет многоранговые MUSt3R признаки, кодирующие неявную геометрическую корреспонденцию с визуальными признаками SAM2 через кросс-внимание и сверточную доработку
- **Улучшение обучения**: Использует стратегию осведомленности о поле зрения (Field-of-View) для предотвращения обучения неоднозначным соответствиям
- **На основе памяти**: Использует архитектуру памяти SAM2, добавляя геометрическую согласованность

### Процесс слияния признаков
Метод усиливает SAM2 MUSt3R признаками следующим образом:
1. **Извлечение признаков на нескольких уровнях**: SAM2 обрабатывает кадры для создания 2D признаковых карт, в то время как MUSt3R обрабатывает те же кадры для получения геометрически ориентированных признаковых карт
2. **Межвидовая корреспонденция**: Слияние признаков использует многоранговые MUSt3R признаки с визуальными признаками SAM2 для создания объединенных представлений, сочетающих визуальную семантику с геометрической структурой
3. **Поэтапная интеграция**: Слияние избирательно включает признаки из разных глубин MUSt3R, уравновешивая семантическую насыщенность (ранние уровни) с геометрической структурой (поздние уровни)

### Выборка кадров при обучении
- **Выборка с учетом поля зрения**: Для каждой итерации обучения первый выбранный кадр служит эталонным кадром; остальные кадры выбираются в зависимости от того, попадают ли их замаскированные 3D точки в поле зрения эталонной камеры
- **Основанный на пороге отбор**: Кадры сохраняются только если достаточная доля их замаскированных 3D точек попадает внутрь поля зрения эталонной камеры:
  - `{замаскированные точки внутри эталонного фруструма}/{замаскированные точки в кадре-кандидате} > τ`
- **Пространственная согласованность**: Обеспечивает, чтобы выбранные кадры наблюдали перекрывающиеся физические области объекта, избегая вырожденных случаев, когда два вида одного и того же экземпляра соответствуют удаленным, неперекрывающимся частям
