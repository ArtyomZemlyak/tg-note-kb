# 3D Gaussian Splatting

## Краткое описание

3D Gaussian Splatting — это метод представления 3D-сцен с использованием набора 3D гауссианов, который позволяет эффективно и фотореалистично синтезировать новые ракурсы сцены. Каждый гауссиан кодирует информацию о цвете, непрозрачности, ковариации и положении в пространстве.

## Основные характеристики

### Технический подход
- Представление 3D-сцены как коллекции 3D гауссианов
- Каждый гауссиан определяется параметрами: положением (x, y, z), цветом (r, g, b), непрозрачностью, ковариацией (описывающей форму и ориентацию)
- Использование дифференцируемого рендеринга для оптимизации параметров

### Преимущества
- **Высокая скорость рендеринга**: Более 100 FPS на стандартных GPU
- **Фотореалистичное качество**: Четкие детали и тонкие структуры
- **Эффективная оптимизация**: Меньше параметров и времени обучения по сравнению с нейронными сетями
- **Масштабируемость**: Подходит для сложных сцен с высокой детализацией

## Архитектура и реализация

### Компоненты представления
- **Позиции точек**: 3D координаты каждого гауссиана
- **Цвета**: RGB значения для каждого гауссиана
- **Ковариации**: 3x3 матрицы, описывающие форму и ориентацию
- **Непрозрачность**: Параметр, контролирующий вклад в финальное изображение

### Процесс оптимизации
- Использование обратного распространения ошибки для оптимизации параметров
- Динамическое добавление и удаление гауссиан в процессе обучения
- Регуляризация для предотвращения переподгонки

## Применение

### В компьютерном зрении
- **Синтез новых ракурсов**: Генерация изображений с новых точек зрения
- **3D реконструкция**: Восстановление 3D-представлений из 2D изображений
- **Дополненная реальность**: Быстрое создание 3D-представлений для AR-приложений

### Известные реализации
- **Apple SHARP**: Использует 3D Gaussian Splatting для монокулярной реконструкции
- **3D Gaussian Splatting for Real-Time Radiance Field Rendering**: Первоначальная статья от исследователей из UC Berkeley и Google
- **Mip-Splatting**: Улучшенная версия с лучшим представлением текстур

## Сравнение с другими методами

### 3D Gaussian Splatting vs. NeRF
- **Скорость**: 3D Gaussian Splatting значительно быстрее (100+ FPS vs. несколько FPS у NeRF)
- **Качество**: Сопоставимое качество с NeRF, но с лучшей детализацией
- **Обучение**: Быстрое обучение (несколько минут vs. часы для NeRF)
- **Оптимизация**: Прямая оптимизация параметров, а не нейронной сети

### 3D Gaussian Splatting vs. Plenoxels
- **Репрезентация**: Гауссианы vs. воксельные сетки
- **Гибкость**: Более гибкая репрезентация с адаптивным разрешением
- **Производительность**: Лучшая производительность при рендеринге

## Технические детали

### Дифференцируемый рендеринг
- Использование подхода рендеринга с учетом ковариаций для корректного сглаживания
- Применение фильтрации для устранения артефактов при сэмплировании

### Оптимизация параметров
- Использование квадрупольной оптимизации для обновления ковариаций
- Динамическое масштабирование для поддержания стабильности
