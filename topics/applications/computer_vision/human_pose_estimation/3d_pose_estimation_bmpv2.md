# 3D оценка позы человека с использованием BBoxMaskPose v2

## Общее описание

BBoxMaskPose v2 (BMPv2) расширяет возможности своей 2D системы для задач восстановления 3D позы и формы человеческого тела. Система использует точные 2D данные (маски, ограничивающие рамки и позы), полученные через циклический процесс BMP, в качестве подсказок для 3D оценщика позы человека. Это позволяет достичь точного 3D восстановления даже в сценах с экстремальным перекрытием и заслонением.

## Интеграция с 3D восстановлением

### Использование 3D моделей

BMPv2 использует маски, ограничивающие рамки и 2D позы в качестве подсказок для:
- **3D оценщика позы человека**: Используется SAM-3D-Body [1] в качестве примера 3D модели
- **Модели восстановления 3D тела**: Может работать с различными 3D моделями, принимающими 2D подсказки

### Процесс интеграции

- **Последовательный подход**: 3D шаг выполняется только после сходимости цикла BMP, поскольку 3D модели вычислительно тяжелые
- **Избежание итеративного уточнения**: Хотя 3D оценка теоретически может быть интегрирована в цикл аналогично 2D позе, её стоимость делает итеративную перенастройку непрактичной
- **Однократное кодирование изображения**: 3D оценщик позы кодирует полное изображение один раз, чтобы получить признаки изображения

### Параметры 3D восстановления

- Для каждого обнаруженного человека предсказывается 3D поза и форма с помощью подсказок с ограничивающей рамки и маски оцененного экземпляра
- Избегает повторного извлечения признаков и сохраняет приемлемое увеличение вычислительных затрат на человека
- Отфильтрованные 3D тела с использованием 3D подавления максимального значения (non-maximum suppression)
- Доверие к экземпляру для NMS наследуется от 2D предсказаний, произведенных циклом BMP

## Технические детали

### Модель SAM-3D-Body

- **Требования**: Модель SAM-3D-Body нуждается в подсказке для реконструкции полигональной сетки
- **Подсказки**: Подсказки могут быть ограничивающей рамкой, маской или 2D позой
- **Эффективность**: Эксперименты показали, что поза не оказывает такой же помощи как маски сегментации
- **Качество**: При подаче масок BMPv2 предсказанные 3D сетки имеют сопоставимое качество с 2D позой

### Преимущества точных 2D подсказок

- **Упрощение задач**: Точные маски упрощают как 2D, так и 3D оценку позы в толпе
- **Разрешение перекрытий**: Помогает точно назначить конечности индивидуумам в сценах с перекрывающимися людьми
- **Устойчивость**: Обеспечивает надежные 3D оценки в сложных сценах с плотными взаимодействиями

### Качественные результаты

- **Качественные примеры** представлены на рисунках 1 и 6 в оригинальной статье
- **Воспроизводимость**: Результаты подтверждают, что точные 2D подсказки принципиально важны для точной 3D оценки позы в толпе
- **Преимущество масок**: Подсказки с BMPv2 маски обеспечивают значительно лучшие 3D позы благодаря гораздо более точным маскам экземпляров

## Устойчивость к сдвигу домена

### Оценка на частном наборе данных

- **Сценарии**: Данные о взаимодействиях взрослый-младенец, где стандартные оценщики позы испытывают трудности с разделением индивидуумов
- **Преимущества BMP**: BMPv1 и BMPv2 значительно превосходят промышленные эталоны (RTMDet + ViTPose)
- **Устойчивость PMPose**: Благодаря вероятностному моделированию, PMPose правильно предсказывает ключевые точки вне изображения и избегает смешивания индивидуумов

### Результаты на частном наборе данных

| Метод | AP оценки позы |
|-------|----------------|
| RTMDet-l + ViTPose-B | 73.3 |
| RTMDet-l + ViTPose*-B | 76.9 |
| RTMDet-l + PMPose-B | 76.4 |
| BMPv1 2× | 83.2 |
| BMPv2 2× | 83.3 |

### Вызовы и ограничения

- **Частично видимые взрослые**: Затрудняют работу верхнеуровневых методов
- **Отсутствие младенцев в учебных наборах**: Вызывает сильный сдвиг домена
- **Домены с приватностью**: Детские датасеты редко распространяются, что затрудняет обучение моделей

## Практические применения

### Сценарии с высокой точностью

- **Качественные оценки**: BMPv2 достигает сильной производительности в сложных сценах с множественными телами и подходит, когда точность является основной целью
- **Аннотация данных**: Может использоваться для автоматической аннотации сложных сцен для задач машинного обучения
- **Анализ взаимодействий**: Позволяет понять сложные физические взаимодействия между людьми

### Сценарии в реальном времени

- **PMPose-S**: Для приложений, ограниченных по времени, PMPose-S, особенно PMPose-S, предлагает благоприятный баланс между точностью и скоростью
- **Траектории движения**: Может быть применен в системах слежения за движением и анализа поведения

## Заключение

Интеграция BBoxMaskPose v2 с 3D восстановлением тела демонстрирует важность точных 2D подсказок для надежной 3D оценки позы в сложных сценах. Работа показывает, что сильные 2D оценки улучшают 3D оценку позы человека с использованием SAM-3D-Body, и что точные подсказки являются ключом для точного восстановления 3D позы в толпе.
