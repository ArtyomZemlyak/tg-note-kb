# OCHuman-Pose: Улучшенный датасет для оценки позы человека в толпе

## Общее описание

OCHuman-Pose – это улучшенный вариант датасета OCHuman, разработанный для более точной оценки задач обнаружения, сегментации и оценки позы человека в сложных сценах с несколькими взаимодействующими людьми. Датасет расширяет оригинальный OCHuman, добавляя аннотации ключевых точек для всех видимых людей, которые были исключены в исходной версии.

## Проблемы оригинального датасета OCHuman

### Основные ограничения

- **Неполные аннотации**: В оригинальном датасете OCHuman многие индивидуумы не были аннотированы
- **Проблема отбора экземпляров**: Датасет оставлял только случаи с IoU_max = 0 или IoU_max > 0.5, исключая все экземпляры с промежуточным перекрытием (0 < IoU_max ≤ 0.5)
- **Смещенная оценка**: Модели вынуждены были присваивать наивысшую уверенность аннотированным экземплярам, даже если они не являются наиболее заметными людьми на изображении
- **Фоновые субъекты**: Аннотированные субъекты часто находились в фоне, что не отражает реальные условия

### Влияние на оценку производительности

- В протоколе оценки COCO-style mAP предсказания сортируются по уверенности и назначаются на основе жадного подхода
- Любое предсказание, которое занимает первое место без соответствующей аннотации, становится ложно положительным
- Модели вынуждены были назначать наивышнюю уверенность аннотированным экземплярам, даже если они не были наиболее заметными на изображении

## Решения, реализованные в OCHuman-Pose

### Расширение датасета

- **Добавление пропущенных аннотаций**: Все пропущенные экземпляры были добавлены с аннотациями ключевых точек
- **Восстановление оригинальных аннотаций**: Возвращены аннотации, которые были исключены из-за схемы фильтрации датасета
- **Ручная аннотация**: Добавлены ручные аннотации для всех экземпляров, у которых их не было

### Статистические улучшения

| Dataset | # изображений | # keypoints | # masks | IoU_max (val) | IoU_max (test) |
|---------|---------------|-------------|---------|---------------|----------------|
| OCHuman val | 2,500 | 4,291 | 4,291 | 0.545 | - |
| OCHuman test | 2,231 | 3,819 | 3,819 | - | 0.546 |
| OCH-Pose val | 2,500 | 6,546 | 4,291 | 0.527 | - |
| OCH-Pose test | 2,231 | 5,863 | 3,819 | - | 0.527 |
| CIHP val | 5,000 | 0 | 17,520 | 0.209 | - |

- В OCHuman-Pose добавлено более 50% новых экземпляров к оригинальным изображениям
- Среднее значение IoU_max остается схожим, но распределение теперь лучше отражает условия в дикой природе
- Уменьшено количество изолированных случаев с IoU_max = 0
- Теперь представлен ранее отсутствующий диапазон 0 < IoU_max ≤ 0.5

## Применение и влияние

### Улучшенная оценка производительности

- Оценка производительности оценки позы на OCHuman-Pose отражает реальность более точно, чем на оригинальном OCHuman
- Показывает, что разница между ошибками обнаружения и оценки позы стала более реалистичной
- Модели, использующие истинные ограничивающие рамки (GT bboxes), показывают более сопоставимую производительность с обнаруженными рамками, что указывает на то, что ошибка оценки позы, а не обнаружения, является основным препятствием

### Сравнение производительности

По сравнению с оригинальным OCHuman:
- Модели показывают более реалистичные результаты
- BMPv2+ показывает почти ту же производительность, что и ViTPose с GT bboxes (85.8 vs 86.4) на val set
- Даже превосходит ViTPose с GT bboxes на тестовом наборе (86.8 vs 86.2)

## Значение для области

- **Более реалистичная оценка**: Позволяет более точно измерять прогресс в задачах, связанных с оценкой позы человека в толпе
- **Улучшенное понимание瓶颈ов**: Показывает, что проблема обнаружения в загруженных сценах в значительной степени решена, а основные ошибки исходят из неточной оценки позы
- **Развитие области**: Предоставляет более надежный стандарт для оценки будущих методов оценки позы человека

## Сравнение с другими датасетами

| Датасет | Особенности | Цель |
|---------|-------------|------|
| OCHuman | Отфильтрованные экземпляры, неполные аннотации | Оригинально для задачи поза-сегментация |
| OCHuman-Pose | Полные аннотации, все видимые экземпляры | Улучшенная оценка в реальных условиях |
| CIHP | Больше изображений, более точные маски, нет поз | Сосредоточен на толпе, а не на взаимодействиях |
