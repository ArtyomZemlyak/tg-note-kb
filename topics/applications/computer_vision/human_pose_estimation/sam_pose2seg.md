# SAM-pose2seg: Ориентированная на позу сегментация экземпляров человека

## Общее описание

SAM-pose2seg – это адаптированная версия модели Segment Anything Model (SAM) 2.1, специализирующаяся на задаче ориентированной на позу сегментации экземпляров человека. Модель обучена использовать 2D позу человека в качестве подсказки для точной сегментации соответствующего человека, преодолевая проблемы традиционных подходов, таких как пере-сегментация кожных покровов.

## Архитектура и особенности

### Основные изменения

- **Модификация декодера для человека**: Тонкая настройка декодера для предсказания только экземпляров человека, включая одежду, как определено в учебных аннотациях
- **Удаление задачевой неопределенности**: Устраняет неопределенность задачи и напрямую решает главную проблему BMPv1: пере-сегментацию кожных участков
- **Обучающее подсказывание, ориентированное на позу**: Заменяет случайное подсказывание точками на осознанное подсказывание, ориентированное на позу, чтобы ввести информацию о ключевых точках человека в модель

### Подсказывание при обучении

- **Первая подсказка**: Наиболее видимая ключевая точка
- **Последующие итерации**: Выбирается ключевая точка, находящаяся в текущей области ошибки
- **Резервный вариант**: Если ключевые точки не находятся в области ошибки, используется выборка случайной точки из этой области
- **Обучение на позационно управляемых подсказках**: Модель обучается работать с подсказками, управляемыми позой, что имеет другое пространственное распределение, чем случайные точки, использованные в первоначальном обучении SAM

### Подсказывание при выводе

- Не требуется сложной стратегии подсказывания BMPv1
- Выбор небольшого числа ключевых точек с высокой видимостью дает сравнимые или лучшие результаты
- Достаточно двух-трех ключевых точек для полной характеристики экземпляра

## Применение в цикле BBoxMaskPose v2

### Интеграция с PMPose

- SAM-pose2seg использует прогнозы позы человека, созданные ProbPose (PMPose) для обучения
- Это позволяет использовать наборы данных без истинных аннотаций ключевых точек (например, CIHP [5])
- Возможность быстрой специализации для класса человека

### Улучшенная сегментация

- Производит маски сегментации более высокого качества, чем исходный SAM
- Значительно упрощает проблему выбора подсказок, выявленную в BMPv1
- Повышает качество маскировки за счет точного использования информации о позе

## Преимущества по сравнению с другими методами

- **Лучшая специализация**: В отличие от общих сегментаторов, таких как SAM, специализируется на сегментации людей
- **Простота**: Не требует сложных стратегий выбора подсказок
- **Высокое качество**: Превосходит SAM по качеству сегментации в задачах, связанных с людьми
- **Устойчивость**: Повышает устойчивость всего цикла BMP за счет более точной маскировки

## Технические детали

- Основана на архитектуре SAM-hiera-B+
- Тонкая настройка на наборах данных COCO и CIHP
- Для обучения CIHP используются псевдоистинные аннотации позы, сгенерированные предварительной версией PMPose-B вместе с истинной маской сегментации
