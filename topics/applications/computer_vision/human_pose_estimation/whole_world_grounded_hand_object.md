# WHOLE: World-Grounded Hand-Object Reconstruction из эгоцентрических видео

**WHOLE** (World-Grounded Hand-Object Lifted from Egocentric Videos) — метод для совместной реконструкции согласованных движений рук и объектов в мировом пространстве из эгоцентрических видео с использованием генеративного априорного распределения движений.

![WHOLE Method Overview](../../../../media/doc_1772263637_e8c3386c_arxiv_2602.22209.pdf)
*WHOLE: World-Grounded Hand-Object Lifted from Egocentric Videos — метод совместной реконструкции движений рук и объектов в мировом пространстве из эгоцентрических видео. Given a metric-SLAMed egocentric video и object templates, WHOLE reconstructs motions of both hands and objects of interest.*

## Ключевая проблема

Эгоцентрические видео манипуляции объектами чрезвычайно сложны для анализа из-за:
- **Серьёзных окклюзий** во время взаимодействий рук и объектов
- **Частого появления и исчезновения объектов** из поля зрения камеры при движении человека
- **Независимых предсказаний** поз рук и объектов, приводящих к несогласованным отношениям рука-объект

Существующие методы фокусируются на восстановлении либо позы рук, либо позы объектов по отдельности, но оба подхода сталкиваются с трудностями во время взаимодействий и не справляются со случаями, когда объекты выходят из поля зрения.

## Ключевая идея

**Руки и объекты взаимосвязаны** — их движения следует моделировать совместно для захвата согласованных взаимодействий рука-объект.

WHOLE формулирует реконструкцию как **управляемую генерацию** на основе генеративного априорного распределения движений, изученного на взаимодействиях рук и объектов.

## Методология

### Архитектура WHOLE

```
Вход: metric-SLAMed эгоцентрическое видео + 3D шаблон объекта
         ↓
[Generative Motion Prior] ← Diffusion модель
         ↓
[Guidance Step] ← 2D маски, контактные сигналы от VLM
         ↓
Выход: H (движения рук), T (6D траектория объекта), C (бинарный контакт)
```

### 1. Generative Hand-Object Motion Prior

**Диффузионная модель**, которая обучается априорному распределению движений взаимодействий рук и объектов.

**Входные условия:**
- Приблизительная траектория руки `H̄` (от готового оценщика поз рук, например HaWoR)
- 3D шаблон объекта `O` (BPS дескриптор геометрии)

**Выход:**
- Уточнённые движения рук `H` (параметры MANO: ориентация, трансляция, артикуляция, форма)
- 6D траектории объектов `T` (SE(3) трансформации)
- Бинарные метки контакта `C` (левая/правая рука)

**Представление движений:**
- **Руки:** Параметры MANO включая глобальную ориентацию Γ, трансляцию Λ, артикуляцию Θ, форму β, позиции и скорости суставов J, J̇
- **Объекты:** 9D представление в SE(3)
- **Ambient Sensor Feature:** Для каждого сустава руки измеряется смещение до ближайшей точки на поверхности объекта — эквивалентно BPS позиционированного объекта с использованием суставов руки как векторного базиса

**Gravity-Aware Local Coordinate Frame:**
- Все последовательности нормализуются относительно гравитационно-выровненной камеры
- Z-ось выравнивается по вектору гравитации
- Позволяет модели фокусироваться на относительном движении рука-объект, а не произвольных глобальных вращениях

**Обучение:**
- **Dataset:** HOT3D-CLIP (2,443 последовательности по 150 кадров)
- **Функция потерь:** Conditional DDPM Loss + вспомогательные потери:
  - **Interaction Loss (L_inter):** Поощряет реалистичный контакт рука-объект
  - **Consistency Loss (L_const):** Согласованность между предсказанными признаками рук и прямой кинематикой MANO
  - **Temporal Smoothness (L_smooth):** Штраф за большие ускорения

### 2. Reconstruction as Guided Generation

На этапе тестирования предварительно обученный априор направляется визуальными наблюдениями из видео.

**Classifier Guidance:**
Управляет диффузионной моделью через модификацию score-функции:

```
∇ₓₙ log p(xₙ) → ∇ₓₙ log p(xₙ) + ∇ₓₙ g(ŷ, x)
```

где `g(ŷ, x)` — специфичные для задачи объективы на основе наблюдений из видео.

**Три категории объективов для управления:**

1. **Reprojection term (g_reproj):**
   - Выравнивание с 2D наблюдениями: бинарные метки контакта, 2D суставы рук, маски объектов
   - One-way Chamfer loss между репроецированным объектом и сегментированной маской

2. **Interaction term (g_inter):**
   - Реалистичная динамика рука-объект
   - Минимизация расстояний, поощрение жёсткого транспорта при контакте
   - Штраф за движение при отсутствии контакта

3. **Temporal smoothness term (g_temp):**
   - Регуляризация временной согласованности
   - Плавные траектории

### 3. VLM Contact Assignment

Для детекции контакта рука-объект используется **Vision-Language Model (VLM)** с пространственными подсказками.

**Метод:**
- Сегментация и индексация рук и кандидатов объектов
- Наложение масок на изображение для улучшения локализации в загромождённых сценах
- VLM выдаёт JSON с контактами, ограниченный правилами валидации (например, "одна из k" для каждой руки)
- **In-context learning:** 5 аннотированных примеров для калибровки

**Результат:** F1 score детекции контактов улучшен с 57% до 81%

### 4. Blending Long Videos

Диффузионная модель генерирует клипы фиксированной длины (T=120 кадров).

**Для длинных последовательностей (L > 120):**
- Разделение на перекрывающиеся скользящие окна
- Параллельная денoизация всех окон на каждом шаге диффузии
- Блендинг перекрывающихся регионов
- Сшивание параметров формы по кадрам

## Результаты

### Датасет и оценка

**HOT3D-CLIP:**
- Эгоцентрический датасет, записанный через Aria Glasses
- Реальные взаимодействия рук с объектами
- Проверенные аннотации поз рук и объектов, шаблоны, траектории камеры
- 50 динамических траекторий объектов (смещение > 5 см) для оценки

**Метрики:**

**Руки:**
- **WA-MPJPE:** Выравнивание по первому кадру (cm)
- **W-MPJPE:** Глобальное выравнивание всех суставов (cm)
- **PA-MPJPE:** Покадровое Procrustes выравнивание (mm)
- **ACC-NORM:** Ошибка ускорения суставов (временная плавность)

**Объекты:**
- **ADD/ADD-S AUC:** Среднее расстояние между соответствующими точками модели (6D оценка позы)

**Взаимодействие (HOI):**
- ADD/ADD-S после глобального выравнивания по траектории рук

### Сравнение с базовыми методами

**Таблица 1: Движения рук**

| Метод              | WA-MPJPE ↓ | W-MPJPE | ACC-NORM ↓ | PA-MPJPE ↓ |
|--------------------|------------|---------|------------|------------|
| HaMeR              | 16.93      | 28.35   | 32.31      | 12.76      |
| HaWoR              | 3.76       | 11.26   | 4.15       | 8.99       |
| FP+HaWoR-simple    | 3.34       | 9.16    | 0.95       | 8.99       |
| FP+HaWoR-contact   | 5.85       | 12.19   | 1.26       | 8.99       |
| **WHOLE (Ours)**   | **3.26**   | 10.41   | **0.58**   | **6.67**   |

**Ключевые достижения:**
- **SOTA по оценке движения рук:** Лучший WA-MPJPE (3.26 cm) и PA-MPJPE (6.67 mm)
- **Лучшая временная плавность:** Наименьший ACC-NORM (0.58)
- **SOTA по оценке позы объектов 6D:** Превосходит FoundationPose
- **SOTA по реконструкции взаимодействий:** Лучшее относительное выравнивание рука-объект

### Генерация движений

WHOLE может также **синтезировать разнообразные движения** из грубых траекторий рук и меток контакта без видео-входа.

**Применение:** Планировщик HOI для роботов — генерация кандидатов траекторий для манипуляции.

## Ограничения и режимы отказов

1. **Переворот ориентации объекта:** Иногда объекты переворачиваются — репроекция по маскам недостаточна для полного ограничения 6D позы
2. **Наклон после отпускания:** Небольшие ошибки позы приводят к несогласованности с гравитацией в мировом пространстве после того, как объект отпущен
3. **Зависимость от качества VLM:** Ложные позитивы в детекции контактов требуют калибровки

## Связь с другими работами

### Egocentric Video Understanding
- **Ego-SLAM:** Методы оценки движения камеры для выравнивания эгоцентрической точки обзора с мировым пространством
- **Global Human/Hand Motion:** Методы реконструкции движений человека в мировых координатах

### Hand Pose Estimation
- **HaMeR:** Image-based система предсказания поз рук (не выровнена в 4D)
- **HaWoR:** World-grounded оценка движений рук (используется как базовый оценщик в WHOLE)

### Hand-Object Interaction (HOI)
- **Template-based:** Оценка позы объекта для данного шаблона
- **Template-free:** Восстановление геометрии объектов и паттернов контакта на коротких клипах

### 4D Reconstruction
- **STaRTrack, SpatialTracker:** 3D-aware трекинг точек на уровне сцены
- **FoundationPose:** 6D оценка позы объектов с известной геометрией

## Применения

3. **HOI Planning:** Генерация кандидатов траекторий для планирования манипуляций роботов
