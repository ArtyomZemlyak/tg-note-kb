# ObjSplat: Активная реконструкция объектов с использованием геометрически осознанных гауссовых поверхностных элементов

## Общее описание

**ObjSplat** - это инновационная система активной реконструкции объектов, разработанная исследовательской группой из Пекина (Li-Yuetao), которая использует геометрически осознанные гауссовы поверхностные элементы (Gaussian surfels) в качестве унифицированного представления для прогрессивной реконструкции неизвестных объектов. Система создает высококачественные гауссовы модели и водонепроницаемые (water-tight) меш-сетки, готовые для использования в физических симуляциях. 

Autonomous high-fidelity object reconstruction is fundamental for creating digital assets and bridging the simulation-to-reality gap in robotics. ObjSplat представляет собой активную систему реконструкции, которая использует гауссовы поверхностные элементы (Gaussian surfels) в качестве унифицированного представления для прогрессивной реконструкции неизвестных объектов с фотореалистичным внешним видом и точной геометрией. 

Объективная функция ObjSplat объединяет фотометрические, глубинные, нормальные, опаковые и масочные термины с весовыми коэффициентами: L = λd*Lp + λd*LD + λn*Ln + λo*Lo + λm*Lm, где каждый компонент способствует улучшению качества реконструкции.

## Архитектура и принципы работы

### Геометрически осознанные гауссовы поверхностные элементы (Gaussian Surfels)

- Использует гауссовы поверхностные элементы (surfels) вместо традиционных точек в 3D Gaussian Splatting
- Эти элементы обеспечивают как фотореалистичный внешний вид, так и точную геометрию
- Объединяет геометрические и визуальные аспекты в единой структуре данных
- Каждый surfel параметризован центром μ ∈ R³, ковариационной матрицей Σ, непрозрачностью o ∈ [0, 1] и цветовой информацией, зависящей от вида
- Использует 2D Gaussian surfels (GSurfels), где пространственное распределение каждого surfel приближает диск

### Ключевые компоненты системы

ObjSplat состоит из трех основных компонентов:

#### 1. Реконструкция на основе гауссовых поверхностных элементов

- Инкрементально обновляет модель объекта и совместно оптимизирует геометрию и внешний вид с использованием нормалей поверхности
- Использует surfels для представления объекта с поддержкой динамического добавления новых surfel-ов в недостаточно реконструированные области
- Прогрессивное обновление Gaussian surfels происходит путем идентификации четырех категорий недостаточно реконструированных областей:
  - Низкая непрозрачность (m_op): области, где накопленная рендеренная непрозрачность ˆO ниже порога τO = 0.5
  - Фотометрическое расхождение (m_tex): пиксели, где рендеренный цвет отклоняется от наблюдаемого цвета с MSE, превышающим τC = 0.25
  - Геометрическое отклонение (m_geo): области, где рендеренная глубина находится позади наблюдаемой глубины, превышающей среднюю ошибку глубины (MDE) множителем λ = 2
  - Поверхности с обратным направлением (m_back): области, где рендеренная нормаль образует острый угол с оптической осью камеры

#### 2. Геометрически осознанная оценка точек обзора

- Модуль восприятия, который явно квантифицирует качество реконструкции
- Идентифицирует недостаточно реконструированные и задние области через анализ видимости с учетом заслонений
- Включает три основных компонента:
  - Моделирование доверия по поводу surfel-ов: присваивает каждому Gaussian surfel атрибут достоверности κi ∈ [0, 1] для количественной оценки надежности исторических наблюдений
  - Обнаружение задних поверхностей: детектирует задние области, где рендерированная нормаль образует острый угол с оптической осью камеры
  - Оценка полноты на основе видимости: использует рендеренную непрозрачность ˆO как прямую меру геометрического покрытия

#### 3. Планирование лучшего дальнейшего пути (Next-Best-Path)

- Использует эти метрики качества для выполнения многократного просмотра на топологии пространства
- Генерирует траектории, которые глобально оптимизируют баланс между получением информации и стоимостью перемещения
- В отличие от традиционного подхода greedy NBV, использует стратегию Next-Best-Path (NBP), которая выполняет многократный просмотра на динамически построенной топологии пространства

### Основные инновации

#### Геометрически осознанная оценка точек обзора

- Вводит pipeline геометрически осознанной оценки точек обзора, который явно моделирует видимость задних поверхностей и многовидовую соприсутствие с учетом заслонений
- Обеспечивает надежное определение недостаточно реконструированных регионов, даже на геометрически сложных объектах
- Использует метрику соприсутствия с учетом заслонений (occlusion-aware covisibility metric), которая явно моделирует геометрическую видимость между видами с использованием дифференцируемого рендеринга

#### Многоступенчатое планирование

- В отличие от традиционных greedy стратегий планирования, ObjSplat использует планировщик Next-Best-Path (NBP)
- Выполняет многократное просмотра на динамически построенных пространственных графах
- Совместно оптимизирует получение информации и стоимость перемещения, генерируя глобально эффективные траектории

### Активная реконструкция

- Автономно планирует точки обзора (viewpoints) для эффективной реконструкции
- Реализует прогрессивный подход к сбору информации об объекте
- Оптимизирует траекторию просмотра для минимизации времени и пути сканирования
- Использует стратегию глобального-локального выбора точек обзора, где:
  - Локальные виды: выбираются k видов с самой высокой степенью соприсутствия ρt,j для тонкой настройки недавно наблюдаемых регионов
  - Глобальные виды: поддерживает разреженное множество глобальных видов Wglobal, отобранных из более ранних ключевых кадров вне локального окна

### Интеграция с физическими симуляциями

- Создает модели, готовые к использованию в физических симуляциях
- Генерирует водонепроницаемые меш-сетки (water-tight meshes)
- Обеспечивает высокую точность геометрии для физических расчетов
- Извлекает поверхностные меш-сетки через TSDF слияние или реконструкцию по алгоритму Поассона с использованием рендеренных карт глубины и нормалей

### Количественные результаты

- **Полнота реконструкции**: При 30 шагах ObjSplat-NBP достигает 91.42% покрытия (CR) с 3.96 м длины пути, в то время как традиционный NBV требует 18.02 м для достижения 91.89% покрытия
- **Геометрическая точность**: ObjSplat-NBP достигает 0.611 мм по метрике Chamfer Distance и 0.970 F-Score, что превосходит большинство существующих методов
- **Визуальное качество**: ObjSplat-NBP достигает 32.35 dB по PSNR, 0.966 по SSIM и 0.039 по LPIPS на тестовых видах
- **Временная эффективность**: Общее онлайн-время составляет 121.96 секунд, что на 6× быстрее, чем FisherRF и на 2.3× быстрее, чем GauSS-MI

### Преимущества по сравнению с традиционными подходами

- **Эффективность**: Требует значительно более коротких траекторий (в среднем около 4 метров) и времени (около 5 минут)
- **Качество**: Обеспечивает как визуально привлекательные, так и геометрически точные модели
- **Готовность к использованию**: Создает модели, которые можно напрямую использовать в симуляторах
- **Автономия**: Автоматически планирует оптимальные точки обзора без человеческого вмешательства
- **Полнота**: Достигает высокой полноты реконструкции (91%+) с минимальными затратами на движение
- **Устойчивость**: Демонстрирует стабильные результаты на объектах с разной геометрией и текстурой

## Архитектурные особенности

### Гауссовы поверхностные элементы (Gaussian Surfels)

- Использует непроцессированное множество 2D Gaussian surfels (GSurfels) для представления целевого объекта
- Каждый surfel параметризован центром μ ∈ R³, ковариационной матрицей Σ, непрозрачностью o ∈ [0, 1] и цветовой информацией, зависящей от вида c ∈ RK×3, используя сферические гармоники (SH) коэффициенты степени LD
- Для оптимизации ковариационная матрица Σ декомпозируется в матрицу вращения R и масштабирующую матрицу S = diag(sx, sy, 0), так что Σ = RSSTRT
- Нулевое z-масштабное ограничение обеспечивает локальную плоскостную структуру, позволяя напрямую выводить нормаль поверхности n из кватерниона q

### Совместная оптимизация геометрии-текстуры

- Совместно оптимизирует геометрические и фотометрические параметры всех Gaussian surfels с использованием комбинации терминов потерь
- Применяет фотометрическую потерю Lp для контроля за внешним видом цвета, объединяя L1-термин и термин D-SSIM
- Глубинный надзор осуществляется через L1-потерю на предсказанной глубине
- Дополнительно включает нормальный надзор Ln и потерю геометрической согласованности Lc между рендерированной нормалью и нормалью, полученной из глубины
- Для предотвращения артефактов полупрозрачного смешивания и обеспечения четких границ поверхностей регуляризует непрозрачность каждого surfel так, чтобы она имела тенденцию к полностью непрозрачному или полностью прозрачному состоянию

### Оценка неопределенности на основе геометрии

- Генерирует оценку неопределенности, взвешенную по геометрии, которая объединяет доверие surfel-ам, обнаружение задних поверхностей и полноту на основе видимости
- Использует CUDA-акселерированный растеризатор в гауссовом сплэйтинге, который позволяет рендерить карту неопределенности за ~2 мс, позволяя планированию траекторий в реальном времени
- Компоненты оценки неопределенности:
  - Карты доверия surfel-ов (K(u)): основаны на атрибуте достоверности κi, который количествует надежность исторических наблюдений
  - Баллы задних поверхностей (B(u)): обнаруживают области с неправильной стороны поверхности
  - Оценки видимости (V(u)): измеряют полноту реконструкции на основе рендерированной непрозрачности

### Алгоритм планирования Next-Best-Path (NBP)

- Формулирует задачу планирования как вариант проблемы Prize-Collecting Traveling Salesman Problem (PC-TSP)
- Генерирует пространственный топологический граф G=(V, E), где узлы V={Vcand ∪ vt}, а ребра соединяют каждую точку обзора с ее k-ближайшими соседями в евклидовом пространстве
- Назначает веса ребрам, которые балансируют расстояние движения с потенциальным получением информации
- Использует формулу: w(vi, vj) = dij / (α + β * Ui), где dij - евклидово расстояние между точками обзора vi и vj, а Ui - неопределенность в целевой точке
- Ищет топ-M кратчайших простых путей и оценивает каждый путь, компенсируя полученные награды (информацию) против длины пути

### Критерии качества

- **Visual Quality Metrics**: Peak Signal-to-Noise Ratio (PSNR), Structural Similarity Index (SSIM), Learned Perceptual Image Patch Similarity (LPIPS)
- **Geometry Quality Metrics**: Depth L1 Error (cm), Chamfer Distance (CD), F-Score@0.005m
- **Completeness and Efficiency**: Completion Ratio (CR%), Completion Error (cm), Movement Cost (m), Required Views, Time Cost (s)

## Сравнительный анализ

### Существующие методы:
- **SEE [15]**: Frontier-based метод, работающий непосредственно с облаками точек для изучения краев видимой поверхности
- **PB-NBV [21]**: Проекционный greedy планировщик NBV, максимизирующий объемную информацию
- **MA-SCVP [24]**: Основанный на облаках точек метод one-shot планирования, решает задачу покрытия множества
- **FisherRF [17]**: Information-theoretic подход, использующий Fisher Information для количественной оценки неопределенности параметров
- **GauSS-MI [20]**: Recent information-theoretic метод, использующий гауссовый splatting Shannon mutual information

### Ключевые различия:
- В отличие от FisherRF и GauSS-MI, которые полагаются на стандартный 3DGS и могут страдать от размытости и артефактов, ObjSplat вводит геометрически осознанные метрики
- В отличие от традиционных greedy NBV планировщиков, ObjSplat использует стратегию Next-Best-Path с многократным просмотра
- В отличие от one-shot методов, ObjSplat адаптивно уточняет реконструкцию на протяжении всего процесса

## Экспериментальные результаты

### Симуляция:
- Использовались 16 разнообразных моделей из датасета Google Scanned Objects (GSO)
- Симулировалась RGB-D камера с разрешением 1280×720, полем зрения 90°×65° и диапазоном глубины [0.1, 3.0] м
- ObjSplat достигает лучшей полноты реконструкции (91.42% против 69-72% для базовых методов) 
- Также показывает лучшие результаты по геометрической точности (0.611 мм по Chamfer Distance против 2-4 мм для базовых методов)

### Реальные эксперименты:
- Проведены на 4 сложных объектах: скульптура Sika Deer, реплика Fu Hao Owl Zun, реплики Sancai Horse и Pottery Figure
- Система завершала реконструкцию с траекторией менее 4.0 м
- Демонстрирует способность восстанавливать тонкие геометрические детали и ричную текстуру

## Технические детали

### Обработка в реальном времени:
- Онлайн картирование: SH степень установлена в L_D=0 для уменьшения вычислительной нагрузки
- Каждый новый кадр подвергается 10 итерациям оптимизации
- Локальное окно оптимизации ограничено top-k=9 наиболее соприсутствующими ключевыми кадрами
- Оффлайн донастройка: 7000 итераций оптимизации с восстановлением высших порядков SH (L_D=3)

### Оценка качества:
- Визуальные метрики: PSNR, SSIM, LPIPS
- Геометрические метрики: Depth L1, Chamfer Distance, F-Score
- Метрики полноты: Completion Ratio (CR), Completion Error
- Эффективность: Общее расстояние движения, количество требуемых точек обзора, время выполнения

## Ограничения и будущая работа

### Текущие ограничения:
- Система в настоящее время адаптирована для реконструкции отдельных, статических, жестких объектов
- Обработка сложных оптических свойств (экстремальные изменения освещения, прозрачность или высокая зеркальность) остается вызовом для текущей модели рендеринга
- Пока не рассматривает динамические объекты или сцены с несколькими объектами

### Направления будущей работы:
- Интеграция методов оценки устойчивости материалов
- Исследование динамических представлений объектов
- Расширение сферы автономного цифрового дублирования на интерактивные и неуправляемые среды реального мира
