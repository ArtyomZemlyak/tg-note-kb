# Qwen-Image-Edit-2511

## Обзор

**Qwen-Image-Edit-2511** - это расширенная модель редактирования изображений, представленная 23 декабря 2025 года, разработанная для точного редактирования изображений с улучшенной согласованностью и поддержкой нескольких изображений.

### Основные особенности и возможности

#### 1. Улучшенная согласованность персонажей
- Значительно улучшенное сохранение идентичности персонажа при воображаемом редактировании
- Лучшее сохранение идентичности лица, поддерживающее различные стили портретов и преобразования поз
- Сохраняет визуальные характеристики субъектов при возможности творческих модификаций

#### 2. Согласованность нескольких человек
- Улучшенная согласованность в групповых фотографиях с несколькими людьми
- Возможность высокоточной интеграции отдельных изображений людей в когерентные групповые снимки
- Превосходная производительность с 1-3 входными изображениями для оптимальных результатов

#### 3. Поддержка редактирования нескольких изображений
- Поддерживает различные комбинации, такие как "человек + человек", "человек + продукт", "человек + сцена"
- Расширенная архитектура для одновременной обработки нескольких входных изображений

#### 4. Встроенная поддержка LoRA
- Интегрирует популярные LoRA, созданные сообществом, непосредственно в базовую модель
- Не требуется дополнительная настройка для эффектов LoRA
- Примеры включают LoRA для улучшения освещения для реалистичного контроля освещения
- Поддерживает генерацию точек обзора непосредственно из базовой модели

#### 5. Промышленное проектирование
- Возможности пакетного промышленного проектирования продуктов
- Замена материалов для промышленных компонентов
- Поддержка практических сценариев проектирования

#### 6. Улучшенное геометрическое рассуждение
- Более сильные возможности геометрического рассуждения
- Может генерировать вспомогательные линии построения для проектирования или аннотаций

## Технические спецификации

- **Дата выпуска**: 23 декабря 2025 года
- **Архитектура**: Основана на 20B MMDiT (Multi-Modal Diffusion Transformer)
- **Точность**: Поддерживает bfloat16 точность
- **Шаги инференса**: Рекомендуется 40 шагов для оптимальных результатов
- **Шкала истинного CFG**: 4.0 (рекомендуется)
- **Шкала руководства**: 1.0 (для многократных входных изображений)

## Использование

### Основное использование
```python
import os
import torch
from PIL import Image
from diffusers import QwenImageEditPlusPipeline
from io import BytesIO
import requests

pipeline = QwenImageEditPlusPipeline.from_pretrained("Qwen/Qwen-Image-Edit-2509", torch_dtype=torch.bfloat16)
pipeline.to('cuda')

image1 = Image.open(BytesIO(requests.get("https://qianwen-res.oss-accelerate-overseas.aliyuncs.com/Qwen-Image/edit2511/edit2511input.png").content))
prompt = "эта девушка смотрит на телевизионный экран перед собой, на экране написано \" Alibaba\""

inputs = {
    "image": [image1],
    "prompt": prompt,
    "generator": torch.manual_seed(0),
    "true_cfg_scale": 4.0,
    "negative_prompt": " ",
    "num_inference_steps": 40,
    "guidance_scale": 1.0,
    "num_images_per_prompt": 1,
}

with torch.inference_mode():
    output = pipeline(**inputs)
    output_image = output.images[0]
    output_image.save("output_image_edit_2511.png")
```

## Оптимизации производительности

### Поддержка аппаратного ускорения
- **LightX2V**: Обеспечивает поддержку Day 0 с 25x сокращением DiT NFEs и 42.55x общим ускорением
- Поддерживает NVIDIA, Hygon, Metax, Ascend и Cambricon оборудование
- Редактирование изображений в реальном времени на различных ускорителях ИИ

### Высокопроизводительный инференс
- **vLLM-Omni**: Поддерживает высокопроизводительный инференс Qwen-Image-Edit-2511
- Включает параллелизм длинных последовательностей, ускорение кэширования и быстрые ядра
- **SGLang-Diffusion**: Обеспечивает поддержку Day 0 для моделей Qwen-Image
- [[../diffusion_models/sglang_diffusion.md]] - Подробное описание SGLang Diffusion, фреймворка, обеспечивающего поддержку Day 0 для моделей Qwen-Image

## Технические требования

- **Зависимости**: transformers>=4.51.3, последние diffusers
- **Оборудование**: Рекомендуется GPU с поддержкой CUDA
- **Память**: Доступна поддержка нескольких GPU для крупномасштабных операций

## Доступность модели

- **HuggingFace**: Доступна в "Qwen/Qwen-Image-Edit-2509" (примечание: использует идентификатор 2509 в текущей реализации)
- **ModelScope**: Доступна для загрузки
- **Qwen Chat**: Интегрирована для онлайн-опыта

## Расширенные возможности

- Встроенная поддержка ControlNet (карты глубины, карты краев, карты ключевых точек)
- Инструменты улучшения запросов для повышения стабильности
- Поддержка нескольких соотношений сторон
- Управление очередью для высокой конкурентности в API-развертываниях
