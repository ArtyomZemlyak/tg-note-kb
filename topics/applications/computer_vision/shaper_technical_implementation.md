# ShapeR: Техническая реализация робастной условной генерации 3D-форм

## Краткое описание

ShapeR представляет собой передовой метод генерации 3D-форм, который использует комбинацию разреженных точек SLAM, изображений с нескольких точек зрения и текстовых описаний для создания метрически точных 3D-моделей объектов из повседневных снимков. Технически система реализует революционный подход к 3D-восстановлению с использованием трансформеров с исправленным потоком.

## Техническая реализация

### Архитектура модели

ShapeR использует архитектуру трансформера с исправленным потоком, которая работает с VecSet-латентными представлениями. Модель генерирует код формы объекта, который затем декодируется в 3D-меш. Архитектура включает:

- **Кодировщик точечных облаков**: Использует разреженные 3D-свертки для обработки SLAM-точек
- **Функция извлечения признаков изображений**: Использует DINOv2 и признаки лучей для анализа изображений
- **Модель исправленного потока**: Основной компонент, который генерирует формы через процесс диффузии
- **3D-VAE**: Автоэнкодер для преобразования между латентным и меш-представлениями форм

### Процессинг данных

1. **Входные данные**: Сериализованные pickle-файлы с предобработанными данными
2. **Содержимое файлов**: Точечные облака, многовидовые изображения, параметры камеры, текстовые аннотации и эталонные меш-модели
3. **Предобработка**: Использование конвейера ARIA MPS и детектора 3D-объектов

### Инференс конфигурации

- **Качество**: 16 видов, 50 шагов (лучшее качество, медленнее всего)
- **Баланс**: 16 видов, 25 шагов (рекомендуемый вариант)
- **Скорость**: 4 вида, 10 шагов (быстрее всего)

### Объектно-ориентированный подход

Модель применяется индивидуально к каждому обнаруженному объекту, что позволяет:
- Использовать манипуляции с отдельными объектами в сцене
- Обеспечивать метрическую точность на уровне отдельных объектов
- Обрабатывать сложные сцены с несколькими объектами

## Обучение модели

ShapeR обучается исключительно на синтетических данных с использованием двухступенчатой программы:
- **Предварительное обучение на одиночных объектах**: Тренировка на данных с одним объектом
- **Куррикулярное обучение**: Постепенное усложнение данных от простых до сложных сценариев
- **Составные аугментации**: Использование сильных аугментаций в процессе обучения для повышения робастности

## Применение и результаты

ShapeR достигает значительных результатов по сравнению с предыдущими методами:
- Высокая метрическая точность восстановления форм
- Робастность к реальным сценариям с заглушениями и зашумленностью
- Возможность работы с casually-сфотографированными последовательностями
- Хорошее обобщение с синтетических на реальные данные

## Сравнение с аналогами

| Метод | Подход | Тип данных | Метрическая точность | Робастность |
|-------|--------|------------|---------------------|-------------|
| ShapeR | Объектно-ориентированный, трансформер с исправленным потоком | Casual captures | Высокая | Высокая |
| 3D Gaussian Splatting | Растеризация гауссиан | Multi-view фото | Высокая | Средняя |
| NeRF | Нейронные радиационные поля | Multi-view фото | Высокая | Низкая |

## Ограничения и будущие направления

- Требует предварительной сегментации объектов в сцене
- Необходимость качественной SLAM-обработки
- Ограниченная поддержка динамических сцен
- Лицензия CC BY-NC ограничивает коммерческое использование
