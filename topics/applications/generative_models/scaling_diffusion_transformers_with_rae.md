# Масштабирование трансформеров диффузии с использованием RAE

## Общее описание

Исследование масштабирования Text-to-Image диффузионных трансформеров с использованием Representation Autoencoders (RAE) представляет собой важный шаг в понимании альтернативных подходов к архитектуре VAE при генерации изображений на основе текстового описания. В отличие от традиционных VAE, RAE кодируют как высокочастотную информацию (необходимую для качества реконструкции), так и семантическую информацию, что делает их особенно подходящими для задач масштабирования.

## Архитектурные особенности

### Инициализация и обучение RAE

RAE инициализируются с использованием семантических энкодеров (например, SigLIP или WebSSL), что обеспечивает хорошую стартовую точку для обучения. После инициализации RAE дообучаются на задачу реконструкции с применением нескольких видов лоссов:

- **LPIPS (Learned Perceptual Image Patch Similarity)** - обеспечивает качество восприятия
- **Грам лосс** - сохраняет стилистические особенности
- **Адверсариальный лосс** - повышает реалистичность генераций
- **Реконструкция** - точное восстановление исходного изображения

### MetaQuery архитектура

Ключевой особенностью RAE является использование MetaQuery - последовательности обучаемых токенов фиксированной длины (256 токенов для изображений 224x224), которые соответствуют выходному пространству RAE. Эта архитектура позволяет эффективно обрабатывать как визуальные, так и текстовые признаки в едином представлении.

### Обучение: претрейн и файнтюн

Обучение RAE состоит из двух этапов:
1. **Претрейн** - обучение на больших объемах данных для захвата общих признаков
2. **Файнтюн** - тонкая настройка на более качественных и специфических данных

## Экспериментальные результаты

### Обучающие настройки

- **Текстовый энкодер**: Qwen-2.5 1.5B параметров
- **Диффузионная модель**: DiT (Diffusion Transformer) 2.4B параметров
- **Итоговый объем**: Общая система ~3.9B параметров

### Сравнение с VAE

Сравнение RAE (на основе SigLiP-2) с VAE (на основе FLUX) показало следующие результаты:
- RAE **сходятся значительно быстрее**, чем VAE при обучении text-to-image моделей с нуля
- В **GenEval** RAE опережает VAE в 4.0 раза
- В **DPG-Bench** RAE опережает VAE в 4.6 раза
- Качество реконструкции находится между SDXL VAE и FLUX VAE

### Влияние состава данных

Исследование показало, что:
- Смешивание реальных и синтетических данных дает лучшие результаты, чем увеличение количества данных одного типа
- Синтетические данные играют важную роль в улучшении качества генерации
- Правильный баланс между типами данных критичен для достижения наилучших результатов

## Архитектурные особенности при масштабировании

### Что работает хорошо
- **Сдвиг расписания (flow shift)** остается важным при масштабировании
- **Доливание текстовых данных** важно для реконструкции текстов
- **Использование семантических энкодеров** для инициализации

### Что меняется при масштабировании
- В отличие от оригинальных RAE, для задач text-2-image:
  - Шумление латентов дает меньше прироста при длительном обучении
  - Широкая DDТ голова менее критична
  - Более важна архитектурная стабильность при долгом обучении

## Тест-тайм возможности

Интересной особенностью RAE является способность оценивать качество собственных генераций, что позволяет использовать подходы типа **Best-of-N** для улучшения качества на этапе инференса без дополнительного обучения.

## Вычислительная эффективность

### Преимущества RAE
- Более быстрая сходимость - значит меньше GPU часов на обучение
- Эффективное использование вычислительных ресурсов за счет лучшей конвергенции
- Возможность ранней остановки обучения при достижении целевых метрик

### Ограничения
- После достижения определенного порога дальнейший рост размера модели не дает значительного прироста качества
- Ограниченность определяется скорее данными, чем параметрами модели

## Значение для области

Эта работа предоставляет важную валидацию подхода RAE в масштабе text-2-image задач, показывая, что:
1. RAE могут эффективно конкурировать с VAE в задачах генерации изображений
2. Скорость сходимости может быть критическим преимуществом при ограниченных вычислительных ресурсах
3. Новая архитектура открывает возможности для новых подходов к масштабированию
