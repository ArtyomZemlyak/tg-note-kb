# Двухбашенная архитектура (Two-Tower Architecture)

## Описание

Двухбашенная архитектура — это популярная архитектура рекомендательных систем, в которой используются две отдельные нейронные сети: одна для представления пользователей, другая для представления айтемов (документов, продуктов и т.д.). Каждая "башня" генерирует эмбеддинги, которые затем используются для вычисления схожести или релевантности.

## Структура архитектуры

### User Tower
- Обрабатывает признаки пользователя: история взаимодействий, демографические данные, контекстные признаки
- Генерирует эмбеддинг пользователя u ∈ R^d
- Может использовать рекуррентные сети, трансформеры или другие архитектуры

### Item Tower  
- Обрабатывает признаки айтема: контентные признаки, метаданные, текстовое описание
- Генерирует эмбеддинг айтема v ∈ R^d
- Обычно обучается отдельно от user tower

### Функция схожести
- Обычно вычисляется как косинусное сходство или скалярное произведение: sim(u,v) = u · v / ||u||||v||
- Иногда используется дополнительный ранжирующий компонент для уточнения оценок

## Преимущества

- **Масштабируемость**: можно заранее вычислить эмбеддинги айтемов и использовать эффективные методы ANN (Approximate Nearest Neighbor)
- **Гибкость**: каждая башня может использовать разные признаки и архитектуры
- **Производительность**: на этапе инференса требуется только вычисление сходства

## Проблемы и вызовы

- **Проблема стабильности**: при дообучении модели эмбеддинги могут "повернуться", сохраняя при этом хорошие предсказания, но нарушая стабильность
- **Синхронизация**: необходимо согласованное обновление обеих башен
- **Размерность**: выбор оптимальной размерности эмбеддингов
