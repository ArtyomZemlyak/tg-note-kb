# Подборка статей 2025 (часть 3): Attention-based Ranking

## Описание

Эта подборка представляет собой обзор ключевых исследований 2025 года в области attention-based ranking в рекомендательных системах. Включает в себя как традиционные подходы к ранжированию с использованием attention-механизмов, так и современные методы масштабирования и оптимизации для промышленного применения.

## Ключевые направления

### 1. Масштабирование моделирования длинных последовательностей (LONGER)

LONGER (Scaling Up Long Sequence Modeling in Industrial Recommenders) - это новая архитектура трансформера, оптимизированная для рекомендательных систем на GPU. Метод включает:

- **Token Merging**: группировка рядом стоящих токенов для уменьшения эффективной длины последовательности с L до L/K, снижая FLOPs аттеншна примерно на 40-50%
- **InnerTrans**: внутренний трансформер для улучшения качества при объединении токенов
- **Global Tokens**: глобальные токены как "якоря" для профилей пользователей и контекстных признаков
- **Оптимизации обучения**: BF16/FP16 обучение, пересчет активаций на backward, KV Cache Serving для инференса

См. также: [[../../transformer_based_models.md]], [[../../long_context_handling_methods.md]]

### 2. Моделирование долгосрочного поведения на Pinterest (TransAct V2)

TransAct V2 - производственная модель для системы ранжирования ленты Pinterest, включающая три ключевые инновации:

- **Использование очень длинных пользовательских последовательностей**: эффективное моделирование последовательностей поведения пользователей длиной в месяцы и годы
- **Масштабируемый attention**: архитектура, позволяющая обрабатывать гораздо более длинные последовательности, чем традиционные трансформеры
- **Жизненное моделирование последовательностей**: способность улавливать долгосрочные и краткосрочные интересы пользователей одновременно

### 3. Двойной поток генеративных сетей ранжирования (Twin-Flow GRN)

Twin-Flow Generative Ranking Network (TFGRN) - архитектура, разделяющая моделирование пользовательских интересов и айтемов для улучшения производительности:

- Два независимых потока для пользовательского и айтемного представления
- Повышенная эффективность при увеличении размера каталога
- Возможность параллельной обработки различных компонентов системы
- Генеративный подход к ранжированию, позволяющий моделировать распределения айтемов

### 4. Эффективное гетерогенное взаимодействие (InterFormer)

InterFormer - архитектура трансформера для эффективного обучения гетерогенным взаимодействиям в задаче предсказания CTR:

- Динамическое чередование признаков для эффективного масштабирования
- Обработка различных типов признаков в единой архитектуре
- Использование специализированных attention-голов для разных типов взаимодействий
- Улучшенная масштабируемость по сравнению с традиционными подходами

### 5. Аугментация памяти и масштабируемая сложность (MARM)

MARM (Memory-Augmented Recommendation Model) разблокирует закон масштабирования кэша рекомендаций:

- Аугментация памяти для хранения и извлечения прошлых взаимодействий
- Масштабируемая вычислительная сложность
- Оптимизация использования памяти при увеличении размера системы
- Обучение масштабируемых кэшей для рекомендательных моделей

### 6. Единый фреймворк для эффективного реранжирования (GReF)

GReF (Generative Framework for Efficient Reranking) - единый генеративный фреймворк для эффективного реранжирования через упорядоченное предсказание по нескольким токенам:

- Архитектура, оптимизированная для финального реранжирования
- Моделирование упорядоченных последовательностей айтемов
- Генеративный подход к реранжированию, обеспечивающий лучшее качество

### 7. Масштабирование ранжирующих моделей (RankMixer)

RankMixer - аппаратно-ориентированный дизайн модели для рекомендательных систем промышленного масштаба:

- Новая архитектура для масштабирования ранжирующих моделей
- Аппаратная оптимизация для эффективного развертывания
- Улучшенная производительность и эффективность

### 8. Эффективные законы масштабирования (Climber)

Climber - подход к эффективным законам масштабирования для больших рекомендательных моделей:

- Специализированная архитектура модели
- Совместно разработанные ускоряющие методы
- Исследование оптимального соотношения параметров, данных и вычислительных ресурсов

### 9. Промышленный генеративный рекомендательный фреймворк (MTGR)

MTGR (Meituan Generative Recommendation) - генеративный рекомендательный фреймворк промышленного масштаба:

- Основан на архитектуре HSTU
- Генеративный подход к рекомендациям
- Масштабируемость для промышленного использования

### 10. Action is All You Need (Dual-Flow GRN)

Action is All You Need - двойной поток генеративной сети ранжирования для рекомендаций:

- Новаторская архитектура с двумя потоками для эффективного ранжирования
- Учет пользовательских действий в модели
- Генеративный подход к моделированию предпочтений

### 11. Конечная модельрование 10k-последовательностей (Make It Long, Keep It Fast)

End-to-End 10k-Sequence Modeling at Billion Scale on Douyin - система масштабирования моделирования длинных последовательностей:

- Конечная система моделирования последовательностей длиной до 10k элементов
- Масштабирование до миллиардных масштабов
- Подход "сделай длинным, держи быстрым" для сохранения эффективности

### 12. Единая архитектура трансформера (OneTrans)

OneTrans - единый трансформер для взаимодействия признаков и моделирования последовательностей:

- Единый трансформерный стек как основа
- Совместное выполнение моделирования последовательностей поведения пользователей и взаимодействия признаков
- Единый токенизатор для последовательных и не-последовательных атрибутов
- Унификация архитектуры для снижения сложности и повышения эффективности

### 13. Массовое запоминание (Massive Memorization)

Massive Memorization with Hundreds of Trillions of Parameters - исследование масштабного запоминания:

- Использование сотен триллионов параметров для запоминания прошлого поведения
- Методы эффективного использования памяти при больших масштабах
- Влияние размера модели на способность к запоминанию и обобщению

### 14. Практики моделирования длинных поведенческих последовательностей в рекламе Tencent

Practice on Long Behavior Sequence Modeling in Tencent Advertising - практический опыт:

- Практические подходы к моделированию длинных поведенческих последовательностей в рекламной платформе Tencent
- Архитектуры для обработки долгосрочной истории пользователей
- Инженерные решения для масштабирования в промышленных условиях

### 15. Пирамидальный миксер (Pyramid Mixer)

Pyramid Mixer - многомерное много-периодное моделирование интересов для последовательных рекомендаций:

- Использование архитектуры MLP-Mixer для эффективного и полного взаимодействия
- Моделирование интересов на разных временных шкалах
- Пирамидальная структура для захвата интересов разного уровня абстракции

### 16. Адаптивное масштабирование доменов (Adaptive Domain Scaling)

Adaptive Domain Scaling (ADS) - адаптивное масштабирование для персонализованного последовательного моделирования:

- Улучшение персонализационных возможностей в таргетно-ориентированном моделировании последовательностей
- Адаптация к различным доменам и сценариям использования
- Моделирование интересов в различных доменах

### 17. Переосмысление трансформеров для CTR-предсказания

From Features to Transformers: Redefining Ranking for Scalable Impact - переосмысление трансформеров:

- Переход от традиционных подходов на основе признаков к современным трансформерным архитектурам
- Архитектуры, ориентированные на масштабируемый эффект
- Оптимизация для достижения максимального влияния

### 18. От масштабирования к структурированной экспрессивности

From Scaling to Structured Expressivity: Rethinking Transformers for CTR Prediction - структурированная экспрессивность:

- Переход от масштабирования только за счет размера к структурированной экспрессивности
- Архитектурная согласованность как ключ к эффективности
- Внедрение приоритетов взаимодействия признаков на основе домена

### 19. Мета-решетка для рекламных рекомендаций (Meta Lattice)

Meta Lattice: Model Space Redesign for Cost-Effective Industry-Scale Ads Recommendations:

- Перепроектирование пространства моделей для экономически эффективных рекламных рекомендаций
- Архитектурные решения для снижения вычислительных затрат
- Масштабируемые решения для промышленных рекламных систем
