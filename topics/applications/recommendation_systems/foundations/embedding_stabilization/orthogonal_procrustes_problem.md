# Ортогональная задача Прокруста (Orthogonal Procrustes Problem)

## Описание

Ортогональная задача Прокруста — это математическая задача оптимизации, в которой требуется найти ортогональную матрицу, которая наилучшим образом отображает одну матрицу в другую. В контексте стабилизации эмбеддингов, задача используется для приведения текущего пространства эмбеддингов к эталонному пространству.

## Формулировка задачи

Формально, имея матрицы A (текущее пространство) и B (эталонное пространство), требуется найти такую ортогональную матрицу R, что RA ≈ B, минимизируя ||RA - B||F, где ||·||F — фробениусова норма.

## Решение

Задача решается с помощью сингулярного разложения (SVD). Пусть M = BAᵀ, и пусть M = UΣVᵀ — сингулярное разложение M. Тогда оптимальная ортогональная матрица R = UVᵀ.

В некоторых случаях, чтобы гарантировать, что R — это вращение (det(R) = 1), а не отражение, может потребоваться корректировка:

R = U diag(1,...,1,det(UVᵀ)) Vᵀ

## Применение в стабилизации эмбеддингов

В контексте стабилизации эмбеддингов задача Прокруста используется для отображения текущего пространства эмбеддингов в эталонное пространство. Это позволяет:
- Сохранить геометрические свойства пространства
- Обеспечить стабильность между версиями модели
- Сохранить значения скалярных произведений

## Свойства

- Решение всегда существует и единственно (с точностью до отражений)
- Оптимальная матрица R сохраняет евклидовы расстояния
- Трансформация является изометрией, что сохраняет внутренние произведения векторов
