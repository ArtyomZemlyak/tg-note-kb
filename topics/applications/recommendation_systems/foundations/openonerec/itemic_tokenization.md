# Itemic Tokenization: Иерархический подход к представлению айтемов в LLM

## Общее описание

**Itemic Tokenization** - это инновационный подход, представленный в фреймворке OpenOneRec, для представления айтемов (например, продуктов, видео, публикаций) в пространстве больших языковых моделей (LLM). Основная проблема, которую решает этот подход, - это несоответствие между непрерывным языковым пространством и дискретным пространством айтемов.

## Проблема

Традиционные подходы к представлению айтемов в LLM сталкиваются с двумя крайностями:
- **Детальные текстовые описания**: Приводят к излишне длинным контекстам для истории пользователя
- **Дискретные ID**: Не гарантируют генерацию айтемов из корпуса и затрудняют семантическое понимание

Itemic Tokenization предлагает промежуточное решение, используя иерархическую квантизацию для сжатия семантики айтемов в короткие, фиксированные последовательности токенов.

## Методология

### 1. RQ-Kmeans: Иерархическая квантизация

- **RQ (Residual Quantization)**: Метод квантизации, при котором вектор разбивается на несколько уровней, каждый из которых кодируется отдельно
- **K-means**: Применяется на каждом уровне для определения кодовых книг
- **Семантические эмбеддинги**: Используются предобученные эмбеддинги метаданных айтемов

### 2. Трехуровневая схема квантизации

Каждый айтем i отображается в кортеж иерархических кодов:
```
S_i = (c1, c2, c3)
```
где:
- `c1`: Грубый уровень (наиболее общий)
- `c2`: Средний уровень (средняя детализация)
- `c3`: Детальный уровень (наиболее специфичный)

Каждый уровень имеет размер кодовой книги 8192.

### 3. Формат токенизации

- Токены заключаются в специальные токены: `<|item_begin|>` и `<|item_end|>`
- Формат токенов: `<item_a_xxx><item_b_yyy><item_c_zzz>` где a, b, c соответствуют трем уровням иерархии

## Преимущества

### 1. Эффективное моделирование длинных контекстов
- Сжатие семантики айтемов в короткие последовательности
- Возможность эффективного моделирования длинных историй пользователей

### 2. Сохранение коллаборативной структуры
- Сохранение информации о схожести айтемов через близость токенов

### 3. Передача знаний через близость токенов
- Айтемы с похожей семантикой делят общие префиксы токенов
- Возможность передачи знаний на основе схожести токенов

### 4. Интеграция с LLM архитектурами
- Совместимость с существующей инфраструктурой трансформеров
- Возможность использования стандартных методов обучения

## Применение в OpenOneRec

### В предобучении:
- **Itemic Dense Caption Data**: Обучение модели ассоциировать itemic токены с текстовыми описаниями
- **Sequential User Behavior Data**: Использование itemic токенов для next-item prediction
- **Interleaved User Persona Grounding Data**: Интеграция itemic токенов с пользовательскими портретами

### В бенчмарке RecIF-Bench:
- Предварительная токенизация всех айтемов в датасете
- Возможность прямого потребления LLM-рекомендательными системами
- Гибкость: исследователи могут использовать предоставленные эмбеддинги для обучения собственных токенизаторов

## Адаптация для домена приложения

При переносе на другие домены (например, Amazon) были протестированы три стратегии:

### 1. Расширенная остаточная квантизация
- Добавление четвертого уровня через FSQ (Finite Scalar Quantization)
- Снижение коллизий до 3.05%
- Улучшение среднего R@10 на 10.0% по сравнению с LC-Rec

### 2. Адаптация только текста
- Представление айтемов через 5 ключевых слов из метаданных
- Снижение коллизий до 4.27%
- Улучшение среднего R@10 на 18.8% по сравнению с расширенной квантизацией

### 3. Текст-расширенные Itemic токены (рекомендуется)
- Сохранение оригинальных itemic токенов + конкатенация ключевых слов
- Снижение коллизий до 0.47%
- Сохранение иерархической семантики и лингвистических возможностей

## Значение и влияние

Itemic Tokenization представляет собой важный шаг к интеграции рекомендательных систем с LLM, позволяя:
- Эффективно представлять айтемы в пространстве LLM
- Сохранять и использовать семантические отношения между айтемами
- Масштабировать рекомендательные возможности с использованием LLM архитектур
- Поддерживать интероперабельность с существующими подходами к рекомендациям
