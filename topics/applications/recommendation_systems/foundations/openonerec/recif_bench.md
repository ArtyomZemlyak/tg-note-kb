# RecIF-Bench: Голистический бенчмарк для рекомендаций с инструкциями

## Общее описание

**RecIF-Bench** - это первый комплексный бенчмарк, разработанный для всесторонней оценки возможностей фундаментальных моделей рекомендаций в выполнении задач через инструкции. В отличие от традиционных бенчмарков, ограниченных точностью ранжирования в замкнутом множестве внутри одного домена, RecIF-Bench оценивает широкие возможности LLM в рекомендательных системах.

## Структура бенчмарка

### 1. Данные

**Статистика датасета:**
- ~120M взаимодействий
- ~200K уникальных пользователей
- **~15M+ айтемов**
- Три гетерогенных домена с различными характеристиками:
  - **Короткие видео**: Очень длинные истории пользователей с сотнями взаимодействий
  - **Реклама**: Меньше айтемов и кликов по сравнению с видео
  - **Продукты (e-commerce)**: Отдельный домен со своими паттернами поведения
- Богатые метаданные:
  - **User-side**: Пользовательские портреты (User Portrait), содержащие демографию, историю создания контента, поисковые запросы, поведение просмотра и покупок, подписки
  - **Item-side**: Мультимодальные эмбеддинги (4096-дим текстовый эмбеддинг и 5-кадровые визуальные эмбеддинги с 1152-дим на кадр), плотные описания (dense captions) для ~13M видео
  - **Interaction-side**: Многоуровневые сигналы поведения (лайк, подписка, комментарий, эффективный просмотр, дизлайк)

### 2. Иерархия задач (4 уровня)

**L0: Семантическое выравнивание**
- **Понимание айтема (Item Understanding)**: Генерация текстового описания по itemic токену, проверяет выравнивание между токенами айтемов и языковыми токенами

**L1: Фундаментальная рекомендация**
- **Рекомендация коротких видео**: Прогноз следующего видео на основе истории просмотра
- **Рекламная рекомендация**: Прогноз следующей рекламы на основе истории взаимодействия
- **Продуктовая рекомендация**: Прогноз следующего продукта на основе истории просмотра и покупки
- **Прогнозирование метки**: Бинарная классификация - предсказание взаимодействия с кандидатом

**L2: Следование инструкциям**
- **Интерактивная рекомендация**: Рекомендация на основе пользовательского портрета и естественно-языкового запроса
- **Условная по метке рекомендация**: Рекомендация айтемов для конкретного типа действия (лайк, шер, и т.д.)

**L3: Логическое мышление**
- **Объяснение рекомендаций**: Генерация естественно-языкового объяснения, почему айтем соответствует пользовательскому профилю

## Метрики оценки

### Рекомендательные метрики (L1 & L2)
- **Pass@K**: Вероятность, что целевой айтем находится в топ-K сгенерированных кандидатов
- **Recall@K**: Пропорция релевантных айтемов, извлеченных из K кандидатов

### Метрики генерации текста (L0 & L3)
- **LLM-as-Judge**: Использование независимой LLM для оценки качества генерации по размерам точности и когерентности

## Проверка здравого смысла: Общие возможности

Для оценки сохранения общих возможностей моделей рекомендаций, RecIF-Bench включает санитарную проверку, охватывающую четыре категории:
- **Математика и текстовые рассуждения**: MATH-500, GSM8K, AIME'24
- **Общие задачи**: MMLU-Pro и GPQA-Diamond
- **Выравнивание**: IFEVAL (строгий промт)
- **Кодирование**: LiveCodeBench v5

## Стратегия разделения данных

- **Строгое пользовательское разделение**: 20% пользователей полностью исключаются из обучающей выборки
- **Временное разделение**: Последовательность взаимодействий каждого пользователя делится по времени: данные до определенного таймстемпа - история, после - цель для оценки

## Значение и влияние

RecIF-Bench играет ключевую роль в развитии фундаментальных моделей для рекомендаций, предоставляя:
- **Единый стандарт**: Комплексная оценка всех аспектов рекомендательных возможностей
- **Тестовая среда**: Оценка синергии между следованием инструкциям и рекомендациями
- **Платформу для сравнения**: Возможность справедливого сравнения различных подходов
- **Направляющий принцип**: Четкая цель для разработки более интеллектуальных рекомендательных систем
