# OxygenREC: Инструкционно-ориентированная генеративная рекомендательная система

## Описание

OxygenREC - это инновационная инструкционно-ориентированная генеративная рекомендательная система, разработанная для масштабных e-commerce приложений. Система объединяет возможности дедуктивных рассуждений и мульти-сценарное адаптацию в единой архитектуре, преодолевая ограничения традиционных рекомендательных систем, которые страдают от несогласованности многоступенчатых оптимизационных целей и ограниченных возможностей дедуктивных рассуждений.

## Ключевые аспекты

### Fast-Slow Thinking архитектура
OxygenREC использует архитектуру "Fast-Slow Thinking" для интеграции знаний и дедуктивных рассуждений без введения онлайн задержек:
- **Slow thinking**: Близко-линейный LLM пайплайн выполняет медленное рассуждение о намерениях и генерирует высокоточные Инструкции Контекстных Рассуждений (Contextual Reasoning Instructions)
- **Fast thinking**: Высокопроизводительная энкодер-декодер архитектура для генерации в реальном времени на основе этих инструкций

### Инструкционно-ориентированная генерация
Система преобразует рекомендацию в задачу генерации последовательностей на основе инструкций:
- **Сценарные инструкции (Is)**: определяют контекст сценария для контролируемой генерации
- **Контекстные рассуждающие инструкции (Ir)**: указывают скрытые намерения пользователя через адаптер

### Instruction-Guided Retrieval (IGR)
Для усиления контролируемой генерации используется IGR для фильтрации исторического контекста и выбора взаимодействий, наиболее релевантных инструкциям:
- **Adapter Mechanism**: проектирует инструкции и айтемы в общее эмбеддинговое пространство
- **Q2I alignment**: использует целевой айтем для обучения супервизии схожести инструкция-айтем
- **IGR**: выполняет topK ретривал во время инференса для предоставления декодеру контекста, выровненного с инструкцией

### Мульти-сценарная адаптация
OxygenREC реализует парадигму "обучай один раз - разворачивай везде" (train-once-deploy-everywhere):
- Использует единый backbone для всех сценариев
- Применяет сценарные инструкции для адаптации поведения модели
- Использует SA-GCPO (Soft Adaptive Group Clip Policy Optimization) для синхронизации единой политики с различными бизнес-объективами

## Архитектура

### Общая структура
OxygenREC объединяет различные задачи рекомендаций в единую инструкционно-ориентированную генеративную парадигму:
1. **Model Input Representation**: интегрирует профиль пользователя, поведение и контекст в единое пространство
2. **Instruction-Following Pre-training**: модель обучается следовать инструкциям через мульти-задачный объектив
3. **Post-training with Multi-Scenario Alignment**: использует систему reward mapping для перевода различных сценарных целей в унифицированные сигналы вознаграждения
4. **Multi-Scenario Serving**: позволяет одной модели обслуживать различные сценарии одновременно

### Модельное представление
- **Энкодер**: отображает пользовательские входы в латентное пространство
- **Декодер**: генерирует рекомендательные последовательности на основе инструкций
- **Мультимодальные квантованные представления**: айтемы представлены как мультимодальные семантические ID (SIDs)

## Технические детали

### Мультимодальные квантованные представления айтемов
- Используется контрастивное обучение Item-to-Item (I2I) с использованием пар айтемов на основе крос-сценарного поведения
- Встроенные текстовые метаданные и изображения продуктов обрабатываются отдельными энкодерами
- Применяется схема RQ-KMeans для квантование эмбеддингов
- Иерархическая структура с глубиной 3 и размером словаря 8,192 на уровне

### Контекстные рассуждающие инструкции
Получены через три параллельные ветки:
- **Spatiotemporal and profile Reasoning**: инференс явных потребностей пользователя в конкретных условиях окружения
- **User Query Rewrite**: семантическое завершение и нормализация поисковых запросов
- **User Intent Reasoning**: генерация инструкций, соответствующих намерениям, и их логических обоснований

## Результаты и влияние

OxygenREC была успешно развернута в JD.com в различных сценариях рекомендаций, включая:
- Homepage Floor (сценарии 1 и 2)
- Channel Feeds (сценарии 3 и 4) 
- Checkout Path (сценарии 5 и 6)

Система показала статистически значимые улучшения по ключевым бизнес-метрикам, включая User Click-Through Rate (UCTR), User Conversion Rate (UCTCVR), объем заказов и GMV.

## Сравнение с другими подходами

OxygenREC отличается от других систем:
- В отличие от RecGPT, непосредственно использует LLM для генерации в онлайн-сценариях (через near-line pipeline)
- В отличие от OneRec-Think, фокусируется на мульти-сценарной адаптации и дедуктивных рассуждениях
- В отличие от PLUM, использует архитектуру Fast-Slow Thinking для масштабирования
