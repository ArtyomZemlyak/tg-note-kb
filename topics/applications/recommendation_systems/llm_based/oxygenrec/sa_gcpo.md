# SA-GCPO: Soft Adaptive Group Clip Policy Optimization

## Описание

SA-GCPO (Soft Adaptive Group Clip Policy Optimization) - это метод оптимизации политики, разработанный для решения проблемы нестабильности обучения в мульти-сценарной и мульти-задачной среде OxygenREC. Метод использует мягкие (soft) адаптивные функции вместо жесткого (hard) клиппинга для обеспечения стабильности обучения при сохранении эффективности сэмплирования.

## Проблематика

Традиционные методы оптимизации политики в рекомендательных системах с генерацией сталкиваются с рядом проблем:
- **Нестабильность обучения**: Особо выраженная в условиях мульти-сценарного и мульти-задачного обучения
- **Проблема жесткого клиппинга**: Hard clipping стратегии часто приводят к неэффективности сэмплирования и разрывным градиентам
- **Проблема определения позитивных/негативных преимуществ**: Простое использование знака advantage значения становится недостаточным в мульти-задачной среде

## Архитектура SA-GCPO

### Адаптивное сглаженное гейтирование
- **Замена жесткой функции клиппинга**: Используется непрерывная сигмоидная гейт-функция для сглаживания
- **Снижение шума оптимизации**: Повышение стабильности обучения
- **Сохранение обучающих сигналов**: Плавное затухание градиентов при отклонении от оптимального значения

### Реальный пользовательский фидбек как порог для определения преимуществ
- **Порог на основе пользовательского поведения**: Использование оценок вознаграждения из реального поведения пользователей как порога для различения позитивных и негативных advantage сэмплов
- **Снижение проблемы reward hacking**: Уменьшение проблемы "взлома вознаграждения" во время RL обучения
- **Явное определение позитивных сэмплов**: Возможность явного определения позитивных фидбек сэмплов в мульти-сценарной и мульти-задачной пост-обучении

### Асимметричный температурный контроль
- **Разные температурные коэффициенты**: Применение различных температурных коэффициентов τ_pos и τ_neg для позитивных и негативных advantage сэмплов
- **Ускоренное затухание негативных градиентов**: Более быстрое затухание градиентов негативных токенов для улучшения стабильности
- **Разные значения температур**: τ_pos > τ_neg для более стабильной работы модели

## Математическая формулировка

### Оптимизационный объектив
Для каждого сэмпла x ~ D, для группы айтемов {yi}^G_{i=1}, сгенерированных политикой поведения πθ_old, SA-GCPO использует следующий оптимизационный объектив:

Определяется token-level importance ratio t_{i,t}(θ) следующим образом:
t_{i,t}(θ) = π_θ(y_{i,t}|x, y_{<i,t}) / π_{θ_old}(y_{i,t}|x, y_{<i,t})

### Soft adaptive function
В уравнении 4 f_{i,t}(ρ) обозначает soft adaptive функцию:
f_{i,t}(ρ) = σ((r_{i,t}(θ) - 1) / τ_pos) для позитивных advantage сэмплов
f_{i,t}(ρ) = σ((1 - r_{i,t}(θ)) / τ_neg) для негативных advantage сэмплов

где τ_pos и τ_neg - температуры для позитивных и негативных сэмплов, σ(z) = 1 / (1 + e^{-z}) - сигмоидная функция.

### Градиентный вес
Градиентный вес w_{i,t}(θ) задается как:
w_{i,t}(θ) = f_{i,t}(ρ) * (1 - f_{i,t}(ρ))

который достигает максимума при r_{i,t}(θ) = 1 и плавно затухает при отклонении, реализуя soft trust region.

### Threshold Function
Γ_adv в уравнении 4 представляет собой функцию порога для различения позитивных и негативных advantage сэмплов Â_{i,t}:

Γ_adv = 1, если Â_i ≥ R*_g
Γ_adv = 0, в противном случае

где R_i - оценка вознаграждения для айтема yi, а R*_g - оценка вознаграждения для целевого айтема в этой группе. Â_i - нормализованное advantage для айтема yi.

## Экспериментальные результаты

### Сравнение с другими методами
| Методы | Доля синтетических данных | HR@1 | HR@10 |
|--------|---------------------------|------|-------|
| OxygenREC-0.7B-GRPO | 33% | 23.85% | 62.15% |
| OxygenREC-0.7B-GSPO | 33% | 24.13% | 62.88% |
| OxygenREC-0.7B-SA-GCPO | 33% | 25.58% | 65.95% |

### Абляция температурных настроек
| τ_pos | τ_neg | HR@1 | HR@10 |
|-------|-------|------|-------|
| 1 | 1.05 | 25.35% | 65.64% |
| 1 | 1 | 25.48% | 65.95% |
| 1 | 0.95 | 25.51% | 66.01% |

Результаты показывают, что при τ_pos > τ_neg производительность модели становится более стабильной. Назначение более низкого температурного коэффициента негативным сэмплам помогает предотвратить коллапс производительности во время RL обучения и повышает общую стабильность обучения.

## Основные преимущества

1. **Адаптивное сглаженное гейтирование**: Замена жесткой клиппинг функции на непрерывную сигмоидную гейт-функцию, снижающую шум оптимизации и повышающую стабильность обучения
2. **Реальный пользовательский фидбек как порог для определения позитивных/негативных advantage**: Использование оценок вознаграждения из реального поведения пользователей как порога для различения позитивных и негативных advantage сэмплов, тем самым смягчая проблему "взлома вознаграждения" во время RL обучения
3. **Асимметричный температурный контроль**: Использование разных температурных настроек для τ_neg и τ_pos для более быстрого затухания градиентов негативных токенов, улучшая стабильность
4. **Когерентность последовательности**: SA-GCPO преобразуется в сглаженную sequence-level gate, подобно GSPO, но без внезапного клиппинга

## Интеграция в OxygenREC

### В пост-обучении
- **Мульти-сценарное обучение**: SA-GCPO используется для обучения единой политики на данных из различных сценариев
- **Объединение целей**: Синхронизация единой политики с различными бизнес-объективами
- **Синтетические данные**: Использование синтетических данных для улучшения устойчивости модели в различных сценариях

### Сравнение с GRPO
- **Стабильность**: SA-GCPO показывает более стабильные результаты по сравнению с GRPO при различных долях синтетических данных
- **Эффективность**: SA-GCPO демонстрирует превосходную производительность по сравнению с GRPO при различных долях синтетических данных
- **Превосходство**: SA-GCPO достигает +1.45pp и +1.73pp по сравнению с HR@1 GSPO и GRPO соответственно
