# Семантическое выравнивание в OxygenREC

## Описание

Семантическое выравнивание - критическая часть архитектуры OxygenREC, которая обеспечивает эффективное управление инструкциями в генеративной рекомендательной системе. Механизм включает в себя Query-to-Item (Q2I) loss и Instruction-Guided Retrieval (IGR) для обеспечения согласованности между инструкциями и целевыми айтемами.

## Компоненты семантического выравнивания

### Query-to-Item (Q2I) loss
- **Назначение**: Отображение инструкций в пространство эмбеддингов айтемов для обеспечения сопоставимости между ними
- **Механизм**: Использует целевой айтем как контролируемый сигнал для привязки запроса к пространству айтемов
- **Преимущества**: Позволяет запросу использоваться для поиска релевантных исторических взаимодействий во время инференса, когда истинный целевой айтем отсутствует

### Instruction-Guided Retrieval (IGR)
- **Назначение**: Фильтрация исторических взаимодействий пользователя на основе инструкций
- **Механизм**: Использует эмбеддинги инструкций как запрос для поиска наиболее релевантных взаимодействий из долгосрочной истории
- **Преимущества**: 
  - Уменьшает шум в исторических данных
  - Улучшает точность генерации
  - Повышает эффективность за счет сокращения длины входных последовательностей

## Архитектурные детали

### Механизм адаптера для сопоставления признаков
Для схожести-базированного поиска запрос и исторические айтемы должны быть сопоставимы в одном пространстве. Для этого используется проекция адаптера:
- **Проекция запросов**: ψq проектирует инструкции в общее эмбеддинговое пространство
- **Проекция айтемов**: ψi проектирует айтемы (включая ID, боковую информацию и текст) в то же пространство
- **Текстовый энкодер**: Общий текстовый энкодер g(·) используется как для инструкций, так и для текстов айтемов

### Q2I выравнивание
Для того чтобы эмбеддинги запроса q и эмбеддинги исторических айтемов {h} были сопоставимы для поиска, используется выравнивание q с эмбеддингом целевого айтема t:
- Используется вспомогательный объектив для оптимизации схожести
- Включает регуляризационные и декорреляционные термы для предотвращения коллапса размерностей
- Обеспечивает, что q может использоваться для поиска релевантных исторических взаимодействий во время сервиса

## Обучение и оптимизация

### Joint Learning Objectives
Объектив обучения объединяет точность генерации с выравниванием запрос-айтем:
- **L_NTP (Weighted Next Token Prediction)**: Оптимизация автогрессивного правдоподобия целевой последовательности айтемов
- **Q2I Alignment Loss**: Обеспечивает выравнивание между инструкцией и целевым айтемом
- **Взвешивание**: Более высокие веса присваиваются высокозначимым пользовательским действиям (например, Purchase > Cart > Click)

### Адаптивное обучение
- Используется вспомогательный объектив для выравнивания инструкция-айтем
- Регуляризационные и декорреляционные термы помогают избежать коллапса размерностей
- Средства обучения используются для обучения модели генерации с учетом инструкций

## Практическое применение

### Влияние на производительность
Абляционные исследования показали значительное влияние компонентов IGR и Q2I на качество рекомендаций:

| Конфигурация | HR@1 | HR@10 | Recall@10 | Recall@30 |
|--------------|------|-------|-----------|-----------|
| Base Model (без IGR/Q2I) | 3.76% | 12.20% | 9.87% | 15.53% |
| + IGR Только | 4.02% | 12.91% | 10.25% | 15.95% |
| + IGR+Q2I (Полная) | 4.19% | 13.38% | 10.52% | 16.23% |

### Эффекты
- **Улучшенная фокусировка**: Модель лучше фокусируется на релевантных исторических взаимодействиях
- **Меньший шум**: Устранение нерелевантных сигналов из истории
- **Контролируемая генерация**: Точное управление выводом на основе инструкций пользователя

## Интеграция в систему

### Взаимодействие с другими компонентами
- **Fast-Slow Thinking**: Инструкции, сгенерированные slow-thinking компонентом, используются для управления IGR
- **Мульти-сценарная адаптация**: Q2I выравнивание используется во всех сценариях для обеспечения последовательности
- **Instruction Following**: Семантическое выравнивание усиливает способность модели следовать инструкциям

## Преимущества

1. **Улучшенная точность**: Более точное соответствие между инструкциями и целевыми айтемами
2. **Эффективность**: Уменьшение шумных данных в истории пользователя
3. **Контролируемость**: Лучшее управление процессом генерации
4. **Интерпретируемость**: Более понятные связи между инструкциями и рекомендациями
