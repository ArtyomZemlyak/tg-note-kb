# Значимые научные статьи по рекомендательным системам за 2024-2025 годы

## Обзор

Этот раздел содержит обзор значимых научных статей в области рекомендательных систем, опубликованных в 2024-2025 годах. Статьи отсортированы в порядке значимости и влияния на индустрию рекомендательных систем.

## Классификация статей

### 1. Основные направления исследований

#### 1.1. Генеративные рекомендательные системы
- **Семантические идентификаторы (Semantic IDs)** - Токенизация айтемов для интеграции с LLM
- **OneRec** - Единая архитектура для end-to-end рекомендаций

#### 1.2. Эмбеддинги и представления
- **Unified Embedding** - Объединение эмбеддинг-таблиц для sparse фичей
- **RQ-VAE/VQ-VAE** - Векторное квантование для генеративных рекомендаций

#### 1.3. Нейронный ретривал
- **Revisiting Neural Retrieval on Accelerators** - Mixture-of-Logits (MoL)
- **Новые архитектуры ретривала** - Замена HNSW подходов

- **Actions Speak Louder than Words** - Новое представление истории
- **HSTU** - Иерархические трансформеры для моделирования поведения пользователей

## Значимые статьи

### 1. DeepMind: Семантические идентификаторы (Semantic IDs)

> **Примечание:** Это серия статей, считающихся №1 по значимости в последнее время.

Семантические идентификаторы представляют собой парадигменный сдвиг в рекомендательных системах, позволяющий использовать токенизатор, который представляет контентную информацию об объектах в виде кодов из конечного словаря, полученного из иерархической кластеризации (RQ-VAE). Ключевые статьи:

- **Generative Retrieval** - Основы генеративного ретривала с использованием SIDs
- **Better Generalization** - Улучшенная обобщающая способность подхода
- **PLUM** - Промышленная реализация для YouTube

[См. подробнее: [[semantic_ids_series.md]]]

### 2. Kuaishou: OneRec

> **Примечание:** Революционная end-to-end рекомендательная система без нескольких стадий ранжирования.

Семейство архитектур, разработанных Kuaishou, доводящих идею семантических идентификаторов до логического завершения, создавая первую индустриальную end-to-end рекомендательную систему. Ключевые статьи:

- **OneRec**
- **OneRec Technical Report**
- **OneRec-V2 Technical Report**
- **OneRec-Think**

[См. подробнее: [[onerec_series.md]]]

### 3. Meta: Actions Speak Louder than Words

> **Примечание:** Первая статья, показавшая возможность обучения огромных моделей для рекомендаций.

Знаменитая статья от Meta, которая ввела HSTU (Hierarchical Semantic Transformer for User behavior modeling) и новое представление истории пользователя. Была первым намёком на возможность отказа от всех ручных фичей.

[См. подробнее: [[actions_speak_louder_than_words.md]]]

### 4. Meta: Revisiting Neural Retrieval on Accelerators

> **Примечание:** Статья, показавшая, что retrieval можно делать лучше, чем традиционным HNSW.

Работа, в которой Meta показала, что retrieval можно делать на GPU без индексов и вводит модель mixture-of-logits (MoL), которая является более выразительной, но всё ещё относительно дешевой в вычислениях функцией.

[См. подробнее: [[revisiting_neural_retrieval_on_accelerators.md]]]

### 5. DeepMind: Unified Embedding

> **Примечание:** Практическая статья о возможности использовать одну универсальную таблицу эмбеддингов для многих sparse фичей.

Статья о подходе Feature Multiplexing, где используется одна унифицированная таблица эмбеддингов вместо независимых таблиц для каждого признака.

[См. подробнее: [[unified_embedding.md]]]

### 6. ByteDance: Streaming Vector Quantization Retriever

> **Примечание:** Устраняет недостаток RQ-VAE обучаемого отдельно, не end-to-end с задачей.

Работа, исправляющая проблему обучения RQ-VAE отдельно от рекомендательной задачи, позволяющая обучать VQ-VAE в потоковом режиме.

[См. подробнее: [[streaming_vector_quantization_retriever.md]]]

### 7. DeepMind: Stop Regressing

> **Примечание:** Единственная статья не про рекомендации, но может быть полезной в рекомендательных системах.

Статья о том, как в задачах регрессии (на примере value function в RL) моделирование распределения таргета с помощью Histogram Loss улучшает масштабируемость.

[См. подробнее: [[stop_regressing.md]]]

### 8. LogQ Correction и улучшения

> **Примечание:** Улучшение знаменитой техники Google LogQ-коррекции.

Статья, улучшающая технику LogQ-коррекции, которая широко используется для повышения качества обучения нейронных сетей для ретривала.

[См. подробнее: [[correcting_logq_correction.md]]]

## Влияние на индустрию

Эти статьи оказали или окажут значительное влияние на индустрию рекомендательных систем:

1. **Смена парадигмы** - переход от классических двухстадийных моделей к генеративным
2. **Интеграция с LLM** - возможность прямого взаимодействия рекомендательных систем с языковыми моделями
3. **Эффективность обучения** - использование VQ-VAE и SIDs для более эффективного обучения
4. **Скаляряемость** - возможность работы с миллионами айтемов и пользователями
