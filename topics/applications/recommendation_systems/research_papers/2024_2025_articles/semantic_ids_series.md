# Semantic IDs: Революция в рекомендательных системах (сериал статей от DeepMind)

## Описание

Semantic IDs - это серия статей от DeepMind, считающаяся №1 по значимости по сдвигу парадигмы последнего времени. Это токенизатор рекомендательного мира, представляющий контентную информацию об объектах в виде кодов из конечного словаря, полученного из иерархической кластеризации (RQ-VAE). Использование этой токенизации позволяет создавать новые методы retrieval, более эффективные эмбеддинги в ранжировании и связь с LLM.

## Контекст проблемы

Традиционные рекомендательные системы сталкиваются с рядом фундаментальных ограничений:

- **Разрыв между представлениями**: Айтемы представлены в виде непрерывных векторов, несовместимых с LLM
- **Ограниченная генерация**: Трудности с прямым предсказанием айтемов с помощью генеративных моделей
- **Отсутствие объяснимости**: Непонятно, почему конкретные айтемы рекомендуются
- **Проблема холодного старта**: Трудности с новыми айтемами без истории взаимодействий

## Архитектурное решение: Семантические идентификаторы

### Основные компоненты:

#### 1. Токенизация айтемов
- Извлечение мультимодальных признаков айтема (текст, изображение, метаданные)
- Использование RQ-VAE (Residual Quantization Variational Autoencoder) для кодирования в дискретные токены
- Получение конечного словаря через иерархическую кластеризацию

#### 2. RQ-VAE для представления
- Иерархическое квантование для более точного представления
- Интеграция как семантической информации, так и коллаборативного сигнала
- Возможность end-to-end обучения

#### 3. Интеграция с LLM
- Использование SIDs как специальных токенов в словаре LLM
- Прямое предсказание айтемов с помощью генеративных моделей
- Возможность объяснений рекомендаций

## Серия статей

### 1. Generative Retrieval
- Основы генеративного ретривала с использованием SIDs
- Архитектура TIGER (Transformer Index for Generative Recommenders)
- Прямое предсказание айтемов как токенов

### 2. Better Generalization
- Улучшенная обобщающая способность подхода
- Более эффективное кодирование и декодирование
- Повышение качества на новых айтемах и пользователях
- **Новое**: Методы хеширования под-компонентов SID для ранжирования
- См. подробнее: [[better_generalization_semantic_ids.md]]

### 3. PLUM (Generative Recommendations at YouTube)
- Индеграция SIDs с архитектурой Gemini
- Прямое предсказание видео для пользователей YouTube
- Улучшение метрик в сравнении с традиционными подходами
- Mixture-of-Experts архитектура с ~900 млн активных параметров

## Преимущества Semantic IDs

### 1. Совместимость с LLM
- Прямая интеграция с большими языковыми моделями
- Возможность использования предобученных знаний
- Объяснимость через естественный язык

### 2. Генеративные возможности
- Прямое предсказание айтемов как токенов
- Возможность генерации новых комбинаций рекомендаций
- Контролируемая генерация с условиями

### 3. Объяснимость
- Возможность генерации объяснений для рекомендаций
- Понимание, почему конкретные айтемы были выбраны
- Прозрачность для пользователей и разработчиков

### 4. Эффективное обучение
- Возможность использования эффективных архитектур трансформеров
- Учет долгосрочных зависимостей между айтемами
- Масштабируемость за счет эффективных attention-механизмов

## Технические детали

### RQ-VAE (Residual Quantization VAE)
- Использование кодбуков (codebooks) для дискретизации непрерывных представлений
- Многоуровневое квантование для лучшего представления
- Обучение с учетом как семантического смысла, так и коллаборативного сигнала

### Contrastive Learning в PLUM
- Обучение с использованием InfoNCE и пар айтемов, встречавшихся в истории
- Интеграция коллаборативного сигнала в процесс токенизации
- Multi-Resolution Codebooks и Progressive Masking

## Влияние на индустрию

Semantic IDs оказали революционное влияние на всю индустрию:

- **Парадигменный сдвиг**: Переход от векторных представлений к токенизированным
- **Интеграция с LLM**: Возможность прямого взаимодействия рекомендательных систем с LLM
- **Генеративные рекомендации**: Новый класс рекомендательных систем
- **Новые архитектуры**: Развитие TIGER, PLUM и других подходов

## Сравнение с традиционными эмбеддингами

| Характеристика | Традиционные эмбеддинги | Семантические ID (SIDs) |
|----------------|------------------------|-------------------------|
| Представление | Непрерывные векторы | Дискретные токены |
| Совместимость с LLM | Низкая | Высокая |
| Генеративные возможности | Ограниченные | Высокие |
| Объяснимость | Низкая | Высокая |
| Обработка коллаборативного сигнала | Прямая | Косвенная, через обучение |
| Масштабируемость | Высокая | Средняя-высокая |
| Качество представления | Высокое | Зависит от дискретизации |
