# Massive Memorization with Hundreds of Trillions of Parameters for Sequential Transducer Generative Recommenders

## Краткое описание

Исследование от Meta*, представляющее элегантный двухстадийный фреймворк для масштабирования рекомендательных моделей с целью обработки пожизненной истории взаимодействий пользователя (lifelong user interaction history). Вместо того чтобы использовать тяжелый трансформер для обработки миллионов событий в контексте, архитектура сжимает всю историю в компактные эмбеддинги и использует их в рантайме.

## Ключевые инновации

### Двухстадийный фреймворк
- **Офлайн сжатие**: Полная история пользователя сжимается с помощью квазилинейного (quasi-linear) аттеншна
- **Рантайм использование**: Сжатые эмбеддинги используются для построения target attention между сжатыми представлениями и кандидатами

### Квазилинейное внимание (Quasi-Linear Attention - QLA)
- Обработка сверхдлинных последовательностей за разумное время
- Нелинейность через SiLU для лучшего моделирования сложных взаимодействий
- Линейная по длине последовательности формулировка

### Суммаризирующие эмбеддинги
- До 128 суммаризирующих эмбеддингов для сжатия истории
- Виртуальные "seed"-токены для сжатия истории
- Асинхронно обновляемый кэш эмбеддингов

### Реконструкционный лосс
- Дополнительная функция потерь для восстановления исходной последовательности из эмбеддингов
- Повышает качество сжатия и "дисциплину" модели

## Архитектурные особенности

### VISTA (Visual Interface for Sequential Transduction Architecture)
- Основной фреймворк, реализующий подход
- Использует Summary-as-a-Service концепцию
- Компактные summary-эмбеддинги выгружаются в систему доставки эмбеддингов
- Модель на проде подтягивает нужные эмбеддинги и вычисляет target-attention

### Сравнение с предшественниками
- **HSTU (History-based Sequential Transformer Units)**: Подход "берём всё", требует полной прогонки
- **SIM/TWIN**: Подход "берём релевантный срез", приводит к линейному росту стоимости по числу кандидатов
- **VISTA**: Фиксированная стоимость инференса независимо от длины истории

## Эксперименты и результаты

### Офлайн эксперименты
- Сравнимые результаты с HSTU
- Постоянная скорость инференса при увеличении длины последовательности

### A/B тестирование
- Проведено на базе Reels (Meta)
- Бейзлайн: HSTU-модель
- **C-task** (внутренняя метрика вовлеченности): +0.5%
- **O1 task** (дополнительная метрика удержания): +0.2%
- **O2 task** (дополнительная метрика удержания): +0.04%
- Заявлено, что даже 0.01% рост O2 считается существенным успехом

## Технические детали

### Квазилинейный аттеншн (QLA)
- Линейная по длине последовательности вычислительная сложность
- Без "перетекания" внимания между кандидатами, предотвращая утечки
- Похож на подходы Mamba/Linear Attention, адаптированные для рекомендательных систем

### Сжатие истории
- Использование виртуальных seed-токенов для сжатия UIH (User Interaction History)
- До 1M событий в пожизненной истории пользователя
- Квадратичный рост вычислений по длине истории на этапе обучения
- Фиксированная стоимость инференса

## Влияние и значение

### Технологическое
- Решение проблемы масштабирования рекомендательных систем
- Возможность использования пожизненной истории пользователей
- Фиксированная стоимость инференса независимо от длины истории

### Практическое
- Улучшение рекомендаций за счет более полного контекста
- Возможность масштабирования до сотен триллионов параметров
- Обеспечение устойчивого роста метрик в продакшене

## Ключевые термины
- **UIH (User Interaction History)**: История взаимодействий пользователя
- **Sequential Transducer**: Последовательный трансдьюсер (архитектура для обработки последовательностей)
- **Quasi-Linear Attention (QLA)**: Квазилинейный механизм внимания
- **Summary-as-a-Service**: Концепция, при которой сжатые эмбеддинги предоставляются как сервис
- **Target Attention**: Механизм внимания между сжатыми представлениями и кандидатами
