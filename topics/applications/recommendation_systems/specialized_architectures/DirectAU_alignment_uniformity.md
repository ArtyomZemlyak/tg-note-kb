# DirectAU: Методы с явными Alignment и Uniformity потерями

## Описание

DirectAU (Direct Alignment and Uniformity) — это современный метод обучения рекомендательных систем, который использует явные функции потерь на выравнивание (alignment) и равномерность (uniformity) эмбеддингов. Этот подход представляет собой альтернативу контрастивному обучению с аугментациями и достигает state-of-the-art результатов на стандартных бенчмарках.

## Мотивация

Традиционные методы графовых рекомендаций (LightGCN, SGL, SimGCL) полагаются на:
- Контрастивное обучение с аугментациями графа
- Сложные архитектуры для улучшения представлений
- Эвристики для регуляризации

DirectAU предлагает более прямой и интерпретируемый подход:
- **Явное выравнивание**: прямое сближение эмбеддингов связанных пользователей и айтемов
- **Явная равномерность**: равномерное распределение эмбеддингов на гиперсфере для максимальной информативности

## Теоретические основы

### Alignment Loss (Потеря выравнивания)

Цель alignment loss — сближать эмбеддинги пользователей и айтемов, с которыми они взаимодействовали:

```
L_align = E_(u,i)~D_pos[||e_u - e_i||²]
```

Где:
- `(u, i)` — пары пользователь-айтем из положительных взаимодействий
- `e_u, e_i` — нормализованные эмбеддинги пользователя и айтема
- Минимизация приводит к тому, что связанные узлы имеют близкие представления

### Uniformity Loss (Потеря равномерности)

Цель uniformity loss — равномерно распределить эмбеддинги на единичной гиперсфере:

```
L_uniform = log E_(u,u')~D[exp(-t * ||e_u - e_u'||²)] + log E_(i,i')~D[exp(-t * ||e_i - e_i'||²)]
```

Где:
- `(u, u')` и `(i, i')` — случайные пары пользователей и айтемов
- `t` — параметр температуры (обычно t=2)
- Минимизация приводит к равномерному распределению эмбеддингов

### Интуиция

- **Alignment**: «Если пользователь взаимодействовал с айтемом, их представления должны быть похожи»
- **Uniformity**: «Эмбеддинги должны использовать всё доступное пространство признаков равномерно»

## Архитектура DirectAU

### Общая функция потерь

```
L_total = L_BPR + λ_align × L_align + λ_uniform × L_uniform + λ_reg × ||Θ||²
```

Где:
- `L_BPR` — стандартная Bayesian Personalized Ranking loss
- `λ_align, λ_uniform` — веса соответствующих функций потерь
- `λ_reg` — коэффициент L2-регуляризации

### Особенности реализации

1. **Нормализация эмбеддингов**: Все эмбеддинги проецируются на единичную гиперсферу
2. **Прямое вычисление**: Loss вычисляется напрямую на эмбеддингах, без аугментаций
3. **Минимальные гиперпараметры**: Только веса функций потерь

## Преимущества DirectAU

### 1. Интерпретируемость

- Явные цели обучения понятны и измеримы
- Можно отслеживать alignment и uniformity отдельно

### 2. Простота реализации

- Не требует аугментаций графа
- Не требует сложных архитектурных решений
- Минимум гиперпараметров

### 3. Теоретическое обоснование

- Связь с теорией информационных потерь
- Оптимальность равномерного распределения на гиперсфере

### 4. Стабильность обучения

- Меньшая чувствительность к гиперпараметрам
- Более стабильная сходимость

## Недостатки и ограничения

### 1. Вычислительная сложность

- Uniformity loss требует вычисления попарных расстояний
- O(n²) сложность для n эмбеддингов в батче

### 2. Требования к памяти

- Необходимо хранить все эмбеддинги батча для uniformity loss

### 3. Чувствительность к размеру батча

- Маленькие батчи приводят к плохой оценке uniformity

## Практические рекомендации

### Рекомендуемые гиперпараметры

```python
# DirectAU гиперпараметры
n_layers = 3              # Число слоёв GNN
emb_dim = 64              # Размерность эмбеддингов
λ_align = 0.01            # Вес alignment loss
λ_uniform = 0.001         # Вес uniformity loss
λ_reg = 1e-4              # L2 регуляризация
t = 2                     # Температура для uniformity
batch_size = 2048         # Большой батч для uniformity
```

### Советы по обучению

1. **Начните с LightGCN** — используйте как базовую модель
2. **Добавьте alignment loss** — сначала только alignment для стабильности
3. **Добавьте uniformity loss** — постепенно увеличивайте λ_uniform
4. **Используйте большой батч** — минимум 1024, лучше 2048+
5. **Мониторьте обе метрики** — alignment и uniformity должны уменьшаться

## Сравнение подходов

| Аспект | SGL/SimGCL | DirectAU |
|--------|------------|----------|
| Основная идея | Контрастивное обучение | Явные alignment/uniformity |
| Аугментации | Требуются (SGL) / нет (SimGCL) | Не требуются |
| Интерпретируемость | Средняя | Высокая |
| Вычислительная сложность | Низкая-Средняя | Средняя-Высокая |
| Качество | Хорошее | Лучшее (SOTA) |
| Стабильность | Зависит от аугментаций | Высокая |

## Связь с другими методами

### LightGCN++

LightGCN++ использует обучаемые веса слоёв вместо равномерного усреднения:
- Улучшает LightGCN на ~5%
- Может комбинироваться с DirectAU

### SimGCL

SimGCL добавляет шум вместо аугментаций графа:
- Проще чем SGL
- DirectAU превосходит на ~3%

### NCL (Neighborhood-enriched Contrastive Learning)

NCL обогащает контрастивные пары соседней информацией:
- Более сложные контрастивные пары
- DirectAU проще в реализации

## Будущие направления

### 1. Комбинирование подходов

- DirectAU + SimGCL шум для дополнительной регуляризации
- DirectAU + обучаемые веса слоёв из LightGCN++

### 2. Масштабирование

- Эффективные аппроксимации uniformity loss
- Mini-batch методы для больших графов

### 3. Адаптивные потери

- Динамическая настройка λ_align и λ_uniform
- Зависимость от степени узла
