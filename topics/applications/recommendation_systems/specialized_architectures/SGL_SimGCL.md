# SGL и SimGCL: Контрастивное самообучение для графовых рекомендаций

## Описание

SGL (Self-supervised Graph Learning) и SimGCL (Simple Graph Contrastive Learning) — это методы самообучения с контрастивной функцией потерь для рекомендательных систем на графовых нейронных сетях. Эти подходы представляют собой значительный прогресс по сравнению с базовыми моделями вроде LightGCN, добавляя саморегуляризацию через контрастивное обучение.

## Основная идея

Контрастивное обучение в рекомендательных системах основано на принципе максимизации взаимной информации между различными представлениями одних и тех же пользователей или айтемов:
- Создаются два «вида» (views) одного узла через аугментацию графа
- Контрастивная функция потерь сближает представления одного узла и отталкивает представления разных узлов
- Это улучшает качество эмбеддингов и предотвращает переобучение

## SGL (Self-supervised Graph Learning)

### Архитектура

SGL расширяет LightGCN добавлением самообучения с контрастивной функцией потерь:

**Аугментации графа:**
- **Edge Dropout** (наилучшая) — случайное удаление рёбер с вероятностью p
- **Node Dropout** — случайное удаление узлов и их рёбер
- **Random Walk** — сэмплирование подграфа через случайные блуждания

**Функция потерь:**
```
L_total = L_BPR + λ_cl × L_CL + λ_reg × ||Θ||²
```

Где:
- `L_BPR` — стандартная BPR loss для рекомендаций
- `L_CL` — контрастивная loss (InfoNCE)
- `λ_cl` — вес контрастивной функции потерь
- `λ_reg` — коэффициент регуляризации

### Контрастивная функция потерь (InfoNCE)

Для узла i с двумя аугментированными представлениями z_i и z_i':

```
L_CL = -log[exp(sim(z_i, z_i')/τ) / Σ_j exp(sim(z_i, z_j)/τ)]
```

Где:
- `sim()` — косинусное сходство
- `τ` — температура (temperature parameter)
- Знаменатель суммирует по всем негативным примерам j

### Результаты

| Dataset | LightGCN Recall@20 | SGL Recall@20 | Улучшение |
|---------|-------------------|---------------|-----------|
| Yelp2018 | 0.0639 | 0.0675 | +6% |
| Amazon-Book | 0.0411 | 0.0478 | +16% |

**Ключевые выводы:**
- SGL показывает наибольший прирост на разреженных датасетах
- Edge dropout превзошёл node dropout и random walk
- Оптимальное значение τ ≈ 0.2

## SimGCL (Simple Graph Contrastive Learning)

### Мотивация

SimGCL был разработан как упрощение SGL:
- SGL требует сложных аугментаций графа
- SimGCL показывает, что простое добавление шума работает лучше

### Архитектура

Вместо аугментации графа SimGCL добавляет шум непосредственно в эмбеддинги:

**Генерация двух views:**
```
z_i^(1) = E_i + ε_1
z_i^(2) = E_i + ε_2
```

Где ε_1, ε_2 — случайный шум из равномерного распределения U(-1, 1)

**Функция потерь:**
```
L_total = L_BPR + λ × L_CL
```

### Преимущества SimGCL над SGL

| Аспект | SGL | SimGCL |
|--------|-----|--------|
| Аугментация | Edge/Node dropout, Random Walk | Простое добавление шума |
| Вычислительная сложность | Высокая (перестройка графа) | Низкая (просто шум) |
| Гиперпараметры | Вероятность dropout, тип аугментации | Только λ и τ |
| Производительность | Хорошая | Лучше или равна |
| Стабильность | Зависит от аугментации | Более стабильный |

### Результаты

SimGCL показывает результаты на уровне или лучше SGL при значительно меньшей вычислительной сложности:
- **Yelp2018**: Recall@20 ≈ 0.068 (лучше SGL)
- **Amazon-Book**: Recall@20 ≈ 0.048 (на уровне SGL)
- **Время обучения**: в 2-3 раза быстрее SGL

## XSimGCL (Extended SimGCL)

### Улучшения

XSimGCL расширяет SimGCL дополнительными улучшениями:
- **Адаптивный шум** — интенсивность шума зависит от степени узла
- **Hard negative mining** — выбор более информативных негативных примеров
- **Multi-view обучение** — более двух views для лучшей регуляризации

### Результаты

XSimGCL показывает дальнейшее улучшение:
- **Yelp2018**: Recall@20 ≈ 0.069
- **Amazon-Book**: Recall@20 ≈ 0.049

## Практические рекомендации

### Выбор метода

- **Базовый уровень**: LightGCN — быстро и эффективно
- **Улучшенное качество**: SimGCL — лучший баланс качества и сложности
- **Максимальное качество**: DirectAU — текущий SOTA на стандартных бенчмарках
- **Ограниченные ресурсы**: LightGCN или SimGCL с малым числом слоёв

### Гиперпараметры для SimGCL

```python
# Рекомендуемые значения
n_layers = 3          # Число слоёв GNN
emb_dim = 64          # Размерность эмбеддингов
λ = 0.1               # Вес контрастивной loss
τ = 0.2               # Температура
noise_eps = 1.0       # Интенсивность шума
n_epochs = 1000       # Число эпох
```

### Аугментации для SGL

Если используется SGL:
- **Edge dropout** с p = 0.2 — наилучший выбор
- Избегать node dropout на разреженных графах
- Random walk эффективен только на плотных графах
