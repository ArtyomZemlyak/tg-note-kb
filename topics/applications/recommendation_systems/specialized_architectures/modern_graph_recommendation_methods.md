# Современные методы графовых рекомендаций: Обзор 2024-2025

## Описание

Этот документ представляет собой обзор современных (state-of-the-art) методов графовых рекомендательных систем по состоянию на 2024-2025 годы. Описаны лучшие практики, сравнение методов и рекомендации по выбору подхода для различных сценариев.

## Эволюция методов графовых рекомендаций

### Хронология развития

```
2019: NGCF (Neural Graph Collaborative Filtering)
         ↓
2020: LightGCN (упрощение и усиление)
         ↓
2021: SGL (Self-supervised Graph Learning)
         ↓
2022: SimGCL (Simple Graph Contrastive Learning)
         ↓
2023: XSimGCL, DirectAU, NCL
         ↓
2024-2025: LightGCL, GFormer, CGCL, DCCL, GLSCL
```

### Ключевые вехи

1. **NGCF (2019)** — первая специализированная GNN для рекомендаций
   - Message passing с MLP-агрегаторами
   - Явное моделирование связей высокого порядка

2. **LightGCN (2020)** — революция упрощения
   - Удаление MLP и нелинейностей
   - Только линейная агрегация соседей
   - Превосходит NGCF несмотря на простоту

3. **SGL (2021)** — эра самообучения
   - Контрастивное обучение с аугментациями графа
   - Значительное улучшение на разреженных данных

4. **SimGCL (2022)** — упрощение контрастивного обучения
   - Замена аугментаций на простой шум
   - Сопоставимое качество при меньшей сложности

5. **DirectAU (2023)** — явные цели обучения
   - Alignment + Uniformity потери
   - Текущий SOTA на стандартных бенчмарках

### Категории методов

#### 1. Базовые архитектуры

| Метод | Ключевая идея | Преимущества | Недостатки |
|-------|--------------|--------------|------------|
| NGCF | Message passing с MLP | Сильная математическая основа | Склонность к переобучению |
| LightGCN | Упрощённая свёртка | Быстро, эффективно | Базовый уровень |

#### 2. Контрастивное обучение

| Метод | Ключевая идея | Преимущества | Недостатки |
|-------|--------------|--------------|------------|
| SGL | Аугментации графа | Улучшение на разреженных данных | Сложные аугментации |
| SimGCL | Простой шум | Проще чем SGL, лучше качество | Требует настройки λ |
| XSimGCL | Адаптивный шум | Лучшее качество | Больше гиперпараметров |
| NCL | Neighborhood contrastive | Учёт локальной структуры | Вычислительно сложнее |

#### 3. Явные функции потерь

| Метод | Ключевая идея | Преимущества | Недостатки |
|-------|--------------|--------------|------------|
| DirectAU | Alignment + Uniformity | SOTA качество, интерпретируемость | O(n²) сложность uniformity |
| CGCL | Cluster-level alignment | Учёт кластерной структуры | Сложнее реализация |
| DCCL | Disentangled losses | Разъединенные представления | Много гиперпараметров |

#### 4. Продвинутые архитектуры

| Метод | Ключевая идея | Преимущества | Недостатки |
|-------|--------------|--------------|------------|
| GFormer | Masked autoencoding | Мощные представления | Требует много данных |
| LightGCL | Упрощённое контрастивное | Баланс качества и сложности | Новый метод, мало тестов |
| HCCF/HGCF | Гиперболическая геометрия | Учёт иерархий | Сложная оптимизация |

## Лучшие практики 2024-2025

### 1. Инициализация и обучение

```python
# Рекомендуемые настройки
embedding_init = 'xavier_uniform'  # Инициализация эмбеддингов
optimizer = 'Adam'
learning_rate = 0.001
batch_size = 2048  # Большой батч для uniformity loss
n_layers = 2-3     # Глубина GNN
emb_dim = 64       # Размерность эмбеддингов
```

### 2. Выбор числа слоёв

- **2-3 слоя** — оптимально для большинства датасетов
- **Более 3 слоёв** — возникает over-smoothing
- **1 слой** — недостаточно для моделирования связей высокого порядка

### 3. Регуляризация

- **Dropout**: 0.1-0.3 на слоях GNN
- **L2 регуляризация**: 1e-4 — 1e-5
- **Contrastive weight (λ)**: 0.01 — 0.1 для SimGCL/DirectAU

### 4. Аугментации (если используются)

- **Edge dropout**: p = 0.2 — наилучший выбор
- **Node dropout**: избегать на разреженных графах
- **Random walk**: только на плотных графах

### 5. Отрицательные примеры

- **In-batch negatives** — эффективны для контрастивного обучения
- **Hard negatives** — улучшение качества, но сложнее обучение
- **Popularity-weighted** — сэмплирование пропорционально популярности

## Рекомендации по выбору метода

### Сценарий 1: Быстрый старт / Baseline

**Метод**: LightGCN

```python
# Конфигурация
n_layers = 3
emb_dim = 64
loss = 'BPR'
```

**Преимущества**:
- Быстрая реализация и обучение
- Хороший базовый уровень
- Минимум гиперпараметров

### Сценарий 2: Улучшенное качество

**Метод**: SimGCL или DirectAU

```python
# SimGCL конфигурация
n_layers = 3
emb_dim = 64
λ = 0.1
τ = 0.2
noise_eps = 1.0

# DirectAU конфигурация
n_layers = 3
emb_dim = 64
λ_align = 0.01
λ_uniform = 0.001
t = 2
```

**Преимущества**:
- SimGCL: баланс качества и сложности
- DirectAU: текущий SOTA, интерпретируемость

### Сценарий 3: Разреженные данные

**Метод**: SGL или XSimGCL

```python
# SGL конфигурация для разреженных данных
n_layers = 3
emb_dim = 64
λ_cl = 0.5
augmentation = 'edge_dropout'
dropout_rate = 0.2
```

**Преимущества**:
- Контрастивное обучение особенно эффективно на разреженных данных
- Улучшение до 16% на Amazon-Book

### Сценарий 4: Максимальное качество

**Метод**: LightGCL или GFormer

```python
# LightGCL конфигурация
n_layers = 3
emb_dim = 128
λ_cl = 0.05
τ = 0.1

# GFormer конфигурация
n_layers = 4
emb_dim = 128
mask_ratio = 0.3
reconstruction_weight = 1.0
```

**Преимущества**:
- State-of-the-art результаты
- Мощные представления

### Сценарий 5: Ограниченные ресурсы

**Метод**: LightGCN с оптимизациями

```python
# Оптимизированная конфигурация
n_layers = 2
emb_dim = 32
loss = 'BPR'
batch_size = 1024
```

**Преимущества**:
- Минимальные требования к памяти
- Быстрое обучение и инференс

## Тренды 2024-2025

### 1. Упрощение архитектур

- «Less is more» — простые модели превосходят сложные
- LightGCN принцип: удаление избыточных компонентов
- Фокус на функциях потерь, а не архитектуре

### 2. Контрастивное обучение

- Доминирующий подход в современных методах
- Переход от сложных аугментаций к простому шуму
- Интеграция с другими техниками регуляризации

### 3. Явные цели обучения

- Alignment + Uniformity как явные функции потерь
- Интерпретируемость и теоретическое обоснование
- Превосходство над эвристическими подходами

### 4. Гиперболическая геометрия

- HCCF, HGCF используют гиперболическое пространство
- Учёт иерархических отношений
- Перспективное направление

### 5. Разъединенные представления (Disentangled)

- DCCL и подобные методы
- Разделение латентных факторов
- Улучшение интерпретируемости

### 6. Masked Autoencoding

- GFormer и аналоги
- Заимствование идей из NLP (BERT, MAE)
- Мощные представления без контрастивного обучения

## Будущие направления

### Исследовательские вызовы

1. **Масштабирование** — обучение на графах с миллиардами рёбер
2. **Динамические графы** — учёт временной эволюции взаимодействий
3. **Мультимодальность** — интеграция текста, изображений, аудио
4. **Обучение без разметки** — unsupervised и self-supervised подходы
5. **Интерпретируемость** — понимание решений модели

### Перспективные направления

- **Foundation Graph Models** — единые модели для нескольких доменов (TTGL подход)
- **Нейросимволические системы** — интеграция графов знаний
- **Федеративное обучение** — обучение на распределённых данных
- **Зелёный AI** — энергоэффективные алгоритмы
