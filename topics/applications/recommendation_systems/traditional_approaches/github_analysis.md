# Анализ GitHub репозиториев

В этой подсекции рассматриваются методы анализа GitHub репозиториев, включая:
- Создание эмбеддингов репозиториев на основе активности пользователей
- Использование GitHub звёзд как сигнала для рекомендательных систем
- Методы collaborative filtering для анализа поведения разработчиков
