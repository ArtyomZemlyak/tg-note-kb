# Остаточные соединения (Residual Connections)

## Определение

Остаточные соединения (residual connections) - это архитектурный элемент глубоких нейронных сетей, позволяющий передавать информацию напрямую из более ранних слоев в более поздние, минуя промежуточную обработку.

## Математическая формулировка

Структура одного слоя с остаточным соединением описывается формулой:
```
x_{l+1} = x_l + F(x_l, W_l)
```
где:
- x_l - вход l-го слоя
- x_{l+1} - выход l-го слоя
- F - остаточная функция
- W_l - параметры слоя

## История

- Введены в ResNet (He et al., 2016)
- Ставшие основой для архитектур типа Transformers и больших языковых моделей

## Свойства

- **Свойство тождественного отображения** - обеспечивают стабильность передачи сигналов
- **Сохранение градиентов** - помогают решить проблему исчезающих градиентов
- **Простота** - минимальное изменение архитектуры
