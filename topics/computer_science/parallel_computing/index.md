# Параллельные вычисления

## Обзор

Раздел о параллельных вычислениях охватывает теоретические и практические аспекты выполнения вычислений с использованием нескольких вычислительных единиц одновременно. Это включает как архитектурные аспекты, так и программные подходы.

- Другие темы о параллельных вычислениях

## Основные концепции

- GPU (Graphics Processing Unit) - процессоры, оптимизированные для параллельных вычислений
- SIMD (Single Instruction, Multiple Data) - модель параллельных вычислений
- Кластеризация вычислений - распределение задач между несколькими процессорами
- CUDA - платформа параллельных вычислений от NVIDIA
- OpenCL - открытая платформа для параллельных вычислений
