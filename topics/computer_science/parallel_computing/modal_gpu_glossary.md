# GPU Glossary от Modal Labs: исчерпывающая база по GPU

## Обзор

GPU Glossary от Modal Labs - это словарь терминов, связанных с программированием GPU, с особым акцентом на NVIDIA GPU, используемые на платформе Modal. Глоссарий решает проблему фрагментированной документации, с которой сталкиваются разработчики при работе с графическими процессорами.

Modal Labs (бренд Modal) – компания, основанная в 2021 году, которая предоставляет высокопроизводительную серверную вычислительную платформу для разработчиков, работающих с данными, ИИ и машинным обучением.

## Цель глоссария

Цель глоссария - охватить весь стек GPU-программирования в одном месте, включая:

### Ядра и архитектура
- **CUDA ядра** - программные блоки, выполняемые на GPU NVIDIA
- **SM (Streaming Multiprocessors)** - вычислительные блоки GPU NVIDIA
- **Тензорные ядра** - специализированные ядра для высокопроизводительных матричных операций
- **Warp-планировщики** - компоненты GPU, управляющие выполнением групп потоков

### Потоки и память
- **Потоки** - базовые единицы выполнения в GPU-программировании
- **PTX (Parallel Thread Execution)** - виртуальная инструкция NVIDIA для GPU
- **Иерархия памяти** - различные уровни памяти в GPU (глобальная, разделяемая, константная и т.д.)

### Производительность и оптимизация
- **Roofline модель** - метод анализа производительности вычислений
- **Дивергенция** - явление, снижающее эффективность выполнения программ на GPU

### Инструменты и библиотеки
- **nvcc** - компилятор CUDA
- **nvidia-smi** - инструмент мониторинга GPU
- **cuBLAS** - библиотека линейной алгебры для GPU
- **Nsight** - инструменты профилирования NVIDIA
- **libcuda** - низкоуровневая библиотека для работы с GPU

## Создание глоссария

Modal Labs прочитали PDF-документацию от NVIDIA, изучили тематические Discord-сообщества и даже приобрели бумажные учебники, чтобы создать всестороннюю базу знаний.

## Особенности

- **Взаимосвязанность**: все страницы глоссария связаны между собой, что позволяет переходить к разделу о Warp Scheduler, чтобы лучше понять потоки, о которых читали в статье о модели программирования CUDA
- **Полный охват**: охватывает весь стек GPU-программирования
- **Практическая направленность**: создан для решения реальных задач, с которыми сталкиваются инженеры
- **Открытый доступ**: проект с открытым исходным кодом
