# LATENT: Обучение атлетических навыков тенниса для гуманоидных роботов на несовершенных данных motion capture

## Краткое описание

**LATENT** (Learning Athletic humanoid TEnnis skills from imperfect human moTion daTa) — это система для обучения гуманоидных роботов навыкам игры в теннис, использующая несовершенные данные захвата движения (motion capture). Проект разработан исследователями из Университета Цинхуа и GalaxyGeneralRobotics.

**Ключевая особенность:** Система способна обучаться на ограниченных данных motion capture (всего 5 часов реальных данных) и демонстрирует атлетические навыки игры в теннис на гуманоидных роботах.

## Основная проблема

### Несовершенные данные motion capture

Данные захвата движения людей имеют фундаментальные ограничения для обучения роботов:

1. **Анатомические различия**: Человеческое тело отличается от робота (другие степени свободы, ограничения суставов, кинематика)
2. **Неполнота данных**: Motion capture фиксирует только позиции маркеров, не все суставы и степени свободы
3. **Шум и артефакты**: Реальные данные MoCap содержат шум, пропуски кадров, артефакты захвата
4. **Ограниченное покрытие**: Данные могут не покрывать все возможные состояния и ситуации

### Почему антропоморфные роботы?

Несмотря на кажущиеся недостатки (хрупкость, неустойчивость, медленность), антропоморфные роботы имеют ключевое преимущество:

**Доступность данных для обучения:**
- Огромные объёмы видео с людьми (кожаные гуманоиды)
- Датасеты motion capture (AMASS, LAFAN1, и другие)
- Возможность использования человеческих демонстраций и реплеев
- Переносимость навыков между людьми и роботами через retargeting

Это создаёт уникальную возможность для обучения с подражанием (imitation learning), используя богатые человеческие данные.

## Архитектура LATENT

### Этапы обучения

```
┌─────────────────────────────────────────────────────────────┐
│  ЭТАП 1: Motion Tracker Pre-training                        │
│  ─────────────────────────────────────────────────────────  │
│  • Предобучение трекера движений на MoCap данных           │
│  • Retargeting человеческих движений на робота             │
│  • Выравнивание кинематических пространств                 │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  ЭТАП 2: Online Distillation (DAgger)                       │
│  ─────────────────────────────────────────────────────────  │
│  • Онлайн-дистилляция через DAgger                         │
│  • Итеративное расширение датасета                         │
│  • Решение проблемы каскадных ошибок                       │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  ЭТАП 3: High-level Policy Learning                         │
│  ─────────────────────────────────────────────────────────  │
│  • Обучение высокоуровневой политики игры в теннис         │
│  • Обучение с подкреплением (RL)                           │
│  • Интеграция восприятия и принятия решений                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  ЭТАП 4: Sim2Real Transfer                                 │
│  ─────────────────────────────────────────────────────────  │
│  • Перенос навыков из симуляции в реальный мир             │
│  • Domain randomization для робастности                    │
│  • Развёртывание на физическом роботе                      │
└─────────────────────────────────────────────────────────────┘
```

### Ключевые компоненты

| Компонент | Описание |
|-----------|----------|
| **Motion Tracker** | Трекер движений для retargeting человеческих движений на кинематику робота |
| **DAgger Distillation** | Онлайн-дистилляция через алгоритм DAgger для решения проблемы накопления ошибок |
| **High-level Policy** | Высокоуровневая политика для принятия решений в теннисе |
| **MuJoCo Simulation** | Симуляция на базе MuJoCo для безопасного обучения |
| **Multi-GPU Training** | Поддержка многопроцессорного обучения для ускорения |

## Технические детали

### Стек технологий

- **Симуляция:** MuJoCo
- **Фреймворки:** JAX, Brax
- **Зависимости:** loco-mujoco, mujoco_playground, OpenTrack
- **Параллелизация:** Multi-GPU поддержка

### Структура проекта

```
LATENT/
├── latent_mj/                    # Основной Python пакет
│   ├── motion_tracker/           # Трекер движений
│   ├── daggger_distillation/     # DAgger дистилляция
│   ├── policy_learning/          # Обучение политики
│   └── sim2real/                 # Sim2Real перенос
├── scripts/
│   └── process_motion/           # Скрипты обработки движений
├── storage/

```

### Сравнение с OmniXtreme

| Характеристика | LATENT | OmniXtreme |
|----------------|--------|------------|
| **Домен** | Теннис (специфичный навык) | Разнообразные экстремальные движения |

## Применение и значение

### Научная ценность

1. **Доказательство концепции:** Обучение на ограниченных MoCap данных возможно
2. **Антропоморфный дизайн:** Подтверждение ценности человеческих данных для обучения
3. **Спортивная робототехника:** Демонстрация сложных динамических навыков

### Практическое применение

- **Спортивные роботы:** Демонстрационные и развлекательные системы
- **Исследования:** Платформа для изучения обучения с подражанием
- **Образование:** Открытый исходный код для научного сообщества
