# Newton 1.0 GA: GPU-ускоренный физический движок для робототехники

## Краткое описание

**Newton 1.0 GA** (General Availability) — это открытый GPU-ускоренный физический симулятор для промышленной робототехники, анонсированный на NVIDIA GTC 2026. Проект разработан совместно NVIDIA, Google DeepMind, Disney Research и Toyota Research Institute в рамках Linux Foundation.

**Ключевая особенность**: впервые в одном инструменте объединены реалистичная физика деформируемых объектов, продвинутое обнаружение столкновений и масштабируемое обучение с подкреплением на GPU.

## Общее описание

Newton представляет собой модульный физический движок с открытым исходным кодом, построенный на базе **NVIDIA Warp** — CUDA-X библиотеки для GPU-ускоренных вычислений. Симулятор предоставляет стабильный API для моделирования, решения физических задач, управления и сенсорного моделирования.

### Ключевые характеристики

| Характеристика | Описание |
|----------------|----------|
| **GPU-ускорение** | Построен на NVIDIA Warp для параллельных сред обучения |
| **Открытый исходный код** | Проект Linux Foundation, свободное использование и модификация |
| **Модульная архитектура** | Комбинируемые компоненты: обнаружение столкновений, контактные модели, сенсоры, управление, решатели |
| **Стабильный API** | Унифицированный интерфейс для всех компонентов |
| **Production-ready** | Готов к промышленному использованию с GTC 2026 |

## Архитектура решателей

Newton объединяет **несколько решателей** в единой архитектуре, каждый из которых оптимизирован для своих задач:

### Kamino (Disney Research)

Решатель от Disney Research для **сложных механизмов с замкнутыми кинематическими цепями**:

- Поддержка параллельных рычажных механизмов
- Пассивная актуация
- Многозвенные шагающие роботы с несколькими замкнутыми контурами на ногу
- Пример: Dr. Legs — закрытый механизм роботизированной ноги

**Применение**: сложные кинематические цепи, роботизированные руки, шагающие системы.

### MuJoCo Warp / MJWarp (Google DeepMind)

GPU-ускоренная версия MuJoCo от Google DeepMind:

- Наследует стабильность и точность классического MuJoCo
- **Масштабная пропускная способность** на GPU для тысяч параллельных сред обучения
- **Ускорение производительности** (на NVIDIA RTX PRO 6000 Blackwell):
  - **252x** для задач локомоции
  - **475x** для задач манипуляции

**Применение**: массовое параллельное обучение с подкреплением, высокоскоростная симуляция.

### VBD (Vertex Block Descent)

Решатель для **деформируемых объектов**:

- **Линейные деформируемые объекты**: кабели, провода
- **Тонкие деформируемые объекты**: ткань, материалы
- **Объёмные деформируемые объекты**: резина, мягкие материалы

**Применение**: симуляция кабелей, тканей, мягких объектов.

### iMPM (Implicit Material Point Method)

Решатель для **частичной симуляции**:

- Гранулированные материалы
- Сыпучие среды
- Неровный рельеф

**Применение**: локомоция по сложным поверхностям, взаимодействие с гранулированными средами.

## Производительность

### Ускорение вычислений

| Задача | Ускорение | Платформа тестирования |
|--------|-----------|------------------------|
| Локомоция | **252x** | NVIDIA RTX PRO 6000 Blackwell |
| Манипуляция | **475x** | NVIDIA RTX PRO 6000 Blackwell |

### Оптимизации производительности

1. **Tiled camera sensor** — высокоскоростные пакетные визуальные наблюдения across parallel environments
2. **Конвейер обнаружения столкновений** — выбираемые broadphase/narrowphase алгоритмы в зависимости от сложности сцены
3. **Ray-tracing рендеринг** — поддержка triangle meshes и Gaussian splats

## Интеграция с экосистемой

### Совместимость с форматами

Newton поддерживает **широкую модель данных времени выполнения**:

- **URDF** (Universal Robot Description Format)
- **MJCF** (MuJoCo XML format)
- **OpenUSD** (Universal Scene Description)

Это позволяет подключать существующие роботизированные активы и рабочие процессы без привязки к единому формату.

### Isaac Sim и Isaac Lab

| Интеграция | Детали |
|------------|--------|
| **Isaac Sim 6.0** | Нативная интеграция через OpenUSD слой данных |
| **Isaac Lab 3.0** (EA) | Newton как физический и camera-sensor бэкенд |
| **Рабочий процесс** | Определение задач, PPO обучение, наблюдения/награды остаются идентичными — меняется только бэкенд симуляции |
| **Валидация** | Среды могут валидироваться across различных физических движков |

#### Пример конфигурации (Isaac Lab + Newton)

```python
from isaaclab.sim import SimulationCfg
from isaaclab_newton.physics import NewtonCfg, MJWarpSolverCfg

FrankaCubeEnvCfg.solver_cfg = MJWarpSolverCfg(
    solver="newton",
    integrator="implicitfast",
    njmax=2000,
    nconmax=1000,
    iterations=20,
    ls_iterations=100,
    ls_parallel=True,
)
```

## Применение в промышленной робототехнике

### 1. Автоматизация сборки GPU-стоек (Skild AI)

**Задача**: вставка коннекторов, размещение плат, крепление

**Используемые технологии**:
- SDF-based обнаружение столкновений для сложной CAD геометрии
- Hydroelastic контактное моделирование для распределённых контактных давлений
- Non-convex tri-mesh модели для деталей с жёсткими допусками

**Преимущество**: высокая точность контактов для RL обучения с переносом на реальные системы.

### 2. Манипуляция кабелями для сборки холодильников (Samsung + Lightwheel)

**Задача**: вставка кабелей (водопроводный шланг холодильника)

**Используемые технологии**:
- VBD решатель для 1D деформируемой симуляции кабелей
- Двусторонняя связь с MuJoCo Warp для взаимодействия робот-кабель
- SimReady активы, настроенные по реальным измерениям

**Преимущество**: генерация синтетических данных для обучения vision-language-action (VLA) моделей.

### 3. Дополнительные применения

| Применение | Возможность |
|------------|-------------|
| **Ловкая манипуляция** | Манипуляция в руке с тактильными сенсорами |
| **Шагающая локомоция** | Навигация по сложному рельефу с деформируемой поверхностью |
| **Манипуляция тканью** | Работа с тонкими деформируемыми материалами |
| **Взаимодействие с гранулированными материалами** | Локомоция по неровному рельефу |
