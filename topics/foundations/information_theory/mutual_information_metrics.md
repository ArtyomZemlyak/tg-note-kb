# Метрики взаимной информации для оценки качества моделей

## Обзор

Взаимная информация (Mutual Information, MI) — это фундаментальная концепция из теории информации, используемая для измерения зависимости между двумя случайными переменными. В контексте оценки языковых моделей и агентных систем, взаимная информация может измерять, насколько много информации в одной переменной (например, сжатом саммари) позволяет предсказать другую переменную (например, исходный контекст или целевой ответ).

## Определение взаимной информации

Для двух дискретных случайных переменных X и Y, взаимная информация определяется как:

I(X; Y) = Σₓ Σᵧ p(x,y) log [p(x,y) / (p(x)p(y))]

Альтернативные выражения:
- I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)
- I(X; Y) = KL(P(X,Y) || P(X)P(Y))

Где:
- H(X) — энтропия переменной X
- H(X|Y) — условная энтропия X при данном Y
- KL — расстояние Кульбака-Лейблера

## Информационный рейтинг (Information Rate) в агентных системах

Согласно статье "An Information Theoretic Perspective on Agentic System Design", **Information Rate** определяется как взаимная информация на токен. Это метрика, которая измеряет эффективность передачи информации в архитектуре Compressor-Predictor.

### Формула оценки

Поскольку взаимная информация для текста не может быть вычислена напрямую, авторы предлагают Monte Carlo оценку:

Î(X; Z) ≈ 1/(NM) * Σ [ log p(z|x_true) - log (mean(p(z|x_random))) ]

Где:
- x_true — истинный контекст
- z — саммари, созданное компрессором
- x_random — случайные (отрицательные) контексты
- N — количество контекстов
- M — количество сэмплов

## Применения взаимной информации

### 1. Оценка качества компрессоров

В архитектуре Compressor-Predictor:
- I(X; Z) измеряет, насколько много информации из исходного контекста X сохраняется в саммари Z
- Высокая I(X; Z) указывает на то, что компрессор сохраняет релевантную информацию
- Может быть использована как метрика качества сжатия, независимая от downstream задачи

### 2. Оценка качества саммари

- Модельная оценка качества саммари без отсылки к эталону
- Позволяет сравнивать разные подходы к саммари без человеческой оценки
- Универсальная метрика для любого типа контента

### 3. Оптимизация архитектуры моделей

- I(X; Z) может использоваться для выбора оптимального размера саммари
- Помогает определить баланс между компрессией и сохранением информации
- Используется как целевая функция для обучения компрессоров

## Методология оценки

### Использование прокси-модели (Proxy Model)

Поскольку мелкие компрессоры (1B-3B) часто плохо калиброваны, авторы используют прокси-модель:
- Вероятности p(z|x) оцениваются через более мощную и стабильную модель (например, Qwen-2.5-7B-Instruct)
- Это позволяет измерить реальное семантическое содержание, а не уверенность компрессора в собственной галлюцинации

### Точность и надежность метрики

- Information Rate тесно коррелирует (R²=0.71) с точностью downstream задач
- Позволяет оценить качество компрессора независимо от предиктора
- Предоставляет объективную меру, не зависящую от конкретного downstream приложения

## Преимущества перед традиционными метриками

### Сравнение с перплексией

- Перплексия: мера предсказуемости, зависит от конкретной задачи
- Взаимная информация: мера передачи информации, универсальная метрика

### Сравнение с семантической близостью

- Семантическая близость: оценка через эмбеддинги, может не учитывать важные детали
- Взаимная информация: учитывает семантическое содержание через вероятностные оценки

### Сравнение с людской оценкой

- Людская оценка: дорогостоящая, медленная, субъективная
- Взаимная информация: автоматическая, объективная, быстрая

## Ограничения и проблемы

### Вычислительная сложность

- Прямое вычисление взаимной информации для текста невозможно
- Требуется Monte Carlo оценка с использованием модели
- Зависит от качества прокси-модели

### Чувствительность к прокси-модели

- Результат зависит от выбранной прокси-модели
- Если прокси-модель чего-то не понимает, метрика может быть неточной
- Требуется выбор подходящей прокси-модели

### Применимость к разным типам данных

- Метрика лучше работает с семантически связанными парами X и Z
- Может не учитывать важные структурные аспекты данных
- Требуется осторожная интерпретация для разных доменов

## Практические примеры использования

### Оптимизация компрессоров

- Использование Information Rate для выбора между разными компрессорными моделями
- Определение оптимального размера саммари для заданной задачи
- Ранжирование архитектур компрессоров по их способности сохранять информацию

### Сравнение архитектур

- Оценка влияния разных подходов к сжатию на качество downstream задач
- Сравнение end-to-end подходов с архитектурой Compressor-Predictor
- Определение точек оптимального распределения вычислительных ресурсов

### Мониторинг качества

- Автоматический мониторинг качества компрессии в production системах
- Обнаружение деградации качества компрессоров
- А/Б тестирование обновлений компрессоров

## Связь с другими метриками

### Связь с точностью downstream задач

- Высокая Information Rate обычно коррелирует с высокой точностью downstream задач
- R²=0.71 корреляция между Information Rate и downstream точностью
- Позволяет предсказывать downstream производительность без запуска полного pipeline

### Связь с Information Bottleneck

- Information Rate используется в рамках принципа Information Bottleneck
- Баланс между эффективностью сжатия (rate) и потерей смысла (distortion)
- Помогает находить оптимальную точку в этом балансе

## Будущие направления

### Автоматическая оптимизация

- Автоматическая настройка размера саммари на основе метрики
- Адаптивные архитектуры, оптимизируемые под Information Rate

### Расширение на другие домены

- Интеграция с обучением представлений
