# Контрфактуальные объяснения (Counterfactual Explanations)

## Краткое описание

Контрфактуальное объяснение (Counterfactual Explanation) — это метод объяснимого ИИ (XAI), который предоставляет минимальное изменение входных данных, необходимое для изменения прогноза модели. Другими словами, это «ближайший» пример в пространстве данных, который приводит к другому прогнозу.

## Основная концепция

Контрфактуальные объяснения отвечают на вопрос: **«Что минимально нужно изменить в исходных данных, чтобы модель выдала другой результат?»**

### Игрушечный пример

Представьте, что вы прогнозируете вес через 3 года на основе признаков:
- **Исходные данные**: вес 60 кг → **прогноз**: 80 кг
- **Контрфактуальное объяснение**: минимальные изменения (например, «добавить 30 минут физической активности в день»), которые приводят к прогнозу «остаться в текущем весе»

## Проблема

Задача поиска ближайшего примера в пространстве примеров — сложная оптимизационная проблема. Существующие методы:
- Не гарантируют минимального количества изменённых признаков
- Могут рекомендовать множество микро-действий, которые не нужны на практике
- Методы на основе пертурбации (LIME, SHAP) могут давать разные результаты для схожих входов и легко путаются

## Решение: COLA

**COLA** (Refining Counterfactual Explanations With Joint-Distribution-Informed Shapley Towards Actionable Minimality) — свежая реализация, использующая SHAPley values для улучшения контрфактуальных объяснений.

### Идея COLA

1. **Использование SHAPley values** — легендарный алгоритм для определения важности признаков
2. **Отбор наиболее значимых признаков** — сначала определяются ключевые признаки, влияющие на прогноз
3. **Изменение только значимых признаков** — для генерации контрфактуала изменяются только отобранные признаки

### Преимущества подхода

- Гарантирует минимальность изменений
- Делает объяснения более действенными (actionable)
- Учитывает совместное распределение признаков

## Применение

Контрфактуальные объяснения особенно полезны для задач, где важно исследовать:
- **Объект применения модели** — что изменить в конкретных данных для получения желаемого прогноза
- **Исследование самой модели** — понимание границ принятия решений моделью

### Области использования

- **Медицинская диагностика** — какие изменения в показателях пациента приведут к другому диагнозу
- **Финансовый скоринг** — что нужно изменить заёмщику для получения одобрения кредита
- **Персонализированные рекомендации** — минимальные действия для достижения желаемого результата

## Связь с другими методами XAI

### Отличия от LIME и SHAP

- **LIME/SHAP** — объясняют важность признаков для текущего прогноза через пертурбацию и выборку
- **Контрфактуалы** — показывают конкретное минимальное изменение для смены прогноза

### Проблемы методов на основе пертурбации

Как отмечается в литературе, методы типа LIME и SHAP:
- Могут предоставлять очень разные результаты для схожих входов
- Демонстрируют нестабильность и высокую дисперсию
- Выводят контрфактуальные объяснения, но могут быть легко запутаны
- Не гарантируют связь с истинным распределением данных
