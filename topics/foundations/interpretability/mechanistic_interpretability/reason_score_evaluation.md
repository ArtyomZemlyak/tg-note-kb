# ReasonScore: Метрика для идентификации признаков рассуждения

## Описание

ReasonScore - это автоматическая метрика, разработанная для идентификации признаков (features) разреженного автоэнкодера (SAE), ответственных за процессы рассуждения в языковых моделях. Метрика была представлена в работе AIRI "I Have Covered All the Bases Here: Interpreting Reasoning Features in Large Language Models via Sparse Autoencoders".

## Цель

ReasonScore предназначен для:
- Количественной оценки степени активности i-го признака на "рассуждающих" словах (reasoning words)
- Идентификации SAE-признаков, которые наиболее связаны с внутренними процессами рассуждения
- Автоматического определения признаков, ответственных за неопределенность, исследование и рефлексию в моделях

## Методология

### Словарь рассуждения (Reasoning Vocabulary)
Первым шагом является построение словаря рассуждения R, состоящего из 10 слов, которые модели используют во время рассуждений:
- "alternatively", "hmm", "maybe", "wait", "perhaps", "let me", "therefore", "however", "but", "another"

Эти слова выбраны на основе частотного анализа между формальными решениями задач и процессом "мышления" моделей.

### Базовая оценка
Для i-го признака сначала определяется базовая оценка:

```
score_base(i) = (µ(i, D_R) - µ(i, D_¬R)) / (µ(i, D_R) + µ(i, D_¬R))
```

где:
- µ(i, D) = (1/|D|) Σ_{x∈D} f_i(x) - среднее значение активации i-го признака на наборе данных D
- D_R содержит активации для слов в R
- D_¬R содержит активации для всех остальных слов

### Контекстно-зависимая оценка
Чтобы учесть контекстуальную информацию, метрика использует наборы с окном:
- D_W_R - набор активаций в окне ± нескольких токенов вокруг слов в R
- D_W_¬R - все остальные активации

### Штраф за энтропию
Чтобы избежать признаков, активных только на малом подмножестве слов R, используется штраф за энтропию:

```
H_i = -Σ_{r_j ∈ R} p_i(r_j) * log(p_i(r_j)) / log|R|
```

где p_i(r_j) - нормализованное значение активации i-го признака на слове r_j.

### Итоговый ReasonScore
```
ReasonScore(i) = score_contextual(i) * (1 + α * H_i)
```

где α контролирует баланс между специфичностью (α → 0) и обобщением (α > 1).

## Применение

### Идентификация множества признаков рассуждения
Множество признаков рассуждения F_R определяется как:

```
F_R = {i | ReasonScore(i) ≥ τ}
```

где τ - q-й квантиль распределения ReasonScore по всем признакам.

### Результаты применения
- В исследовании было идентифицировано 200 признаков с высоким ReasonScore
- Из них 46 прошли ручную интерпретацию и были классифицированы как отражающие неопределенность, исследование и рефлексию

## Экспериментальная валидация

### Ручная интерпретация
Признаки с высоким ReasonScore были проверены на:
1. Надежное наличие связанной концепции в контексте при активации
2. Срабатывание в различных примерах задач рассуждения
3. Влияние на интерпретируемые логиты, соответствующие процессам рассуждения

### Автоматическая интерпретация
Использовался метод автоматической интерпретации с GPT-4O для проверки функционального влияния признаков.

### Эксперименты по управлению (steering)
- Усиление признаков с высоким ReasonScore увеличило производительность на бенчмарках рассуждения
- Признаки #4395, #16778, #25953 и др. показали значительное улучшение

## Значение

### Для интерпретируемости
- ReasonScore предоставляет объективный способ идентификации признаков, связанных с рассуждением
- Позволяет количественно оценить "рассуждающую составляющую" в активациях модели

### Для анализа моделей
- Может использоваться для сравнительного анализа способностей к рассуждению разных моделей
- Помогает понять, как развиваются способности к рассуждению в процессе обучения

### Для улучшения моделей
- Идентифицированные признаки могут быть целенаправленно усилены или подавлены
- Позволяет разработать методы улучшения рассуждающих способностей моделей

## Ограничения

### Гиперпараметры
Metric зависит от гиперпараметров (размер окна, штраф за энтропию α), требующих дополнительного анализа.

### Частичное покрытие
Только 46 из 200 кандидатов прошли достоверную ручную интерпретацию, остальные могли быть пропущены из-за неоднозначных паттернов активации.

### Словарь рассуждения
Словарь может не охватывать все аспекты рассуждений, использованные моделями.

## Сравнение с другими подходами

### Отличие от традиционного анализа признакей
- ReasonScore фокусируется конкретно на рассуждениях, а не на любых интерпретируемых признаках
- Использует конкретный словарь, основанный на лингвистическом анализе процессов рассуждения

### Связь с другими метриками
- Использует аналогичный подход к оценке специфичности, как и другие метрики в области
- Введение штрафа за энтропию является уникальным элементом ReasonScore

## Перспективы развития

### Улучшенный словарь рассуждения
- Расширение словаря на основе анализа большего числа моделей
- Адаптация словаря для разных типов задач (математика, наука, программирование)

### Уточнение метрики
- Автоматическая оптимизация гиперпараметров
- Интеграция с другими метриками интерпретируемости

### Расширение области применения
- Применение к другим аспектам поведения моделей (например, честность, креативность)
- Использование для целевой настройки моделей
