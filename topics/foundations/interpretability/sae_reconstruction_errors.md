# Ошибки реконструкции SAE (SAE Reconstruction Errors)

## Описание

Ошибки реконструкции Sparse AutoEncoders (SAE) представляют собой разницу между исходным вектором активации и его реконструкцией после прохождения через SAE. Эти ошибки не являются просто случайным шумом, а обладают сложной структурой, которая может влиять на поведение модели.

## Типы ошибок

### Линейно предсказуемые ошибки

Согласно работе "Decomposing The Dark Matter of Sparse Autoencoders":

- Около половины вектора ошибки может быть линейно предсказано из исходного вектора активации
- Более 90% нормы вектора ошибки может быть линейно предсказано из исходного вектора активации
- Это показывает, что значительная часть ошибки не является случайной, а имеет систематическую структуру

### Нелинейные ошибки

- Оставшаяся часть ошибки не может быть линейно предсказана
- Содержит меньше "еще не изученных признаков" по сравнению с линейной ошибкой
- SAE, обученные на нелинейной ошибке, количественно хуже
- Помогает предсказать масштабирование SAE на уровне отдельных токенов
- Отвечает за пропорциональное увеличение кросс-энтропийной ошибки при вставке активаций SAE в модель

## Патологический характер ошибок

Работа "SAE reconstruction errors are (empirically) pathological" показывает, что:

- Ошибки SAE ведут себя патологически по сравнению со случайным шумом
- При одинаковой норме возмущения SAE-ошибка приводит к большему KL-расхождению по сравнению со случайным шумом
- Это означает, что ошибки SAE качественно отличаются от обычного шума и могут негативно влиять на поведение модели

## Возможные улучшения

- Время вывода градиентный поиск: приводит к небольшому уменьшению нелинейной ошибки
- Линейные преобразования из выходов SAE более ранних слоев: приводят к более значительному снижению нелинейной ошибки

## Влияние на интерпретируемость

Наличие структурированных ошибок в SAE означает, что:

- Декомпозиция активаций не является полной
- Оставшаяся "темная материя" может содержать важные признаки
- Необходимо учитывать ошибки при анализе результатов работы SAE
