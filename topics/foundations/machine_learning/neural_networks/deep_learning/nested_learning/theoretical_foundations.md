# Теоретические основы вложенного обучения

## Математическое представление

Вложенное обучение (NL) представляет модель машинного обучения как набор вложенных, многоуровневых и/или параллельных задач оптимизации, каждая из которых имеет собственный "поток контекста". Математически это можно выразить как:

Для системы с K уровнями, каждый уровень k состоит из набора оптимизационных задач:

{(L^(k)_i, C^(k)_i, Θ^(k)_i)}^(N_k)_(i=1)

где:
- L_i(·; ·) - целевая функция для i-й задачи
- C_i - контекст (набор данных, на котором происходит оптимизация)
- Θ_i - допустимый набор параметров
- каждый параметр оптимизируется с помощью градиентного спуска

## Частота обновления

Определение частоты обновления компонентов критично для иерархии:

f_A - частота обновления компонента A, определяется как количество обновлений за единицу времени.

Сравнение компонентов:
- A быстрее B (A ≻ B) если f_A > f_B
- Или если f_A = f_B, но вычисление состояния B при времени t требует вычисления состояния A при времени t

## Вложенная система ассоциативной памяти (NSAM)

NSAM - особый случай NL, в котором каждая оптимизационная задача представляет собой задачу ассоциативной памяти. Каждый уровень k содержит задачи, где C_i = {(k^(i)_j, v^(i)_j)}^(L_i)_(j=1) - набор пар "ключ-значение", а L_i(·; ·, ·) измеряет качество отображений памяти.

## Основные операторы в NL

### 1. Ассоциативная память
Для набора ключей K ⊆ R^d_k и значений V ⊆ R^d_v, ассоциативная память - это оператор M(·), который отображает ключи в значения. Процесс обучения осуществляется через решение оптимизационной задачи:

M = argmin_M ˜L(M; K, V)

### 2. Delta Gradient Descent (DGD)
Обобщение градиентного спуска, которое использует L2 регрессию вместо скалярного произведения. Обновление:

W_{t+1} = W_t - η_t * (W_t * x_{t+1} - u_{t+1}) * x_{t+1}^T / (||x_{t+1}||² + η_t)

где u_{t+1} - целевое значение (например, локальный сигнал ошибки).

### 3. Многоуровневые связи
Возможны различные варианты передачи знаний между уровнями:
- Прямое соединение (параметрическое и непараметрическое)
- Передача через обратное распространение
- Инициализация через метаобучение
- Генерация весов/контекста

## Формализация нейронных обучающихся модулей

Нейронный обучающийся модуль (Neural Learning Module) - это представление модели, при котором архитектура и процесс оптимизации совместно определяют модель и её выходы. В отличие от классических подходов, где обучение и тестирование отделены, NL рассматривает непрерывный процесс обучения без четкого разделения на фазы обучения и тестирования.

## Контекстный поток

Ключевая идея NL - каждый компонент модели имеет свой собственный "поток контекста":
- Для архитектуры: токены/последовательности
- Для оптимизатора: градиенты
- Для систем более высокого уровня: результаты обучения нижнего уровня
