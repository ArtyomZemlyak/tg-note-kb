# Теоретический анализ DroPE: Удаление позиционных эмбеддингов для расширения контекста

## Обзор

DroPE (Dropping the Positional Embeddings) представляет собой метод расширения контекста предобученных языковых моделей (LLM), основанный на удалении явных позиционных эмбеддингов (PE) после фазы предобучения. Этот подход основывается на идее, что позиционные эмбеддинги действуют как "строительные леса" для обучения, но становятся препятствием для обобщения на длинные последовательности.

## Три ключевых наблюдения

### 1. Важность позиционных эмбеддингов при обучении

Позиционные эмбеддинги, особенно RoPE, обеспечивают важный индуктивный сдвиг, который значительно ускоряет сходимость во время предобучения. В отличие от NoPE архитектур (без явных позиционных эмбеддингов), модели с RoPE демонстрируют лучшую сходимость и стабильность:

- **RoPE ускоряет развитие позиционного сдвига**: Обеспечивает сильный индуктивный сдвиг с самого начала, позволяя головкам внимания быстрее aprenderать диагональные или отоф-диагональные паттерны
- **Градиенты выше при инициализации**: Нормы градиентов для функционала позиционного сдвига (A^c) значительно выше в RoPE трансформерах по сравнению с NoPE
- **Проблема с равномерностью**: NoPE трансформеры сталкиваются с проблемой "пробития равномерности" - разброс скрытых состояний остается низким из-за малой дисперсии инициализации

### 2. Проблема экстраполяции длины у RoPE

Традиционные методы масштабирования RoPE (PI, RoPE-NTK, YaRN) решают проблему OOD (out-of-distribution) вращений при экстраполяции длины, но не решают фундаментальные проблемы:

- **Сдвиг частот**: Методы сжимают низкие частоты, чтобы фазы оставались в пределах [0, 2π]
- **Повреждение семантического внимания**: Низкочастотные компоненты, используемые семантическими головами, смещаются, что ведет к ухудшению производительности на задачах типа "needle-in-a-haystack"
- **Невозможность zero-shot обобщения**: Модели требуют дообучения на длинных последовательностях

### 3. Возможность удаления позиционных эмбеддингов

Позиционные эмбеддинги не являются обязательной частью эффективного языкового моделирования и могут быть безопасно удалены после предобучения после короткой фазы перекалибровки.

## Теоретический анализ NoPE трансформеров

### Определение позиционного сдвига внимания

Позиционный сдвиг внимания A^c определяется как:

A^c = Σ c_ij * α_ij

где c_ij - центрированные позиционные веса с условием Σ_j≤i c_ij = 0, а α_ij - веса внимания.

### Теорема 3.4: Проблема разброса префикса

Для NoPE трансформеров определяется "разброс префикса" скрытых состояний на слое l:

Δ^(l)_h = max_i ||h_i - (1/i)Σ_j≤i h_j||

Существует ε > 0 и константы C1, C2, C3 такие что если начальные эмбеддинги Δ^(1)_h ≤ ε, то для всех слоев l ≤ L:

||∇_θ A^c|| ≤ C1 * Δ^(l)_h + C2
|A^c| ≤ C3 * Δ^(l)_h

с высокой вероятностью по распределению инициализации. Константы зависят только от числа слоев и головок, но не от длины последовательности.

### Почему NoPE модели медленно сходятся

1. **Проблема с постоянными последовательностями**: На последовательности из одинаковых токенов x₁ = ... = x_T все головки внимания в NoPE становятся равномерными: α_ij = 1/i
2. **Ванishing градиенты**: Градиенты по параметрам WQ, WK исчезают: ∂L/∂WQ = ∂L/∂WK = 0
3. **Ограниченная скорость развития**: Позиционный сдвиг развивается медленно из-за ограниченных градиентов при инициализации

## Механизм работы DroPE

### Процесс применения

1. **Предобучение с RoPE** - модель обучается традиционным способом с использованием RoPE
2. **Удаление позиционных эмбеддингов** - после достижения желаемого контрольного пункта все RoPE компоненты удаляются из каждой операции внимания
3. **Короткая фаза перекалибровки** - модель дообучается на исходной длине контекста (обычно 2% от бюджета предобучения)

### QKNorm для стабилизации

В процессе перекалибровки используется QKNorm (Query-Key Normalization), который применяет LayerNorm или RMSNorm к запросам (queries) и ключам (keys) перед скалярным произведением для стабилизации логитов внимания. Это позволяет использовать более агрессивные скорости обучения (например, 10^-3) без всплесков потерь.

## Экспериментальные результаты

### Zero-shot экстраполяция

DroPE демонстрирует значительное превосходство на задачах "иголка в стоге сена":

| Метод | Multi-Query | Multi-Key | Multi-Value |
|-------|-------------|-----------|-------------|
| RoPE + YaRN | 17.8% | 0.5% | 14.6% |
| DroPE | 28.0% | 41.6% | 23.3% |

### Сохранение производительности в исходном контексте

DroPE соответствует качеству RoPE в исходном контексте обучения и превосходит NoPE baseline:

- **Сопоставимая перплексия** на валидационных данных
- **Лучшие результаты** по сравнению с NoPE обученным с нуля
- **Низкий бюджет перекалибровки** (менее 2% от исходного обучения)

## Архитектурные последствия

### Парадигма "строительных лесов"

DroPE представляет новую парадигму в дизайне архитектур LLM:
- Позиционные эмбеддинги рассматриваются как временные "строительные леса"
- Их функция - обеспечить стабильность обучения, а не долгосрочное функционирование
- После выполнения своей обучающей функции их можно безопасно удалить

### Универсальность метода

- **Применим к уже предобученным моделям** (включая Llama2-7B, SmolLM)
- **Масштабируется до крупных архитектур** (до 7B параметров)
- **Низкие вычислительные требования** для перекалибровки (до 0.5% бюджета)

## Сравнение с альтернативными архитектурами

| Архитектура | Обучение | Zero-shot экстраполяция | Компромиссы |
|-------------|----------|-------------------------|-------------|
| RoPE | Быстрое | Отсутствует | Требует масштабирования |
| NoPE | Медленное | Потенциально хорошая | Плохая сходимость |
| RoPE-Scaling | Без изменений | Ограниченная | Требует дообучения |
| **DroPE** | **Быстрое** | **Отличная** | **Короткая перекалибровка** |

## Практические применения

DroPE особенно полезен для:
- Обработки длинных документов (>8K токенов)
- Анализа кода с полным контекстом проекта
- Юридических и научных текстов
- Задач, где требуется доступ к информации на краях последовательности

## Ограничения и предостережения

- Требует доступа к весам модели для удаления PE
- Необходима фаза перекалибровки (хотя и короткая)
- Потенциальные изменения в архитектуре при использовании QKNorm
- Только для моделей, обученных с позиционными эмбеддингами
