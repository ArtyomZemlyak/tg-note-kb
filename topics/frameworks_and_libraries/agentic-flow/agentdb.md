# AgentDB: Интеллектуальная векторная база данных для AI-агентов

## Обзор

**AgentDB** - первая векторная база данных, специально разработанная для автономных AI-агентов. В отличие от традиционных баз данных, которые просто хранят векторы, AgentDB **учится на каждом взаимодействии**, **самовосстанавливается** и **становится умнее с течением времени** - при этом она в **150 раз быстрее** облачных аналогов и работает **везде** (Node.js, браузеры, пограничные функции, даже в автономном режиме).

## Ключевые особенности

### Шесть когнитивных паттернов памяти
- **Рефлексия** (самокритика): Обучение на основе самокритики и эпизодического повторения
- **Навыки** (переиспользуемый код): Создание переиспользуемых, настраиваемых навыков из успешных паттернов
- **Когнитивная память** (вмешательства): Отслеживание причинно-следственных связей между действиями и результатами
- **Объяснимое извлечение** (доказательства Меркла): Криптографические доказательства полноты и релевантности извлеченной информации
- **Рейтинг полезности**: Ранжирование извлеченных паттернов по фактической полезности, а не просто схожести
- **Ночной ученик**: Фоновый процесс, который обнаруживает паттерны, пока вы спите

### Производительность
- **🚀 150x Более быстрый векторный поиск** - RuVector Rust backend с SIMD (61μs p50 задержка, 8.2x быстрее, чем hnswlib)
- **🎮 25 Симуляций латентного пространства** - Эмпирически проверенные HNSW, GNN внимание, самовосстановление, лучевой поиск (98.2% воспроизводимость)
- **🔄 97.9% Самовосстановление** - Автоматическое предотвращение деградации с помощью Model Predictive Control (30-дневная проверка)
- **🧬 Графовые нейронные сети** - 8-головое внимание для адаптивного улучшения запросов (+12.4% полноты, 3.8ms прямой проход)

### Платформенная совместимость
- **🌐 Работает везде** - Node.js, браузеры, пограничные функции, MCP инструменты - работает в автономном режиме с устойчивым деградированием
- **⚙️ Нулевая конфигурация** - `npm install agentdb` и запуск - автоматический выбор оптимального бэкенда (RuVector → HNSWLib → better-sqlite3 → sql.js)
- **🤖 32 MCP инструмента + 59 CLI команд** - Полная интеграция с Claude Code, интерактивный мастер симуляции, пакетные операции

## Когнитивные памяти

### 1. ReasoningBank - Хранилище паттернов рассуждения
Хранит и извлекает успешные паттерны выполнения задач, позволяя агентам учиться на прошлых успехах и неудачах.

### 2. Рефлексия - Память с самокритикой
Сохраняет эпизоды выполнения задач вместе с самокритикой и результатами, позволяя агентам учиться на своих ошибках и успехах.

### 3. Библиотека навыков - Пожизненное обучение
Автоматически консолидирует повторяющиеся успешные выполнения задач в параметризованные навыки, которые можно составлять и повторно использовать.

### 4. Граф когнитивной памяти - Причинно-следственная связь
Отслеживает `p(y|do(x))` с использованием дважды робастной оценки и инструментальных переменных. Понимает, какие действия приводят к каким результатам.

### 5. Объяснимое извлечение - Сертификаты достоверности
Каждое извлечение сопровождается криптографическим доказательством, объясняющим, почему оно было выбрано, с доказательствами Меркла, подтверждающими полноту и актуальность.

### 6. Причинное извлечение - Реранжирование по полезности
Стандартный векторный поиск возвращает похожие памяти. Причинное извлечение rerank'ит по фактической полезности, учитывая схожесть, причинный эффект и задержку.

### 7. Ночной ученик - Автоматическое открытие паттернов
Фоновый процесс, который обнаруживает паттерны в истории эпизодов, находя паттерны, которые вы не запрограммировали явно.

## Использование

### Установка

```bash
# Установка Alpha версии (v2.0 с новыми функциями - для ранних адаптеров)
npm install agentdb@alpha

# Или установка стабильной версии
npm install agentdb@latest
```

### Базовое использование

```typescript
import { createDatabase, ReasoningBank, EmbeddingService } from 'agentdb';

const db = await createDatabase('./agent-memory.db');
const embedder = new EmbeddingService({ model: 'Xenova/all-MiniLM-L6-v2' });
await embedder.initialize();

const reasoningBank = new ReasoningBank(db, embedder);

// Сохранение того, чему научился ваш агент
await reasoningBank.storePattern({
  taskType: 'code_review',
  approach: 'Анализ с фокусом на безопасности',
  successRate: 0.95
});

// Поиск похожих успешных паттернов позже (32.6M операций/сек!)
const patterns = await reasoningBank.searchPatterns({
  task: 'безопасность кода',
  k: 10
});
```
