# Llama Index

This section contains information about Llama Index, the framework for building applications using large language models over custom data.

## Overview
Llama Index (formerly GPT Index) is a central interface for connecting private or domain-specific data with large language models through a data framework.

## Components
- Data connectors
- Indices
- Query engines
- Data agents
- Embeddings
- Storage contexts

## Applications
- Private data querying
- Question answering over documents
- Enterprise search
- Data analysis
- RAG (Retrieval-Augmented Generation) systems
