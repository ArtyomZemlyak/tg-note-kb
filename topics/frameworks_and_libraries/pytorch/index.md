# PyTorch

## Описание

PyTorch — это открытая библиотека машинного обучения, разработанная Facebook (ныне Meta). Она предоставляет гибкую и мощную платформу для разработки и обучения нейронных сетей с поддержкой динамических вычислительных графов.
