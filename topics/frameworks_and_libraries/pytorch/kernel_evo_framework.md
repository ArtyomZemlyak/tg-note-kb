# kernel-evo: Эволюционная генерация эффективных GPU-ядер

## Краткое описание

**kernel-evo** — это фреймворк с открытым исходным кодом для эволюционной генерации эффективных GPU-ядер, разработанный коллегами из AIRI (AXXX-Institute). Фреймворк предназначен для запуска эволюционных алгоритмов на задачах KernelBench и любых других задачах в том же формате.

**Разработчики:** AIRI (AXXX-Institute)

**Год:** 2026

**Репозиторий:** [https://github.com/AXXX-Institute/kernel-evo](https://github.com/AXXX-Institute/kernel-evo)

## Основная информация

kernel-evo использует эволюционные алгоритмы для автоматической оптимизации GPU-ядер. Фреймворк интегрируется с KernelBench и поддерживает как существующие задачи из бенчмарка, так и пользовательские задачи в том же формате.

### Ключевые особенности

| Особенность | Описание |
|-------------|----------|
| **Интеграция с KernelBench** | Использование существующих задач KernelBench (уровни 1, 2, 3) |
| **Пользовательские задачи** | Определение собственных задач в формате KernelBench |
| **Поддержка бэкендов** | Triton и CUDA inline бэкенды |
| **Режимы выполнения** | Локальная или удалённая валидация через eval server |
| **Экономичность** | Работа с доступными моделями (gemini flash 3, gpt-oss-120b) |
| **Мониторинг** | Интеграция с TensorBoard для отслеживания прогресса |
| **Извлечение программ** | Экспорт лучших программ из конкретных итераций через Redis |
| **Сравнение программ** | Инструменты сравнения программ по корректности и производительности |

## Архитектура системы

### Компоненты

```
┌─────────────────────────────────────────────────────────────┐
│                    kernel-evo SYSTEM                        │
├─────────────────┬─────────────────┬─────────────────────────┤
│  Task Definition│  GigaEvo        │  Validation             │
│  (Определение   │  (Эволюционный  │  (Валидация на GPU)     │
│  задач)         │  алгоритм)      │                         │
└─────────────────┴─────────────────┴─────────────────────────┘
```

#### 1. GigaEvo — Эволюционный фреймворк

kernel-evo использует эволюционный алгоритм GigaEvo с настраиваемыми параметрами:

- **`--max-generations`**: Максимальное количество поколений (например, 400)
- **`--max-mutations-per-generation`**: Максимальное количество мутаций на поколение (например, 4)
- **LLM для мутаций**: Использует LLM для генерации/мутации кода ядер
- **Отслеживание родословной**: Поддержка lineage tracking (можно отключить через `--disable-insights-lineage`)

#### 2. Redis — Управление состоянием эксперимента

Redis используется для хранения состояния эволюционного процесса и обеспечения координации между компонентами системы.

#### 3. LLM Backend — Бэкенд языковых моделей

Поддерживаются OpenAI-совместимые API:
- **OpenRouter**
- **SGLang**
- Другие совместимые бэкенды

#### 4. GPU — Этап оценки

GPU используется для измерения корректности и производительности сгенерированных ядер.

## Интеграция с KernelBench

### Использование существующих задач

```bash
# Запуск эволюции на задаче из KernelBench
python main.py --level 1 --problem-id <problem_id>
```

### Пользовательские задачи

Пользовательские задачи определяются в формате KernelBench:

```
tasks/<name>/task.py
```

### Валидация

- Совместима с метриками оценки KernelBench
- Поддерживает локальную и удалённую валидацию
- Измеряет корректность и ускорение относительно PyTorch baseline

## Рекомендуемые модели

| Модель | Категория | Преимущества |
|--------|-----------|--------------|
| **gemini flash 3** | Лучшее соотношение | Способная, низкая стоимость, может восстанавливаться из ошибочного кода |
| **gpt-oss-120b** | Лучшая open-source | Хорошее рассуждение для восстановления из ошибок |
| **GLM-5** | Альтернатива | Хорошо знает Triton, но медленнее/больше |

## Производительность и стоимость

### Стоимость экспериментов

- **Текущие эксперименты**: $0.5–1 за эксперимент с эффективными моделями

### Наблюдения

1. **Triton** лучше работает на малых эффективных ядрах (softmax, matmuls)
2. **Сложные задачи** (KernelBench level 2) показывают меньшие различия
3. **Результаты варьируются** от seed к seed; перезапуск после 200k токенов может помочь при плохих результатах

## Практическое применение

### Оптимизация для альтернативного железа

kernel-evo особенно полезен для оптимизации на альтернативном железе (не Nvidia), где может быть много недооптимизированного кода. Это делает фреймворк ценным инструментом для:

- Оптимизации на AMD GPU
- Оптимизации на собственных акселераторах (TPU, IPU, и др.)
- Исследования кросс-платформенной оптимизации

### Сценарии использования

1. **Автоматическая оптимизация ядер**: Запуск эволюционного поиска для оптимизации существующих ядер
2. **Генерация новых ядер**: Создание новых реализаций для заданных спецификаций
3. **Исследование оптимизаций**: Изучение различных стратегий оптимизации через эволюционный поиск
4. **Бенчмаркинг**: Оценка производительности различных подходов к генерации ядер

## Технические детали

### Требования

- **Python**: >= 3.12
- **LLM API**: OpenAI-совместимый
- **Redis**: Для управления состоянием GigaEvo
- **GPU**: Для оценки ядер

### Конфигурация

```bash
# Пример запуска
python main.py \
  --level 1 \
  --problem-id <id> \
  --max-generations 400 \
  --max-mutations-per-generation 4 \
  --backend triton \
  --eval-mode local
```
