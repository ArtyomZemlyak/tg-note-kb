# Вычислительная эффективность в LLM: DeepConf подход

## Обзор

DeepConf (Deep Think with Confidence) представляет собой метод, направленный на повышение вычислительной эффективности Large Language Models в задачах логического мышления за счет использования внутренних сигналов уверенности для фильтрации низкокачественных трасс рассуждений.

## Проблемы вычислительной эффективности в рассуждениях LLM

### Проблемы традиционных методов
1. **Высокие вычислительные затраты**: генерация множества цепочек рассуждений приводит к значительному увеличению количества сгенерированных токенов
2. **Уменьшение отдачи от точности**: с увеличением количества трасс точность часто насыщается или ухудшается
3. **Линейный рост затрат**: количество вычислений масштабируется линейно с количеством генерируемых трасс

### Пример из статьи
- Для улучшения pass@1 точности с 68% до 82% с помощью стандартного голосования большинства на AIME 2025 требуется 511 дополнительных трасс рассуждений на один вопрос с Qwen3-8B, потребляя 100 миллионов дополнительных токенов

## Подход DeepConf к повышению эффективности

### Центральные принципы
1. **Фильтрация по качеству**: использовать внутренние сигналы уверенности модели для отсеивания низкокачественных трасс рассуждений
2. **Динамическая остановка**: останавливать генерацию неперспективных трасс до завершения
3. **Уверенность как индикатор**: использовать метрики уверенности как показатель качества рассуждений

### Архитектура для эффективности
- **Офлайн режим**: фильтрация завершенных трасс с последующим взвешенным голосованием
- **Онлайн режим**: ранняя остановка трасс во время генерации на основе локальных показателей уверенности

## Механизмы повышения эффективности

### Локальные измерения уверенности
- В отличие от глобальных мер уверенности, локальные измерения позволяют выявлять сбои на промежуточных этапах рассуждений
- Позволяют принимать решения о продолжении/остановке генерации в реальном времени

### Две стратегии DeepConf
1. **DeepConf-low**: более агрессивная стратегия, сохраняющая только топ-10% самых уверенных трасс
2. **DeepConf-high**: более консервативная стратегия, сохраняющая топ-90% самых уверенных трасс

## Экспериментальные результаты по эффективности

### Снижение количества токенов
- **DeepConf-low**: снижение генерации токенов на 43-84% (до 84.7%) при сохранении или улучшении точности
- **DeepConf-high**: снижение на 16-59% с практически неизменной точностью
- **Пример**: на AIME24 с DeepSeek-8B метод DeepConf-low снижает количество токенов на 77.9% при увеличении точности на 5.8%

### Адаптивная выборка
- **Динамическая остановка**: генерация прерывается после достижения консенсуса (V(â)/ΣV(a) ≥ τ), что дополнительно экономит вычислительные ресурсы
- **Адаптация к сложности задачи**: оценка сложности по консенсусу среди сгенерированных трасс

### Экспериментальные данные

| Модель | Датасет | Majority Voting | DeepConf-high | DeepConf-low |
|--------|---------|-----------------|---------------|--------------|
| DeepSeek-8B | AIME24 | 3.55 (100%) | 1.45 (-59.0%) | 0.78 (-77.9%) |
| Qwen3-32B | AIME24 | 2.00 (100%) | 0.88 (-56.0%) | 0.66 (-66.8%) |
| GPT-OSS-120B | AIME25 | 3.23 (100%) | 1.42 (-56.0%) | 0.49 (-84.7%) |

*Все значения в 10^8 токенов, значения в скобках - процент экономии по сравнению с majority voting*

## Техническая реализация

### Гиперпараметры онлайн DeepConf
- **N_init**: 16 начальных трасс для оффлайн разогрева
- **η (фильтрация)**: 10% для DeepConf-low и 90% для DeepConf-high
- **τ (консенсус)**: 0.95
- **B (бюджет)**: 32, 64, 128, 256, 512

### Применение в vLLM
- Минимальные изменения в архитектуре vLLM
- Расширение LogprobsProcessor для поддержки скользящего окна уверенности
- Добавление проверки check_conf_stop() для ранней остановки

## Сравнение с другими методами

### Традиционные методы повышения эффективности
- **Ранняя остановка самосогласованности (ESC)**
- **Осознанная самосогласованность рассуждений (RASC)**
- **Адаптивная самосогласованность**
- **Динамическое голосование**

### Преимущества DeepConf
1. **Более точная оценка качества**: использование локальных измерений уверенности вместо глобальных
2. **Ранняя остановка**: возможность прекращения генерации неперспективных трасс
3. **Нет необходимости в дополнительном обучении**: использует внутренние сигналы модели
4. **Простота интеграции**: может быть интегрирован в существующие фреймворки

## Применение в реальных сценариях

### Ресурсоемкие задачи
DeepConf особенно эффективен в сценариях с ограниченными вычислительными ресурсами или когда важна скорость отклика.

### Математические рассуждения
- AIME (American Invitational Mathematics Examination)
- HMMT (Harvard-MIT Mathematics Tournament)
- BRUMO (Brown University Math Olympiad)
- GPQA-Diamond (Graduate-level STEM problems)

## Заключение

DeepConf демонстрирует значительный потенциал для повышения вычислительной эффективности в сложных задачах логического мышления с LLM. Метод достигает существенной экономии (до 84.7%) в количестве генерируемых токенов при сохранении или улучшении точности, что делает его важным шагом в направлении более эффективного использования вычислительных ресурсов в LLM.
