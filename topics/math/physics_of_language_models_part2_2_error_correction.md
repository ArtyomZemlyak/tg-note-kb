# Физика языковых моделей: Часть 2.2, Как учиться на ошибках в задачах математики начальной школы

## Краткое описание
Этот документ представляет собой резюме научной статьи "Physics of Language Models: Part 2.2, How to Learn From Mistakes on Grade-School Math Problems", посвященной исследованию того, как языковые модели могут улучшать свои рассуждения за счет включения данных об ошибках и их исправлениях в процесс предварительного обучения. Исследование показывает, что предварительное обучение на данных с ошибками и их коррекциями может привести к более высокой точности рассуждений по сравнению с обучением на безошибочных данных.

## Основная информация

### Ключевые вопросы исследования
1. Почему языковые модели совершают ошибки в рассуждениях, если могут исправлять их после генерации?
2. Почему бы не корректировать ошибки сразу во время генерации, а не после?
3. Может ли обучение на данных с ошибками и их исправлениями улучшить точность рассуждений?
4. Какова разница между коррекцией ошибок после генерации и включением обучающих данных с ошибками?
5. Может ли обучение на "данных с повторными попытками" (retry data) научить модели корректировать ошибки?

### Основные результаты

#### Результат 0-1: Модели могут испытывать "сожаление" после совершения ошибок
- Даже модели, предварительно обученные на правильных решениях, могут "понимать", что совершили ошибку, на основе внутренних состояний
- Это может быть обнаружено с помощью zondирования (probing) - техники изучения внутреннего состояния модели
- Модели с 99% точностью могут обнаруживать, когда следующий параметр не может быть вычислен (can_next задача)

#### Результат 1: Повторение при сожалении (Retry upon regret)
- Если модель обнаруживает ошибку, она может вернуться и перегенерировать решение
- Этот подход дает улучшение по сравнению с beam search, но требует высокой точности детектора ошибок
- Также усложняет процесс инференса и требует дополнительных проверок

#### Результат 2-3: Предварительное обучение на данных с повторными попытками
- Обучение на данных, содержащих ошибки и их исправления ("retry data"), приводит к более высокой точности рассуждений
- В разумном диапазоне, чем больше ошибок, тем лучше результат (например, при retry_rate=0.5 точность возрастает с 78% до 94%)
- Маскировка ошибочных токенов не требуется для эффективности

#### Результат 4: Модели редко повторяют попытки при оценке
- Модели, предварительно обученные на данных с повторными попытками, редко совершают повторные попытки во время оценки
- Даже с высоким retry_rate (например, 0.5), модели обычно совершают < 0.3 повторных попыток в среднем

#### Результат 5: Модели по-прежнему генерируют кратчайшие решения
- Несмотря на обучение на данных с ошибками, модели сохраняют способность генерировать кратчайшие решения
- Они не вычисляют ненужные параметры и следуют наиболее эффективному пути решения

#### Результат 6: Коррекция ошибок vs. поисковые методы
- Коррекция ошибок - это навык, принципиально отличающийся от beam search или коррекции на основе случайности
- Обучение на данных с ошибками дает значительно лучшие результаты, чем поисковые методы

#### Результат 7: Тонкая настройка с данными о повторных попытках
- Параметрически эффективные тонкие настройки (LoRA) не могут эффективно приобрести навык коррекции ошибок из модели, предварительно обученной на безошибочных данных
- Для приобретения этого навыка необходимы полные изменения параметров (full fine-tuning) или предварительное обучение на данных с ошибками

#### Результат 8: Предварительное обучение с фейковыми ошибками
- "Слабые" данные с ошибками (retry weak), где случайные параметры из будущего решения вставляются как ошибки, также улучшают точность
- Этот метод легко реализуем на практике и не требует семантического понимания решений

## Новые концепции и термины

### Данные с повторными попытками (Retry data)
- Обучающие данные, содержащие ошибочные шаги, сразу за которыми следуют их исправления
- Формат: [ошибочный шаг] -> [BACK] -> [правильный шаг]
- Используется для обучения моделей автоматической коррекции ошибок

### Скорость повторных попыток (Retry rate)
- Вероятность вставки неправильного параметра (ошибки) в процессе генерации решения
- Обозначается как retry_rate ∈ [0, 1)
- При retry_rate = 0.5 примерно половина шагов решения будет содержать ошибки

### Сожаление модели (Model regret)
- Явление, при котором внутренние состояния модели указывают на то, что она совершила ошибку
- Может быть обнаружено с помощью zondирования (probing) последнего скрытого слоя
- Выражается в "раскаянии" или "осознании" ошибки в модели

### Повтор при сожалении (Retry upon regret)
- Метод генерации, при котором модель проверяет, совершила ли она ошибку, и при обнаружении ошибки перегенерирует решение
- Требует внешнего детектора ошибок

### Фейковые ошибки (Fake mistakes)
- Синтетически созданные ошибки для обучения, которые не обязательно логически неправильны
- retry_weak: случайный параметр из будущего решения вставляется как ошибка
- retry_miss: случайный параметр из проблемы, который еще не был вычислен

## Пример данных
### Пример решения с retry_rate = 0.5:
```
(Solution) Define Dance Studio's School Daypack as p; so p = 17. 
Define Film Studio's School Daypack as [BACK]. 
Define Film Studio's Messenger Backpack as W; so W = 13. 
Define Central High's Classroom as [BACK]. 
Define Central High's Backpack as [BACK]. 
Define Central High's Film Studio as B; so B = p + W = 17 + 13 = 7. 
...
```

### Сравнение подходов:
- **Оригинал (error-free)**: Только правильные шаги решения без ошибок
- **Retry upon regret**: Модель генерирует, проверяет ошибки, при необходимости перегенерирует
- **Retry data**: Модель обучается на данных с ошибками и коррекциями, автоматически корректирует во время генерации

## Примеры применения
- Повышение точности рассуждений в языковых моделях за счет включения данных об ошибках
- Улучшение математических рассуждений без требования многоступенчатой генерации или проверки
- Повышение эффективности инференса за счет коррекции ошибок во время генерации, а не после
- Разработка более устойчивых языковых моделей с улучшенными способностями к рассуждению
