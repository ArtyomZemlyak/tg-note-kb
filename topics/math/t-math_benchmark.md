# T-Math бенчмарк

## Описание

T-Math - это специализированный бенчмарк для оценки математических рассуждений на русском языке, состоящий из 331 задачи из Всероссийских и Московских олимпиад по математике за период 1998-2025 годов. Бенчмарк был автоматически извлечен и проверен вручную, что делает его надежным инструментом для оценки математических способностей русскоязычных языковых моделей.

## Структура и содержание

### Источники задач
- Всероссийские математические олимпиады (школьный, муниципальный, региональный и заключительный этапы)
- Московские математические олимпиады
- Период охвата: 1998-2025 годы
- Общее количество задач: 331

### Уровень сложности
- Задачи охватывают широкий диапазон сложности
- Соответствуют уровню олимпиад для старших классов
- Включают задачи из различных областей математики: алгебра, геометрия, теория чисел, комбинаторика

### Типы задач
- Доказательства теорем
- Решение уравнений и неравенств
- Геометрические задачи
- Комбинаторные задачи
- Задачи на логические рассуждения

## Создание и проверка

### Автоматическое извлечение
- Использование автоматических методов для сбора задач из различных источников
- Структурирование задач в единый формат

### Ручная проверка
- Проверка корректности условий задач
- Проверка существования решений
- Обеспечение качества и точности формулировок

## Применение

### Оценка моделей
- Оценка математических рассуждений в русскоязычных LLM
- Сравнение различных подходов к решению математических задач
- Измерение прогресса в области автоматического решения олимпиадных задач

### Использование в T-pro 2.0
- Включён в набор бенчмарков для оценки производительности
- Используется для проверки рассуждающих способностей модели
- Входит в интерактивную демонстрацию для тестирования

## Результаты оценки

### Производительность T-pro 2.0
- В режиме рассуждений: ускорение 2.25× по сравнению с базовой моделью
- Демонстрирует высокую эффективность EAGLE-декодирования для математических задач
- Средняя длина принятой последовательности: 4.01

## Значение

T-Math представляет собой важный ресурс для:
- Оценки способностей русскоязычных моделей к математическим рассуждениям
- Исследования продвинутых математических рассуждений в LLM
- Создания специализированных математических ассистентов
- Стандартизации оценки математических способностей в русскоязычных моделях
