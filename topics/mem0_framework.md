# Mem0: Фреймворк для AI-агентов с масштабируемой долгосрочной памятью

## Краткое описание

Mem0 - это масштабируемая архитектура, ориентированная на память, которая решает проблему фиксированных контекстных окон LLM, динамически извлекая, консолидируя и извлекая важную информацию из текущих разговоров. Mem0 включает в себя улучшенный вариант, который использует графовые представления памяти для захвата сложных структур отношений между элементами разговора.

## Архитектура

### Mem0 (базовая версия)

Mem0 реализует инкрементную обработку с двумя фазами:

1. **Фаза извлечения**:
   - Обрабатывает новую пару сообщений (mt-1, mt), где mt - текущее сообщение, а mt-1 - предыдущее
   - Использует два источника контекста: 
     - Обобщение разговора S из базы данных
     - Последовательность недавних сообщений {mt-m, mt-m+1, ..., mt-2}
   - Создает комплексный промпт P = (S, {mt-m, ..., mt-2}, mt-1, mt) для LLM
   - Извлекает набор ярких воспоминаний Ω = {ω1, ω2, ..., ωn}

2. **Фаза обновления**:
   - Оценивает каждый кандидат в воспоминания по отношению к существующим воспоминаниям для поддержания согласованности
   - Определяет соответствующую операцию управления памятью: ADD, UPDATE, DELETE или NOOP
   - Вместо использования отдельного классификатора, использует возможности логического вывода LLM для прямого выбора соответствующей операции

### Mem0g (графовая версия)

Mem0g реализует подход к памяти на основе графов, эффективно захватывающий, хранящий и извлекающий контекстную информацию из естественных языковых взаимодействий.

1. **Представление памяти**:
   - Память представлена как направленный помеченный граф G = (V, E, L), где:
     - V: узлы представляют сущности (например, Alice, San_Francisco)
     - E: ребра представляют отношения между сущностями (например, lives_in)
     - L: метки присваивают семантические типы узлам (например, Alice - Person, San_Francisco - City)

2. **Экстракция**:
   - Двухэтапный конвейер, использующий LLM для преобразования неструктурированного текста в структурированные представления графов
   - Модуль извлечения сущностей идентифицирует набор сущностей вместе с соответствующими типами
   - Компонент генерации отношений выводит осмысленные связи между сущностями

3. **Обновление**:
   - Использует эвристический конфликт-детектирующий механизм для идентификации потенциально конфликтующих существующих отношений при поступлении новой информации

4. **Извлечение**:
   - Двухуровневая стратегия: сущностно-ориентированная и семантический подбор тройного типа

## Преимущества

- Достигает 26% относительного улучшения в метрике LLM-as-a-Judge по сравнению с OpenAI
- Mem0 с графической памятью достигает примерно на 2% более высокого общего балла по сравнению с базовой конфигурацией Mem0
- Значительно снижает вычислительную нагрузку по сравнению с подходом полного контекста
- Достигает на 91% более низкой задержки p95 и экономит более 90% стоимости токенов

## Оценка производительности

Mem0 был протестирован на бенчмарке LOCOMO, где он превзошел все существующие системы памяти в четырех категориях вопросов:
- Одношаговые (single-hop)
- Временные (temporal)
- Многошаговые (multi-hop)
- Открытой области (open-domain)
