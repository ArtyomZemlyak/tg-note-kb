# ML/DS/AI Technology Navigation Map

## By Framework

### Deep Learning Frameworks
- **[PyTorch](index.md)** - Dynamic computation graph, Python-first approach, research-friendly
- **[TensorFlow](index.md)** - Production-focused, static computation graph, enterprise-ready
- **[JAX](index.md)** - NumPy-compatible research framework with transformations, high-performance computing

### Classical ML Frameworks
- **[scikit-learn](index.md)** - Classical ML algorithms and preprocessing, accessible for beginners
- **[Hugging Face](index.md)** - Pretrained models and transformers, NLP-focused ecosystems

### Application-Specific Frameworks
- **[LangChain](index.md)** - LLM application development, orchestration of language models
- **[Llama Index](index.md)** - Data framework for LLM applications, RAG system development

## By Algorithm Type

### Classical ML Algorithms
- **[Supervised Learning](index.md)** - Learning from labeled examples, classification and regression
- **[Unsupervised Learning](index.md)** - Learning from unlabeled data, clustering and dimensionality reduction
- **[Reinforcement Learning](index.md)** - Learning through environment interaction, decision making

### Neural Network Architectures
- **[Feedforward Networks](index.md)** - Basic neural networks, function approximation
- **[Convolutional Networks](index.md)** - Image processing, spatial feature extraction
- **[Recurrent Networks](index.md)** - Sequence processing, temporal dependencies
- **[Transformer Architectures](index.md)** - Attention-based models, state-of-the-art in many domains
