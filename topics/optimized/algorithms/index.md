# Algorithms

This section contains information about various machine learning and data science algorithms organized by approach and application area.

## Categories

### [Classical ML Algorithms](index.md)
Traditional machine learning approaches that form the foundation of many systems:
- Supervised learning algorithms (linear regression, SVM, decision trees, etc.)
- Unsupervised learning algorithms (k-means, hierarchical clustering, etc.)
- Ensemble methods (random forests, gradient boosting, etc.)
- Dimensionality reduction techniques (PCA, LDA, etc.)

### [Neural Networks](index.md)
Deep learning architectures and approaches:
- Feedforward networks
- Convolutional neural networks (CNNs)
- Recurrent neural networks (RNNs)
- Transformer architectures
- Generative models (GANs, VAEs)

### [Specialized Algorithms](index.md)
Cutting-edge and domain-specific algorithms:
- Graph neural networks
- Reinforcement learning algorithms
- Diffusion models
- Meta-learning algorithms
- Causal inference methods

## Purpose

Understanding algorithms is fundamental to applying ML/DS/AI techniques effectively. This section covers everything from classical approaches to cutting-edge deep learning architectures, with emphasis on when to use each approach and their practical considerations.
