# Frameworks and Libraries

This section contains information about specific machine learning and data science frameworks and libraries organized by technology focus and use case.

## Categories

### [PyTorch](index.md)
Deep learning framework known for flexibility and dynamic computation graphs. Key topics include:
- Tensor operations and neural network modules
- Dynamic graph construction
- Distributed training
- Model optimization and deployment

### [TensorFlow](index.md)
Google's end-to-end open-source platform for machine learning. Key topics include:
- Static computation graphs
- TensorFlow Extended (TFX) for production pipelines
- TensorFlow Serving for model deployment
- TensorFlow Lite for mobile/edge deployment

### [scikit-learn](index.md)
Classical machine learning library for Python. Key topics include:
- Traditional ML algorithms (SVM, random forests, etc.)
- Model selection and evaluation
- Preprocessing and feature engineering
- Pipeline construction

### [JAX](index.md)
NumPy-compatible library for high-performance numerical computing and ML research. Key topics include:
- Automatic differentiation
- Vectorization and JIT compilation
- Research-focused deep learning
- Scientific computing applications

### [Hugging Face](index.md)
Ecosystem for transformer models and NLP. Key topics include:
- Pre-trained model hub
- Tokenizers and datasets
- Transformers library
- MLOps for NLP

### [LangChain](index.md)
Framework for developing applications with LLMs. Key topics include:
- Prompt engineering
- Chain composition
- Memory management
- Tool integration

### [LlamaIndex](index.md)
Data framework for LLM applications. Key topics include:
- Data connectors and indexing
- Query engines
- Embedding strategies
- Retrieval-augmented generation (RAG)

## Purpose

This section provides detailed information about different frameworks and libraries used in machine learning, data science, and AI applications. Each subdirectory contains specific information about installation, usage, best practices, and practical examples for the corresponding framework or library.
