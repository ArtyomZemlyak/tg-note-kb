# Robo4D-200k: Крупномасштабный 4D робототехнический датасет

## Общее описание

**Robo4D-200k** — это крупнейший на сегодняшний день 4D робототехнический датасет, созданный для обучения моделей с пространственно-временной и физической осознанностью. Датасет содержит **201,426 эпизодов** взаимодействий робота с миром с высококачественными 4D аннотациями [[kinema4d_arxiv_2603_16669|Kinema4D arXiv:2603.16669]].

Датасет был создан специально для обучения модели Kinema4D и предоставляет беспрецедентный объём и разнообразие взаимодействий для обучения foundation моделей в области embodied simulation [[kinema4d.md|Kinema4D]].

## Характеристики датасета

### Объём и формат

- **201,426 эпизодов** взаимодействий робот-мир
- **49 кадров** на эпизод (uniform temporal downsampling для длинных демонстраций)
- **Полные spatiotemporal взаимодействия:** Каждый эпизод захватывает полный цикл взаимодействия (например, полный pick-and-place цикл)
- **4D аннотации:** Pixel-aligned pointmap последовательности с (x, y, z) координатами в camera space

### Источники данных

#### Реальные данные (Real-world datasets):
- **DROID** — Крупномасштабный робототехнический датасет
- **Bridge** — Датасет робототехнических манипуляций
- **RT-1** — Robot Transformer датасет от Google

#### Синтетические данные:
- **LIBERO** — Платформа для генерации синтетических робототехнических демонстраций, включая успешные выполнения и критические failure modes

## Процесс создания

### 1. Сбор данных

Агрегация 2D RGB видео потоков из ведущих репозиториев робототехнических демонстраций:
- DROID, Bridge, RT-1 для реальных данных
- LIBERO для синтетических данных с разнообразными сценариями

### 2. 4D аннотирование

**Ключевая проблема:** Поднятие сырых 2D RGB видео из реальных датасетов в 4D метрическое пространство, требуемое для joint generative моделирования.

**Протестированные методы реконструкции:**
- MonST3R
- MegaSaM
- VGGT/VGGT4D
- ViPE
- **ST-V2** — Выбран как наиболее робастный и темпорально согласованный для робототехнических манипуляций с быстрым движением

**Решение:**
- **Для реальных данных:** ST-V2 для реконструкции высококачественных pixel-aligned 4D траекторий
- **Для синтетических данных:** Прямое использование native noise-free depth параметров для абсолютной ground-truth точности

### 3. Курация данных

**Процесс обеспечения качества:**
1. **Ручная верификация:** Отбраковка низкокачественных записей и артефактов реконструкции
2. **Temporal downsampling:** Uniform downsampling до 49 кадров для обеспечения консистентной частоты движения
3. **Контроль полноты:** Каждый эпизод должен захватывать полное/непрерывное spatiotemporal взаимодействие

## Примеры данных

Датасет включает разнообразные сценарии:
- **Pick-and-place** мелких объектов
- **Tool-use** для работы с crowded tiny objects
- **Long-horizon манипуляции** с разнообразными объектами
- **Различные spatial constraints** и физические взаимодействия

Визуализация 4D point clouds с различных camera frustums демонстрирует пространственную точность псевдо-аннотаций [[kinema4d_arxiv_2603_16669|Kinema4D arXiv:2603.16669]].

## Применения

Robo4D-200k предназначен для:

- **Обучение 4D world моделей:** Kinema4D и аналогичные архитектуры
- **Embodied simulation:** Симуляция взаимодействий робот-мир
- **Физическое рассуждение:** Long-term dependencies для robust physical reasoning
- **Zero-shot transfer:** Обобщение на новые сцены без дообучения
- **Foundation модели:** Масштабное предобучение с spatiotemporal awareness

## Сравнение с другими датасетами

| Датасет | Объём | 4D аннотации | Реальные/Синтетические |
|---------|-------|--------------|------------------------|
| **Robo4D-200k** | **201,426** | **Да (pointmap)** | **Оба** |
| DROID | ~50k | Нет | Реальные |
| Bridge | ~100k | Нет | Реальные |
| RT-1 | ~100k | Нет | Реальные |
| LIBERO | ~10k | Частично | Синтетические |

Robo4D-200k является **крупнейшим 4D робототехническим датасетом** на момент создания, предоставляя беспрецедентный объём и разнообразие для обучения моделей с физической и пространственно-временной осознанностью [[kinema4d_arxiv_2603_16669|Kinema4D arXiv:2603.16669]].
