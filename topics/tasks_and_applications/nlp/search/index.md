# Поиск (Search)

## Обзор

В этой категории рассматриваются различные аспекты поисковых систем, включая алгоритмы поиска, оценку качества, ранжирование и методы улучшения релевантности результатов.

## Подкатегории

- [[evaluation/]] - Методы оценки качества поиска
- [[retrieval/]] - Алгоритмы извлечения и поиска
- [[ranking/]] - Методы ранжирования результатов поиска
- [[search_algorithms/]] - Алгоритмы поиска и оптимизации
