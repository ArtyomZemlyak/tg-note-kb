# Подборка статей 2025: Attention-based Ranking и Non-Two-Tower Retrieval

## Обзор

Эта подборка представляет собой анализ ключевых направлений исследований в области рекомендательных систем 2025 года, сфокусированных на двух важных трендах: 
1. Attention-based ranking - улучшение процесса ранжирования с помощью внимательных механизмов 
2. Non-Two-Tower retrieval - отказ от традиционной двухбашенной архитектуры в пользу более гибких подходов

## Основные тренды 2025 года

### 1. Масштабирование длинных последовательностей

Одним из ключевых направлений стало моделирование очень длинных последовательностей поведения пользователей:

- **LONGER** - подход к масштабированию моделирования длинных последовательностей в промышленных рекомендательных системах
- **TransAct V2** - моделирование долгосрочного поведения пользователей в системах Pinterest
- **Make It Long, Keep It Fast** - подход к моделированию последовательностей длиной до 10k элементов на масштабе миллиардов на Douyin

### 2. Генеративные подходы к рекомендациям

Множество работ сфокусированы на генеративных методах:

- **Twin-Flow GRN** - двойной поток генеративных сетей ранжирования
- **GReF** - единый генеративный фреймворк для эффективного реранжирования
- **MTGR** - промышленный генеративный рекомендательный фреймворк от Meituan
- **Action is All You Need** - двойной поток генеративной сети ранжирования для рекомендаций

### 3. Переход от масштабирования к структурированной экспрессивности

Новый подход к эффективности:

- **From Scaling to Structured Expressivity** - переосмысление трансформеров для предсказания CTR
- **InterFormer** - эффективное гетерогенное взаимодействие в задаче предсказания CTR
- **Meta Lattice** - перепроектирование пространства моделей для экономически эффективных рекламных рекомендаций

### 4. Отказ от двухбашенной архитектуры

Тренд в извлечении:

- **Autoregressive Generative Retrieval** - автогрессивный подход к генеративному извлечению
- **GRank** - фреймворк Generate-Rank для целевого-ориентированного извлечения
- **Sparse Meets Dense** - объединенные генеративные рекомендации с каскадными представлениями
- **MISS** - мульти-модальное дерево индексации и поиска

### 5. Улучшенное моделирование интересов

Продвинутое моделирование пользовательских интересов:

- **DualGR** - моделирование долгосрочных и краткосрочных интересов
- **Pyramid Mixer** - многомерное много-периодное моделирование интересов
- **Adaptive Domain Scaling** - адаптивное масштабирование для персонализованного моделирования
- **MPFormer** - адаптивный фреймворк для много-задачного персонализованного извлечения

## Архитектурные инновации

### Трансформерные архитектуры
- **OneTrans** - единая архитектура трансформера для взаимодействия признаков и моделирования последовательностей
- **InterFormer** - эффективное гетерогенное взаимодействие с трансформерной архитектурой
- **Climber** - эффективные законы масштабирования для больших рекомендательных моделей

### Оптимизация и масштабирование
- **MARM** - аугментация памяти для разблокировки законов масштабирования кэша рекомендаций
- **RankMixer** - масштабирование ранжирующих моделей в промышленных рекомендательных системах
- **SilverTorch** - унифицированная модель-ориентированная система для демократизации рекомендаций на GPU

### Эффективность и вычислительная оптимизация
- **Residual Quantization** - методы TARQ для оснащения пред-ранжирования целевым вниманием
- **GPU-Powered Feature Interaction** - эффективное извлечение рекламы с GPU-ускорением
- **Hierarchical Structured Neural Networks** - масштабирование извлечения для больших рекомендательных систем

## Промышленные применения

### Практики в крупных компаниях
- **Tencent** - практики моделирования длинных поведенческих последовательностей в рекламе
- **Pinterest** - автогрессивное генеративное извлечение для промышленных рекомендаций
- **Meituan** - MTGR как промышленный масштабный генеративный рекомендательный фреймворк
- **Alibaba** - переосмысление трансформеров для CTR-предсказания с акцентом на структурированную экспрессивность

### Инженерные решения
- **Bidding-Aware Retrieval** - учет ценообразования в много-стадийных рекомендательных системах
- **MISS** - использование мульти-модальной информации для улучшения рекомендаций
- **Pyramid Mixer** - эффективное моделирование интересов на разных временных шкалах

## Будущие направления

- Переход от жестких архитектур к более адаптивным системам

- Увеличение генеративных возможностей в рекомендательных системах

### Эффективность и масштабируемость
- Разработка новых законов масштабирования, основанных на структурированной экспрессивности
- Улучшенные методы оптимизации для промышленного развертывания
- Баланс между точностью и вычислительной эффективностью

### Персонализация и адаптация
- Более точное моделирование индивидуальных пользовательских интересов
