# Подборка статей 2025 (часть 3): Non-Two-Tower Retrieval

## Описание

Эта подборка представляет собой обзор ключевых исследований 2025 года в области non-two-tower retrieval в рекомендательных системах. Включает в себя современные подходы к генеративным и автогрессивным методам извлечения, а также архитектуры, которые отказываются от традиционной двухбашенной структуры для более эффективного и точного извлечения релевантных айтемов.

## Ключевые направления

### 1. Автогрессивное генеративное извлечение (Pinterest)

Autoregressive Generative Retrieval for Industrial-Scale Recommendations at Pinterest - автогрессивный подход к генеративному извлечению:

- Использование автогрессивной модели для генерации релевантных айтемов
- Устранение необходимости в традиционной двухбашенной архитектуре
- Промышленная реализация для масштабных рекомендаций
- Генерация последовательностей айтемов на основе пользовательского контекста

### 2. Адаптивный фреймворк для много-задачного персонализованного извлечения (MPFormer)

MPFormer - адаптивный фреймворк для промышленного много-задачного персонализованного последовательного извлечения:

- Динамическая много-задачная трансформерная архитектура
- Систематическое решение проблем персонализованного извлечения
- Адаптация к различным типам задач извлечения
- Объединение последовательного моделирования и персонализации

### 3. Индексация и поиск на основе мульти-модального дерева (MISS)

MISS (Multi-Modal Tree Indexing and Searching) - мульти-модальное дерево индексации и поиска с долгосрочным последовательным поведением:

- Использование древовидной структуры для индексации айтемов
- Интеграция мульти-модальной информации в процесс извлечения
- Завершение долгосрочного последовательного поведения для рекомендательного поиска
- Извлечение айтемов на основе деревьев вместо традиционных векторных представлений

### 4. Объединение разреженных и плотных представлений (Sparse Meets Dense)

Sparse Meets Dense - объединенные генеративные рекомендации с каскадными разреженно-плотными представлениями:

- Гибридный подход, сочетающий разреженные и плотные методы извлечения
- Каскадное представление айтемов как (Sparse ID, Dense Vector)
- Устранение проблемы значительной потери информации в предыдущих генеративных моделях
- Комбинирование преимуществ обеих парадигм извлечения

### 5. Bidding-Aware Retrieval

Bidding-Aware Retrieval для много-стадийной согласованности в онлайн-рекламе:

- Интеграция информации о ценообразовании в процесс извлечения
- Повышение согласованности между различными этапами рекомендательной системы
- Улучшение согласованности между стадиями извлечения и ценообразования
- Учет экономических аспектов в процессе извлечения

### 6. Target-ориентированное извлечение (Equip Pre-ranking with Target Attention)

TARQ (Target Attention by Residual Quantization) - фреймворк для оснащения пред-ранжирования целевым вниманием:

- Интеграция целевого внимания в пред-ранжирование с помощью остаточной квантизации
- Мост между эффективностью пред-ранжирования и точностью точного ранжирования
- Архитектура, приближенная к целевому вниманию, для пред-ранжирования
- Снижение задержки при сохранении качества извлечения

### 7. Генеративное извлечение с фреймворком Generate-Rank (GRank)

GRank - целевое-ориентированное и упрощенное промышленное извлечение с фреймворком Generate-Rank:

- Новая парадигма извлечения без структурированных индексов
- Объединение целевого обучения с пользовательским извлечением
- Генеративно-ранжировочный фреймворк для более точного извлечения
- Улучшенная согласованность между генерацией и ранжированием

### 8. Унифицированная модель-ориентированная система (SilverTorch)

SilverTorch - унифицированная модель-ориентированная система для демократизации рекомендаций на GPU:

- Объединение всех компонентов сервиса рекомендаций в единую модель PyTorch
- Оптимизация для эффективного развертывания на GPU
- Упрощение архитектуры извлечения и развертывания
- Повышение доступности и эффективности масштабных рекомендательных систем

### 9. Генеративное извлечение с моделированием долгосрочных и краткосрочных интересов (DualGR)

DualGR - генеративное извлечение с моделированием долгосрочных и краткосрочных интересов:

- Явное моделирование интересов разного времени горизонта
- Двух-ветвевой маршрутизатор (DBR) для долгосрочных/краткосрочных интересов
- Управляемое контекстом извлечение для более точного понимания предпочтений
- Селективная активация интересов в зависимости от контекста

### 10. Эффективное извлечение на основе эмбеддингов (GPU-Powered Feature Interaction)

An Efficient Embedding Based Ad Retrieval with GPU-Powered Feature Interaction - эффективное извлечение рекламы:

- Использование GPU для ускорения взаимодействия признаков в процессе извлечения
- Оптимизация традиционной двухбашенной архитектуры через GPU-ускорение
- Повышение эффективности извлечения рекламных объявлений
- Инжиниринг признаков на GPU для более точного извлечения

### 11. Иерархическая структурированная нейронная сеть

Hierarchical Structured Neural Network - эффективное масштабирование извлечения для больших рекомендательных систем:

- Иерархическая архитектура для обучения сложным пользовательским и айтемным представлениям
- Структурированный подход к масштабированию нейронных сетей для извлечения
- Модульный дизайн для эффективного извлечения
- Улучшенная масштабируемость для больших рекомендательных систем

## Сравнение с Two-Tower архитектурой

### Преимущества Non-Two-Tower подходов:

- **Более сложное моделирование взаимодействий**: возможность моделировать сложные отношения между пользователем и айтемом на лету
- **Генеративные возможности**: способность генерировать айтемы или их свойства, а не просто извлекать предварительно закодированные
- **Контекст-зависимость**: лучшая адаптация к конкретному пользовательскому контексту
- **Динамические представления**: возможность формирования представлений на основе текущего контекста

### Вызовы Non-Two-Tower подходов:

- **Вычислительная сложность**: часто требуют больше вычислительных ресурсов по сравнению с пред-вычисленными эмбеддингами
- **Инференс-время**: более высокие задержки по сравнению с быстрым скалярным произведением в two-tower системах
- **Масштабирование**: сложнее масштабировать до миллиардных каталогов по сравнению с индексированными системами

## Промышленные применения

### Pinterest
Использование автогрессивного генеративного извлечения для рекомендаций в ленте, где контекст и последовательность пользовательских взаимодействий имеют решающее значение.

### Meituan
Реализация MTGR (Meituan Generative Recommendation) для промышленных генеративных систем, которые отказываются от строгой двухбашенной структуры в пользу более гибких архитектур.

### Alibaba
Использование структурированной экспрессивности и подходов "From Scaling to Structured Expressivity" в масштабных коммерческих рекомендательных системах.

## Будущие направления

### Гибридные архитектуры
Комбинирование преимуществ both two-tower и non-two-tower подходов для достижения оптимального баланса между эффективностью и точностью.

### Адаптивные фреймворки
Разработка адаптивных систем, которые могут динамически выбирать между различными архитектурами извлечения в зависимости от контекста запроса.

### Энергоэффективность
Развитие более энергоэффективных non-two-tower архитектур для устойчивого масштабирования рекомендательных систем.
