# Самоконтролируемое обучение в Vision Transformers

## Определение

Самоконтролируемое обучение (self-supervised learning) - это подход к машинному обучению, при котором модель обучается на непомеченных данных, создавая искусственные задачи (pretext tasks), позволяющие ей изучать полезные представления без внешних меток.

## Принципы самоконтролируемого обучения

### Основная идея
- Модель учится решать задачи, которые можно сформулировать с использованием только входных данных
- Цель - изучить полезные представления, которые могут быть переданы в другие задачи
- Обучение проводится без человеческих меток, что позволяет использовать огромные объемы непомеченных данных

### Классические задачи
- Прогнозирование заблокированных областей (masked image modeling)
- Прогнозирование поворота изображения
- Сравнение различных увеличенных видов одного и того же изображения
- Контрастное обучение между положительными и отрицательными образцами

## Применение в Vision Transformers

### Vision Transformers с самоконтролируемым обучением
- Masked Autoencoders (MAE)
- DINO и DINOv2
- BYOL, SimCLR, MoCo
- iBOT (image-based self-supervised learning)

### Преимущества самоконтролируемого обучения в ViT
- **Лучшая обработка целостной формы**: как показывает исследование BFD (би-ортогональной факторизации), модели с самоконтролируемым обучением, такие как DINOv2, лучше сохраняют пространственную топологию на протяжении всех слоев
- **Более богатые представления**: самоконтролируемые модели выделяют больше энергии на контент-позиция сопряжение и работают через более богатый спектр режимов
- **Лучшее обобщение**: такие модели более устойчивы к искажениям и лучше обобщаются на разных задачах

### Механизмы самоконтролируемого обучения

#### DINO (контрастный подход)
- Использует два вида одного и того же изображения (с разными аугментациями)
- Обучает онлайн-модель предсказывать представления, полученные от целевой модели
- Целевая модель обновляется медленно (momentum update)

#### DINOv2 (улучшенный подход)
- Безусловно обучаемая модель (fully self-supervised)
- Лучше сохраняет геометрическую структуру
- Использует регистры для улучшения качества представлений

#### MAE (маскировочный подход)
- Маскирует случайные патчи входного изображения
- Энкодер обрабатывает только видимые патчи
- Декодер восстанавливает исходное изображение из скрытых состояний и маскировочной информации

## Различия с контролируемым обучением

| Аспект | Контролируемое обучение | Самоконтролируемое обучение |
|--------|-------------------------|----------------------------|
| Данные | Требуются помеченные данные | Используются непомеченные данные |
| Цель | Классификация, детекция и т.д. | Изучение полезных представлений |
| Пространственная структура | Может разрушаться в середине сети | Лучше сохраняется (например, DINOv2) |
| Объем данных | Ограничен доступностью меток | Миллиарды изображений доступно |
| Обработка формы | Склонна к текстурному смещению | Лучше сохраняет целостность формы |

## Влияние на архитектуру внимания

Как показывает исследование би-ортогональной факторизации (BFD):
- DINOv2 поддерживает значительно более высокий "stable rank" по сравнению с ViT с контролируемым обучением
- Его внимание работает через более распределенное множество каналов коммуникации
- Показывает меньшее выравнивание мод, особенно на промежуточных слоях
- Содержит более плоский спектр сингулярных значений, поддерживая большее количество активных мод

## Приложения

- Предобучение на больших наборах данных без меток
- Передача знаний в downstream задачи (классификация, сегментация, детекция)
- Мультимодальное обучение (CLIP, ALIGN)
- Устойчивое обучение без необходимости в помеченных данных

## Перспективы развития

- Совмещение самоконтролируемого и контролируемого обучения
- Лучшие механизмы для сохранения пространственной информации
- Более эффективные задачи для предобучения
- Интеграция с другими парадигмами (foundation models, large multimodal models)
