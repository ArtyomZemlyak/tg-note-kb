# Основы Vision Transformers (ViT)

## Введение

Vision Transformers (ViT) - это архитектура нейронных сетей, применяемая в компьютерном зрении, которая адаптирует механизм внимания (attention), широко используемый в трансформерах для обработки естественного языка, для решения задач, связанных с изображениями.

## Архитектура

### Сегментация изображения на патчи
- Изображение делится на неперекрывающиеся патчи фиксированного размера (например, 16×16 пикселей)
- Каждый патч линейно проецируется в векторное представление (токен)
- Эти векторы рассматриваются как последовательность, как в языковых трансформерах

### Позиционные вложения
- Поскольку само внимание перестановочно инвариантно, добавляются позиционные вложения для сохранения пространственной информации
- Позиционные вложения могут быть обучаемыми или фиксированными (например, синусоидальные функции)

### Многоуровневое внимание
- Модель состоит из серии трансформерных блоков
- Каждый блок содержит:
  - Механизм многоуровнего внимания (Multi-Head Self-Attention)
  - Позиционно-зависимую полносвязную сеть (Feed-Forward Network)
  - Механизмы нормализации и остаточные соединения

## История и развитие

- Впервые предложены Dosovitskiy и др. в 2020 году в статье "An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale"
- Изначально требовали больших объемов данных для обучения, но затем были адаптированы для ограниченных наборов данных
- Значительно повлияли на развитие компьютерного зрения

## Обучение

### Контролируемое обучение
- Традиционное обучение на помеченных данных
- Использование кросс-энтропийной функции потерь
- Проблема: может недооценивать пространственную структуру

### Самоконтролируемое обучение
- Обучение без пометок, часто с использованием задач прогнозирования
- Примеры: DINO, DINOv2, MAE, SimCLR
- Такие модели показывают лучшую обработку целостной формы и структуры объектов
- Более устойчивы к искажениям и обобщаются лучше

## Приложения

- Классификация изображений
- Сегментация (семантическая и инстансная)
- Обнаружение объектов
- Генеративные модели
- Мультимодальные задачи (в сочетании с текстовыми трансформерами)

## Преимущества

- Возможность моделирования долгосрочных зависимостей в изображениях
- Параллелизуемость вычислений (в отличие от CNN с локальным рецептивным полем)
- Масштабируемость с увеличением объема данных и параметров
- Хорошая интерпретируемость через визуализацию внимания

## Ограничения и вызовы

- Требование большого объема данных для эффективного обучения
- Высокая вычислительная стоимость для больших изображений
- Ограниченная индуктивная предвзятость по сравнению с CNN
- Потенциальные проблемы с пространственной локализацией

## Современные разработки

- Улучшение эффективности через спарсное внимание
- Интеграция с CNN для гибридных архитектур
- Применение в мультимодальных моделях (например, CLIP)
- Развитие методов анализа внутренней работы (например, BFD - би-ортогональная факторизация)
